# 寒衣节送寒衣

![寒衣节（送寒衣）/ The Cold-Clothes Festival](../../../assets/images/19-cold-clothes-festival.png)


## 一、释义

寒衣节，农历十月初一，又称「十月朝」「送寒衣」「祭祖节」。是日以焚化纸制寒衣、纸钱的方式为祖先「送寒衣」，以备冬季御寒。

它是汉族的**三大鬼节之一**（另二为清明、中元），也是岁时祭祖体系中的最后一个重要节点。

## 二、历史源流

- 起源与「十月一」的时令意义相关：农历十月进入冬季，古人「授衣」（发放冬衣），同时推己及祖先，为其「送衣」。
- 宋《东京梦华录》记「十月一日，宰臣以下受棉衣，……士庶以新衣相遗」「朔日，出城飨坟，如中元仪」，说明宋代十月初一已有上坟之俗。
- 明清方志记载「十月初一，剪纸为衣，焚于墓前」「以五色纸剪为衣冠，焚化于门外」，是「送寒衣」的通行形态。
- 关于「寒衣节」与孟姜女传说的关联：民间有「孟姜女千里送寒衣」的故事，部分地区将十月初一与孟姜女送寒衣相联系，但这是后起的附会，非节俗起源。
- 当代：北方部分地区仍行「烧寒衣」，城市多以文明祭扫替代。

## 三、仪节流程

1. **备物**：备五色纸（剪纸衣）、纸钱、香烛、供品。
2. **剪纸衣**：以彩纸剪成衣裤形（或购买现成的纸衣），有的写上祖先名讳。
3. **家祭或墓祭**：
   - **家祭**：在祖先牌位前设供、上香、跪拜；
   - **墓祭**：上坟设供、跪拜（部分地区）。
4. **焚化寒衣**：在门外（或墓前）焚化纸衣与纸钱，边烧边念：「给×××送寒衣，天冷了，多穿些。」
5. **撒灰圈**：部分地区以灰撒圈，圈内焚化（防「野鬼抢衣」）。
6. **谢祖**：跪拜致谢，收拾供品。
7. **部分地区的配套习俗**：十月初一有「吃饺子」「吃糍粑」之俗。

## 四、地域与民族变体

- **华北**：称「十月一」「送寒衣」，讲究剪纸衣、墓前焚化。
- **江南**：称「十月朝」，多在家门前焚化，供品备「团子」。
- **闽台**：部分地方不重十月初一，而以「冬至」为重要祭祖日（见「冬至与除夕祭祖」条）。
- **广东**：部分地区以十月初一为祭祖日，讲究「烧衣」。
- **少数民族**：部分民族有冬季祭祖的习俗，如彝族的「十月年」（彝历年）、羌族的「羌年」（十月初一）、哈尼族的「十月年」。**这些是本民族的年节，其时间与汉族寒衣节重合但含义完全不同**，不可混称。

## 五、器物与文书

- **五色纸、纸衣（寒衣）**。
- **纸钱、香烛、供品**。
- **「包袱」**：部分地区把寒衣装入写有祖先名讳的纸包，一并焚化。
- **族谱、墓图**：查找祭祀对象。
