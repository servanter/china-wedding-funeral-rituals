# 冬至与除夕祭祖

## 一、释义

- **冬至祭祖**：冬至为「亚岁」（次于年节），古有「冬至大如年」之说。冬至日祭祖，是岁末祭祖的第一节点。周代曾以冬至为岁首，故冬至祭天、祭祖之礼极古。
- **除夕祭祖**：农历年末（除夕）祭祖，是岁时祭祖的最高节点。是日「请祖先回家过年」，供奉至正月初三或元宵后「送祖」。

二者同为**家祭**（在祠堂或家中牌位前举行），与清明、中元、寒衣的**墓祭**在空间与形式上不同（参见「墓祭与祠祭比较」条）。

## 二、历史源流

- 《周礼·春官》记「以冬日至，致天神人鬼」——冬至祭祖的礼制渊源可上溯至周代。
- 汉以后「冬至」为重要节日，官民皆祭祖贺节。《后汉书·礼仪志》载冬至之礼。
- 唐宋以降，除夕祭祖之俗定型：设供、上香、跪拜，「请祖先过年」；又于正月择日「送祖」。
- 《朱子家礼》定四时祭（「四时之祭」）与「冬至祭始祖」「立春祭先祖」等，是宋代家礼的祭祖框架。
- 明清方志记「冬至设馔祭祖」「除夕设祖先位，供酒馔」「元日谒祖先」，为通行之制。
- 当代：除夕祭祖仍是汉族地区最普遍的祭祖活动；冬至在南方（尤其闽台、广东、江浙）尤为重视，有「冬大过年」之说。

## 三、仪节流程

### 冬至祭祖

1. **清扫设位**：清扫祖先牌位（或祠堂），设香案、供桌。
2. **备供**：备酒、菜、饭、果、糕点，有的备「三牲」（南方）、汤圆（南方）、饺子（北方）。
3. **上香**：家长（或长子）上香，向祖先禀告。
4. **跪拜**：全家依辈分长幼依次跪拜（或三鞠躬）。
5. **奠酒**：酹酒于地。
6. **焚纸**：焚化纸钱。
7. **聚餐**：全家聚餐（「冬至宴」），有的地方「吃冬至团」。

### 除夕祭祖

1. **请祖**：除夕午后，家长（或长子）到门外（或路口）焚香烧纸，呼请祖先回家过年（「请年」「接祖」）。
2. **设位设供**：在堂屋设祖先牌位（或遗像），摆供桌，备年夜饭的菜肴、酒、饭、筷子。
3. **上香跪拜**：全家依次跪拜。
4. **守香**：除夕夜香火不断；供奉至初二或初三。
5. **送祖**：择日（正月初三、初五或元宵后）焚化纸钱、纸衣，送祖先归位（「送年」「送祖」）。
6. **撤供**：撤去供品，恢复正常。

## 四、地域与民族变体

- **北方**：除夕祭祖隆重，「请年」「送年」之俗普遍；冬至吃饺子，祭祖从简。
- **江南**：冬至「大如年」，祭祖隆重，供「冬至团」；除夕亦祭祖。
- **闽台**：「冬至」祭祖极为重要（「冬节」），有「冬节不回无祖」之谚——冬至须回家祭祖，否则视为无祖；除夕「辞年」「围炉」前必先祭祖。
- **广东**：冬至「做冬」祭祖，「冬大过年」；除夕祭祖。
- **少数民族**：部分民族有自己的年节祭祖（如彝族的「彝历年」、苗族的「苗年」、侗族的「侗年」、水族的「端节」），其时间与内容各依本族历法，与汉族冬至、除夕祭祖不是同一种制度。

## 五、器物与文书

- **祖先牌位、神主、祠堂、遗像**。
- **香案、香炉、烛台、供桌、供器**。
- **供品**：酒、菜、饭、果、饺子（北）、汤圆／冬至团（南）、三牲（南）。
- **纸钱、纸衣、包袱**。
- **祭祖祝文**：格式见「婚丧文书范本／祭祖祝文范本」条。
- **族谱**：祭祖时陈于案前（部分地区）。
