# 中元节祭祖

![中元节放水灯（河灯）/ Zhongyuan Festival river lanterns](../../../assets/images/12-zhongyuan-river-lanterns.png)


## 一、释义

中元节，农历七月十五，俗称「七月半」「鬼节」「盂兰盆节」。是日祭祖、超度亡魂，其习俗由三条源流融合而成：

1. **道教的中元**：道教以正月十五为上元（天官赐福）、七月十五为中元（地官赦罪）、十月十五为下元（水官解厄）。中元之地官赦罪正是超度亡魂的节日。
2. **佛教的盂兰盆会**：《盂兰盆经》载目连救母的故事，佛嘱于七月十五以百味饮食供养十方僧众，可救七世父母之厄。故七月十五为「盂兰盆节」。
3. **民间祭祖**：与寒食、清明、十月初一并列为汉族的年度墓祭节点（「三大鬼节」之一，另有上巳）。

## 二、历史源流

- 中元节的形成在南北朝至唐代之间，是佛道两教与民间祭祀合流的结果。
- 唐宋中元节极盛：民间祭祖、佛寺设盂兰盆会、道观设中元斋醮；夜间「放河灯」超度水中亡魂。
- 明清方志记载中元「家家备酒馔祭祖先，焚冥衣、纸钱」「设盂兰盆会，放河灯」。
- 民间有「七月十五鬼门开」之说，认为此日亡魂可归家；故又有「烧包」（焚化写有祖先姓名的纸包，内含纸钱）之俗。
- 当代中元节的宗教色彩减弱，祭祖、烧包、放河灯等习俗在部分地区仍有保留；同时各地推行「文明祭扫」，以鲜花、网络祭祀替代焚化。
- 涉及民间信仰，本库作民俗记录。

## 三、仪节流程

1. **备物**：备香烛、供品（酒、菜、饭、果）、纸钱、「包」（写有祖先姓名的纸包）。
2. **家祭**：在祖先牌位（或遗像）前设供、上香、跪拜。
3. **写包（烧包）**：在纸包上书写祖先名讳与「某某收」，装入纸钱。
4. **焚化**：在门外（或指定地点）焚化纸包、纸钱、冥衣。有的地方在灰堆周围画圈防止「野鬼抢钱」。
5. **放河灯**：以纸灯（或荷叶灯）置于河中，超度水中亡魂。多在河湖沿岸地区。
6. **盂兰盆会（寺庙）**：寺院设盂兰盆法会，诵经、施食。
7. **中元斋醮（道观）**：道观设中元醮仪，超度亡魂。
8. **墓祭（部分地区）**：中元亦上坟，尤以新丧者为重（「新坟不过社，老坟不过清明」的地方性规则，各地不同）。

## 四、地域与民族变体

- **华北**：称「七月十五」「鬼节」，讲究「烧包」；有的地方在河边放灯。
- **江南**：称「七月半」，讲究「放河灯」「盂兰盆会」，供品备「茄饼」。
- **闽台**：中元节是仅次于春节的大节，各村落轮办「普度」（中元普渡），宴请宾客，规模宏大；「抢孤」为特色民俗。
- **广东**：称「七月十四」，讲究「烧衣」（焚化纸衣）与「施孤」（施食孤魂）。
- **少数民族**：部分民族有本族的「鬼节」或祭祖节（如彝族的火把节期间祭祖、壮族的中元祭祖），但不能与汉族中元的佛道来源混同。

## 五、器物与文书

- **纸包（包袱）**：写有祖先名讳，是「烧包」的核心器物。
- **纸钱、冥衣、纸扎**。
- **河灯（荷叶灯）**。
- **香烛、供品**。
- **盂兰盆供**：寺庙所用。
- **醮仪疏文**：道观所用。
