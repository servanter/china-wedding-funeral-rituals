# 百日祭

## 一、释义

百日祭（「做百日」「百期」），是死者去世后第一百日设祭之礼。它上接「七七」（四十九日），下接「周年」（小祥），是葬后祭祀序列中的第三个重要节点。

其功能是**「过渡」**：七七表示「中有期」结束，周年则是服制的重要节点；百日居中，使祭祀的节奏得以延续，避免长期的空白。

## 二、历史源流

- 「百日」的礼制依据不显于先秦礼经。《礼记·王制》有「三月而葬」之制，百日大致相当于「三月」之期。
- 佛教的「中有」期有「七七」之说，也有「百目」之说。佛教典籍中「百目」指亡者于百日内受生，故有「百日」之祭。这与汉族的「三月而葬」传统结合，形成「百日祭」。
- 《朱子家礼》未专列「百日祭」，但宋代以后家礼类书籍已多将「百日」列入丧祭日程。
- 明清方志与笔记中「做百日」记载普遍，且多在灵位前（若未除灵）或坟前进行。
- 当代仍普遍行百日祭，形式简化为上坟或在家中设供。

## 三、仪节流程

1. **计日**：自去世之日起算，第一百日。
2. **备祭**：备供品（酒、菜、果、糕点，部分地区备牲）、香烛、纸钱。
3. **设祭**：
   - **若灵位未除**：在家中灵位前设祭、上香、跪拜；
   - **若灵位已除**：到墓前（或骨灰安放处）设祭。
4. **诵经（如设佛事）**：请僧人或家属自行诵经回向。
5. **哭祭**：亲属哭祭，念追思之语。
6. **焚纸**：焚化纸钱、纸扎。
7. **待周年**：此后至周年祭（小祥）之间无固定祭祀。
8. **部分地区**：在百日行「除灵」「脱孝」之礼（详见「除服与禫祭」条）。

## 四、地域与民族变体

- **华北**：称「做百日」，多在坟前祭祀，供品较简。
- **江南**：称「百日」，若灵位未除则在家设祭，讲究「百日之内不剃发」。
- **闽台**：称「做百日」，多请「司公」诵经；有的地方与「除孝」结合。
- **广东**：称「百日」，讲究「做百日、脱孝服」（部分地区）。
- **少数民族**：部分民族有自己的「百日」类的祭祀节点，如彝族的「百日祭」在某些支系中存在；但更多民族以「周年」或「三年祭」为主要节点，或依宗教历法安排祭祀（藏族依藏历、伊斯兰教依教历的节日）。**「百日」不是各族共有的祭祀节点。**

## 五、器物与文书

- **供品**：酒、菜、果、糕点。
- **香烛、纸钱**。
- **经书、法器**（如设佛事）。
- **祭文**：百日祭时所读。
- **丧事日程记录**：记录七期、百日、周年等节点。
