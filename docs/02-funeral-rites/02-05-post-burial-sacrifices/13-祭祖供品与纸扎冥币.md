# 祭祖供品与纸扎冥币

## 一、释义

本条汇总祭祖所用的两大类物品：

- **供品（食物类）**：可供、可食、祭毕可分食者。
- **纸扎与冥币（焚化类）**：不可食，专供焚化者。

二者的共同逻辑是「**事死如生**」：以生者的需要推想死者的需要。供品解决「吃」，纸扎与冥币解决「用」与「花」。

## 二、历史源流

- **供品的礼制依据**：《仪礼》《礼记》所记的祭祀供品以牲（牛、羊、豕）、粢盛（黍稷）、醴酒、笾豆之实为主，讲究等级（太牢、少牢）。
- **纸钱的起源**：唐代文献（《封氏闻见记》）记「纸钱」为魏晋以来之事；「打钱」（以纸凿孔成钱形）是唐宋常见形态。
- **纸扎（纸明器）的兴起**：宋代以后，以纸制器物代替实物随葬与供奉，成本低、易焚化，迅速普及（详见「冥币与纸钱」「纸扎」条）。
- **「烧包」的形成**：明清以后，将纸钱、纸衣装入写有祖先名讳的纸包，一并焚化，形成「烧包」「包袱」之制。
- **宗教融合**：佛教的施食、道教的金桥银桥、民间的「冥府银行」观念，共同丰富了纸扎的品类。
- 当代：各地推行文明祭扫，以鲜花、植树、网络祭扫替代焚化；纸扎业在城市收缩，农村仍存。

## 三、仪节流程

### 供品（按节令）

| 节令 | 常见供品 |
| --- | --- |
| 清明 | 青团（江南）、润饼（闽台）、水果、糕点 |
| 中元 | 三牲、饭菜、果、茄饼（江南）、米糕 |
| 寒衣节 | 饺子（北方）、糍粑、时令果品 |
| 冬至 | 饺子（北）、汤圆／冬至团（南） |
| 除夕 | 年夜饭菜肴、酒、饭、筷（请祖先「同吃年饭」） |
| 忌日 | 逝者生前所好之食 |
| 祠祭 | 三牲（猪、羊、鸡）、酒、果、糕点 |

### 纸扎与冥币（焚化类）

| 品类 | 内容 |
| --- | --- |
| 纸钱（打钱、冥币） | 以纸制钱形，或印「冥府银行」字样 |
| 银纸／金纸／库钱（闽台） | 银纸给亡者、金纸给神明、库钱还阴债 |
| 纸衣（寒衣） | 五色纸剪成衣裤 |
| 纸扎器用 | 纸屋（灵屋）、纸箱、纸家具、纸电器、纸车 |
| 纸人纸马 | 侍从与坐骑 |
| 包袱（纸包） | 上书祖先名讳，内装纸钱纸衣 |
| 金桥银桥 | 道教度亡所用 |

### 焚化次序

1. 家祭／墓祭设供、上香、跪拜。
2. 先焚「给神明的纸」（如金纸），后焚「给亡者的纸」（银纸）。
3. 焚「包袱」时书写名讳，念诵亡者称谓。
4. 焚化时用棍拨动使透气（俗谓「让亡者好收」）。
5. 焚化毕，撒酒、跪拜、收拾。

## 四、地域与民族变体

- **华北**：纸钱以「打钱」（圆孔纸片）为主，讲究「烧纸不烧空」。
- **江南**：纸扎品精细，供品讲究时令（青团、茄饼、团子）。
- **闽台**：纸钱分类最精细（金纸、银纸、库钱、溪钱等），用途严格区分；纸扎（灵厝）规模宏大。
- **广东**：称「金银衣纸」，「烧衣」成套；供品讲究「意头」。
- **民族差异**：纸扎、冥币是汉族的产物，**穆斯林民族不用纸钱**（教法视为无益），藏族以酥油灯、风马旗、供品为主要供奉形式，傣族以「赕」与鲜花。**这些物品体系须按族别分别记录。**
