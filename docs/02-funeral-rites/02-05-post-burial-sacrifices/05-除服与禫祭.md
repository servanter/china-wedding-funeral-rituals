# 除服与禫祭

## 一、释义

- **除服**：服丧期满，脱去丧服、恢复正常生活的仪节。
- **禫祭**：「禫」（dàn）为大祥之后所行之祭，是除服前最后一次祭祀。《礼记》释「禫」为「澹澹然平安之意」——哀情渐淡，心境转安。

禫祭与除服是「三年之丧」的终点。行礼之后，服丧者恢复常服、恢复正常社会交往（可婚娶、可赴宴、可理发），丧礼至此真正结束。

## 二、历史源流

- 《礼记·间传》详述丧服在后期的变除：**「期而小祥……又期而大祥……中月而禫」**——「中月」即间隔一月，故禫在二十七个月之际。
- 《礼记·檀弓》：「三年之丧，二十五月而毕。」与「二十七月」之说并行，历代礼制取用不一：
  - 汉魏多用二十五月；
  - 唐宋以后礼制多用二十七月（如唐《开元礼》、宋《政和礼》）；
  - 明代官员丁忧为二十七个月。
- 《仪礼·丧服》对各类丧服的「除服」时间有明确规定（如「大功九月」「小功五月」「缌麻三月」）。
- 《朱子家礼》定「禫」的仪节，是后世民间遵循的范式。
- 民间实际执行多有简化：以「除孝」「脱孝」「谢孝」的形式在百日、周年或「三年」之际完成除服，不一定严格履行禫祭。
- 当代火化与城市生活中，除服演为「脱孝」——脱去黑纱、白花、孝箍，恢复正常着装。

## 三、仪节流程

1. **择日**：大祥之后一个月（「中月」）择吉日行禫祭。
2. **备祭**：备供品、香烛、纸钱，设礼生（若有）。
3. **设祭**：在灵位（或祠堂、墓前）设奠，行三献礼。
4. **读祝文**：宣读禫祭祝文，告以服制将终。
5. **变服**：着「纤」（黑经白纬之布）之服，或改着常服。
6. **撤灵位（除灵）**：撤去灵位、魂帛，改设神主，祔于祖庙（或家中的祖先牌位之列）。
7. **除服**：脱去丧服，改着素色常服；男子理发，女子去饰。
8. **宴客（谢孝宴）**：设宴答谢亲友与操办丧事者（「禫宴」）。
9. **告庙**：将亡者之神主正式列入家庙（或家中祖先神位），祭祀秩序恢复正常。
10. **恢复正常交往**：此后可婚娶、可赴宴、可参与节庆。

## 四、地域与民族变体

- **华北**：称「除孝」「脱孝」，多在「三年」之际（或周年、百日）举行；讲究「除孝后可行吉礼」。
- **江南**：称「除灵」「脱孝」，多在「大祥」或「三年祭」时完成。
- **闽台**：称「脱孝」，多在「三年祭」或「合炉」时进行——把亡者之名合入公妈牌（祖牌），是极重要的仪式。
- **广东**：称「脱孝」，多在周年或三年时完成，讲究「换红」（脱去白色，换上红色或素色）。
- **当代**：城市多简化为戴黑纱或白花数日至百日，届时即除。
- **少数民族**：部分民族有服丧期与除服的制度，如彝族的服丧期以家族支系而定；藏族以「周年」为脱孝之期。**服丧期的长度与除服仪式，各族的习惯法规定不同。**

## 五、器物与文书

- **丧服（禫服、纤服）**。
- **神主（木主）**：除服后所奉之神主。
- **公妈牌（闽台）**：合炉所用的祖牌。
- **禫祭祝文**：文书。
- **供品、香烛、纸钱**。
- **族谱**：除服后正式记入。
