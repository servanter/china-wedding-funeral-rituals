# 复三（圆坟）

## 一、释义

复三，又称「圆坟」「复山」「三朝」「暖墓」，是下葬后第三日亲属再到墓地，修整坟头、设奠哭祭之礼。

「复三」之名有两解：一说「复」为再往（第三次上坟？实为葬后三日再往）；一说取「三」之数（三日）。其实际内容为：**添土修坟（把坟头修圆修整）＋设奠哭祭＋焚烧纸钱**。

## 二、历史源流

- 《仪礼·既夕礼》记葬后有「反哭」「虞祭」，但「复三」之名不见于礼经。
- 《朱子家礼》规定葬后「三日而虞」的日程框架，是「三日」这一时间节点的礼制依据。
- 复三之俗在明清方志中记载普遍，名称因地而异：北方多称「复三」「圆坟」，江南称「复山」「三朝」，闽台称「巡山」「圆坟」。
- 复三的实际功能是**把「新坟」整理成「成品坟」**：下葬当日的封土多属草创，三日后来修整成形，是造坟的最后一道工序。
- 部分地区还有「接三」「迎三」之说（认为亡魂三日后回家），与复三时间重合，但观念不同。
- 当代土葬地区仍普遍行复三；火化地区则简化为「骨灰安放后三日的祭扫」。

## 三、仪节流程

1. **择时**：下葬后第三日（有的是「三日」含下葬日，有的是次日起算，须依地方规定）。
2. **备物**：备香烛、供品（酒、果、糕点）、纸钱、纸扎，及修坟工具（锹、筐）。
3. **至墓**：亲属着孝服至墓地，男眷先到、女眷随后。
4. **修坟（圆坟）**：添土、修整坟头，使成规整的圆形；修整坟圈，清除杂草。
5. **设奠**：在坟前设供、上香、跪拜。
6. **哭祭**：亲属哭祭，念告亡者「已安居于此」的话。
7. **焚纸**：焚化纸钱、纸扎。
8. **返程**：返程不回头（部分地区）。
9. **后续**：此后进入「做七」的周期祭祀。

## 四、地域与民族变体

- **华北**：称「复三」「圆坟」，讲究「三日圆坟，坟头要圆要正」。
- **江南**：称「复山」「三朝」，讲究备酒菜在坟前「陪亡者吃饭」。
- **闽台**：称「巡山」「圆坟」，有的地方须连续三日上坟。
- **广东**：称「复坟」，讲究「三朝上坟、修坟立碑」。
- **少数民族**：部分民族有葬后再祭的习俗，如彝族的「做斋」「送灵」在葬后择日举行，规模远大于汉族的复三；苗族的「烧灵」在葬后数年方行；藏族以「七七」期间的诵经为主要祭祀。**「复三」是汉族（及部分受汉文化影响民族）的特定习俗。**

## 五、器物与文书

- **供品**：酒、果、糕点。
- **香烛、纸钱、纸扎**。
- **修坟工具**：锹、筐、锄。
- **孝服、孝巾**。
- **墓图、墓地契书**：墓位记录。
