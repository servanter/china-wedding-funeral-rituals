# 做七（七七）

![葬后祭祀时序图 / Timeline of post-burial sacrifices](../../../assets/diagrams/葬后祭祀时序图.svg)

*图 7　葬后祭祀时序：复三—七七—百日—周年—除服。*

## 一、释义

做七（烧七、七七斋），是死者去世后每七日设祭一次，共七次（共四十九日）的祭祀制度。名目为：**头七、二七、三七、四七、五七、六七、七七（断七）**。

做七的时间框架与佛教「中有（中阴）」观念相关：认为亡者死后七七四十九日内处于「中有」阶段，随业受生；每一七日的祭祀与诵经可为其「回向功德」，助生善道。

## 二、历史源流

- **教理依据**：《地藏菩萨本愿经》以大量篇幅讲述为亡者「七七日」内作福、诵经、称念名号的功德。
- **历史形成**：七七斋之俗随佛教传入而兴起，唐代已大盛（敦煌文书中有大量「七七斋」的文书与愿文）。
- **礼俗融合**：与汉族的「朝夕奠」「朔望奠」体系结合，形成「七」与「旬」并行的祭祀节奏。
- **地方差异**：各地对七期的重视程度不同，**「五七」普遍被认为最重要**（俗谓「五七为先」，一说亡者至五七方知自己已死），也有以「头七」与「七七」最重者。
- **当代**：火化制度下，做七仍普遍进行（尤其农村），多简化为「头七」「五七」「七七」三次。

## 三、仪节流程

1. **计日**：自去世之日（或次日起，依地方习惯）计算，每七日为一期。
2. **设祭**：每期设祭，供品较日常丰盛（部分地区讲究「三七」「五七」备「牲」）。
3. **诵经（如设佛事）**：请僧人诵经、拜忏，或家属自行念佛号回向。
4. **哭祭**：亲属在灵前哭祭，尤以女儿、儿媳为主哭者。
5. **焚纸**：焚化纸钱、纸扎（部分地区每七焚化不同物品，如五七焚「纸伞」）。
6. **五七**：多设较隆重的祭祀（部分地区请道士、僧人做法事）。
7. **七七（断七）**：最后一期，标志「中有」期结束，仪式较盛，有「除灵」「送亡」之意。
8. **忌日接续**：七七之后转入百日祭、周年祭（见相关条目）。

## 四、地域与民族变体

- **华北**：重「五七」，讲究「五七三十五，亡人正受苦」——故五七须隆重祭奠。
- **江南**：七期各有名目，讲究「做七不空」，逢七必祭。
- **闽台**：七期与佛道法事结合，「五七」多请司公做功德。
- **广东**：称「做七」，每七设斋，讲究「斋七」。
- **少数民族**：部分民族也受佛教影响而有「七七」之俗（如白族、纳西族的部分地区）；彝族的「做斋」有自己的周期（不定期，多在山寨农闲时举行，规模大）；藏族以「七七」期间的诵经为主要祭祀，由喇嘛主持。**同是「七」的周期，教义背景与仪式内容不同，须分别记录。**

## 五、器物与文书

- **供品**：酒、菜、果、糕点，五七多备牲。
- **香烛、纸钱、纸扎**。
- **经书、法器**（如设佛事）。
- **七期日程表**：丧家内部的记录。
- **祭文、疏文**：做七时所读。
