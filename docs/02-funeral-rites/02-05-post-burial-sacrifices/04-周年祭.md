# 周年祭（小祥、大祥）

## 一、释义

周年祭即「祥祭」，分两级：

- **小祥**：去世后满一周年之祭。「祥」意为「吉」，即「渐近于吉」。
- **大祥**：去世后满两周年之祭。
- **禫祭**：大祥之后再过一月（或三月）之祭，除服之礼（详见「除服与禫祭」条）。

三者构成「三年之丧」的阶段性节点。「三年之丧」实际为二十七月（或二十五个月），以「周年」为单位划分阶段。

## 二、历史源流

- 《仪礼·士虞礼》记虞祭之后的「祔祭」，即新死者之主要「祔」于祖庙，是祥祭的前导。
- 《礼记·间传》详述丧服在后期的「变除」：小祥「练冠」，即冠改用练（白熟丝）制，故小祥又称「练」；大祥「素缟麻衣」；禫而「纤」（着黑经白纬的布）。
- 《礼记·檀弓》：「三年之丧，二十五月而毕。」汉代以后有「二十五月」「二十七月」两说，历代礼制采用不一。
- 《朱子家礼》定「小祥」「大祥」「禫」的仪节，是后世民间遵循的范式。
- 明清礼制对「三年之丧」有所调整（如官员丁忧二十七个月），民间则多在周年、二周年设祭，未必严格服满。
- 当代：周年忌日（「做周年」）仍普遍设祭，但「小祥」「大祥」之名与「练」「缟」的服饰变化多已不存。

## 三、仪节流程

### 小祥（一周年）

1. **择日**：去世后满一周年之日（多按农历）。
2. **备祭**：备供品、香烛、纸钱。
3. **设祭**：在灵位（或墓前）设奠，行三献礼（若有礼生主持）。
4. **读祝文**：宣读小祥的祭文。
5. **变服**：**改着「练冠」**——由斩衰之粗麻改为练制的白熟布冠，标志着哀情稍减、「渐近于吉」。
6. **宴客（部分地区）**：小祥时「略为治具，谢宾客」，即俗称的「周年答谢亲友」。

### 大祥（二周年）

1. **择日**：满两周年之日。
2. **备祭与设祭**：仪同小祥。
3. **读祝文**。
4. **变服**：改着「素缟麻衣」（或换用较细的丧服）。
5. **撤灵位**：部分地区在大祥时撤去灵位（「除灵」）。
6. **告庙**：将亡者之「主」正式祔于祖庙（若行祔主之礼）。

### 禫祭

- 大祥之后再一月（或三月）行禫祭，除服，服制终结（详见「除服与禫祭」条）。

## 四、地域与民族变体

- **华北**：称「做周年」「一周年」，在坟前或家中设祭；「二周年」有的地方不办（「不上二周年」），须依地方惯例。
- **江南**：称「小祥」「大祥」，传统礼制保留较多，讲究「变服」。
- **闽台**：称「做周年」，与「除孝」结合；「三年祭」（合满三年之说）亦为重要节点。
- **广东**：称「做周年」，讲究「一周年、二周年、三周年」三次。
- **少数民族**：部分民族有自己的周年祭，如彝族的「周年祭」多在「做斋」仪式中一并完成；纳西族有「三年祭」（东巴主持）；藏族以「周年」时的诵经为主要祭祀。**「小祥」「大祥」是儒家礼制的专名，不宜推及他族。**

## 五、器物与文书

- **供品、香烛、纸钱**。
- **练冠、素缟麻衣**：小祥、大祥的变服之服。
- **祭文（小祥祝文、大祥祝文）**：文书，格式见「婚丧文书范本／祭文范本」条。
- **神主（若行祔主之礼）**。
- **族谱**：祥祭后可记入族谱。
