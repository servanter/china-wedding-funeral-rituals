# 丧礼执事称谓

## 一、释义

丧事是集体协作的礼仪活动，其分工有固定的称谓系统。

| 称谓 | 职责 | 备注 |
| --- | --- | --- |
| **都管／总管（总理）** | 总揽丧务 | 多请族中或地方有威望者 |
| **护丧** | 主持丧礼仪式（《家礼》所设） | 丧主之辅 |
| **司书** | 记礼、登记吊客与赙赠 | 《家礼》所设 |
| **司货** | 掌管财物收支 | 《家礼》所设 |
| **账房** | 管账 | 近世称 |
| **大宾／题主官** | 题主、点主者 | 请显者充任 |
| **礼生／赞礼** | 唱礼、导引仪式 | 「通赞」「引赞」有别 |
| **司仪** | 主持仪式程序 | 近世称 |
| **阴阳先生／地理先生** | 择日、看风水 | 民间称「先生」 |
| **杠夫／抬棺者** | 抬棺送葬 | 八人、十六人、三十二人不等 |
| **吹鼓手／乐队** | 奏哀乐 | 有的地区请僧道法事 |
| **厨子／饭房** | 办丧宴 | 「流水席」 |

## 二、历史源流

- **先秦**：《仪礼·士丧礼》有「祝」「史」「甸人」等执事之分。
- **唐宋**：《家礼》定「护丧、司书、司货」三职，为后世蓝本。
- **明清**：民间形成「都管、账房、礼生、杠房」等分工；「杠房」「棚铺」为专营行业。
- **近代以来**：殡仪馆取代大部分民间分工；「司仪」「礼仪师」为新兴称谓。

## 三、仪节流程

1. **开局**：设「丧事办事处」（有的贴「丧榜」列执事名单）。
2. **分工**：都管总理，账房记礼，礼生赞礼，阴阳择日。
3. **受吊**：司书登记吊客与赙赠，礼生唱名导引。
4. **出殡**：杠夫抬棺，吹鼓手奏乐，阴阳择向。
5. **谢执事**：丧后以宴或礼答谢执事者。

## 四、地域与民族变体

- **华北**：杠房、棚铺、吹鼓手为专营职业，「大宾」点主之礼隆重。
- **闽台**：「师公」（道士）、「先生」（地理师）、「孝男团」等分工明确。
- **江南**：礼生（赞礼）由熟悉古礼者充任，仪式用四字唱礼。
- **少数民族**：执事者多为宗教职业者（如藏族的僧人、傣族的「波章」），其称谓与职责体系不同，须分别记录。

## 五、器物与文书
