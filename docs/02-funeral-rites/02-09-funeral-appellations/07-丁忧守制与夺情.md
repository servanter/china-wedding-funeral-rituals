# 丁忧、守制与夺情

## 一、释义

**丁忧**指官员遭父母之丧，须**解官离职、回籍守制**；**守制**即服满三年（实二十七月）之丧；**夺情**（夺情起复）则是朝廷因公需要，命令官员**在职守制、不得解官**。

| 名目 | 含义 |
| --- | --- |
| **丁忧／丁艰** | 遭父母丧而离职（丁父忧、丁母忧） |
| **守制** | 居丧守礼，二十七月 |
| **夺情** | 朝廷不许其解官，命在职（「夺其情」） |
| **起复** | 服满或夺情后重赴任所 |
| **终制** | 服满除服 |

**制度要点**：丁忧期间不得婚娶、作乐、赴宴；违者以「不孝」论罪。明清制度：官员丁忧须呈报，服满候补（「起复即用」「降级起用」各有差）。

## 二、历史源流

- **先秦**：《礼记·王制》「**父母之丧，三年不从政**」，为丁忧之礼源。
- **汉代**：丁忧之制渐成，有「举孝廉」与「居丧过礼」的风尚。
- **唐宋**：丁忧入律；《唐律疏议》对「闻父母丧不举哀」「居丧作乐」有明确科罚；夺情之例渐多。
- **明清**：制度最为详备，正史人物传中大量「丁忧去官」「夺情起复」记载。
- **近代以来**：丁忧制度随官僚体制改革而废止；「守制」「夺情」成为历史名词。

## 三、仪节流程

1. **闻丧**：得讣即举哀、报官（呈报丁忧）。
2. **解官**：离任回籍守制。
3. **守制**：三年（二十七月）居丧，闭门不出。
4. **夺情（例外）**：朝廷因其才、其职而不许解官，令在职守制（如明之张居正）。
5. **起复**：服满或夺情后赴阙、补官。

## 四、地域与民族变体

- **汉族地区**：丁忧为文官制度，与民间丧礼并行。
- **少数民族政权**：辽、金、元、清各代对汉官丁忧之制有承袭与变通规定，须分别记录。

## 五、器物与文书
