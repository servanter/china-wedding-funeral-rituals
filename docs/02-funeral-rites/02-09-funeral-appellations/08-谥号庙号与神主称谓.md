# 谥号、庙号与神主称谓

## 一、释义

| 名目 | 含义 | 例举 |
| --- | --- | --- |
| **谥号** | 死后依其行迹所上的褒贬称号 | 文、武、忠、献、孝；幽、厉（贬） |
| **庙号** | 入太庙奉祀的称号 | 太祖、太宗、高宗（多用于帝王） |
| **尊号／徽号** | 生前或死后所上的尊崇称号 | 多用于帝王、后妃 |
| **神主称谓** | 神主（木主）上书写的死者名号 | 「显考某公讳某某神主」 |
| **赠官／赐谥** | 朝廷追赠的官爵与谥号 | 赠某官、谥某某 |

**书写规则**（神主、铭旌、碑志）：
- 先冠以「显考／先妣」，次列官爵（如「诰授某大夫」），次列「讳某」，末署「神主」「之柩」「之墓」。
- 谥号置于姓名之前或之后，如「某公讳某某谥文忠」。

**礼义**：谥号是「**盖棺论定**」的制度化形式，其褒贬与「劝惩」的政治伦理功能密切相关。

## 二、历史源流

- **先秦**：《逸周书·谥法解》为最早的谥法文本；《礼记·檀弓》「死谥，周道也」。
- **秦汉**：帝后之谥、臣僚之谥并行；汉代谥法趋滥。
- **唐宋**：谥法制度化，设「议谥」之官；名臣多获美谥。
- **明清**：谥法严格控制，唯品官及以上、有特殊功勋者可得；「文正」为文臣第一谥。
- **近代以来**：谥号制度废止；墓碑、神主题名保留「显考」等旧式。

## 三、仪节流程

1. **立谥**：由礼官议定（「议谥」「请谥」）。
2. **赐谥／赠官**：朝廷颁下。
3. **题主**：神主依谥号、官爵题名。
4. **书旌**：铭旌同书官爵（见「铭旌与招魂幡」条）。
5. **碑志**：墓志铭、神道碑以官爵、谥号冠首。

## 四、地域与民族变体

- **汉族地区**：谥法用于帝王、官员与名儒（私谥亦有，如「乡贤」门人私谥其师）。
- **少数民族政权**：辽、金、元、清帝后亦行谥号、庙号制度，其谱系与汉族并行而自成体系，须分别记录。
