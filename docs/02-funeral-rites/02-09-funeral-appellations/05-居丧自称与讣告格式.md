# 居丧自称与讣告亲属称谓格式

## 一、释义

讣告（讣闻）是丧礼文书的核心，其称谓格式以**服制排行**为骨架，是五服制度在文书上的直接遗留。

**讣告基本结构**：

1. **首行**：死者名号——「先考某公讳某某府君」。
2. **次行**：生卒年月日时、享年。
3. **三行**：殁于何地、葬于何地、何时设奠开吊。
4. **孝属排行**：依服制自亲及疏排列——
   - 「孤子某某泣血稽颡」
   - 「期服孙某某拭泪稽首」
   - 「大功服侄某某拭泪顿首」
   - 「缌服侄孙某某抆泪拜」
5. **末行**：「谨此讣闻」「哀此讣闻」。

**服制称谓用语对照**：

| 服制 | 自称用语 | 行礼用语 |
| --- | --- | --- |
| 斩衰（子） | 孤哀子 | 泣血稽颡 |
| 齐衰期（孙、侄） | 期服孙／期服侄 | 拭泪稽首 |
| 大功 | 大功服侄 | 拭泪顿首 |
| 小功 | 小功服侄孙 | 抆泪顿首 |
| 缌麻 | 缌服曾侄孙 | 抆泪拜 |

## 二、历史源流

- **先秦至唐宋**：讣告之称谓散见于书启；《家礼》规范丧礼文书格式。
- **明清**：讣告格式定型，「服制排行」成为通例；现存大量清代、民国讣闻实物。
- **近代以来**：报刊讣告用新式行文，但署名仍保留「服制排行」痕迹。
- **当代**：讣告以「不孝男／女」署名为主，间附「期服孙」等旧称。

## 三、仪节流程

1. **草讣**：由司书依服制拟定孝属排行。
2. **送讣**：讣告分送亲友（「报丧」）。
3. **开吊受吊**：依讣告所载时日设奠开吊。
4. **谢帖**：葬后具谢帖（谢吊），格式与讣告相配。
5. **存档**：族谱、家乘多附讣告、哀启文本。

## 四、地域与民族变体

- **华北**：讣告称「讣闻」，丧榜（丧事榜）用大字张贴门首。
- **闽台**：讣闻（「白帖」）格式古雅，「服制排行」保留完整。
- **江南**：讣告、哀启文辞讲究，多请文人代笔。
- **少数民族**：多以口头报丧代替文字讣告；文字讣告形式与汉族不同，须分别记录。

## 五、器物与文书

- **讣告（讣闻）**、**哀启**、**谢帖**、**丧榜**、**行状**。
- **书写材料**：白纸、白帖、素绢；字用蓝色或黑色。
- **相关文书**：挽联簿、丧礼簿（登记吊客与赙赠）。
