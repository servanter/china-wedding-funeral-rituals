# 丧葬称谓总览

## 一、释义

丧葬称谓是**丧事语境中的整套称名系统**，其特点是「讳」与「敬」并行：对死者用敬称、讳称，对丧家用谦称，对吊客用敬语。分类如下：

| 大类 | 例举 | 本板块条目 |
| --- | --- | --- |
| **逝者称谓** | 先考、先妣、显考、亡妻 | 02 |
| **丧主与孝属** | 丧主、孝子、孝女、孝妇 | 03 |
| **居丧自称** | 孤子、哀子、孤哀子、不孝男 | 04、05 |
| **死亡讳称** | 崩、薨、卒、不禄、逝世 | 06 |
| **制度性称谓** | 丁忧、守制、夺情、起复 | 07 |
| **名号类** | 谥号、庙号、神主题名 | 08 |
| **执事称谓** | 大宾、礼生、司仪、杠夫 | 09 |
| **吊唁用语** | 吊、唁、赙、赠、襚 | 10 |

**两个基本原则**：
1. **「讳」**——不直称死者名，而以讳、字、行第、官爵代之（「讳某」「字某」）。
2. **「别亲疏」**——称谓的用字直接标示服制远近（如「期服孙」「小功服侄」），与五服制度相表里。

## 二、历史源流

- **先秦**：《尔雅·释亲》为最早系统整理亲属称谓的文献；《礼记·曲礼》定「崩、薨、卒、不禄、死」的等级讳称。
- **汉唐**：避讳制度盛行，丧葬称谓与「讳」紧密相连；品官之丧有赠官、谥号之称。
- **宋明**：《家礼》规范讣告、题主称谓；《称谓录》（清·梁章钜）集其大成。
- **明清**：讣告「服制排行」格式成熟定型。
- **近代以来**：丧葬称谓保留在讣告、挽联、碑志中；当代讣告仍用「先考」「不孝男」「泣血稽颡」等语。

## 三、仪节流程

1. **初丧**：改称死者以「讳某」「先考／先妣」，生者自称「不孝男」。
2. **讣告**：以称谓行文，列服制排行。
3. **题主、立旌**：书「显考某公讳某神主」。
4. **吊唁答谢**：以「泣血稽颡」「拭泪稽首」等自称作答。
5. **碑志、神主**：称谓终定，长期沿用。

## 四、地域与民族变体

- **汉族各地**：称谓大体一致，方言另有俗称（如「老的」「先人」）。
- **闽台**：讣告、挽幛沿用古式称谓较多；「显考」「先妣」并行。
- **少数民族**：各族的亲称谓体系与本民族的亲属制度相关（如彝族家支称谓），不适用汉式丧葬称谓规则，须分别记录。

## 五、器物与文书

- **文献依据**：《尔雅·释亲》《礼记·曲礼》《称谓录》。
- **文书载体**：讣告、哀启、挽联、挽幛、神主、墓志铭、碑文。
- **常用套语**：「泣血稽颡」「杖期」「期服」「功服」「缌服」等。
