# 慰唁用语与吊丧称谓

## 一、释义

吊丧语境中的用语分「**吊死者**」与「**唁生者**」两类，另有赠赠财物之名。

| 用语 | 含义 | 说明 |
| --- | --- | --- |
| **吊** | 吊死者 | 「吊丧」「往吊」 |
| **唁** | 慰问生者（丧家） | 《穀梁传》「吊失国曰唁」；后世「唁」专指慰丧家 |
| **赙** | 赠财物助丧 | 「赙金」「赙仪」 |
| **赠** | 赠葬品（明器、衣物） | 《仪礼·既夕礼》有「赠」之节 |
| **襚** | 赠死者衣物 | 先秦之礼 |
| **奠** | 致祭品 | 「上奠」「送奠」 |
| **挽** | 赠挽联、挽幛、花圈 | 近代形态 |

**慰唁套语**：「节哀顺变」「节哀自重」「宽慰自爱」「请多保重」「善自珍摄」；忌语：不可在丧家说「再见」「再来」等语。

**答谢用语**：丧家答礼称「谢吊」，用语如「泣血稽颡」「拭泪稽首」「不敢当」。

## 二、历史源流

- **先秦**：《礼记·曲礼》《檀弓》详载吊丧之礼与用语（如「知生者吊，知死者伤」）。
- **汉唐**：吊、唁、赙、赠的分别渐明。
- **宋明**：《家礼》规定受吊答礼之节。
- **明清**：赙赠、挽礼（挽联、挽幛）盛行，形成书面的吊丧用语体系。
- **近代以来**：以「挽」为核心，赙金改称「奠仪」「帛金」（粤语区）、「白包」。

## 三、仪节流程

1. **报丧**：讣告送达，亲友备吊。
2. **往吊**：吊客至灵前上香、行礼，丧主陪哭答礼。
3. **致赙**：赠赙仪（奠仪），司书登记。
4. **慰唁**：慰问丧家，「节哀顺变」。
5. **谢吊**：葬后具谢帖或设宴答谢。

## 四、地域与民族变体

- **华北**：吊客「上香、磕头」，丧主「跪棚」陪礼；赙金称「奠仪」。
- **闽台**：奠仪称「白包」或「奠仪」，挽幛称「轴」；答礼用「答谢帖」。
- **广东**：赙金称「帛金」，须为单数；丧家回「吉仪」（含糖、利是）以「化解」。
- **少数民族**：吊唁方式多样（献哈达、献酒、唱丧歌、跳丧），用语与汉族套语不同，须分别记录。

## 五、器物与文书

- **吊唁文书**：讣告、谢帖、挽联、挽幛、唁电、唁函。
- **赙赠登记**：礼单、丧礼簿。
- **相关器物**：香烛、奠仪封包、挽带。
