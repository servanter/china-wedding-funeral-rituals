# 死之讳称体系（崩、薨、卒、不禄）

## 一、释义

古人讳言「死」，而以**等级化的讳称**代替。《礼记·曲礼下》：「**天子死曰崩，诸侯曰薨，大夫曰卒，士曰不禄，庶人曰死。**」

| 讳称 | 适用 | 释义 |
| --- | --- | --- |
| **崩** | 天子 | 如山崩，至尊之辞 |
| **薨** | 诸侯、有封爵者 | 次尊之辞 |
| **卒** | 大夫 | 终、尽之义 |
| **不禄** | 士 | 不终其禄 |
| **死** | 庶人 | 本字 |

**民间婉辞体系**（近世通行）：

- **老**：「老了」「老了人」。
- **走／去了**：「走了」「去了」「过去了」。
- **过世／去世／辞世／逝世**。
- **殁／故／亡**：文言婉辞。
- **仙逝／归西／归天／登遐／跨鹤**：含宗教或祝愿意味。
- **百年／身后**：「百年之后」「身后事」。
- **没了／不在了**：口语婉辞。

## 二、历史源流

- **先秦**：《礼记·曲礼》定等级讳称；《公羊传》《穀梁传》亦有「崩、薨、卒」的用例辨析。
- **汉唐**：史书严格依等级用字（帝王「崩」，臣僚「薨」「卒」）。
- **宋元明清**：讳称制度沿袭；民间婉辞日益丰富。
- **近代以来**：等级讳称仅存于史学与礼学语境；民间婉辞通行，「逝世」「去世」为通用书面语。

## 三、仪节流程

1. **报丧用语**：以婉辞告知亲友（「老大人于某时仙逝」）。
2. **讣告行文**：文言讣告用「卒」「以疾卒于某地」等。
3. **碑志用语**：依死者身份择用（官宦用「薨」「卒」）。
4. **口头上**：乡里以「老了人」相告。
5. **忌直言**：当面忌直说「死」字，为丧葬语言禁忌之一。

## 四、地域与民族变体

- **华北**：「老了」「老了人」为常用婉辞。
- **闽台**：「过身」「返去」「往生」（佛教影响）。
- **江南**：「过世」「走脱」。
- **少数民族**：各族的死亡婉辞与其宗教信仰相关（如「往生」「上天」），并常伴语言禁忌（忌直称），须分别记录。

## 五、器物与文书

- **载体**：讣告、哀启、碑志、挽联。
- **用语**：崩、薨、卒、不禄、殁、逝、仙逝、归西。
- **文献依据**：《礼记·曲礼》《公羊传》《称谓录》。
