# 丧主、孝子、孝女、孝妇

## 一、释义

| 称谓 | 身份 | 职责 |
| --- | --- | --- |
| **丧主** | 主持丧事者，通常为长子（父丧）或承重孙 | 主丧、受吊、行礼之主 |
| **主妇** | 丧主之妻（或亡者之媳、女） | 主中馈、治丧内事 |
| **护丧** | 亲友中主持丧务者 | 总揽丧务（《家礼》设「护丧」一人） |
| **孝子** | 亡者之子 | 服斩衰、执杖、迎宾、守灵 |
| **孝女** | 亡者之女 | 哭丧、执礼 |
| **孝妇** | 亡者之媳 | 主内、执礼 |
| **孝孙、孝侄** | 孙辈、侄辈 | 依服制行礼 |

**「丧主」的确定**（宗法原则）：父丧以**长子**为主，长子不在则以**长孙（承重孙）**为主，即「**为人后者为之子**」之义；母丧则以**长子**为主或由**夫（若在）** 为主。

**相关名目**：《家礼》设「司书」（记礼）、「司货」（掌财）、「护丧」（总裁）三职，各有人专任。

## 二、历史源流

- **先秦**：《仪礼·士丧礼》详载丧主行事之节；《礼记》论「主丧者」之义。
- **唐宋**：《开元礼》《家礼》定丧主、护丧、主妇等职名。
- **明清**：丧主之责入于宗族礼法；承重孙的认定与财产继承相连。
- **近代以来**：丧主多由长子（或主要赡养人）担任，职责简化为「主持治丧、答谢吊客」。

## 三、仪节流程

1. **立丧主**：初丧时由家族议定丧主（长子／承重孙）。
2. **主丧**：丧主主持成服、朝夕奠、治丧事务。
3. **受吊**：丧主在灵前受吊、答礼。
4. **送葬**：丧主执幡、扶柩、主祭下葬。
5. **谢吊**：葬后具帖（谢帖）答谢吊客。

## 四、地域与民族变体

- **华北**：孝子「跪棚」（在灵棚跪迎吊客），孝妇「跪灵」哭丧。
- **闽台**：丧主称「孝男」，主妇称「孝妇」；承重孙之称迄今沿用。
- **江南**：丧主多由长子担任，「护丧」由族中尊长或执事充任。
- **少数民族**：主丧者依本族亲属制度产生（如彝族的家支长辈、藏族由僧人主导丧仪），与汉族宗法主丧制度不同源，须分别记录。

## 五、器物与文书

- **讣告署名**：「不孝男某某」「期服孙某某」等，依服制排行。
- **执事分工文书**：丧事单、丧榜。
- **礼书依据**：《仪礼·士丧礼》《朱子家礼·丧礼》。
