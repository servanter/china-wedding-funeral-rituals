# 孤子、哀子、孤哀子

## 一、释义

居丧者自称依**父母存亡的不同组合**而变，为讣告署名的用字规范：

| 自称 | 情形 | 出处与说明 |
| --- | --- | --- |
| **孤子** | 父已亡（母在） | 《礼记·曲礼》「孤子当室，冠衣不纯采」 |
| **哀子** | 母已亡（父在） | 取「哀」之义 |
| **孤哀子** | 父母俱亡 | 「孤」＋「哀」，最重之自称 |
| **棘人** | 居丧者之通称 | 《诗经·桧风·素冠》「棘人栾栾兮」 |
| **不孝男** | 丧家子弟之谦称 | 通用（近世讣告多为用） |

**用法要点**：
- 男性丧主多用「孤子／哀子／孤哀子」；女性则用「孤女／哀女」。
- 讣告末署常作「**孤子某某泣血稽颡**」。
- 「孤」在先秦另指「失父之子」，与「哀」组合后成为丧礼专用语。

## 二、历史源流

- **先秦**：《礼记·曲礼》《杂记》已见「孤子」之称；《诗经》「棘人」为居丧者之谓。
- **唐宋**：讣告、书启中「孤子」「哀子」的分别定型。
- **明清**：讣告格式成熟，署名按父母存亡题「孤子」「哀子」「孤哀子」，并冠以「泣血稽颡」等语。
- **近代以来**：旧式讣告沿用；当代讣告多用「不孝男／女」，间用「孤哀子」。

## 三、仪节流程

1. **初丧**：丧家子弟改称孤子／哀子／孤哀子。
2. **具讣**：讣告署名依例书写，末附「泣血稽颡」。
3. **受吊答礼**：丧主以自称行礼、答谢。
4. **神主、碑志**：与「显考」「先妣」等称配用。
5. **除服**：服满后自称复常。

## 四、地域与民族变体

- **汉族各地**：旧式讣告保留；民间口语以「孝子」泛称。
- **闽台**：讣告、谢帖沿用「孤哀子」「泣血稽颡」等语。
- **少数民族**：居丧自称多依本族语汇与禁忌（不称本名等），与汉式「孤子／哀子」不属同一系统，须分别记录。

## 五、器物与文书

- **载体**：讣告、哀启、谢帖、神主、墓碑。
- **套语**：「泣血稽颡」「抆泪稽首」「拭泪顿首」（依服制亲疏而别）。
- **文献**：《礼记·曲礼》《称谓录》。
