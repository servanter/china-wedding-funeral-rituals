# 逝者称谓（先考、先妣）

## 一、释义

对死者的称谓以「**先／显／亡／故**」等字为区别，其用法有严格的**尊卑与亲疏之分**：

| 用字 | 对象 | 例举 |
| --- | --- | --- |
| **先** | 已故的尊长 | 先考（父）、先妣（母）、先祖考、先祖母、先兄、先师 |
| **显** | 已故的尊长（且下有子孙、丧礼隆重的家长） | 显考、显妣（「显」有「显赫昭著」之义） |
| **亡** | 已故的平辈或卑幼 | 亡妻、亡弟、亡儿 |
| **故** | 一般的已故者 | 故友、故人 |
| **府君／孺人** | 尊称死者夫妇 | 某府君、某孺人（女） |

**「讳」与「字」**：讣告、碑志中不直书名，而称「讳某」（讳，死者之名）、「字某」；如「显考某公讳某某府君」。

**使用场合**：灵位、铭旌、讣告、神主、墓志铭、挽联、行状、族谱传略。

## 二、历史源流

- **先秦**：《礼记·曲礼》「生曰父曰母，死曰考曰妣」；《尔雅·释亲》定亲属称谓。
- **汉唐**：避讳之制严，碑志多称「讳某」「府君」。
- **宋明**：《家礼》规定灵位、神主题名格式，「显考」「先考」之别渐明。
- **明清**：「显考／先考」的用法有定制（有子孙者称「显」，无者称「先」，一说以死者为家长者称显）。
- **近代以来**：讣告、碑文沿用旧式称谓。

## 三、仪节流程

1. **初丧**：即改称死者为「先考／先妣」，自称「不孝男／不孝女」。
2. **讣告**：以「先考某公讳某某」起首（详见「居丧自称与讣告」条）。
3. **立旌题主**：铭旌、神主书「显考某公讳某某神主」。
4. **碑志**：墓志铭、墓碑依称谓之定式书写。
5. **族谱**：传略、世系表中以「讳某」著录。

## 四、地域与民族变体

- **汉族各地**：民间口语以「先人」「老人」「上人」泛称，书面则守古式。
- **闽台**：讣告「显考」「先妣」并用，堂号、郡望附于名号前（如「颍川陈公」）。
- **少数民族**：多以本族亲称谓称呼亡者，并常以禁忌（不直称名）约束使用，与汉式「先考／显考」体系不同源，须分别记录。

## 五、器物与文书

- **载体**：灵位牌、铭旌、神主、讣告、行状、墓志铭、墓碑、挽联。
- **套语**：「讳某」「字某」「府君」「孺人」「先考」「显妣」。
- **文献**：《尔雅·释亲》《礼记·曲礼》《称谓录》《家礼》。
