# 入殓用物（打狗棒、五谷袋等）

## 一、释义

入殓用物，是装殓时置于棺内或遗体旁的各类民俗器物。它们不是礼经所定的「明器」，而是民间信仰的物化：每一件都对应死者「赴阴间」路上的一种需要。

本条目集中记录这几类器物的形制、用法与观念依据。

## 二、历史源流

- 礼经所定入殓之物为「明器」（备物而不可用）与「用器」（生前之器），见《礼记·檀弓》「其曰明器，神明之也」。
- 「打狗棒」「五谷袋」等民俗器物不见于礼经，其形成与民间冥界信仰相关：认为亡魂赴阴间途中会遇恶犬拦路、会受饥渴、须过桥渡河，故须预为备办。
- 明清方志中大量记载此类用物，名称因地而异（「打狗棒」「打狗饼」「五谷囤」「过桥饼」「路引」）。
- 这类器物的共同特征是**「解决具体困难的实用逻辑」**，与礼经「明器不用」的象征逻辑形成有趣对照。
- 当代土葬地区仍有保留，火化地区多已不用。

## 三、仪节流程

（用物的置放）

1. **备物**：入殓前备齐各类用物，多由女儿、儿媳置办。
2. **五谷袋**：以红布缝小袋，装五谷（麦、黍、稻、豆、稷），置于死者手中或棺角，寓「阴间有粮不饿」。
3. **打狗棒与打狗饼**：以木棒（或柳枝）系饼若干，置于死者手中或袖中，寓「遇狗以饼掷之、以棒驱之」。俗谚「打狗棒，过狗山」。
4. **过桥饼／桥板**：以饼与（象征性的）小木板随葬，寓「过奈何桥有饼果充饥、有板铺路」。
5. **路引**：部分地区置「路引」（写有死者姓名、籍贯的纸），作「阴间通行凭证」。
6. **铜镜、剪刀**：体积小者置于棺内，寓「照妖」「辟邪」。
7. **生前爱物**：书籍、笔、眼镜、烟斗、梳子、首饰等，视身份而定。
8. **点验登记**：由长者在场点验，部分地区记入丧事账册。

## 四、地域与民族变体

- **华北**：以「打狗棒」「五谷袋」「打狗饼」最常见，讲究「成双」。
- **江南**：除以上外，另有「过桥饼」「桥板」，并置铜镜、剪刀。
- **闽粤**：多置「路引」「冥途指南」，讲究纸制器物的书写格式。
- **客家（二次葬）**：初葬用物较简，拾骨入瓮时另有一套。
- **少数民族**：随葬逻辑不同。彝族随葬生产工具与银饰，意在「在祖界继续劳作」；苗族以银饰随葬，兼具「财富」与「族群标记」意义；藏族天葬与回族速葬均不置随葬品。**各族的「死后所需」观念不同，用物也随之不同。**

## 五、器物与文书

- **五谷袋**：红布小袋，装五谷。
- **打狗棒、打狗饼**：木棒与饼。
- **过桥饼、桥板**：纸制或面制。
- **路引**：写死者姓名的纸。
- **铜镜、剪刀、玉塞**：辟邪与塞窍之物。
- **生前爱物**：视身份而异。
- **丧事账册、随葬清单**：部分家族留存。
