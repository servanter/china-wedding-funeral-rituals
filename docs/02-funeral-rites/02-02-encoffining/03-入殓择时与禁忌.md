# 入殓择时与禁忌

## 一、释义

入殓须择时，是丧俗中最受重视的择日环节之一。择时的内容包括：**日期**（何日入殓）、**时辰**（何时刻入殓）、**方位**（棺木陈放的方向）、**回避之人**（哪些属相、哪些身份的人须回避）。

其观念基础是：入殓是生者与死者「分界」的瞬间，若时辰、方位、人员不当，可能「冲煞」而于生者不利。

## 二、历史源流

- 礼制上大殓有定时：《仪礼·士丧礼》定大殓于小殓之次日；《礼记·王制》定「殡」的期限依等级。
- 唐宋以后择日术介入丧礼。《协纪辨方书》（清乾隆敕撰）系统整理了择吉的规则，包括丧葬择日。
- 明清方志中大量记载入殓择时的讲究，如「必取吉时，忌与死者生肖相冲」「入殓时忌孕妇、产妇、寡妇在场」。
- 民间有「重丧」之说：认为某些日子入殓、出殡会「重丧」（即家中再死人），须以特定方法「化解」（如「做七」时多请一道士、在棺上置公鸡、以符箓压镇）。
- **说明**：这类禁忌属民间俗信，无科学依据，本条目作民俗记录，不作提倡。

## 三、仪节流程

1. **请人择时**：请阴阳先生或依黄历择定入殓的日与时辰。
2. **确定方位**：定棺木的停放方位与头向（依山向、宅向、八字）。
3. **列回避名单**：写明与死者生肖相冲者、须回避的身份（孕妇、产妇、经期妇女、属相相冲者等），贴于门口。
4. **清场**：入殓开始时，依名单清场，回避者退出。
5. **候时**：到择定之时辰，鸣炮示意，开始入殓。
6. **行仪**：举尸入棺、加衣填实、盖棺。
7. **撒镇物**：部分地方在棺上加放公鸡、镜子、尺、符箓，或撒五谷。
8. **解忌**：事后若认为有犯，请道士或僧人做「解煞」仪式。

## 四、地域与民族变体

- **北方**：讲究「入殓不过午」，忌在午后入殓；忌属相相冲者在场。
- **江浙**：讲究「入殓时辰须避三煞」，棺内放灯心草、木炭。
- **闽台**：讲究「看时辰」，由「土公」与道士共同确定；入殓时放「生肖回避牌」。
- **广东**：讲究「入殓不宜见天光」（在室内进行），并忌在农历「重丧日」入殓。
- **少数民族**：入殓（或类似环节）的时机多由宗教人士决定。彝族由「毕摩」占卜，藏族由喇嘛依藏历定，维吾尔族等穆斯林民族则因速葬（当日或次日）而无择时之说，其时间由教法规定的殡礼时间决定。**择时观念的来源不同：汉族基于干支命理，上述民族基于宗教历法或教法。**

## 五、器物与文书

- **黄历、择日书、罗盘**：择时定位之具。
- **生肖回避牌／回避单**：贴于门口。
- **公鸡、镜子、尺、符箓**：镇物（民俗）。
- **五谷、朱砂**：撒镇之物。
- **炮竹**：示意时辰。
