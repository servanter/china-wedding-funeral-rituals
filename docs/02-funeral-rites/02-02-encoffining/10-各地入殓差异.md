# 各地入殓习俗差异

## 一、释义

本条对入殓习俗的区域差异作横向比较，从**时间、仪式、器物、禁忌**四个维度归纳南北与东西之别。

（各地完整记录见「汉族各地域丧俗变体」各条，本条为归纳性对照。）

## 二、历史源流

- 礼经只提供一种范式（士礼：小殓次日大殓），但各地实际执行的差异极大，主要受气候（南方须速殓）、经济（棺木厚薄）、宗族（是否等齐亲属）、宗教（佛道介入程度）影响。
- 明清方志是重要的比较材料来源。胡朴安《中华全国风俗志》汇集了大量民国时期的实地记录，是横向比较的基础文献。
- 近代以来火化的推行与城乡差异，进一步扩大了区域差别。

## 三、区域差异对照

### 时间

| 区域 | 入殓时间 |
| --- | --- |
| 华北 | 多为死后三日，讲究「不过午」 |
| 江南 | 一日至三日，夏季多当日或次日 |
| 闽台 | 12—24 小时内入殓，讲究「看时辰」 |
| 广东 | 一至三日，讲究「不见天光」 |
| 客家 | 三日左右，为「二次葬」作准备 |

### 仪式

- **华北**：入殓前「开光」，入殓时「子孙钉」由诸子依次钉。
- **江南**：入殓与「小殓、大殓」分日进行，程序层次清楚。
- **闽台**：入殓由「土公」操作，道士在场诵经；入殓后设「魂帛」。
- **广东**：入殓与「买水」「报地」等环节相连。
- **客家**：初葬从简，重视数年后的「捡骨」。

### 器物

- **谷袋、打狗棒**：南北皆有，名称与形制不同。
- **闽粤**：多用「路引」等纸制文书类器物；另有「金斗瓮」（二次葬地区）。
- **江南**：讲究「铺金盖银」、铜镜、剪刀。
- **华北**：讲究棺内放「五谷囤」「元宝」。

### 禁忌

- 共同者：忌泪落尸身、忌猫狗近尸、忌属相相冲者到场、忌孕妇送殓。
- 差异者：南方多忌「雨淋棺」，北方多忌「见星」（夜间入殓）。

## 四、地域与民族变体

- 以上「区域」均限于汉族聚居区，已含广府、潮汕、客家、徽州等民系。
- **民族层面**：入殓这一环节在部分民族中不存在（藏族天葬、穆斯林速葬），在部分民族中形式不同（苗族「圆木棺」、瑶族「岩棺」、侗族「船棺」）。须与汉族入殓分别记录，不可作「差异变体」处理。
