# 装殓仪节与随葬铺陈

## 一、释义

装殓，即遗体入棺之后，在棺内的铺、垫、填、塞与随葬品安放的全套操作。其讲究集中在两点：**姿态**（尸体须平稳端正）与**次序**（何物置于何处）。

装殓的实质是「以物定形」：用铺垫与填塞使遗体在棺中固定，以随葬品安置其「死后所需」。

## 二、历史源流

- 《仪礼·士丧礼》记「实」之仪：入棺后以衣、贝、米等「实」于棺内空隙，使尸体不动摇。
- 《礼记·丧大记》记棺内铺垫：「君殡用輴，攒至于上，毕涂屋。」对棺内外的处置有详细规定。
- 考古所见墓葬中，棺内陈设极为丰富：马王堆汉墓的棺内多层丝织物包裹、满城汉墓的玉衣、历代墓葬的「七窍塞」（玉塞塞九窍）。
- 汉代盛行玉衣（金缕、银缕、铜缕），是等级最高的装殓制度。
- 唐宋以后，随葬的宗教性物品增加：写有经文的纸、铜镜（照妖）、五谷袋（粮食）、打狗棒（打狗饼）等。
- 明清以后民间装殓讲究定型：**铺金盖银、垫枕、手握元宝、口含钱、脚踩莲花**——形成固定的「配套」。

## 三、仪节流程

1. **铺底**：棺底铺灰、木炭（吸湿）、灯心草、绸布或「铺金」（黄绸）。
2. **垫枕**：头下置枕（「鸡鸣枕」「元宝枕」），使头部略高。
3. **安放遗体**：举尸入棺，使身体平正、面朝上、手分两侧（或交叠于腹）。
4. **填实**：以衣物、棉纸、丝绵等填塞尸体四周及棺内空隙，使遗体不移。
5. **盖被**：身上覆「盖银」（白绸）或殓被。
6. **安放开光物**：部分地方在遗体手中放元宝、铜钱，脚下放「莲花」（纸制或布制）。
7. **置随葬品**：按俗放置：
   - **五谷袋**：盛五谷，寓「不饿」；
   - **打狗棒、打狗饼**：寓「过阴间遇狗可有物驱之」；
   - **铜镜**：寓「照妖」；
   - **生前爱物**：书籍、笔、烟斗、梳子、首饰等；
   - **明器**：陶俑、陶器、纸扎（另置，不全部入棺）。
8. **点验**：由长者在场点验随葬品数目。
9. **盖棺**：暂停加盖，或即时加盖（见「盖棺与钉棺」条）。

## 四、地域与民族变体

- **华北**：讲究「铺金盖银」「手握元宝」「脚踩莲花」；棺内放五谷袋、打狗饼。
- **江南**：讲究「头枕元宝、脚蹬莲花」，棺内放铜镜、剪刀（辟邪）。
- **闽粤**：棺内多置金银首饰与「纸制冥器」，讲究成双。
- **客家（二次葬地区）**：初葬棺内陈设较简，数年后拾骨入「金斗瓮」时另有一套陈设。
- **少数民族**：随葬品内容反映其信仰。彝族随葬生产工具、银饰；苗族随葬银饰与织锦；藏族天葬不置随葬品；回族、维吾尔族因教法规定，**不设随葬品**（教法认为随葬无用，唯凭善功）。这一差异是教义性的，不是「简省」。

## 五、器物与文书

- **铺金盖银**：黄、白绸布。
- **鸡鸣枕、元宝枕**：头枕。
- **五谷袋、打狗棒、打狗饼**：民俗用物。
- **铜镜、剪刀、玉塞**：辟邪与「塞窍」之物。
- **明器、陶俑、纸扎**：随葬品（详见「丧葬器物明器」板块）。
- **随葬品清单**：部分家族开列，收入丧事账册。
