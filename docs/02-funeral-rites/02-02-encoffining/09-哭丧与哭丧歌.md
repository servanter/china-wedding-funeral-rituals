# 哭丧与哭丧歌

## 一、释义

哭丧，是丧礼中以哭泣表达哀情的礼节性行为。在礼制中，哭有**规定的方式、时节与声音等级**：

- **哭**：有声有泪。
- **泣**：有泪无声。
- **号**：放声呼号。
- **踊**：跳脚而哭，是最激烈者。

哭丧歌则是哭丧时唱出的韵语，把「哭」形式化为有节奏、有词句的歌哭。民间认为「哭得好」是对死者的敬重，也是孝道的公开证明。

## 二、历史源流

- 《礼记·檀弓》：「始死，充充如有穷。」记哀情的形态；又记「哭之日，不闻乐」等规定。
- 《礼记·丧大记》对哭的时节有详细规定：「始卒，主人啼，兄弟哭，妇人哭踊。」不同身份者的哭法有别。
- 《仪礼·士丧礼》记哭位：主人（男）在东方，主妇（女）在西面，男女分位而哭。
- 哭丧歌（挽歌）的传统极早：《诗经·秦风·黄鸟》为挽歌之滥觞；汉代有《薤露》《蒿里》（田横门人所作，后为通用挽歌），《晋书·礼志》记「挽歌」之制。
- 唐宋以后，民间哭丧渐成有腔调的「哭调」「哭歌」；明清方志中记「哭丧歌」「挽歌」「哭灵调」。
- 出现职业化现象：部分地区有雇人代哭（「哭丧婆」「代哭」）之俗，属陋俗，须批判看待。

## 三、仪节流程

1. **始死之哭**：气绝后，家人举哀。男子「括发」，女子「去笄」；主人啼，兄弟哭，妇人哭踊。
2. **入殓之哭**：入殓时哭踊最为激烈（《仪礼》「主人哭踊无算」）；每加一衣，哭一次。
3. **朝夕之哭**：朝夕奠时按例哭；宾客来吊时哭。
4. **哭位**：男东女西，男女分位不混。
5. **哭丧歌**：由主哭者（多为亡者的女儿、儿媳、妻子）领唱，众人和，依内容可分为：
   - **哭父母**：述养育之恩；
   - **哭夫／妻**：述夫妻情分与持家之难；
   - **哭灵**：在灵前叙述亡者一生经历；
   - **哭送**：出殡时哭送；
   - **哭相**：数落丧事安排（民俗中具有监督丧事办得体面与否的功能）。
6. **收哭**：出殡下葬后，哭丧渐转为祭奠时的低声追念。

## 四、地域与民族变体

- **华北**：哭丧调高亢，「哭灵」时多有固定词句，如「我的×呀——」起腔。
- **江浙**：哭丧调婉转，「哭七」「哭灵」成套，讲究词句工整。
- **湘鄂川黔**：哭丧歌最发达，与「哭嫁」同源，有一套完整的「哭」的唱词体系（参见「哭嫁」条的对照）。
- **闽台**：哭丧调带海风腔，常与道士诵经结合。
- **少数民族**：彝族的「哭丧歌」、苗族的「丧歌」、土家族的「丧鼓歌」均成体系，且带有本民族的神话内容（如述说祖先迁徙路线、亡灵归祖的路途），其功能超出「抒情」，兼有**指路与族史传承**的作用，须与汉族哭丧分别记录。

## 五、器物与文书

- **无特定器物**：以人声为核心。
- **哭丧歌抄本**：部分地方有传抄本，多见于《中国歌谣集成》等整理成果。
- **灵位、棺前陈设**：哭丧的空间背景。
- **录音记录**：当代非遗调查成果。
