# 棺椁形制与选材

## 一、释义

- **棺**：直接盛放尸体的葬具，又称「柩」（已入尸之棺称柩）。
- **椁**：套在棺外的大棺，形如外箱，起保护棺木与等级标志的作用。天子、诸侯有椁，士庶多无椁。

棺椁的形制、层数、用材、髹漆，是丧葬制度中等级色彩最强的部分。「棺椁之厚薄，以其爵等为之差」。

## 二、历史源流

- 《礼记·檀弓》记棺的等级：天子棺四重（四层），诸侯三重，大夫二重，士一重；并记「棺椁之制」的尺寸。
- 《礼记·丧大记》记棺的用材：君「松」，大夫「柏」，士「杂木」。另有「柏椁」为诸侯之制。
- 《仪礼·士丧礼》详记士的棺制（「棺自西阶」入）。
- 考古所见：商周木椁墓（如曾侯乙墓的巨型木椁）、汉代「黄肠题凑」（以柏木黄心向内堆垒的椁）、唐宋以后的砖室墓与石椁，均为棺椁制度的重要实物。
- 明清民间棺木以杉、柏、楠、桐为主，讲究「三、四、五」（三寸底、四寸帮、五寸盖）的厚度规格，俗称「四五六」「三五」。
- 20 世纪中期推行殡葬改革，土葬与棺木逐渐为火化取代，棺木在多数城市已不用。

## 三、仪节流程

（棺木的制作与使用流程）

1. **备材**：择木——杉木最常用（轻、耐腐、易加工），柏木为上（细密、故「柏」有「迫」之意），楠木为贵，桐木、松木次之。忌用柳、杨（部分地区），忌用曾有虫蛀、雷击之木。
2. **制棺**：由棺木匠（「大木匠」）按规格锯、拼、榫接。传统棺不用钉而用榫卯与木楔（「子孙钉」为钉棺之钉，取义不同）。
3. **髹漆**：棺外髹漆（黑漆、红漆），讲究层次与光泽。红棺用于年长者、白棺（素棺）用于年少者或特定情形。
4. **铺垫**：棺内铺灰、木炭、灯心草、绸布、棉花，用以吸湿防腐。
5. **入殓**：举尸入棺，加衣填实（详见「装殓仪节与铺陈」条）。
6. **盖棺钉棺**：加棺盖，钉「子孙钉」（详见「盖棺与钉棺」条）。
7. **加棺罩**：出殡时加棺罩（绣罩），详见「棺罩与抬棺」条。

## 四、地域与民族变体

- **华北**：棺木多用柏、杉，讲究「四五六」的厚度，「红棺」为老年人之用。
- **江南**：讲究「十二元」「十八元」（棺板件数），以少件为贵；以「独板」为最上。
- **闽粤**：讲究「阴木」（阴沉木、楠木），厚棺重漆；「二次葬」地区用「金斗瓮」（骨瓮）而非棺。
- **客家**：有「捡骨葬」（二次葬）之俗，初葬用棺，数年后拾骨入瓮。
- **少数民族**：棺制差异很大。苗族、彝族、侗族等有本民族棺材（如「船棺」「圆木棺」）；藏族天葬不用棺；回族、维吾尔族以白布裹身不用棺；瑶族部分地区用「岩棺」。**棺不是普适的葬具，其形态与该民族的葬式直接绑定。**

## 五、器物与文书

- **棺（柩）**、**椁**：核心葬具。
- **棺饰**：棺衣、棺罩、帏帐。
- **子孙钉、木楔**：钉棺之具。
- **灰、木炭、灯心草**：防腐铺垫。
- **漆、桐油**：髹漆材料。
- **棺单（葬具清单）**：部分地区开列。
