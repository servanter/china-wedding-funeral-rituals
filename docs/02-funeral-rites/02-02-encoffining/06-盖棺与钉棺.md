# 盖棺与钉棺礼俗

## 一、释义

盖棺，是加棺盖之动作；钉棺（「封棺」「煞扣」），是以木楔或铁钉将棺盖与棺体固定之礼。

钉棺在民俗中是**生死彻底分隔的瞬间**：钉棺之后再不能见亲人面容，故钉棺时家属多行最激烈的哭别。俗谚「盖棺论定」即由此出——一经钉棺，一生功过成定局。

## 二、历史源流

- 《仪礼·士丧礼》记「乃盖」，即加盖之仪；礼制上大殓后加棺盖，但具体的「钉棺」名目在礼经中不显。
- 汉代棺制用榫卯与「细腰合缝」木楔，考古所见棺盖与棺身的固定方式以榫卯为主，用钉为后世的简便做法。
- 唐宋以后「钉棺」之俗见于记载，并有「子孙钉」之称——钉棺之钉留一钉由长子（或诸子）各捶一下，称「子孙钉」，取义为「子孙兴旺」「钉住家业」。
- 明清方志记钉棺时的讲究：「钉棺时忌外人入房，忌属相相冲者在场」「钉棺时由长子先钉，其余诸子依次」。
- 部分地区钉棺后「封漆」——以生漆封缝，防潮防腐，并寓「永固」之意。
- 当代火化制度下，钉棺仅存于土葬地区与仪式复原场景。

## 三、仪节流程

1. **最后的告别**：钉棺前，亲属依次至棺前看最后一眼，哭别（「瞻仰遗容」「见最后一面」）。
2. **清场**：请生肖相冲者、孕妇、产妇等回避（民俗）。
3. **试探**：抬棺盖虚掩，检查遗体姿态、随葬品位置。
4. **盖棺**：由执事者数人合力抬盖，对准榫卯（或钉孔）放下。
5. **钉子孙钉**：由长子先钉第一钉，诸子依次各钉一钉，称为「子孙钉」；有的地方留最后一钉不钉，谓「留一线生机」（部分地区）。
6. **封漆**：以生漆、桐油调灰封抹棺缝与钉孔。
7. **覆棺罩**：加棺罩（绣罩）覆盖，遮蔽钉孔与缝隙。
8. **设位哭奠**：钉棺后设奠，家属痛哭，此后进入停灵阶段。

## 四、地域与民族变体

- **华北**：称「钉棺」「煞扣」，「子孙钉」之俗普遍。
- **江浙**：称「封棺」，讲究「留一钉」或不留，各地说法不一。
- **闽台**：称「封棺」，多在出殡前一日或当日晨进行，由「土公」操作。
- **部分地区**：钉棺时高呼「×××躲钉啊！」，提醒死者魂魄避开，是极生动的民俗细节。
- **少数民族**：多数民族无「钉棺」之礼。穆斯林民族不钉棺（不用棺）；藏族以天葬为主，无棺；苗族、彝族等的棺盖固定方式各有其俗，未必用钉。**「钉棺」是汉族棺葬的特定仪节，不宜推及他族。**

## 五、器物与文书

- **棺盖、棺钉（子孙钉）、木楔**：钉棺之具。
- **生漆、桐油、灰料**：封缝之用。
- **锤、凿**：工具。
- **棺罩**：覆盖棺木的绣罩。
- **奠席、香烛**：设奠用具。
