# 开光（开眼光）

## 一、释义

开光，是入殓时为死者「开启」五官之仪式：以棉签（或毛笔、柳枝）蘸清水（或酒、茶），依次点触死者的眼、耳、鼻、口（有的还有手、脚），每点一处即念一句吉祥套语。

其观念是：人在死时五官「闭合」，行开光之礼可使死者在阴间「看得见、听得着、吃得到、走得动」。俗称「开眼光」「开面」。

## 二、历史源流

- 开光在礼经中无载，是民俗层面的仪式。其「以物点触」的动作形态，与佛教「开光」（为佛像点睛启用）有形式上的相似，但**丧俗的开光是「为死者开启感知」，与佛像开光的「为神像注灵」在对象与含义上不同**，两者不宜混同。
- 明清方志与笔记中「开光」记载较多，多与入殓合并，且在部分地方由道士、僧人主持。
- 开光的「套语」是其核心：多为四字或八字的顺口话，如「开眼光，看四方」「开耳光，听八方」「开鼻光，闻花香」「开嘴光，吃供香」。
- 部分地区另有「洗手」「洗脚」的套语：「洗手光，拿钱粮」「开脚光，走四方」。
- 当代土葬地区与仪式复原场景中仍可见。

## 三、仪节流程

1. **备物**：备棉签（或毛笔、柳枝）一支，清水（或酒、茶）一小碗。
2. **择人**：由丧主（长子）或全福人、主持仪式的道士（僧人）执行。
3. **依序点触**：
   - **眼**：「开眼光，看四方」——点两眼。
   - **耳**：「开耳光，听八方」——点两耳。
   - **鼻**：「开鼻光，闻花香」——点两鼻孔。
   - **口**：「开嘴光，吃供香」——点口。
   - **手**：「开手光，拿钱粮」——点两手（部分地区）。
   - **脚**：「开脚光，走四方」——点两脚（部分地区）。
4. **祝语收尾**：念「×××，开光已毕，一路走好」之类。
5. **入殓**：开光多在大殓之前或之中进行，随后入棺。

## 四、地域与民族变体

- **华北**：称「开光」，多由长子以棉签蘸水为死者点五官，套语押韵成套。
- **江浙**：称「开光」「开面」，某些地区由道士诵经后主持。
- **闽台**：称「开光」，由「司公」（道士）或「土公」执行，套语用闽南语押韵。
- **广东**：称「开光」，用酒或茶点触，套语用粤语。
- **少数民族**：部分民族有类似的「为亡者开启感知」的仪式，但多与宗教仪轨结合，如藏族由喇嘛诵经并作「指引」（《中有闻教得度密法》即「中阴闻教得度」），其内容是**教导亡者在中阴阶段辨识光明**，与汉族「开五官」的朴素观念层次不同，不可混述。

## 五、器物与文书

- **棉签、毛笔、柳枝**：点触之具。
- **清水、酒、茶**：所蘸之物。
- **套语（开光词）**：口传韵语，部分地方有抄本。
- **香烛、供品**：仪式陈设。
