# 入殓禁忌

## 一、释义

入殓是丧礼中禁忌最密集的环节，涉及**泪、物、人、时**四方面。

| 类别 | 禁忌 |
| --- | --- |
| **泪** | 忌**泪水落在尸身**（「泪落尸上，死者不安」）；哭泣时须背身或侧身 |
| **动物** | 忌**猫、狗近尸**（「猫惊尸」「借气而起」之说）；忌鸡飞入殓房 |
| **衣物** | 忌用**皮毛**（「恐来世为畜」）；忌用**缎子**（谐音「断」）；忌用**纽扣**（用带系）；忌**双数**件数 |
| **人物** | 忌**生肖相冲者**在旁（见「冲煞与生肖禁忌」条）；忌孕妇、产妇临殓 |
| **时** | 忌**重丧日**入殓；忌在日落后入殓（各地不一） |
| **器物** | 忌以**铁器、镜子**入棺；棺内忌留**金属、塑料**不化之物 |
| **言语** | 忌在殓房说「再来」「少见」等语；忌呼生者姓名 |

**相关讲究**：棺内放「打狗饼」「纸钱」「五谷袋」等；下葬后忌「回头看」。

## 二、历史源流

- **先秦**：《仪礼·士丧礼》详载大殓之仪；「袭」「饭含」诸节皆有仪注。
- **汉唐**：入殓之礼与禁忌在《礼记》注疏及方志中渐多记载。
- **明清**：入殓禁忌在地方志「风俗」门与民间日用类书中大量记录。
- **近代以来**：农村禁忌较完整；殡仪馆以卫生规范为主，禁忌减少。

## 三、仪节流程

1. **净身、著衣**：寿衣穿戴（见「寿衣」条）。
2. **入棺**：抬尸入棺，头朝内、脚朝外（或依地方）。
3. **掩殓（小殓、大殓）**：覆衾、加棺盖。
4. **盖棺钉封**：亲属最后瞻视后钉棺。
5. **避忌行事**：相冲者回避，哭泣侧身，忌语忌物。

## 四、地域与民族变体

- **华北**：忌猫近尸之说最盛；入殓多在夜间或清晨。
- **闽台**：入殓讲究时辰，忌生肖相冲者在场。
- **江南**：忌泪落尸身，讲究棺内铺垫与随葬小件。
- **少数民族**：各民族入殓禁忌内容不同（忌某类动物、忌某些人在场），其依据为本族信仰，须分别记录。

## 五、器物与文书

- **棺内随葬**：五谷袋、打狗饼、纸钱、小型明器。
- **寿衣**（忌缎、皮毛）。
- **文书**：入殓单（列入殓时辰与禁忌事项）。
