# 出殡时辰与方位禁忌

## 一、释义

出殡（发引）的**时辰**与**方向**皆须择定，二者同属丧期择吉的核心。

**时辰**：
- 多择「**辰时**」（早 7—9 时）或「寅时」「卯时」起灵，取「早起早行」「不走夜路」之意。
- 忌「重丧时」「空亡时」；有的地区忌午后出殡（「不送落日」）。

**方向**：
- 出殡路线忌「**走回头路**」，忌与来时路重复。
- 忌「**煞方**」（重丧煞、岁煞）——棺木出门须避当值凶方。
- 棺出门后忌「**碰门框、撞门柱**」。
- 「**抬棺不落地**」（中途不得落地，落地为凶）；「**不回头**」（送葬人不得回头张望）。

## 二、历史源流

- **先秦**：出殡之礼见于《仪礼·既夕礼》；时日的选择初以「卜日」「卜宅」为方式。
- **唐宋**：阴阳择时之说盛行，出殡时辰与方位的选择趋于细密。
- **清代**：《协纪辨方书》系统整合各种神煞与方位宜忌。
- **近代以来**：农村仍严守时辰与方向；城市以交通与殡仪馆安排为主，禁忌淡化。

## 三、仪节流程

1. **择时**：先生推定时辰，开具日单。
2. **起灵**：撞门、摔盆，棺出户。
3. **定路线**：避开凶方与禁忌路段，不走回头路。
4. **途中**：抬棺不落地，撒纸钱（买路钱），不回头。
5. **入圹**：依定时刻放棺、封墓。

## 四、地域与民族变体

- **华北**：重「不回头」「棺不落地」，沿途撒纸钱。
- **闽台**：出殡看「三煞方」，忌「煞方」开门。
- **江南**：多择清晨出殡，路线事先踏勘。
- **少数民族**：有的民族以占卜定出殡方向（如彝族毕摩掷木卦、藏族以星算择时），其依据与汉族神煞体系不同源，须分别记录。

## 五、器物与文书

- **择吉依据**：《协纪辨方书》通书、历书。
- **文书**：日单、出殡路线单。
- **器物**：杠具、纸钱、丧盆、灵幡。
