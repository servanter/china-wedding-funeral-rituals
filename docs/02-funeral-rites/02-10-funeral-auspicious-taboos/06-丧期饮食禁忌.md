# 丧期饮食禁忌

## 一、释义

丧期饮食限制源自《礼记》的**居丧之礼**（饮食递减），在民间演为若干具体禁忌。

| 类别 | 内容 |
| --- | --- |
| **忌荤腥** | 孝子孝女在丧期（尤其百日或五七内）不食荤，只食素 |
| **忌酒** | 「居丧不饮酒」；丧宴虽有酒，但孝子不饮或以茶代 |
| **忌盐** | 部分地区初丧「忌盐」（「不食盐」以示哀痛） |
| **斋饭** | 做七、「五七」「百日」设「斋饭」「素席」，僧道诵经时尤严 |
| **丧饭** | 丧家备「丧饭」「流水席」待客，但孝子常另设素席 |
| **忌喜庆食物** | 忌食年糕、汤圆等节庆之物；忌在丧家办「喜酒」 |
| **忌面食（部分地区）** | 有的地方忌「吃面」，以为「面长」于孝期不宜 |

**礼义**：《礼记·间传》以「三日不食 → 食粥 → 疏食水饮 → 菜果 → 复常」的递减序列，体现「哀之杀」；民间禁忌即此礼的通俗化。

## 二、历史源流

- **先秦**：《礼记·间传》定居丧饮食之节。
- **汉唐**：居丧饮食入律，「居丧作乐及食肉」有罚。
- **宋明**：《家礼》规范丧期饮食；佛教「斋饭」「素席」之俗与丧礼结合。
- **明清**：地方志「风俗」门多记「丧家不食肉」「孝子百日不茹荤」等俗。
- **近代以来**：农村保留较多；城市仅守「五七设素席」「丧宴不劝酒」等。

## 三、仪节流程

1. **初丧**：孝子停食（形式化），继而食粥。
2. **殡期**：丧家以素席待客，孝子不食荤酒。
3. **做七**：设「斋饭」，僧道诵经，家人素食。
4. **百日／周年**：渐次开荤。
5. **除服**：饮食复常。

## 四、地域与民族变体

- **华北**：孝子「百日不茹荤」之说较普遍。
- **闽台**：丧宴称「白席」，以素为主，孝子禁酒。
- **江南**：做七设「素席」，请僧道诵经用斋。
- **少数民族**：饮食禁忌多与宗教信仰相关（如回族的清真饮食、藏族的忌食规定），其依据与本族信仰相连，须分别记录。

## 五、器物与文书

- **饮食器物**：素席餐具、斋饭器皿。
- **相关文书**：丧宴席单、斋饭单。
- **文献依据**：《礼记·间传》《家礼》。
