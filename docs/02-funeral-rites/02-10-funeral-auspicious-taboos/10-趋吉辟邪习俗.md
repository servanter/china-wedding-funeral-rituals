# 趋吉辟邪习俗

## 一、释义

丧事被视为「凶事」，故须以**辟邪之物与仪式**化解，祈求「趋吉避凶」。

| 习俗 | 做法 | 解释 |
| --- | --- | --- |
| **桃枝、柳条** | 插于门首、置于棺侧或孝子手中 | 桃木为「五木之精」，能驱鬼 |
| **朱砂、鸡血** | 点主、破土、画符用 | 朱红辟邪，血为生气 |
| **符箓** | 贴于门、棺、孝服 | 道教符法镇邪 |
| **镜子、剪刀** | 悬于门首或棺侧（部分地区） | 反射邪气 |
| **糯米饭、白米、盐** | 撒于棺内、路上 | 驱邪、镇煞 |
| **引魂鸡** | 出殡时以公鸡引路 | 「金鸡引路」 |
| **跨火盆、过桥** | 送葬归来跨火、过「平安桥」 | 以火净身，隔断晦气 |
| **净宅（净屋）** | 葬后以香、符水洒扫房屋 | 清除丧气 |
| **回灵吃糖、红蛋** | 送葬归来发糖、红蛋 | 「压惊」「转吉」 |
| **孝布「回礼」** | 赠亲友白布、糖 | 「散孝」以分晦气 |

## 二、历史源流

- **先秦**：《周礼》方相氏驱疫、桃茢（桃枝扫帚）之礼已见辟邪之用。
- **汉魏**：《荆楚岁时记》等记桃符、艾、菖蒲等辟邪之物。
- **唐宋**：道教符箓、佛教法事与丧葬结合，辟邪习俗系统化。
- **明清**：地方志大量记录「丧后净宅」「跨火」「散孝」之俗。
- **近代以来**：农村保留完整；城市保留「跨火」「吃糖」「白包回礼」等。

## 三、仪节流程

1. **设防**：初丧即插桃枝、贴符于门首。
2. **入殓**：棺内放五谷、纸钱、桃木小件。
3. **出殡**：引魂鸡引路，撒纸钱。
4. **下葬**：破土洒鸡血或朱砂。
5. **归来**：跨火盆、过桥、净宅、散糖——完成「转吉」。

## 四、地域与民族变体

- **华北**：出殡归来「跨火盆」，丧家「撒糖」。
- **闽台**：送葬回程「净身」，门前备「净水盆」与桃枝。
- **江南**：「散孝」与「吃糖」普遍，归来不直接入宅。
- **少数民族**：各族辟邪方式丰富（如藏族煨桑、彝族毕摩诵经驱邪、傣族滴水），其信仰体系与汉族辟邪习俗不同源，须分别记录。

## 五、器物与文书

- **辟邪器物**：桃枝、柳条、朱砂、符箓、镜子、剪刀、公鸡、米盐。
- **仪节器物**：火盆、净水盆、红蛋、糖。
- **文书**：符纸、净宅疏文。
