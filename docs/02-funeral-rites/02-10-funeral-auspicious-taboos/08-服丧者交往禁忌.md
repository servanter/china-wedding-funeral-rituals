# 服丧者交往禁忌

## 一、释义

服丧者的社会交往受到严格限制，核心是「**不与吉礼相通**」。

| 场合 | 禁忌 |
| --- | --- |
| **婚娶** | 「**父母之丧，三年不娶**」；丧期内不为子女议婚、不下聘、不成亲（古律有罚） |
| **赴宴** | 忌赴喜庆之宴、忌饮酒作乐（「居丧不宴乐」） |
| **拜年** | 丧家**春节不拜年、不贴红对联**（贴白联或蓝联）；亲友亦不至丧家贺年 |
| **贺喜** | 忌送贺礼、忌参加满月、寿宴、乔迁等喜事 |
| **送礼** | 忌以红纸包、红礼盒；赙赠用白封 |
| **探访** | 忌入产妇房、病人房（「带孝冲喜」之忌）；忌参与建房上梁、开业等事 |
| **往来** | 孝子不主动登他人门；他人亦多不来拜（「不冲」） |
| **祭祀** | 「丧者不祭」——服丧者不参与宗庙、祠堂祭祀 |

**例外与变通**：客观上难以遵守者，有「百日」「除服」后的渐次解除；亦行「借孝」等变通（先行婚娶，后补丧服之礼）。

## 二、历史源流

- **先秦**：《礼记·曲礼》「居丧不言乐」「父母之丧，三年不娶」。
- **汉唐**：入律——「居丧嫁娶」为罪，唐律有明文处罚。
- **宋明**：礼法与宗族规约强化，族谱「家规」多列此禁。
- **明清**：地方志记录「丧家三年不贴红联」「孝子不贺年」。
- **近代以来**：农村保留较多；城市简化为「孝期不赴宴、不放焰火」等。

## 三、仪节流程

1. **成服**：宣布丧期交往禁忌（由都管知会亲友）。
2. **谢绝吉礼**：婉辞喜庆邀请。
3. **春节处理**：不贴红联、不放爆竹、不拜年。
4. **渐次解除**：五七、百日、周年、除服为节点。
5. **除服**：交往复常。

## 四、地域与民族变体

- **华北**：丧家春节贴蓝联或白联，三年不拜年。
- **闽台**：丧家「三年不做热闹」，不去他人家中拜年。
- **江南**：丧期不赴宴、不参加喜庆为主。
- **少数民族**：交往禁忌内容各异（禁参加特定集会、禁歌舞），其依据为本族信仰，须分别记录。

## 五、器物与文书

- **标志物**：孝服、孝带、白封（赙仪封包）、蓝联白联。
- **文书**：辞谢帖、知会单。
- **律令依据**：历代律令中「居丧嫁娶」条。
