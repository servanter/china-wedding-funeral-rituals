# 停灵日数与“七”的禁忌

## 一、释义

停灵（停柩）日数及其与「七」的关系，是丧期择时的重要一环。

**停灵日数**：
- 通行「**三、五、七**」日（单数为多，俗称「排三」「排五」「排七」）。
- 长者、富家可停「七七」四十九日乃至百日（「殡期」「搁材」）。
- 忌「双日」出殡者以「单数为阳」为解。

**「七」的体系**：自亡故日起，每七日为一「七」，至「七七」（四十九日）为终，称「**做七**」「烧七」。佛教以「中阴」四十九日之说为据（《释氏要览》等），道教亦有「七」的度亡安排。

| 节点 | 仪节 |
| --- | --- |
| **头七** | 孝子设祭、请僧道诵经 |
| **三七、五七** | 隆重；「五七」为「过七」之要 |
| **七七（断七）** | 除灵、焚化，丧事告一段落 |

**相关禁忌**：忌「犯七」（亡日与七日相冲）、忌在「七」日办喜事、忌「撞七」（出殡日与七日相撞）等。

## 二、历史源流

- **佛教传入后**：中阴四十九日之说与本土丧俗结合，形成「做七」。
- **唐宋**：做七之俗已极普遍（《东京梦华录》《梦粱录》有载）。
- **明清**：做七与佛道法事结合，成为丧仪的主干环节。
- **近代以来**：农村做七完整，城市简化为「头七」「五七」或仅在殡仪馆悼念。

## 三、仪节流程

1. **定停灵日数**：阴阳先生择定，通例三、五、七日。
2. **起七**：亡故日起「头七」设祭。
3. **逢七设祭**：每七日一祭，请僧道诵经。
4. **五七**：隆重设祭（有的地区视「五七」为「大七」）。
5. **七七断七**：除灵、焚化灵位、撤灵堂。

## 四、地域与民族变体

- **华北**：重「五七」，亲友齐集上坟。
- **闽台**：做七严谨，「六七」由女儿主祭（「女儿七」）。
- **江南**：做七与佛道法事并重，「五七」为要。
- **少数民族**：部分民族受佛教影响亦行「七」祭（如藏族以「七七」为超度期），但多数民族的丧期安排依本族信仰与生产方式，须分别记录。

## 五、器物与文书

- **祭品与法器**：香烛、供品、经书、法器。
- **文书**：做七单（列七七日期与仪节）、日单。
- **文献依据**：《释氏要览》《协纪辨方书》。
