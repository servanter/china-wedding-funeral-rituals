# 冲煞与生肖禁忌

## 一、释义

丧事择日的核心推算法之一是**干支与生肖的冲煞**：凡与死者日柱、葬日、葬方相冲的生肖，须**回避**相应仪节。

| 名目 | 含义 | 应对 |
| --- | --- | --- |
| **犯冲（生肖相冲）** | 十二生肖相冲（如子午冲、丑未冲） | 相冲者在入殓、出殡、下葬时回避 |
| **犯太岁** | 某生肖与当年太岁相冲、相刑、相害 | 佩戴「太岁符」或回避 |
| **三煞方** | 年、月「三煞」所在方位 | 出殡、破土避其方 |
| **重丧煞方** | 重丧日当值之方 | 棺木出门避之 |
| **岁破、月破** | 与岁、月支相冲 | 忌安葬、破土 |
| **空亡** | 干支旬空 | 忌安葬 |

**回避方式**：相冲者于特定时刻「**转身不见**」或暂避门外；有的地区请相冲者「**系红布**」（红可解）；出殡时以「**解冲符**」贴在孝服或棺上。

## 二、历史源流

- **汉代**：干支择日与「太岁」观念已见于《日书》《论衡》。
- **唐宋**：阴阳五行择吉之学大兴，生肖冲煞推算法成熟。
- **清代**：《协纪辨方书》对神煞、方位宜忌作系统整理。
- **近代以来**：农村丧事严格依通书推算；城市多不讲究。

## 三、仪节流程

1. **报生肖**：丧家将各人生肖报知先生。
2. **推算**：先生推出冲煞生肖与时辰。
3. **回避安排**：相冲者于入殓、出殡、下葬时回避或系红布。
4. **择向**：出殡、破土避开三煞、岁破之方。
5. **解煞**：必要时行「解冲」之仪。

## 四、地域与民族变体

- **华北**：忌「属相相冲」者在入殓时近前。
- **闽台**：出殡看三煞方，孝眷生肖相冲者回避。
- **江南**：以「解冲符」「系红」为常见化解法。
- **少数民族**：各族占卜与回避规则各异（如以本族历法、占卜定忌），与汉族生肖冲煞不属同一体系，须分别记录。

## 五、器物与文书

- **择吉依据**：通书、历书、《协纪辨方书》。
- **器物**：符纸、红布、罗盘。
- **文书**：择日单（列冲煞生肖与回避事项）。
