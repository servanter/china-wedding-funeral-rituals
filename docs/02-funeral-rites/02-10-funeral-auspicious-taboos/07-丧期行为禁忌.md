# 丧期行为禁忌

## 一、释义

居丧期间的行为限制，古礼称「居丧之礼」，民间演为具体禁忌。

| 类别 | 禁忌 |
| --- | --- |
| **身体** | 忌**理发、剃须**（「蓄发百日」，男子不剃头刮脸，女子不梳妆） |
| **妆饰** | 忌涂脂粉、佩首饰、穿彩衣 |
| **娱乐** | 忌看戏、听曲、打牌、宴饮；忌在家中奏乐 |
| **往来** | 忌**串门**（孝子不登他人之门）、忌走亲访友、忌到产妇家 |
| **起居** | 忌房事（「居丧不居内」）；忌坐他人床、忌坐上位 |
| **器物** | 忌**照镜子**（部分地区）；忌坐门槛；忌手触他人头部 |
| **言语** | 忌说「再见」「恭喜」；忌呼名呼姓；忌在丧家言笑 |
| **出行** | 部分地区忌丧期内远行、忌乘舟（「不渡」） |

**「孝子不登门」**是最通行的禁忌之一：居丧者不入他人宅，以免「带孝气」予人。

## 二、历史源流

- **先秦**：《礼记·曲礼》《间传》定居丧行为之节。
- **汉唐**：入律科罚；「居丧作乐」「居丧嫁娶」皆有明文。
- **宋明**：《家礼》规范丧期行为；理学强化。
- **明清**：地方志大量记录「居丧不剃发」「孝子不串门」等俗。
- **近代以来**：农村保留较多；城市仅存「不参加喜庆活动」「不娱乐」等。

## 三、仪节流程

1. **成服后**：停止妆饰、娱乐、社交。
2. **蓄发**：男子不剃须发，女子不梳妆（百日或至除服）。
3. **居丧守静**：闭门不出，不串门、不远行。
4. **阶段性解除**：五七、百日、周年渐次解除部分限制。
5. **除服**：行为复常。

## 四、地域与民族变体

- **华北**：重「百日不剃头」「孝子不串门」。
- **闽台**：守丧期内不参加喜庆、不进庙（有的地区除外）。
- **江南**：丧期行为限制以「不赴宴」「不作乐」为主。
- **少数民族**：各族丧期行为禁忌内容各异（禁猎、禁歌舞、禁劳动一定期限），其依据为本族信仰与生计方式，须分别记录。

## 五、器物与文书

- **相关物品**：孝服、孝带、灵位。
- **文书**：丧期事宜单（列禁忌与解除节点）。
- **文献依据**：《礼记·曲礼》《家礼》。
