# 丧期择日与重丧禁忌

## 一、释义

丧事择日（「看日子」「选期」）由阴阳先生依通书、历书选定，最重避忌「**重丧**」——民间认为若于重丧日出殡下葬，家中会连遭丧事。

| 名目 | 含义 |
| --- | --- |
| **重丧日** | 依干支推得，出殡恐再遭丧事之忌日 |
| **三丧日** | 忌三日内连日有丧 |
| **四离、四绝日** | 二分二至前后一日的忌日 |
| **月破、岁破** | 与当月、当年地支相冲之日 |
| **杨公忌日** | 相传唐代杨筠松所定的十三个忌日 |
| **空亡日** | 干支历中「旬空」之日，忌安葬 |

**化解之法**：民间有「**斩重丧**」（以纸人、纸棺、鸡代死，另择时化送）、「写重丧符贴上」「破土时以鸡血洒地」「打瓦盆」等法。

## 二、历史源流

- **汉代**：择日之术已见于《日书》（睡虎地秦简《日书》有丧葬宜忌），为丧期择日的早期形态。
- **唐宋**：阴阳五行择日之学大兴，《葬书》（托名郭璞）盛行。
- **清代**：《协纪辨方书》（乾隆敕撰）集择吉之大成，成为通书的权威依据。
- **近代以来**：农村普遍请阴阳先生择日；城市多以「方便亲友」为主，择日从简。

## 三、仪节流程

1. **报时**：将死者生卒时日、家属生肖报知阴阳先生。
2. **推日**：依通书推择入殓、出殡、下葬的吉日吉时，避重丧、三丧、月破等。
3. **开具**：先生开具「丧事日单」（含各仪节时辰）。
4. **化解**：如遇忌日难以避让，则行斩重丧、符咒等化解之法。
5. **依期行事**：丧家依单行事。

## 四、地域与民族变体

- **华北**：重丧禁忌最重，斩重丧之俗常见。
- **闽台**：依通书择日，忌「三煞方」「重丧日」。
- **江南**：亦请先生择日，但更重「五七」等祭期安排。
- **少数民族**：各族择日依据不同（如彝族毕摩占卜、藏族星算），其体系与汉族干支择吉不同源，须分别记录。

## 五、器物与文书

- **择日依据**：《协纪辨方书》、通书、历书、《葬书》。
- **文书**：丧事日单、择日单、符咒。
- **化解器物**：纸人、纸棺、公鸡、瓦盆、朱砂、符纸。
