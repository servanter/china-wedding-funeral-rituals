# 水族丧葬

## 一、释义

水族主要聚居于贵州黔南（三都、荔波、独山）及广西、云南部分地区。葬式以**土葬**为主，部分地区有**「停棺待葬」**之俗。

**核心要素**：
- **「水书」择日**——水族有本民族文字与典籍「水书」（水书先生掌握），丧葬择日、择地皆依水书。
- **「水书先生」主持**——由水书先生主持择吉与仪节，兼请「师公」做道场。
- **唱丧歌与「开控」**——守灵唱丧歌；丧仪中有「开控」（招魂送魂）之节。
- **「敬霞」与「端节」**——水族「端节」（年节）祭祖，与丧葬祭祖观念相通。
- **受汉壮影响**——行「做七」「百日」「周年」，二次葬亦有。

## 二、历史源流

- **唐宋**：水族先民（「僚」等）见于史籍。
- **明清**：方志（独山州志、三合县志等）载丧俗；水书文献在民间传承。
- **近代**：与汉、布依、苗族杂居，习俗交融。
- **当代**：水书入选《世界记忆名录》（文献遗产），丧葬择日之俗仍有留存。

## 三、仪节流程

1. **临终**：家人守护；鸣炮报丧。
2. **净身更衣**：净身、着新衣。
3. **入殓停灵**：入棺、设灵，请水书先生择日。
4. **做道场／开控**：师公行法事，唱丧歌、开控送魂。
5. **出殡下葬**：择日送葬、土葬；部分地区停棺待葬，择吉再葬。
6. **葬后祭祀**：圆坟、做七、「周年」；端节、清明祭祖。

## 四、地域与支系变体

- **三都、荔波**：水族聚居核心区，水书传承最完整。
- **独山、都匀**：与汉、布依族杂居，习俗汉化较深。
- **广西（南丹、环江）**：与壮、毛南族相邻，习俗互渗。
- **与其他民族关系**：水族无五服制度，须分别记录。

## 五、器物与文书

- **典籍与文书**：水书（水文抄本）、讣告、族谱。
- **宗教器物**：师公法器、祭器。
- **丧仪用品**：棺木、祭牲（牛、猪）、酒、糯米饭。
