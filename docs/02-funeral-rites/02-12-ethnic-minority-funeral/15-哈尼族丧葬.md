# 哈尼族丧葬

## 一、释义

哈尼族主要分布于云南红河、普洱、玉溪、西双版纳等地。葬式以**土葬**为主，部分地区行**火葬**。

**核心要素**：
- **「莫批」（贝玛）主持**——祭司「莫批」诵经、送魂，把亡魂送回祖先迁徙的北方故地（「送魂」与哈尼族迁徙记忆相应）。
- **「叫魂」与「送魂」**——为亡者「叫魂」「指路」，并举行「寨门」仪式隔离不洁。
- **唱丧歌与「跳丧」**——守灵唱丧歌，有的地区围棺而舞。
- **「长街宴」等公共活动**——村寨公共仪式与丧事活动相互关联。

## 二、历史源流

- **唐宋**：哈尼族先民（「和蛮」等）见于史籍。
- **明清**：方志（临安府志等）载其丧俗；梯田稻作社会中的村寨礼俗稳定传承。
- **近代**：受傣族（南传佛教）、彝族习俗影响。
- **当代**：火葬渐推，乡村仍存莫批主持的送魂仪节。

## 三、仪节流程

1. **临终**：家人守护；鸣枪或击鼓报丧。
2. **净身更衣**：净身、着新衣（或民族服装）。
3. **入殓停灵**：入棺、设灵，莫批诵经。
4. **送魂与吊唁**：莫批诵「送魂经」，亲友吊唁、唱丧歌。
5. **出殡下葬**：择日送葬、土葬；葬地多在村寨附近山林。
6. **葬后祭祀**：圆坟、「祭祖」；年节、六月节（苦扎扎）等节令祭扫。

## 四、地域与支系变体

- **红河（元阳、红河、绿春）**：哈尼族聚居核心区，莫批系统完整。
- **普洱、玉溪（墨江、元江）**：与彝、傣族杂居，习俗互渗。
- **西双版纳、澜沧**：受傣族南传佛教影响，丧仪兼有傣俗。
- **与其他民族关系**：哈尼族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：莫批法器、经文（口传）。
- **丧仪用品**：棺木、民族服装、酒、糯米饭、祭牲。
- **公共设施**：寨门、磨秋场（村寨公共场地）。
