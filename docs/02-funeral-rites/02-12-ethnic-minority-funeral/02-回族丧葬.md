# 回族丧葬

## 一、释义

回族丧葬以**伊斯兰教葬礼规范**为准，核心为「**速葬、土葬、薄葬**」三原则：

| 原则 | 内容 |
| --- | --- |
| **速葬** | 亡故后尽快安葬，一般不超过三日，多当日或次日 |
| **土葬** | 不用棺椁，尸体直接置于墓穴侧室（「拉哈特」），面向麦加（西向） |
| **薄葬** | 不铺张、不备殉葬品，无论贫富皆以白布裹身 |

**关键仪节**：净身（「着水」）、穿「克凡」（白布裹身，男三件、女五件）、殡礼「站者那则」、送葬至墓地。**禁忌**：不得嚎哭喧嚷、不得焚化纸钱纸扎、不得摆设祭品、不得择日看风水。

## 二、历史源流

- **唐宋**：穆斯林（「蕃客」「回回」）入华，伊斯兰葬礼随之传入。
- **元明**：回回民族共同体形成，清真寺与「回回掌教」承担殡葬事务；各地修建回族义地（回民公墓）。
- **清代至民国**：回民社区自治程度高，葬礼规范由阿訇与寺坊主持。
- **当代**：回族殡葬既依宗教仪轨，也纳入国家殡葬管理制度（回族传统土葬在部分火葬区内受尊重与保护）。

## 三、仪节流程

1. **临终**：请阿訇念「讨白」（忏悔），提醒亡者念「清真言」。
2. **归真后**：闭目、理须、覆白布，移于「水床」。
3. **着水（净身）**：由专人（男洗男、女洗女）以清水为亡者沐浴。
4. **穿克凡**：白布裹身，男三件（大卧单、小卧单、衬衣），女五件（另加裹胸布、盖头）。
5. **殡礼（站者那则）**：在清真寺或家中为亡者举行站礼，阿訇领拜、众人列班。
6. **送殡与下葬**：送至墓地，置亡者于墓穴侧室（拉哈特），以土块封口、填土成坟（不起高冢）。
7. **葬后纪念**：于亡后七日、四十日、百日、周年请阿訇「走坟」诵经，并宰牲待客（「尔麦里」）。

## 四、地域与支系变体

- **西北（宁夏、甘肃、青海、新疆）**：制度化程度高，寺坊（教坊）承办。
- **中原与华北**：与汉族杂居，严守宗教规范而不采汉俗。
- **东南（福建、广东、海南）**：沿海回族社区，义地与古墓遗存较多。
- **与其他民族关系**：东乡、撒拉、保安、维吾尔、哈萨克、柯尔克孜、乌孜别克、塔吉克、塔塔尔等族同遵伊斯兰葬礼，各地细节有异，须分别记录。

## 五、器物与文书

- **葬具与用品**：水床、克凡（白布）、香料（樟脑、冰片）、匣子（抬尸用的「塔布提」木匣，可重复使用）。
- **宗教器物**：清真寺、《古兰经》、香炉。
- **墓地**：回民公墓、义地；墓碑多刻阿拉伯文与汉文姓名、生卒。
