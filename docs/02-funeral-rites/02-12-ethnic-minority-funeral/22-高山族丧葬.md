# 高山族丧葬

## 一、释义

高山族是对台湾地区南岛语系各民族的统称（包括阿美、泰雅、排湾、布农、邹、达悟等族群），大陆亦有高山族同胞。各族群葬式差异极大：

| 葬式 | 族群举例 | 说明 |
| --- | --- | --- |
| **室内葬（屋内葬）** | 部分排湾、鲁凯族群 | 葬于屋内地面或石板下 |
| **室外葬** | 阿美、泰雅等 | 葬于村外墓地，多为土葬 |
| **屈肢葬** | 部分族群 | 遗体呈蹲踞或屈肢状 |
| **崖葬、树葬** | 部分族群（视死因、身份） | 用于特殊情形 |

**共同特征**：以「**祖灵**」信仰为核心（如排湾族「五年祭」祭祖灵）；丧期禁忌繁多（不接触他人、不食某些食物、不参加集体活动）；丧事多由近亲与族中长老主持。

## 二、历史源流

- **史前至明清**：台湾考古所见的石板棺墓、室内葬遗存与各族群葬俗相应；明清方志（台湾府志等）载「番俗」丧仪。
- **近代**：外来宗教（基督教）传入部分族群，葬礼形式改变。
- **当代**：各族群文化复兴运动使传统葬俗受到关注与部分恢复。

## 三、仪节流程

1. **临终**：族人守护；视族群而定，或移于特定位置。
2. **净身更衣**：净身、着族群服装（部分族群着盛装、戴饰物）。
3. **停灵**：停尸于屋内，族人守灵，忌喧哗。
4. **出殡下葬**：依族群惯例（室内葬或室外葬），无棺或以石板、竹木为葬具。
5. **葬后**：举行净化仪式（以水、火或植物净化家人与居所）；祖灵祭（如排湾五年祭）中祭祀亡故族人。
6. **禁忌**：丧期禁耕作、狩猎、歌舞；忌呼亡者名。

## 四、地域与支系变体

- **排湾、鲁凯**：室内葬与石板墓，祖灵信仰浓厚。
- **阿美**：室外土葬，聚落集体参与。
- **泰雅、赛德克**：山地土葬，禁忌严格。
- **达悟（雅美）**：海岛族群，另有特定葬俗与禁忌。
- **与其他民族关系**：高山族各族群属南岛语族文化系统，与汉族五服制度无继受关系，须分别记录。

## 五、器物与文书

- **葬具**：石板棺、竹木架、木棺（近代）。
- **仪式用品**：族群服装与饰物、祭品（粟、酒、槟榔）。
- **信仰物**：祖灵屋、祭坛（部分族群）。
