# 拉祜族丧葬

## 一、释义

拉祜族主要分布于云南普洱、临沧、西双版纳、红河等地。葬式以**土葬**为主，村寨设公共墓地。

**核心要素**：
- **「魔八」（祭司）主持**——由「魔八」（或「毕摩」）诵经、送魂，指引亡魂回祖居地。
- **丧歌与芦笙**——守夜唱丧歌，吹芦笙伴丧。
- **「叫魂」与「送魂」**——为亡者送魂，并为生者「叫魂」以求平安。
- **基督教影响**——部分拉祜族（尤以澜沧一带）信仰基督教，行教会葬礼。
- **丧期禁忌**——村寨禁耕作、禁歌舞；葬后行净化仪式。

## 二、历史源流

- **唐宋至明清**：拉祜族先民（「倮黑」等称谓）葬俗见于史籍与方志。
- **近代**：基督教、南传佛教在不同地区传播，丧俗分化。
- **当代**：传统仪节与宗教仪式并行，村寨习俗渐简。

## 三、仪节流程

1. **临终**：家人守护；鸣枪报丧。
2. **净身更衣**：净身、着新衣。
3. **入殓停灵**：入棺、设灵，魔八诵经，唱丧歌。
4. **送魂**：诵送魂经，指引亡魂归祖。
5. **出殡下葬**：择日送葬，葬于村寨公共墓地。
6. **葬后祭祀**：圆坟、「叫魂」净化；年节、火把节等节令祭扫。

## 四、地域与支系变体

- **拉祜纳（澜沧、孟连）**：与傣、佤族杂居，佛教与基督教影响并存。
- **拉祜西（澜沧、西盟）**：支系习俗较古朴。
- **苦聪人（金平、绿春等）**：原为拉祜族一支，习俗另有特点。
- **与其他民族关系**：拉祜族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **乐器**：芦笙、象脚鼓（与傣族习俗相邻地区）。
- **宗教器物**：魔八法器、祭器；十字架、赞美诗（基督教家庭）。
- **丧仪用品**：棺木、祭牲、酒、祭品。
