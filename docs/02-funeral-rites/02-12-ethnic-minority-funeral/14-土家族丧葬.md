# 土家族丧葬

## 一、释义

土家族主要聚居于湘西、鄂西、渝东南、黔东北。葬式以**土葬**为主，其最鲜明的标志是**「跳丧」（撒叶儿嗬）**——以歌舞送亡，称为「欢送亡人」。

**核心要素**：
- **「撒叶儿嗬」（跳丧）**——众人围棺击鼓而舞，唱丧歌，通宵达旦，体现「以歌代哭、以舞送亡」的独特观念。
- **「土老师」（梯玛）主持**——由土家族的祭司「梯玛」行法事、送魂。
- **「绕棺」**——出殡前后绕棺而歌。
- **「丧鼓」**——以鼓领舞领唱，为跳丧核心乐器。
- **受汉族影响**——部分地区兼行「做七」「做道场」。

## 二、历史源流

- **先秦**：土家族先民（巴人）尚歌舞，《楚辞》与巴楚巫风渊源相关。
- **唐宋**：「巴人」丧歌、踏歌之风见于记载。
- **明清**：方志（永顺府志、施南府志等）载「跳丧」「绕棺」之俗。
- **当代**：「撒叶儿嗬」列入国家级非物质文化遗产，丧俗在清江流域保存最完整。

## 三、仪节流程

1. **临终**：家人守护；鸣炮报丧。
2. **净身更衣**：净身、着寿衣。
3. **入殓停灵**：入棺、设灵。
4. **跳丧（撒叶儿嗬）**：亲友围棺击鼓而舞，唱丧歌，通宵达旦。
5. **出殡下葬**：择日送葬、土葬，坟茔依山。
6. **葬后祭祀**：圆坟、「五七」「周年」；清明、中元、年节祭扫。

## 四、地域与支系变体

- **清江流域（长阳、五峰）**：跳丧保存最完整。
- **湘西（龙山、永顺）**：与苗族杂居，兼有苗俗。
- **渝东南（酉阳、秀山）**：近重庆，习俗与川渝相类。
- **黔东北（铜仁）**：与侗、苗族杂居，习俗互渗。
- **与其他民族关系**：土家族服丧不采五服制度，其「欢送亡人」的观念与汉族「哀痛」之礼取向不同，须分别记录。

## 五、器物与文书

- **乐器**：丧鼓、锣、钹。
- **宗教器物**：梯玛法器、面具。
- **丧仪用品**：棺木、寿衣、纸扎、纸钱、祭品。
- **文书**：讣告、丧歌抄本、族谱。
