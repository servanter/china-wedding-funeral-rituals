# 阿昌族丧葬

## 一、释义

阿昌族主要聚居于云南德宏（陇川、梁河）及保山（腾冲）等地。葬式以**土葬**为主，部分地区行**火葬**。

**核心要素**：
- **「活袍」（祭司）主持**——由「活袍」诵经送魂，指引亡魂归祖。
- **唱丧歌与「跳丧」**——守灵唱丧歌，有的村寨围圈跳丧。
- **「窝罗」祭祖**——阿昌族「窝罗」节（正月初四前后）与祭祖、祖先崇拜相关。
- **南传佛教影响**——部分阿昌族信仰南传佛教，丧仪兼有佛事。
- **丧期禁忌**——村寨禁歌舞、禁婚娶。

## 二、历史源流

- **唐宋至明清**：阿昌族先民（「峨昌」）见于史籍（《蛮书》等）与方志。
- **近代**：与傣、景颇、汉族杂居，习俗互渗。
- **当代**：传统仪节在山区保存较多，城镇渐简。

## 三、仪节流程

1. **临终**：家人守护；鸣枪报丧。
2. **净身更衣**：净身、着新衣。
3. **入殓停灵**：入棺、设灵，活袍诵经。
4. **吊唁跳丧**：亲友吊唁、唱丧歌、跳丧。
5. **出殡下葬**：择日送葬、土葬（或火葬）。
6. **葬后祭祀**：圆坟、送魂收束；窝罗节、清明祭祖。

## 四、地域与支系变体

- **陇川（户撒、腊撒）**：阿昌族聚居区，活袍系统较完整。
- **梁河、腾冲**：与傣、汉族杂居，习俗交融。
- **与其他民族关系**：阿昌族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：活袍法器、祭器。
- **丧仪用品**：棺木、祭牲（牛、猪）、酒、祭品。
- **特色工艺**：户撒刀（阿昌族著名工艺，部分随葬或用于仪式）。
