# 哈萨克族丧葬

## 一、释义

哈萨克族主要分布于新疆北部（伊犁、阿勒泰、塔城）及甘肃、青海。丧葬依**伊斯兰教规范**（速葬、土葬、白布裹身、不用棺椁），并保留草原游牧社会的**「周年祭」**传统。

**核心要素**：
- **速葬与土葬**——亡后当日或次日安葬，白布裹身，墓穴设侧室。
- **阿訇主持**——净身、站礼（殡礼）由阿訇主持。
- **女性唱挽歌**——亲属（尤以女性）唱挽歌（「哭丧歌」）致哀。
- **「乃孜尔」**——亡后七日、四十日、周年请阿訇诵经、待客。
- **周年祭与赛马**——周年祭（「阿斯」）规模隆重，旧俗有赛马、摔跤、叼羊等活动以祭亡者。

## 二、历史源流

- **伊斯兰教传入后**：丧葬规范取代草原旧俗中的部分做法。
- **清代**：哈萨克部众迁入伊犁、阿勒泰等地，丧俗与宗教信仰相应。
- **近现代**：游牧社会结构变化，周年祭规模缩小。
- **当代**：城市丧俗简化，宗教仪轨仍为核心。

## 三、仪节流程

1. **临终**：请阿訇念经，家人守护。
2. **归真后**：闭目、覆白布，通报亲友与阿訇。
3. **净身与裹尸**：专人净身，白布裹尸（三件）。
4. **站礼（殡礼）**：在清真寺或墓地举行站礼。
5. **送葬下葬**：送至墓地下葬，墓穴设侧室，面向麦加（西向）。
6. **乃孜尔与周年祭**：七日、四十日、周年请阿訇诵经、待客；周年祭旧有赛马等活动。

## 四、地域与支系变体

- **伊犁、阿勒泰、塔城**：哈萨克族聚居区，仪轨完整。
- **甘肃阿克塞、青海海西**：与回、蒙古族杂居，习俗相类。
- **城市哈萨克族**：殡仪从简，家族祭祀延续。
- **与其他民族关系**：同遵伊斯兰葬礼的各族细节有异，与汉族五服体系不同源，须分别记录。

## 五、器物与文书

- **丧仪用品**：白布（裹尸）、水床、抬尸木架、香料。
- **宗教器物**：《古兰经》、念珠、清真寺。
- **祭祀物**：周年祭所用祭牲、毡房陈设（旧俗）。
