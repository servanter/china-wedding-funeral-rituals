# 藏族丧葬

## 一、释义

藏族丧葬受**藏传佛教**主导，葬式按亡者身份、死因分为数等：

| 葬式 | 对象 | 说明 |
| --- | --- | --- |
| **塔葬** | 达赖、班禅及大活佛 | 遗体经处理入塔供奉 |
| **火葬** | 活佛、高僧、上层 | 焚化后骨灰入塔或撒于山川 |
| **天葬（鸟葬）** | 一般信众（最普遍） | 遗体施于天葬台，供鹫鹰啄食，以食尽为「升天」之吉 |
| **水葬** | 部分地区、婴幼儿、传染病亡者 | 遗体投入江河 |
| **土葬** | 传染病亡者、斗殴凶死者等 | 民间视为「不吉」之葬式 |

**核心观念**：以「**超度**」为要——亡后四十九日为「中阴」期，亲属请僧侣诵经、布施、放生、供灯，助亡魂转世善道。

## 二、历史源流

- **吐蕃时期**：苯教与佛教信仰并行，葬式多样。
- **后弘期以降**：藏传佛教各派掌握超度仪轨，天葬渐成主流，天葬台分区域固定。
- **明清至近代**：政教合一体制下，塔葬、火葬与身份等级相配。
- **当代**：天葬受法律与习俗双重保护，禁止围观与拍摄；城镇居民多行火葬。

## 三、仪节流程

1. **临终**：请僧侣诵经，劝亡者放下执著；家人不哭号，以免扰其神识。
2. **停尸**：以白布裹尸，置于屋内一角，请僧侣连续诵经（常三至七日，或四十九日）。
3. **出殡**：由「背尸人」（天葬师）择吉时背出，不得从门口直出（或另开门洞），不回头。
4. **葬式施行**：天葬台上由天葬师分解遗体；火葬搭炉焚化；水葬投河。
5. **葬后超度**：四十九日内家人诵经、供灯、施舍；请僧侣做「回向」。
6. **祭祀**：忌日为亡者诵经、布施；「酥油灯」「糌粑」为常用供品。

## 四、地域与支系变体

- **卫藏（拉萨、日喀则）**：天葬为主，天葬台规模大。
- **安多（青海、甘肃、四川西北）**：天葬、火葬、水葬并存。
- **康区（四川甘孜、云南迪庆）**：火葬与天葬并重。
- **与汉族关系**：藏族无「五服」概念，亲属服丧以宗教禁忌与丧期（多为四十九日）为限，须分别记录。

## 五、器物与文书

- **宗教器物**：念珠、转经筒、酥油灯、经幡、玛尼堆、风马旗。
- **丧仪用品**：白布（裹尸）、糌粑（供品）、青稞酒、柏枝（煨桑）。
- **文书**：超度经文、祈愿文、亡者名册（用于法会回向）。
