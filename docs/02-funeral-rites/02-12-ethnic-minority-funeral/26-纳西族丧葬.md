# 纳西族丧葬

## 一、释义

纳西族主要聚居于云南丽江及迪庆、四川凉山等地。传统行**火葬**（丽江纳西族），近代多改**土葬**；泸沽湖地区摩梭人另有特色葬俗。

**核心要素**：
- **「东巴」主持**——由东巴祭司主持丧仪，诵「送魂经」及《神路图》相关经文，为亡魂指路回归祖居地。
- **《神路图》**——纳西族东巴教用于丧葬的卷轴画，描绘亡魂升天之路，悬挂于灵堂供祭。
- **「跳「哦热热」」等丧歌丧舞**——通宵唱丧歌、跳丧舞。
- **「祭天」与「祭祖」**——纳西族「祭天」大典与祭祖观念相关。
- **火葬改土葬**——清代以来受汉文化影响，丽江一带改为土葬并建坟茔。

## 二、历史源流

- **唐宋**：纳西族先民（「麽些」）见于史籍，东巴教在唐宋间形成。
- **明清**：木氏土司时期东巴文化兴盛；清代改土归流后，汉文化影响加深，丧俗渐变。
- **近代**：东巴仪式与汉式葬礼并行。
- **当代**：东巴古籍入选《世界记忆名录》，丧俗研究深入。

## 三、仪节流程

1. **临终**：家人守护；鸣枪或吹号报丧。
2. **净身更衣**：净身、着新衣（有的着民族服装）。
3. **停灵设祭**：设灵堂，悬挂《神路图》，东巴诵经。
4. **东巴仪式**：行「送魂」「开丧」等科仪，唱丧歌、跳丧舞。
5. **火葬或土葬**：丽江一带近代多行土葬，其他地区有火葬。
6. **葬后祭祀**：行「祭祖」之礼；清明、年节、祭天时节祭扫。

## 四、地域与支系变体

- **丽江坝区**：土葬为主，东巴仪式与汉式葬礼并行。
- **迪庆（三坝、香格里拉）**：东巴文化保存较多。
- **四川（盐源、木里）**：与彝、藏族相邻，习俗互渗。
- **泸沽湖畔摩梭人**：行火葬，另有母系家庭背景下的丧仪特点。
- **与其他民族关系**：纳西族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：东巴法器（法杖、神牌、五幅冠）、《神路图》、东巴经。
- **丧仪用品**：民族服装、祭品、酒。
- **文书**：东巴经（象形文字写本）、讣告、族谱。
