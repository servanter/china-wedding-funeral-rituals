# 德昂族丧葬

## 一、释义

德昂族主要聚居于云南德宏（芒市、瑞丽、陇川）及临沧（镇康、耿马）等地，信仰**南传佛教**，兼有传统鬼神信仰。葬式以**土葬**为主，部分地区行**火葬**。

**核心要素**：
- **僧侣诵经与「滴水」**——请佛寺僧侣诵经超度，亲属行「滴水」回向功德。
- **「达干」（头人）与寨老主持**——村寨头人参与治丧、择地。
- **分区埋葬**——正常死亡与凶死者分墓地埋葬，为显著禁忌。
- **丧期禁忌**——村寨禁歌舞、禁婚娶；葬后行净化仪式。
- **祭寨神**——村寨「寨神」祭祀与丧事禁忌相关。

## 二、历史源流

- **唐宋至明清**：德昂族先民（「濮人」「崩龙」）葬俗见于史籍与方志。
- **近代**：南传佛教影响加深，佛寺承担诵经超度职责。
- **当代**：传统仪节在山区保存较多，城镇渐简。

## 三、仪节流程

1. **临终**：家人守护；请僧侣诵经。
2. **净身更衣**：净身、着新衣。
3. **停灵诵经**：停尸、设灵，僧侣诵经。
4. **出殡下葬**：择日送葬，葬于村寨公共墓地（按死因分区）。
5. **滴水回向**：葬后于佛寺行「滴水」，回向功德。
6. **葬后祭祀**：祭寨神；泼水节、关门节等节令祭祀。

## 四、地域与支系变体

- **德宏（芒市、瑞丽）**：与傣、景颇族杂居，习俗互渗。
- **临沧（镇康、耿马）**：聚居较集中，佛教影响明显。
- **与其他民族关系**：德昂族服丧以佛教禁忌与丧期为限，不采五服制度，须分别记录。

## 五、器物与文书

- **宗教器物**：佛像、贝叶经、袈裟、滴水器。
- **丧仪用品**：白布、蜡条、糯米饭、祭品。
- **佛寺建筑**：佛寺、佛塔。
