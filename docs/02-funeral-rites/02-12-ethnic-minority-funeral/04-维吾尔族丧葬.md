# 维吾尔族丧葬

## 一、释义

维吾尔族信仰伊斯兰教，丧葬依**速葬、土葬、薄葬**之规范，并由本民族特有的**「乃孜尔」**（亡后纪念仪式）承载祭祀功能。

**要点**：

| 内容 | 说明 |
| --- | --- |
| **速葬** | 亡后尽快安葬，多当日或次日，忌久停 |
| **土葬** | 不用棺椁，白布裹身，墓穴设侧室 |
| **薄葬** | 不用殉葬品，不重坟茔装饰 |
| **乃孜尔** | 亡后三日、七日、四十日、周年请阿訇诵经、待客 |
| **麻扎** | 圣者、贤者陵墓，民间前往朝拜祈愿 |

**禁忌**：忌嚎哭捶胸、忌穿艳丽衣饰、忌焚化纸钱、忌看风水。

## 二、历史源流

- **喀喇汗王朝时期**：伊斯兰教传入，丧葬规范逐步确立，与本地葬俗融合。
- **明清**：叶尔羌汗国等时期形成「麻扎」朝拜传统，陵墓建筑艺术发达。
- **近现代**：城市殡葬纳入规范管理，宗教仪轨仍是核心。
- **文献**：《古兰经》《圣训》、察合台文文书与地方民族志。

## 三、仪节流程

1. **临终**：请阿訇念经、提醒念「清真言」，家人守护。
2. **归真后**：闭目、合口、覆白布，移于净身之处。
3. **净身与裹尸**：由专人（男洗男、女洗女）净身，白布裹尸（三件）。
4. **殡礼（站礼）**：在清真寺或墓地举行站礼，阿訇领拜。
5. **下葬**：送至墓地下葬，墓穴设侧室，面向麦加（西向）。
6. **乃孜尔**：亡后三日、七日、四十日、周年请阿訇诵经、招待来客。
7. **麻扎朝拜**：部分家庭于特定时日前往麻扎祈愿。

## 四、地域与支系变体

- **南疆（喀什、和田、阿克苏）**：宗教生活浓厚，乃孜尔隆重，麻扎朝拜兴盛。
- **北疆（乌鲁木齐、伊犁）**：城镇丧俗简化，仪轨仍依教法。
- **与其他民族关系**：维吾尔族丧俗与汉族五服体系及土葬礼仪均不同源，须分别记录；同遵伊斯兰葬礼的诸族细节亦有差异。

## 五、器物与文书

- **丧仪用品**：白布（裹尸）、水床、抬尸木架（「阿热吾斯」）、香料。
- **宗教器物**：《古兰经》、念珠、清真寺。
- **墓地建筑**：麻扎（陵墓）、清真寺附属墓地、墓碑（多刻阿拉伯文）。
