# 怒族丧葬

## 一、释义

怒族主要聚居于云南怒江（泸水、福贡、贡山）及迪庆（维西）等地。葬式以**土葬**为主，部分地区行**火葬**。

**核心要素**：
- **祭司（「尼玛」「于古」）主持**——由本族祭司诵经送魂，指引亡魂回祖居地。
- **「跳丧」与丧歌**——通宵唱丧歌、围圈跳丧。
- **随葬生产工具**——男性随葬弓弩、刀，女性随葬织具、饰物（部分地区）。
- **基督教影响**——部分怒族（以及相邻傈僳族）信仰基督教，行教会葬礼。
- **丧期禁忌**——村寨禁耕作、禁歌舞；葬后行净化仪式。

## 二、历史源流

- **唐宋至明清**：怒族先民（「怒夷」等）葬俗见于史籍与方志（丽江府志等）。
- **近代**：基督教在怒江传播，形成两种并行的丧俗。
- **当代**：传统仪节在山区保存，城镇渐简。

## 三、仪节流程

1. **临终**：家人守护；鸣枪报丧。
2. **净身更衣**：净身、着新衣。
3. **入殓停灵**：入棺（或以竹木裹席）、设灵，祭司诵经。
4. **跳丧吊唁**：亲友吊唁、唱丧歌、跳丧。
5. **出殡下葬**：择日送葬、土葬（或火葬）。
6. **葬后祭祀**：圆坟、送魂收束；年节、清明祭扫。

## 四、地域与支系变体

- **贡山（怒族支系）**：与独龙、傈僳族相邻，习俗互渗。
- **福贡、泸水**：基督教影响明显，葬礼有教会形式。
- **与其他民族关系**：怒族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：祭司法器、祭器；十字架、赞美诗（基督教家庭）。
- **随葬品**：弓弩、刀、织具、饰物。
- **丧仪用品**：木棺、篾席、酒、祭牲。
