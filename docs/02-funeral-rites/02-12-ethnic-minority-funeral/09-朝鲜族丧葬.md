# 朝鲜族丧葬

## 一、释义

朝鲜族主要分布于吉林、黑龙江、辽宁，其传统丧礼**深受朱子家礼影响**，是各民族中最接近儒家丧服体系者，同时又保留本民族特色（如「丧舆歌」）。

**核心要素**：
- **儒家丧礼体系**——有「初终、袭、小敛、大敛、成服、小祥、大祥、禫」诸节，行**三年之丧**。
- **丧服**——着麻布丧服（「丧服」），服制细分亲疏。
- **「丧舆」与丧舆歌**——出殡用木制丧舆（灵车），抬舆者唱「丧舆歌」。
- **祭礼**——忌日行「忌祭祀」，节日行「茶礼」「墓祭」。
- **土葬为主**——近代多行土葬，现以火葬与骨灰堂为主。

## 二、历史源流

- **朝鲜王朝时期**：以《朱子家礼》为国家礼制典范，丧礼规范高度制度化，并随移民传入中国东北。
- **明清至近代**：朝鲜族迁入东北，丧礼连同家礼文本一并移植。
- **当代**：城市以殡仪馆治丧为主，传统服制仪式显著简化，但「祭祀」「茶礼」等家族礼俗延续。

## 三、仪节流程

1. **初终**：临终迁居正室（「迁居正寝」），属纩、招魂（「复」）。
2. **袭与小敛**：净身、着寿衣、小敛。
3. **大敛与成服**：入棺、亲属依服制成服。
4. **出殡**：择日发引，丧舆前行，抬舆者唱「丧舆歌」。
5. **下葬**：土葬（或火葬），筑坟。
6. **葬后祭祀**：行「初虞」「再虞」「三虞」「卒哭」，继而小祥、大祥、禫，除服。
7. **岁时祭祀**：忌日「忌祭祀」，节日「茶礼」，清明、中秋「墓祭」。

## 四、地域与支系变体

- **延边朝鲜族自治州**：民族聚居，传统礼俗保存较多。
- **黑龙江、辽宁朝鲜族聚居区**：与汉族杂居，仪式简化。
- **城市朝鲜族**：以殡仪馆治丧、家族祭祀为主。
- **与其他民族关系**：朝鲜族与汉族同属儒家丧服传统，但服制细节与「五服」体系有别，须分别记录。

## 五、器物与文书

- **葬具**：棺木（「寿材」）、丧舆（灵车）。
- **丧服**：麻布丧服、丧带。
- **祭祀器物**：祭桌、祭器、牌位（「神主」「纸榜」）。
- **文书**：讣告、家礼抄本、祭文、族谱（「族谱」「家乘」）。
