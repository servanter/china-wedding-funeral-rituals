# 珞巴族丧葬

## 一、释义

珞巴族聚居于西藏东南部（米林、墨脱、察隅、隆子等）。葬式以**土葬**为主，兼有**树葬**（多用于夭折者）、火葬（用于特殊身份）。

**核心要素**：
- **「纽布」（巫师）主持**——由巫师「纽布」或「爸目」主持占卜、送魂。
- **「占卜择地」**——以鸡卜等方式选择葬地与吉日，为显著特点。
- **随葬生产工具与饰物**——男性随葬弓弩、刀，女性随葬饰物、织具。
- **「送魂」**——为亡魂指路，送回祖先原居地。
- **丧期禁忌**——禁耕作、禁歌舞；村寨行净化仪式。

## 二、历史源流

- **唐宋至明清**：珞巴族先民葬俗散见于藏文文献与边防、舆地记录。
- **近代**：因峡谷封闭，传统习俗保存较久。
- **当代**：传统仪式渐简，民族志记录较为重要。

## 三、仪节流程

1. **临终**：家人守护；通报族中长者。
2. **净身更衣**：净身、着新衣。
3. **停灵占卜**：停尸、设灵；纽布占卜择葬地吉日。
4. **出殡下葬**：择地土葬（夭折者或行树葬）。
5. **随葬安置**：随葬生产工具与饰物。
6. **葬后祭祀**：圆坟、送魂收束；年节祭祖。

## 四、地域与支系变体

- **米林、隆子**：聚居较多，习俗记录较完整。
- **墨脱、察隅**：与门巴、藏族杂居，习俗互渗。
- **与其他民族关系**：珞巴族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：纽布法器、占卜用具（鸡骨等）。
- **丧仪用品**：木棺、竹编裹物、祭牲、酒。
- **随葬品**：弓弩、刀、饰物、织具。
