# 基诺族丧葬

## 一、释义

基诺族聚居于云南西双版纳景洪基诺山（基诺乡）。葬式以**土葬**为主，村寨设**公共墓地**，按村寨与家族划分墓区。

**核心要素**：
- **「卓巴」「卓色」主持**——村寨首领「卓巴」「卓色」（寨老）参与治丧与择地。
- **「送魂」与丧歌**——由「莫批」或寨老诵经送魂、唱丧歌，指引亡魂回祖居地。
- **随葬生产工具**——随葬刀、镰等工具与竹制器具。
- **剽牛祭亡**——以牛祭献（旧俗），「剽牛」为基诺族重要仪式。
- **丧期禁忌**——村寨禁耕作、禁歌舞；葬后行净化仪式。

## 二、历史源流

- **清代**：基诺族（「攸乐」）见于方志（《普洱府志》等）。
- **近代**：因山林封闭，传统习俗保存较久。
- **当代**：1979 年确认为单一民族后，文化记录与研究展开；习俗渐简。

## 三、仪节流程

1. **临终**：家人守护；鸣枪或击竹报丧。
2. **净身更衣**：净身、着新衣（或以白布裹身）。
3. **停灵诵经**：停尸、设灵，寨老或莫批诵经，唱丧歌。
4. **剽牛祭亡**（旧俗）：以牛祭献。
5. **出殡下葬**：择日送葬，葬于村寨公共墓地。
6. **葬后祭祀**：圆坟、送魂收束；年节（特懋克节）祭祖。

## 四、地域与支系变体

- **基诺山（巴亚、巴坡等寨）**：聚居核心区，习俗记录较完整。
- **景洪其他地区**：与傣、哈尼族杂居，习俗互渗。
- **与其他民族关系**：基诺族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：祭器、占卜用具。
- **丧仪用品**：白布、竹木葬具、祭牲（牛、猪、鸡）、酒。
- **特色物**：竹编器具、砍刀（随葬）。
