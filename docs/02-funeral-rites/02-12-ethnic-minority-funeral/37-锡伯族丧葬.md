# 锡伯族丧葬

## 一、释义

锡伯族主要聚居于辽宁（沈阳、铁岭）与新疆伊犁察布查尔锡伯自治县。葬式以**土葬**为主，丧俗兼受**萨满信仰、满汉礼制与儒家丧服观**影响。

**核心要素**：
- **萨满送魂**——旧时请萨满送魂；后多请喇嘛或僧道诵经。
- **丧服与三年之丧**——受满汉影响，有丧服制度与守丧期。
- **「烧纸」「做七」**——近世行汉式烧纸、做七、周年之祭。
- **「抹黑脸」旧俗**——守丧期间有以锅底灰抹面（示意哀痛）之俗（部分地区）。
- **西迁支系**——新疆锡伯族因戍边聚居，语言礼俗保存较好。

## 二、历史源流

- **明末清初**：锡伯族居于东北，为科尔沁、满洲所辖。
- **清乾隆年间**：部分锡伯族奉命西迁伊犁戍边，形成察布查尔聚居区。
- **近代**：与满、汉、维吾尔族交往，丧俗多元。
- **当代**：火葬渐推，传统仪节在聚居区仍有留存。

## 三、仪节流程

1. **临终**：家人守护；通报族中长辈。
2. **净身更衣**：净身、着新衣。
3. **入殓停灵**：入棺、设灵；请萨满（或喇嘛、僧道）诵经。
4. **吊唁守灵**：孝子守灵，亲友吊唁。
5. **出殡下葬**：择日送葬、土葬。
6. **葬后祭祀**：烧纸、做七、「百日」「周年」；清明、年节祭扫。

## 四、地域与支系变体

- **辽宁（沈阳、铁岭）**：与满、汉族杂居，习俗汉化较深。
- **新疆察布查尔**：聚居区，语言与部分旧俗保存较好。
- **与其他民族关系**：锡伯族丧俗多元交融，但萨满信仰与西迁群体记忆为特有内容，须分别记录。

## 五、器物与文书

- **宗教器物**：萨满神鼓、神衣（旧时）；喇嘛经卷、法器。
- **丧仪用品**：棺木、孝服、纸钱、祭品。
- **文书**：讣告、族谱（锡伯文、满文家谱）。
