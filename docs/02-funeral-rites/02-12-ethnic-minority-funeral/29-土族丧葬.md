# 土族丧葬

## 一、释义

土族主要聚居于青海互助、民和、大通及甘肃天祝等地。传统葬式以**火葬**为主（尤以互助、民和一带），近代部分改行**土葬**。

**核心要素**：
- **藏传佛教影响**——请喇嘛诵经超度，丧仪带藏传佛教色彩。
- **「本本子」等民间信仰**——土族民间宗教（「本本子」「法拉」）在部分地区参与丧仪。
- **火葬**——焚化后收骨灰，或装罐埋葬，或撒于山野。
- **丧期禁忌**——村寨禁歌舞；亲属有服丧期与服饰标记（如反穿衣物、束白带）。
- **「於菟」**——土族「跳於菟」驱邪仪式（岁末举行），其驱邪观念与丧葬禁忌相通。

## 二、历史源流

- **元明**：土族（「土人」）形成于河湟地区，藏传佛教与民间信仰并行。
- **明清**：方志（西宁府志、碾伯县志等）载其丧俗。
- **近代**：与汉、藏、回族杂居，习俗互有影响。
- **当代**：火葬、土葬并行，宗教仪轨简省。

## 三、仪节流程

1. **临终**：家人守护；请喇嘛诵经。
2. **净身更衣**：净身、着新衣。
3. **停灵诵经**：停尸、设灵，喇嘛诵经超度。
4. **火葬或土葬**：择日送葬，火葬者备薪焚化；土葬者棺殓入土。
5. **葬后祭祀**：收骨安放、诵经回向；年节、清明祭扫。

## 四、地域与支系变体

- **互助、民和**：火葬传统明显，喇嘛诵经隆重。
- **大通、天祝**：与藏、汉族杂居，土葬渐多。
- **与其他民族关系**：土族丧俗受藏传佛教影响较深，与汉族五服体系不同源，须分别记录。

## 五、器物与文书

- **宗教器物**：喇嘛法器、经卷、酥油灯。
- **丧仪用品**：棺木或柴薪（火葬）、民族服装、祭品。
- **文书**：超度经文、族谱。
