# 裕固族丧葬

## 一、释义

裕固族主要聚居于甘肃张掖肃南裕固族自治县，分东部（恩格尔）与西部（尧乎尔）两大支系，语言与习俗有别。葬式传统以**火葬**为主，近代部分改行**土葬**。

**核心要素**：
- **藏传佛教影响**——请喇嘛诵经超度，丧仪带藏传佛教色彩。
- **火葬**——焚化后收骨灰，装罐或撒于山野；部分地区有「先火葬后土葬」的复合形式。
- **「献羊」祭亡**——部分支系以羊祭献。
- **「剪发」哀悼**——亲属剪发（或剪马鬃、衣饰）以示哀悼，为裕固族特点。
- **丧期禁忌**——禁歌舞；服丧期有服饰标记。

## 二、历史源流

- **元明**：裕固族先民（「撒里畏兀儿」）东迁至河西走廊，藏传佛教渐成主要信仰。
- **明清**：方志与民族志载其丧俗。
- **当代**：火葬、土葬并行，宗教仪轨简省。

## 三、仪节流程

1. **临终**：家人守护；请喇嘛诵经。
2. **净身更衣**：净身、着新衣。
3. **停灵诵经**：停尸、设灵，喇嘛诵经超度；亲属剪发示哀。
4. **火葬**：择日送葬火化，收骨灰装罐或撒于山野。
5. **土葬（部分地区）**：骨灰或遗体入土筑坟。
6. **葬后祭祀**：诵经回向；年节、清明祭扫。

## 四、地域与支系变体

- **东部（肃南皇城、康乐）**：与藏、汉族杂居，习俗互渗。
- **西部（肃南明花、大河）**：支系习俗另有特点。
- **与其他民族关系**：裕固族丧俗受藏传佛教影响较深，与汉族五服体系不同源，须分别记录。

## 五、器物与文书

- **宗教器物**：喇嘛法器、经卷、酥油灯。
- **丧仪用品**：柴薪（火葬）、骨灰罐、祭牲（羊）、酒。
- **文书**：超度经文、族谱。
