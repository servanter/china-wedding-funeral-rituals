# 羌族丧葬

## 一、释义

羌族主要聚居于四川阿坝（茂县、汶川、理县、黑水等）。传统以**火葬**为固有葬式，近世兼行**土葬**。

**核心要素**：
- **「释比」主持**——羌族祭司「释比」主持丧仪，诵经送魂、择日择地。
- **火葬**——焚化后收骨灰，装罐埋葬或撒于山野；火葬坪多设于村寨附近。
- **「跳丧」与丧歌**——众人围圈跳丧、唱丧歌。
- **白石崇拜**——羌族白石崇拜与丧葬祭祀（如坟上置白石）相关。
- **「羌年」祭祖**——羌年（农历十月初一）祭祖与丧葬祭祖观念相通。

## 二、历史源流

- **先秦**：羌人葬俗（火葬）见于《荀子》《吕氏春秋》等记载，为羌族火葬传统的早期文献依据。
- **明清**：方志（汶川县志、茂州志等）载其丧俗。
- **近代**：受汉文化影响，土葬渐多。
- **当代**：2008 年汶川地震后，重建与丧俗保护同时推进。

## 三、仪节流程

1. **临终**：家人守护；鸣枪报丧。
2. **净身更衣**：净身、着新衣。
3. **停灵诵经**：停尸、设灵，释比诵经送魂。
4. **跳丧吊唁**：众人跳丧、唱丧歌，亲友吊唁。
5. **火葬（或土葬）**：择吉日火葬于火葬坪，或土葬筑坟。
6. **葬后祭祀**：收骨安放、坟上置白石；羌年、清明祭扫。

## 四、地域与支系变体

- **茂县、汶川**：羌族聚居区，释比系统与火葬传统保存较多。
- **理县、黑水**：与藏、汉族杂居，土葬渐多。
- **与其他民族关系**：羌族火葬传统与汉族土葬礼制不同源，服丧亦不采五服制度，须分别记录。

## 五、器物与文书

- **宗教器物**：释比法器（神杖、羊皮鼓、法冠）。
- **丧仪用品**：柴薪（火葬）、骨灰罐、白石、祭品、酒。
- **文书**：口传经文、族谱。
