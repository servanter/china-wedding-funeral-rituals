# 仡佬族丧葬

## 一、释义

仡佬族主要聚居于贵州（务川、道真、遵义、安顺等）及广西、云南部分地区。葬式以**土葬**为主，历史上曾行**岩葬（岩穴葬、悬棺葬）**，遗存见于贵州、川南等地。

**核心要素**：
- **「掌坛师」（端公）主持**——由端公（掌坛师）行度亡法事。
- **岩葬遗风**——历史上仡佬族行岩穴葬，今贵州、重庆部分地区仍有岩棺遗存。
- **「打牙」旧俗**——古代「打牙仡佬」有敲去门牙随葬之俗（已废），文献记载较多。
- **唱丧歌与「跳丧」**——守灵唱丧歌、跳丧。
- **受汉文化影响**——行「做七」「做道场」。

## 二、历史源流

- **先秦至唐宋**：「僚人」的岩葬习俗见于《华阳国志》等记载。
- **明清**：方志（遵义府志、安顺府志等）载「仡佬」丧俗与岩棺遗存。
- **近代**：与汉、苗族杂居，丧俗汉化程度较高。
- **当代**：岩棺遗存成为考古研究对象；乡村保留传统仪节。

## 三、仪节流程

1. **临终**：家人守护；鸣炮报丧。
2. **净身更衣**：净身、着新衣。
3. **入殓停灵**：入棺、设灵，端公行法事。
4. **做道场**：请端公行「破狱」等科仪；亲友吊唁、唱丧歌。
5. **出殡下葬**：择日送葬、土葬。
6. **葬后祭祀**：圆坟、做七、「周年」；清明、年节祭扫。

## 四、地域与支系变体

- **黔北（务川、道真）**：聚居区，端公系统完整。
- **黔中（安顺、平坝）**：与布依、汉族杂居，习俗交融。
- **渝南、川南**：岩棺遗存较多。
- **广西隆林**：与壮、彝族杂居，习俗各异。
- **与其他民族关系**：仡佬族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：端公法器、经书、面具。
- **丧仪用品**：棺木、纸扎、纸钱、祭牲、酒。
- **遗存物**：岩棺、石棺（考古遗存）。
