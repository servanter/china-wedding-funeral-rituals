# 赫哲族丧葬

## 一、释义

赫哲族分布于黑龙江（同江、饶河、抚远）及内蒙古，历史上以渔猎为生。葬式以**土葬**为主，旧俗兼有**风葬、树葬**（用于特殊情形）。

**核心要素**：
- **「撂档子」（送魂仪式）**——赫哲族最具特色的丧仪：亡后满一定期限（一年、三年不等），请萨满举行「撂档子」，将亡魂送入阴间，萨满以神具「引路」并陈设亡者生前用品。
- **萨满主持**——由萨满送魂、择葬地。
- **殉犬旧俗**——旧俗以犬殉葬（犬为渔猎助手，或「以犬拉雪橇引路」之观念）。
- **丧服与禁忌**——亲属着丧服（白布），丧期禁歌舞、禁渔猎一定期限。
- **受汉文化影响**——近世行烧纸、做七等。

## 二、历史源流

- **明清**：赫哲族（「黑斤」「赫真」等）见于史籍（《柳边纪略》等），葬俗载于民族志。
- **近代**：与汉、满族交往密切，丧俗汉化加深。
- **当代**：定居后土葬为主，「撂档子」仪式在民族志与文艺作品中留存记录。

## 三、仪节流程

1. **临终**：家人守护；通报族人。
2. **净身更衣**：净身、着新衣（或以鱼皮、兽皮衣物）。
3. **入殓停灵**：入棺、设灵；萨满诵神。
4. **出殡下葬**：择日送葬、土葬。
5. **撂档子（送魂）**：期满举行送魂仪式，萨满引魂入阴间。
6. **葬后祭祀**：年节、清明祭扫。

## 四、地域与支系变体

- **同江（街津口）**：聚居区，习俗记录较多。
- **饶河（四排）、抚远**：与汉族杂居，仪式简化。
- **与其他民族关系**：赫哲族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：萨满神鼓、神衣、神偶。
- **葬具**：木棺、桦皮或兽皮覆盖物。
- **丧仪用品**：鱼皮／兽皮衣物、弓弩、渔具（随葬）、祭牲（犬、猪）。
