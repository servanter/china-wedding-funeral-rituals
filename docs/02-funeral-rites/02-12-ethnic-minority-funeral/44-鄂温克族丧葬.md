# 鄂温克族丧葬

## 一、释义

鄂温克族分布于内蒙古呼伦贝尔（鄂温克族自治旗、根河、陈巴尔虎旗）及黑龙江。因生计（牧、猎、农）与居住环境不同，丧俗差异较大，葬式以**土葬**为主，兼有**树葬、风葬**（用于萨满或特殊情况）。

**核心要素**：
- **萨满送魂**——旧时请萨满主持送魂；牧区部分受藏传佛教影响，请喇嘛诵经。
- **殉马旧俗**——牧区旧俗以亡者坐骑殉葬或举行象征性仪式。
- **「风葬／树葬」**——猎区、使鹿部（敖鲁古雅）有以桦皮包裹遗体置于树上的葬法，后拾骨再葬。
- **「祭灵」与丧歌**——停灵祭灵、唱丧歌。
- **丧期禁忌**——忌歌舞、忌婚娶，行净化仪式。

## 二、历史源流

- **明清**：鄂温克族（「索伦」「使鹿部」等）分居于黑龙江、呼伦贝尔，丧俗载于民族志与方式。
- **清代**：编入八旗的索伦部受满汉影响，牧区受藏传佛教影响。
- **当代**：火葬渐推，猎区传统葬俗在文化保护中受到关注。

## 三、仪节流程

1. **临终**：家人守护；通报族中长辈。
2. **净身更衣**：净身、着新衣。
3. **停灵祭灵**：停尸、设灵；请萨满（或喇嘛）诵经。
4. **出殡**：猎区旧俗行树葬、风葬；牧区行土葬。
5. **下葬或拾骨再葬**：土葬者筑坟；树葬者日后拾骨再葬。
6. **葬后祭祀**：圆坟、周年祭；清明、年节祭扫。

## 四、地域与支系变体

- **牧区（鄂温克族自治旗）**：土葬为主，喇嘛诵经可见。
- **猎区（根河敖鲁古雅）**：使鹿鄂温克另有树葬、风葬传统。
- **农区与黑龙江**：与汉、达斡尔族杂居，习俗汉化。
- **与其他民族关系**：鄂温克族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：萨满神鼓、神衣（旧时）；喇嘛经卷、法器。
- **丧仪用品**：桦皮、兽皮、木棺、祭牲（驯鹿、马）。
- **文书**：讣告、族谱。
