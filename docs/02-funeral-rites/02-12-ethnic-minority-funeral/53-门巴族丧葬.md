# 门巴族丧葬

## 一、释义

门巴族主要聚居于西藏墨脱、林芝、错那等地，信仰**藏传佛教**，兼有原始信仰。葬式多样，有水葬、土葬、火葬、天葬等，**以水葬较为常见**。

| 葬式 | 适用 | 说明 |
| --- | --- | --- |
| **水葬** | 一般民众 | 遗体投入江河，为门巴族常见葬式 |
| **土葬** | 部分地区、凶死者 | 掘穴埋葬 |
| **火葬** | 僧侣、上层 | 焚化后收骨 |
| **天葬** | 部分地区 | 施于天葬台 |

**核心要素**：请喇嘛诵经超度；亡后四十九日内诵经、布施；丧期禁忌（禁歌舞、禁耕作）。

## 二、历史源流

- **唐宋至明清**：门巴族先民葬俗见于藏文文献与地方志。
- **近代**：藏传佛教在门巴族地区影响加深。
- **当代**：丧仪渐简，宗教仪轨仍为核心。

## 三、仪节流程

1. **临终**：家人守护；请喇嘛诵经。
2. **停尸**：以白布裹尸，置于屋内一角，喇嘛诵经。
3. **出殡**：择吉时送出，背尸人（或专人）送至葬地。
4. **施行葬式**：水葬投河；土葬掘穴；火葬搭炉焚化。
5. **葬后超度**：四十九日内诵经、布施、供灯。
6. **祭祀**：忌日诵经；年节祭祖。

## 四、地域与支系变体

- **墨脱（门巴族聚居区）**：水葬较常见。
- **错那、林芝**：与藏族杂居，天葬、火葬并存。
- **与其他民族关系**：门巴族丧俗属藏传佛教文化系统，与汉族五服制度无关，须分别记录。

## 五、器物与文书

- **宗教器物**：念珠、酥油灯、经幡、玛尼堆。
- **丧仪用品**：白布、糌粑、青稞酒、柏枝（煨桑）。
- **文书**：超度经文、祈愿文。
