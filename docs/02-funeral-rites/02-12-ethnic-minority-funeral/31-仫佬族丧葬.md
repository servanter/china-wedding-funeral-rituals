# 仫佬族丧葬

## 一、释义

仫佬族主要聚居于广西河池（罗城仫佬族自治县等地）。葬式以**土葬**为主，普遍行**二次葬**（拾骨装坛再葬）。

**核心要素**：
- **「师公」主持**——由师公行度亡法事，兼请道公做道场。
- **唱丧歌**——守灵唱丧歌，以壮、汉双语演唱。
- **受汉壮影响**——行「做七」「百日」「周年」；丧仪与壮族习俗相近。
- **「依饭节」**——仫佬族「依饭节」祭祖传统与丧葬祭祖观念相通。
- **丧期禁忌**——禁歌舞、禁婚娶，行净化仪式。

## 二、历史源流

- **唐宋至明清**：仫佬族先民（「僚」「伶」等）葬俗见于史籍与方志（庆远府志等）。
- **近代**：与壮、汉族杂居，丧俗汉化程度较高。
- **当代**：火葬渐推，乡村二次葬仍有留存。

## 三、仪节流程

1. **临终**：家人守护；鸣炮报丧。
2. **净身更衣**：净身、着新衣。
3. **入殓停灵**：入棺、设灵，师公行法事、唱丧歌。
4. **做七行道场**：每七日设祭，行「打斋」科仪。
5. **出殡下葬**：择日送葬、土葬。
6. **拾骨再葬**：数年后拾骨装坛，择地再葬。
7. **葬后祭祀**：做七、「周年」；清明、依饭节等节令祭扫。

## 四、地域与支系变体

- **罗城**：仫佬族聚居核心区，师公系统完整。
- **宜州、柳城**：与壮、汉族杂居，习俗交融。
- **与其他民族关系**：仫佬族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **葬具**：棺木、拾骨陶坛。
- **宗教器物**：师公法器、经书。
- **丧仪用品**：纸扎、纸钱、祭牲、酒。
