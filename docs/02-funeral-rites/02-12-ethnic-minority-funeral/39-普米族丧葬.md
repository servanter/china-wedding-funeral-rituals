# 普米族丧葬

## 一、释义

普米族主要聚居于云南怒江（兰坪）、丽江（宁蒗）及四川凉山（盐源、木里）等地。传统行**火葬**，近代部分地区改**土葬**。

**核心要素**：
- **「韩规」（祭司）主持**——由韩规诵经送魂，指引亡魂回归祖居地（与普米族迁徙记忆相应）。
- **「罐罐葬」**——火葬后收骨灰装入陶罐（「罐罐」）埋葬，为普米族传统葬式特征。
- **「给羊子」**——部分地区的丧仪中为亡者「给羊子」（献羊引路），为特有仪式。
- **丧歌与跳丧**——通宵唱丧歌、围圈跳丧。
- **藏传佛教影响**——部分地区请喇嘛诵经。

## 二、历史源流

- **唐宋至明清**：普米族先民（「西番」）见于史籍与方志（丽江府志等）。
- **近代**：与纳西、藏、彝族杂居，习俗互有影响。
- **当代**：火葬、土葬并行，传统仪节在聚居区保存。

## 三、仪节流程

1. **临终**：家人守护；鸣枪报丧。
2. **净身更衣**：净身、着新衣。
3. **停灵诵经**：停尸、设灵，韩规诵经送魂。
4. **跳丧吊唁**：亲友吊唁、唱丧歌、跳丧；部分地区行「给羊子」。
5. **火葬（或土葬）**：择日送葬火化，收骨灰装罐埋葬。
6. **葬后祭祀**：罐罐安放、祭祖；年节、清明祭扫。

## 四、地域与支系变体

- **云南兰坪、宁蒗**：聚居区，韩规系统与火葬传统保存较多。
- **四川盐源、木里**：与纳西、藏族杂居，习俗互渗。
- **与其他民族关系**：普米族火葬与「罐罐葬」传统与汉族土葬礼制不同源，服丧亦不采五服制度，须分别记录。

## 五、器物与文书

- **宗教器物**：韩规法器、经书。
- **丧仪用品**：柴薪（火葬）、骨灰陶罐、祭牲（羊）、酒。
- **文书**：口传经文、族谱。
