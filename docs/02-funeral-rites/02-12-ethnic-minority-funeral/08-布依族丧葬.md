# 布依族丧葬

## 一、释义

布依族分布于贵州南部、西南部及云南、四川部分地区。葬式以**土葬**为主，普遍行**二次葬**（「拾骨」装罐再葬）。

**信仰与仪节**：
- **「布摩」（巫师）主持**——由布摩（祭司）诵经、择日、送魂；布依族有土俗文字与经文抄本。
- **「砍牛」（做斋）**——部分地区为亡者「砍牛」（宰牛祭献），为重要仪节。
- **唱孝歌与「跳丧」**——守灵唱孝歌，有的地区行「转场」舞。
- **受汉族影响**——通行「做七」「百日」「周年」，并请道士、僧侣做法事。

## 二、历史源流

- **唐宋**：布依族先民（「僚」等）葬俗见于史籍。
- **明清**：方志（贵州通志、兴义府志等）「风俗」门载丧仪；「砍牛」之俗记载较多。
- **近现代**：与汉族、苗族杂居，丧俗交融。
- **当代**：火葬渐推，乡村仍存做斋、二次葬之俗。

## 三、仪节流程

1. **临终**：家人守护，鸣炮报丧。
2. **净身更衣**：净身、着新衣（或民族服装）。
3. **入殓停灵**：入棺、设灵，请布摩诵经。
4. **做斋砍牛**（部分地区）：宰牛祭亡，亲友共食。
5. **出殡下葬**：择日送葬，土葬。
6. **拾骨再葬**：数年后拾骨装罐，择地再葬。
7. **葬后祭祀**：清明、中元、年节祭扫；「百日」「周年」设祭。

## 四、地域与支系变体

- **黔南（黔南州）**：布依族集中，做斋、砍牛之俗可见。
- **黔西南（兴义、安龙）**：与苗族、彝族杂居，习俗互渗。
- **黔中（贵阳、安顺）**：近汉族，丧俗汉化程度较高。
- **云南（曲靖、文山）**：与壮、壮族支系习俗相近。
- **与其他民族关系**：布依族服丧以禁忌与丧期为限，不采五服制度，须分别记录。

## 五、器物与文书

- **葬具**：棺木、拾骨陶罐。
- **宗教器物**：布摩法器、经文抄本、铜鼓。
- **丧仪用品**：纸扎、纸钱、牛（祭牲）、酒、糯米饭。
- **文书**：讣告、经文抄本、族谱。
