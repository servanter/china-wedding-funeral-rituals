# 独龙族丧葬

## 一、释义

独龙族聚居于云南怒江贡山独龙族怒族自治县独龙江流域。葬式以**土葬**为主，兼有**火葬、水葬**（视死因与年龄而定）。

**核心要素**：
- **「乌」（巫师）主持**——由巫师「乌」或「南木萨」诵经送魂。
- **分区埋葬**——正常死亡者近屋埋葬（或于屋内），凶死者（难产、传染病、意外）另择地埋葬或水葬，为显著禁忌。
- **「剽牛」祭亡**——以牛祭献亡者，剽牛为独龙族重要仪式（兼用于祭天、祭祖）。
- **丧歌与吊唁**——通宵唱丧歌、亲友吊唁。
- **丧期禁忌**——禁耕作、禁歌舞；葬后行净化仪式。

## 二、历史源流

- **唐宋至明清**：独龙族先民（「俅人」等）葬俗见于史籍与方志。
- **近代**：因峡谷封闭，传统习俗保存较久。
- **当代**：交通改善后习俗渐简，传统仪式在村寨仍有留存。

## 三、仪节流程

1. **临终**：家人守护；鸣枪报丧。
2. **净身更衣**：净身、着新衣（或以麻布裹身）。
3. **停灵吊唁**：停尸、设灵，巫师诵经，唱丧歌。
4. **剽牛祭亡**（部分地区）：以牛祭献。
5. **出殡下葬**：择地土葬（凶死者另葬或水葬）。
6. **葬后祭祀**：圆坟、行净化仪式；年节、祭天祭祖时祭扫。

## 四、地域与支系变体

- **独龙江上游、下游村落**：上下游支系习俗略有差异。
- **贡山其他地区**：与怒、傈僳族杂居，习俗互渗。
- **与其他民族关系**：独龙族无五服制度，服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **宗教器物**：乌、南木萨法器，祭器。
- **丧仪用品**：麻布、木棺或篾席、祭牲（牛、猪、鸡）、酒。
- **特色物**：独龙毯（独龙族传统织物，用于裹尸或随葬）。
