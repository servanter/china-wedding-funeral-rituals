# 撒拉族丧葬

## 一、释义

撒拉族主要聚居于青海循化撒拉族自治县及化隆、甘肃积石山等地，信仰伊斯兰教，丧葬依**速葬、土葬、薄葬**原则。

**核心要素**：
- **速葬**——亡后当日或次日安葬。
- **净身与「克凡」**——专人净身，白布裹身（三件）。
- **「站礼」（殡礼）**——阿訇领拜，众人列班。
- **「乃孜尔」**——亡后七日、四十日、周年请阿訇诵经、待客。
- **禁忌**——忌嚎哭、忌焚纸钱、忌看风水、忌久停。

## 二、历史源流

- **元代**：撒拉族先民自中亚东迁至循化，伊斯兰教在社区生活中居核心地位。
- **明清**：清真寺与门宦拱北承担殡葬与纪念事务。
- **当代**：仪轨沿袭，寺坊承办殡葬。

## 三、仪节流程

1. **临终**：请阿訇念经，家人守护。
2. **归真后**：闭目、覆白布，通报寺坊。
3. **净身与裹尸**：专人净身，白布裹尸。
4. **站礼**：在清真寺或墓地举行站礼。
5. **送葬下葬**：送至墓地，墓穴设侧室，面向麦加（西向）。
6. **乃孜尔**：七日、四十日、周年诵经、待客。

## 四、地域与支系变体

- **青海循化**：聚居核心区，仪轨规范。
- **化隆、甘肃积石山**：与回、东乡、保安族杂居，习俗相类。
- **与其他民族关系**：与同遵伊斯兰葬礼诸族细节有异，与汉族五服体系不同源，须分别记录。

## 五、器物与文书

- **丧仪用品**：白布（克凡）、水床、抬尸木匣（塔布提）、香料。
- **宗教器物**：《古兰经》、念珠、清真寺、拱北。
- **墓地**：清真寺附属墓地、墓碑（多刻阿拉伯文）。
