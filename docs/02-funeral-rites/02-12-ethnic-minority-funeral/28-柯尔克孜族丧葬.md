# 柯尔克孜族丧葬

## 一、释义

柯尔克孜族主要分布于新疆克孜勒苏柯尔克孜自治州及伊犁、阿克苏等地，信仰伊斯兰教，丧葬依**速葬、土葬、薄葬**规范，并保留游牧社会的**挽歌与周年祭**传统。

**核心要素**：
- **速葬土葬**——亡后当日或次日安葬，白布裹身，墓穴设侧室。
- **阿訇主持**——净身、站礼（殡礼）由阿訇主持。
- **女性唱挽歌**——亲属（尤以女性）唱挽歌致哀，歌词述亡者生平。
- **「乃孜尔」**——七日、四十日、周年诵经、待客。
- **周年祭**（「艾西」）——旧俗规模隆重，有宰牲、聚会等活动。

## 二、历史源流

- **伊斯兰教传入后**：丧葬规范确立，与游牧旧俗结合。
- **清代**：柯尔克孜部众分布于天山南北，丧俗与宗教信仰相应。
- **当代**：城市丧俗简化，宗教仪轨为核心。

## 三、仪节流程

1. **临终**：请阿訇念经，家人守护。
2. **归真后**：闭目、覆白布。
3. **净身与裹尸**：专人净身，白布裹尸。
4. **站礼**：在清真寺或墓地举行站礼。
5. **送葬下葬**：送至墓地下葬，面向麦加（西向）。
6. **乃孜尔与周年祭**：七日、四十日、周年诵经、待客。

## 四、地域与支系变体

- **克孜勒苏（阿图什、乌恰）**：聚居区，仪轨规范。
- **伊犁、阿克苏**：与维吾尔、哈萨克族习俗相邻。
- **与其他民族关系**：与同遵伊斯兰葬礼诸族细节有异，与汉族五服体系不同源，须分别记录。

## 五、器物与文书

- **丧仪用品**：白布（裹尸）、水床、抬尸木架、香料。
- **宗教器物**：《古兰经》、念珠、清真寺。
- **祭祀物**：周年祭所用祭牲。
