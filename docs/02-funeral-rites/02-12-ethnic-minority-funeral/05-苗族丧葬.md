# 苗族丧葬

## 一、释义

苗族分布广（贵州、云南、湖南、广西、重庆、四川等），支系众多，丧俗差异较大，但共通的信仰内核是**「送魂归祖」**——通过仪式把亡魂送回祖先原居地。

**主要葬式**：土葬为主，部分地区有**岩葬（洞葬、悬棺）** 遗存，个别地区行火葬。

**核心仪节**：
- **「开路」**——由巫师（祭司）诵《指路经》或唱「开路歌」，为亡魂指明返回祖居地的路线。
- **芦笙与鼓**——以芦笙、木鼓伴丧，黔东南苗族「鼓社」组织与丧仪相关。
- **「砍牛」（打牛）**——部分地区以牛祭亡，血缘亲属共食「坨坨肉」。

## 二、历史源流

- **先秦至唐宋**：苗族先民「三苗」「南蛮」的葬俗与迁徙记忆叠合，「送魂」观念与族群迁徙史相应。
- **明清**：方志（贵州通志、湖南通志等）「苗俗」门载丧仪；「鼓社」「议榔」等社会组织承担丧事。
- **近代**：基督教传入部分苗区，少数家庭行教会葬礼。
- **当代**：火葬渐推，传统「开路」「打牛」之俗在黔东南、湘西仍有留存。

## 三、仪节流程

1. **临终**：家人守护，鸣枪或吹芦笙报丧。
2. **净身更衣**：以清水净身，着民族盛装（女性着盛装、银饰）。
3. **停灵与开路**：请祭司「开路」，诵送魂经；亲友吊唁，吹芦笙、击鼓。
4. **打牛祭亡**（部分地区）：宰牛祭献，以牛角挂于门首或坟前。
5. **出殡下葬**：择日下葬，葬地多依山，有的村落设公共墓地。
6. **葬后祭祀**：举行「送魂」仪式的收束之节；清明、年节、吃新节祭扫。

## 四、地域与支系变体

- **黔东南（台江、雷山、剑河）**：「鼓社」与丧仪关系密切，芦笙、木鼓盛行。
- **湘西（湘西州）**：近土家、汉族，「开路」与「跳丧」并存。
- **黔西北、滇东北（毕节、昭通）**：近彝族，丧仪受彝俗影响。
- **滇南、桂北**：与壮、瑶、布依族杂居，习俗互有渗透。
- **与其他民族关系**：苗族无「五服」制度，亲属服丧以禁忌与丧期为限，须分别记录。

## 五、器物与文书

- **乐器**：芦笙、木鼓、铜鼓。
- **丧仪用品**：民族盛装、银饰、牛（祭牲）、酒、糯米饭。
- **宗教器物**：祭祀用具、送魂经（口传）。
- **墓地标志**：牛角、坟标、石碑（近世渐多）。
