# 壮族丧葬

## 一、释义

壮族是人口最多的少数民族，主要分布于广西，兼及云南、广东、贵州。葬式以**土葬**为主，且普遍行**二次葬**（初葬数年后「拾骨」装坛再葬），与汉族华南地区习俗相通。

**信仰与仪节**：
- **「道公」「师公」主持**——由民间道教色彩的「道公」或「师公」主持丧事科仪。
- **唱丧歌**——以壮语唱丧歌，内容述亡者生平与孝道。
- **受汉族影响**——普遍行「做七」「百日」「周年」等祭期，反映汉壮文化交融。
- **「三月三」与祭祖**——歌圩节与祭祖活动相关。

## 二、历史源流

- **先秦至唐宋**：「骆越」「西瓯」先民葬俗的考古遗存（如石铲、铜鼓随葬）。
- **唐宋以降**：道教与佛教先后传入，与本土信仰结合形成「道公」「师公」传统。
- **明清**：方志（广西通志、各府州县志）「风俗」门载丧仪；土司地区丧礼有等级之别。
- **当代**：火葬渐推，二次葬在乡村仍有留存。

## 三、仪节流程

1. **临终**：家人守护；鸣炮或击鼓报丧。
2. **净身更衣**：以清水或柚叶水净身，着新衣。
3. **入殓停灵**：入棺、设灵，请道公做法事，唱丧歌。
4. **做七行道场**：每七日设祭，行「打斋」「破狱」等科仪。
5. **出殡下葬**：择日送葬，土葬；有的地区「停棺待葬」，另择吉日再葬。
6. **拾骨再葬**：数年后开棺拾骨，装入「金坛（金瓮）」择地再葬。
7. **葬后祭祀**：清明、三月三、中元祭扫；「百日」「周年」设祭。

## 四、地域与支系变体

- **桂中（南宁、来宾、柳州）**：道公科仪完整，做七与二次葬并行。
- **桂西（百色、河池）**：与瑶、侗、布依族杂居，习俗互渗。
- **桂北（桂林）**：近湖南，兼有湘俗痕迹。
- **云南壮族（文山）**：与苗、瑶、哈尼族杂居，习俗各异。
- **与其他民族关系**：壮族喪俗与汉族丧俗互有影响，但亲属服制不采五服体系，须分别记录。

## 五、器物与文书

- **葬具**：棺木、金坛（金瓮，拾骨用）。
- **宗教器物**：道公法器（铃、鼓、经书）、香烛、符箓。
- **丧仪用品**：纸扎、纸钱、祭品（糯米饭、鸡、酒）。
- **文书**：讣告、科仪文本、族谱。
