# 蒙古族丧葬

## 一、释义

蒙古族分布以内蒙古自治区为主，兼及东北、西北各省。传统葬式有**野葬（天葬）、火葬、土葬**三种，其中以野葬最具民族特色：

| 葬式 | 适用 | 说明 |
| --- | --- | --- |
| **野葬（天葬）** | 一般平民 | 尸体载于牛车或马背，弃于荒野，任鸟兽食尽为吉 |
| **火葬** | 喇嘛、贵族、上层 | 焚尸拾骨，骨灰入塔或撒于山川 |
| **土葬** | 农区、半农半牧区 | 受汉族影响，棺殓入土 |

**信仰基础**：蒙古族传统信仰萨满教，后普遍皈依藏传佛教，故丧仪中有**请喇嘛诵经超度**之节。民间忌大声哭号，以为哭号会牵扰亡魂、耽误其「转世」之程。

## 二、历史源流

- **蒙元时期**：丧葬「不立冢墓」之风见于使臣行记；贵族行火葬、深埋。
- **明清**：藏传佛教普及，诵经超度成为丧仪核心；农区汉化加深，土葬渐多。
- **近现代**：牧区仍有野葬遗存，农区以土葬为主；殡葬改革后推行火葬。
- **文献**：《蒙古秘史》及明清蒙古文史书、各族简史简志与民俗志。

## 三、仪节流程

1. **临终**：家人守护，请喇嘛诵经「送魂」；忌在帐内哭泣喧闹。
2. **净身与更衣**：以清水净身，着素衣或以白布裹身。
3. **停灵诵经**：请喇嘛诵经超度，通常一至三日或七七四十九日之数。
4. **送葬**：野葬者由牛车送至荒野；火葬者备薪焚化；土葬者棺殓入土。
5. **葬后祭祀**：请喇嘛诵经「回向」，逢忌日、清明、年节设祭；游牧家庭以「敖包」祭祀为场所。

## 四、地域与支系变体

- **内蒙古牧区**：野葬、火葬遗俗较多，诵经隆重。
- **内蒙古农区（土默特、河套）**：土葬为主，礼数近汉族。
- **东北蒙古族（辽宁、吉林、黑龙江）**：与满族、汉族杂居，土葬为主。
- **青海、甘肃、新疆蒙古族**：受藏传佛教影响更深，天葬、火葬并存。
- **与其他民族关系**：蒙古族丧俗与汉族五服体系不同源，须分别记录。

## 五、器物与文书

- **宗教器物**：念珠、玛尼轮、经文、酥油灯、供品。
- **葬具**：木棺（农区）、白布（裹身）、牦牛车（野葬运尸）。
- **祭祀物**：敖包祭品、酒、奶食（奶豆腐、奶子）。
