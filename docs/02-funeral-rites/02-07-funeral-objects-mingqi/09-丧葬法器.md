# 丧葬法器（引磬、木鱼、铃铛）

## 一、释义

丧葬法器是**佛、道二教在丧事法事（做七、放焰口、超度、接三、度亡）中所用的法器与乐器**。自唐宋以来，民间丧礼普遍请僧道诵经设醮，法器遂成为丧葬器物的重要一类。

**常见法器**：

| 法器 | 形制 | 用途 |
| --- | --- | --- |
| **引磬** | 小铜磬，附长柄 | 领众、起止唱念，声清而远 |
| **木鱼** | 木制，鱼形或圆球状 | 节制诵经节拍，调心摄念 |
| **铃／手铃** | 铜铃、金刚铃 | 惊觉、迎请，密教尤重 |
| **铛子、铪子** | 铜制打击乐器 | 法事乐队伴奏 |
| **鼓、大磬** | 大型打击乐器 | 法事主奏 |
| **法尺、令牌** | 木质、金属 | 道教科仪中号令之用 |

## 二、历史源流

- **佛教**：法器随佛教东传（汉魏）而进入中国；「引磬」之名见于唐宋禅林清规，木鱼则至明清定型。
- **道教**：钟、磬、铃、鼓等为斋醮科仪所必备，道教「法器」一词本指行法之具。
- **唐宋**：民间丧事已普遍延请僧道，「做七」「十王斋」之俗与法事结合。
- **明清**：佛道法事与丧礼深度结合，「放焰口」「施食」「拜忏」等科仪盛行，法器种类齐备。
- **近代以来**：农村丧事仍多请僧道用引磬、木鱼；城市殡仪馆则以音响播放替代，或由礼仪人员主持。

## 三、仪节流程

1. **起经**：灵前设经坛、佛像（或神位），法器陈设就位。
2. **诵经拜忏**：以引磬领众，木鱼节拍，铃、鼓、铛铪伴奏。
3. **做七**：自亡故起每七日一次法事（「头七」至「七七」），法器随仪节使用。
4. **放焰口／施食**：法事高潮，铃、磬并用，施食济度孤魂。
5. **出殡奏乐**：送葬时法器乐队前行（「送葬乐」）。

## 四、地域与民族变体

- **江南**：僧道法事繁复，「吹打」「做道场」盛行，法器与丝竹并用。
- **闽台**：佛道兼行，「师公」（道士）与僧侣均用引磬、木鱼、法器乐队。
- **华北**：以「吹鼓手」为主，法器与鼓吹乐并重。
- **少数民族**：各民族宗教性丧仪用器各异（如藏族转经筒、唢呐，傣族铜鼓），其信仰体系与汉族佛道丧仪不同，须分别记录。

- **法器**：引磬、木鱼、铃、铛子、铪子、鼓、大磬、香炉、烛台。
- **经坛陈设**：经书、佛像（神位）、往生牌位、经幡。
- **科仪文本**：《禅门日诵》《瑜伽焰口》、道教度亡科仪、民间「经单」「疏文」。
