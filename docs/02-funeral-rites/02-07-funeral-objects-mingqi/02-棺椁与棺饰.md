# 棺椁与棺饰

## 一、释义

**棺**为直接盛放遗体的葬具；**椁**为套在棺外的大型葬具（木椁或石椁）。《礼记·檀弓上》：「**夫子制于中都，四寸之棺，五寸之椁**」，郑玄注谓棺厚四寸、椁厚五寸，后世遂以「棺椁」连称，成为丧葬等级的核心标识。

- **棺**：又称「柩」（已殓之棺）、「榇」「椟」（较小者）。
- **椁**：又称「椁室」「外椁」；考古所见商周大墓的「椁室」以枋木垒成，内分数室。
- **棺饰**：覆于棺外或悬于殡所棺上的装饰，包括帷、荒、帱、池、纽、齐、揄、翣（扇）等。

**等级原则**：棺椁的**重数**（棺椁层数）与**尺寸**依身份而定——天子「四重」（或谓「五重」）、诸侯三重、大夫二重、士一重，庶人单棺无椁（各地礼书表述略有出入）。

## 二、历史源流

- **先秦**：木椁墓为贵族主流，棺椁多重、多有棺饰；《礼记·丧大记》详载棺饰名物与陈设方位。
- **战国秦汉**：木椁墓极盛（如马王堆汉墓一椁四棺，棺饰华丽，内棺绘帛画）；东汉以后**砖室墓、石室墓**取代木椁，椁室之制渐废，棺成为主要葬具。
- **魏晋至隋唐**：棺制沿袭，唐代对棺的尺寸、材质有令式规定；棺饰（棺罩、棺帷）简化。
- **宋元明清**：棺木材质以柏、杉、松为上，讲究「独木棺」「拼板棺」；南方盛行厚重「土漆棺」，棺罩以绣花绸缎制作。
- **近代以来**：城市推行火葬，棺逐渐退出，骨灰盒取代棺的盛殓功能；农村部分地区仍存棺葬。

## 三、仪节流程

1. **择材制棺**：多在生前或初丧后即制棺，讲究材质（柏、杉为上）、板厚、独木或拼板。
2. **入殓**：大殓时遗体入棺，棺内铺垫、随葬小件明器。
3. **盖棺（盖棺定论）**：亲属最后瞻视后盖棺钉封。
4. **饰棺**：殡期加棺罩、棺帷、绣花棺套；出殡时「棺罩」覆于棺上。
5. **下柩入圹**：即「窆」，棺入墓穴，封墓门。

## 四、地域与民族变体

- **华北**：棺木厚重，讲究「独板」「四独」，出殡时加绣花棺罩。
- **江南**：重漆棺，棺身多髹黑漆或朱漆，棺外常加棺套。
- **闽台**：棺木「上柏下杉」之说，棺罩（棺帷）绣制讲究，出殡有「棺头、棺尾」之分。
- **西南部分地区**：有以整木凿成的「船棺」或「独木棺」，形制独特，属地方传统，与汉式礼制棺椁有别的谱系。
- **少数民族**：各民族葬具差异极大（树葬、天葬、瓮棺、石棺等），不属汉式棺椁体系，须分别记录。

## 五、器物与文书

- **棺木**：柏木、杉木、松木、楠木；板厚有「三寸板」「四寸板」之别。
- **棺饰**：棺罩、棺帷、绣花棺套、翣（大扇）、荒帷。
- **椁**：木椁、石椁（考古所见）。
- **相关文书**：棺之尺寸、材质见于丧仪单（「丧事单」「丧榜」）与族谱家礼抄本。
