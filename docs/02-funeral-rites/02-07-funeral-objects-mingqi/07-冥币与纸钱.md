# 冥币与纸钱

## 一、释义

冥币、纸钱，是**以纸制成、焚烧后供死者在冥间使用的「货币」**，为宋代以来民间丧祭中最通行的明器。称谓多样：「纸钱」「寓钱」「楮钱」「钱纸」「金银纸」「元宝」「锡箔」「冥币」等。

**与明器的关系**：纸钱是最典型的「备物而不可用」之物——本为假币，通过**焚烧（化）**这一仪式动作完成由「纸」向「冥间财物」的转换，故「烧」为纸钱使用的核心。

## 二、历史源流

- **汉魏**：瘗钱（以真钱随葬）之风盛行，魏晋以后渐有以纸代钱之议。
- **唐代**：**纸钱大兴**。封演《封氏闻见记》载：「今代送葬，为凿纸钱，积钱为山」，并辨其为「寓钱」。唐时焚烧纸钱已成通行。
- **唐宋之际**：出现「打钱」（以纸模打制钱纹）、「纸马」「纸钱铺」等行业，汴京、临安有专卖纸马纸钱之铺。
- **宋元明清**：纸钱形成完整体系——「烧纸」「挂纸」「压纸」（墓上压纸）、「撒纸钱」（出殡撒路钱）等多种用法；锡箔元宝在明清尤为流行。
- **近代以来**：出现机器印制的「冥币」，模仿现实货币样式（甚至仿外币）。
- **当代**：城市多有禁烧纸钱之规定，代之以鲜花；农村与部分城市仍有焚烧习俗。

## 三、仪节流程

1. **种类选用**：白纸钱（素纸）用于初丧、报丧；黄纸钱、金银纸（元宝、锡箔）用于烧化供奉。
2. **挂纸、压纸**：葬后于坟头挂纸、压纸，标示祭扫。
3. **烧纸**：在丧礼各节点（入殓、出殡、葬后「复三」「五七」「百日」「周年」「中元」）于坟前或路口焚烧。
4. **撒纸钱（买路钱）**：出殡沿途撒纸钱，民间解释为「买路」或「施舍游魂」。
5. **焚化讲究**：忌用脚踩、忌随意翻动；部分地区讲究「画圈」并留口，或先烧若干「散钱」以施孤魂。

## 四、地域与民族变体

- **华北**：以黄纸「打钱」（用铜钱模子打出钱纹）为主，坟前烧化。
- **江南**：锡箔元宝发达，苏州、杭州一带「锡箔业」历史悠久。
- **闽台**：金银纸分类最细（寿金、刈金、银纸、库钱等），用途有别，祭祀对象不同用纸不同。
- **广东**：「溪钱」「金银纸」并用，出殡沿途撒「溪钱」。
- **少数民族**：部分民族亦焚纸祭祖（受汉族影响），但更多民族以焚香、献牲、献酒等方式祭祀，其体系与汉族纸钱不同，须分别记录。

## 五、器物与文书

- **纸钱类型**：白纸钱、黄纸钱、金银纸、元宝、库钱、冥币。
- **制作工艺**：打钱（钱模）、折元宝、锡箔粘贴。
- **相关器物**：钱模、纸钱凿、化钱炉、焚纸盆。
- **相关文书**：「库钱」之「冥库」文书、封包（写明收受者名号，如「某公讳某收用」）。
