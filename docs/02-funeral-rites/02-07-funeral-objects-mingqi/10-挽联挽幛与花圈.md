# 挽联、挽幛与花圈

## 一、释义

挽联、挽幛、花圈是近代以来最通行的**致哀礼品与陈设**，多由亲友、单位赠送，构成灵堂的主要装饰。

- **挽联**：哀悼死者的对联，悬于灵堂两侧或挽幛之前，上联称「右」，下联称「左」。
- **挽幛**（挽轴、祭幛）：整幅绸、缎、布或纸，书悼念之辞（「驾鹤西归」「音容宛在」），两侧加落款（送者名号）。
- **花圈**：以竹木为架，缀纸花或鲜花，环状陈列，旁附挽带写明上下款。
- **挽带（挽条）**：花圈上的两纸条，上联写「悼念某某先生」，下联写「某某敬挽」。

**陈放次序**：花圈以**亲疏、尊卑**为序排列于灵堂内外；挽幛悬挂于灵堂两侧，挽联居显要位置。

## 二、历史源流

- **远源**：挽（輓）本指「引车」，古有「执绋」助葬之礼，「挽歌」自汉魏以来为送葬之乐（《薤露》《蒿里》）。
- **挽联**：由楹联发展而来，明清文人为人作挽联成风，清代尤盛，出现挽联专集。
- **挽幛**：明清以来以绸缎、布匹为悼礼（「幛」亦作「帐」），可悬可收，兼具礼品性质。
- **花圈**：近代自西方传入（或云由「花圈」与中式「纸花」结合），清末民初随新式葬礼普及。
- **当代**：挽联、挽幛、花圈与黑纱、白花同为当代丧礼的主要致哀形式；城市多以鲜花花圈替代纸花圈。

## 三、仪节流程

1. **送达**：亲友、单位将挽幛、花圈送至灵堂，由「礼房」（执事）登记（记于「挽联簿」「丧礼簿」）。
2. **陈设**：按亲疏、辈分、单位次序排列花圈；挽幛、挽联悬挂。
3. **上款下款**：花圈挽带书写上下款，挽联、挽幛书送者名号。
4. **举哀、行礼**：亲友在灵前致哀、行礼。
5. **撤除**：出殡后挽联挽幛撤下（由其自留或焚化）；花圈多送至墓地或焚化。

## 四、地域与民族变体

- **华北**：挽幛以绸缎为主，「送幛」为重要人情往来。
- **江南**：挽联讲究文辞书法，文人雅集有专集传世。
- **闽台**：挽幛称「轴」，色泽以白、蓝、黑为主，忌大红（唯「喜丧」例外）。
- **城市**：以鲜花花圈与挽联为主。
- **少数民族**：部分民族以特定织物、布幡致哀，其含义与汉族挽礼不同源，须分别记录。

## 五、器物与文书

- **挽联**：宣纸、绫绢（装裱），书上下联及落款。
- **挽幛**：绸缎、布、纸，书悼辞与落款；有「单挂」「双挂」之别。
- **花圈**：竹木架、纸花、绢花、鲜花；挽带为白纸或绸条。
- **相关文书**：挽联簿、丧礼簿（登记挽联、挽幛、花圈、赙金）——为近代丧事文书的重要一类。
