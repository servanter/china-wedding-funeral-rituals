# 随葬器物（陶俑、玉器、铜器）

## 一、释义

随葬器物是**葬入墓圹的各类实物与明器**的总称，范围大于狭义的「明器」——既包括专为丧葬而制的明器，也包括实用器（生器）随葬的情形。其品类随时代与等级而变，是考古分期断代与礼制研究的主要依据。

**主要类别**：

| 类别 | 代表器物 |
| --- | --- |
| **陶器** | 陶俑、陶仓、陶灶、陶井、陶屋、陶院落、唐三彩、陶器皿 |
| **玉器** | 玉璧、玉琮、玉圭、玉衣（金缕／银缕／铜缕玉衣） |
| **铜器** | 青铜礼器（鼎、簋、尊、爵）、铜镜、铜钱、铜灯 |
| **漆木器** | 漆棺、漆奁、木俑、木器 |
| **金属货币** | 瘗钱（随葬真钱）、金银器 |
| **其他** | 骨器、玻璃器、瓷俑、石俑 |

## 二、历史源流

- **新石器时代**：以陶器、石器、骨器、玉器随葬（良渚玉器、大汶口陶器为代表）。
- **商周**：青铜礼器随葬成制，「**列鼎制度**」以鼎的数量标示等级；玉器用于「敛尸」（玉覆面、玉琮）。
- **战国秦汉**：**陶俑与模型明器大兴**；玉衣制度至汉代完备（中山靖王刘胜夫妇金缕玉衣）；「**瘗钱**」与铜器、漆器同葬。
- **魏晋南北朝**：薄葬之风（曹操「薄葬令」）与厚葬并存；随葬品减少，瓷器开始出现。
- **隋唐**：唐三彩明器、陶俑（骑马俑、胡人俑、镇墓俑）极盛；唐令限制明器品数。
- **宋元明清**：随葬品趋于简化，瓷器、金银器为主；纸明器代替实物成为主流（见「纸扎」「冥币」条目）。
- **近代以来**：随葬器物以随身的首饰、手表、眼镜等小件为主。

## 三、仪节流程

1. **备器**：依身份与家力置备随葬器物，登记于**遣策**（遣册）。
2. **陈器**：出殡前陈于柩侧或庭中。
3. **入圹布置**：按方位置于椁室或墓室（头厢、边厢、壁龛、腰坑）。
4. **封墓**：随葬品布置完成后封闭墓门、封土。
5. **祭墓**：葬后祭墓（「墓祭」），后世「五七」「百日」等再行祭扫。

## 四、地域与民族变体

- **中原**：历代陶俑、青铜、玉器墓葬集中，考古序列完整。
- **江南**：六朝至明清墓葬青瓷、金银器发达。
- **北方与西北**：汉唐墓葬壁画、陶俑与「三彩」丰富。
- **少数民族**：各民族随葬传统差异极大——如部分民族随葬马具、生产工具、宗教法器等，其器物体系不以汉式「明器—生器」为框架，须分别记录。
