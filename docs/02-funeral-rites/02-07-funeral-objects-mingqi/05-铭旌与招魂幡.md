# 铭旌与招魂幡

## 一、释义

**铭旌**，又作「明旌」「旌铭」，是丧礼中书写死者名号、官爵的旗帜。《仪礼·士丧礼》：「**为铭，各以其物**」，郑玄注：「铭，明旌也，以死者为不可别已，故以其旗识之。」

- **铭旌**：以绛帛或素帛制成，上写「某官某公之柩」或「显考某公讳某之铭旌」，用竹杠挑起，立于柩前或覆于棺上。
- **招魂幡**：又称「引魂幡」「魂幡」「引路幡」，为引导亡魂的白色长幡，多由孝子执持，出殡时走在队伍最前。

**旌幡之别**：铭旌重在**标识死者身份**（承先秦「复」礼以衣招魂之遗意），招魂幡重在**引导亡魂**（受佛道信仰影响），二者在民间常并用且名称混同。

## 二、历史源流

- **先秦**：《仪礼·士丧礼》《礼记·丧服小记》载「铭」之制，尺寸依身份等差（天子、诸侯、大夫、士各有度）。
- **汉唐**：铭旌沿用，考古所见如马王堆汉墓「T 形帛画」即殓葬时所用之旌类物；唐以降铭旌书官爵、赠谥。
- **宋代**：《朱子家礼》定「铭旌」书「某官某公之柩」，并规定竖于柩前。
- **明清**：铭旌书「皇清诰授……之铭旌」等；招魂幡随佛道法事盛行而普及。
- **近代以来**：农村仍用白布幡、招魂幡；城市以花圈、挽幛替代旌幡功能。

## 三、仪节流程

1. **制旌**：初丧后以绛帛或白布制铭旌，请人书写死者官爵、姓讳。
2. **立旌**：竖铭旌于灵前（依《家礼》「以竹杠张之，立于柩前」）。
3. **执幡引路**：出殡时孝子执招魂幡（引魂幡）前行，为亡魂「指路」。
4. **覆旌入圹**：下葬时将铭旌覆于棺上或置于棺内，同入墓圹。
5. **焚幡**：部分地区葬后焚化招魂幡，或在「复三」「五七」时焚化。

## 四、地域与民族变体

- **华北**：铭旌书「先考某公讳某之铭旌」，招魂幡以白纸剪成，长子执之。
- **闽台**：幡有「魂幡」「招魂幡」之分，孝男执「杖」与幡，队伍前有「铭旌」队。
- **江南**：铭旌多书官衔、封赠，讲究书法与旌架装饰。
- **少数民族**：部分民族有以特定幡、布、纸条标示亡灵的做法（如满族「佛托」、部分西南民族「引路幡」），其信仰与文化脉络与汉族不同，须分别记录。

## 五、器物与文书

- **铭旌**：绛帛（或白布）、竹杠、旌架。
- **招魂幡**：白纸、白布、竹竿；形式有「剪花幡」「长条幡」「宝盖幡」等。
- **书写格式**：「某官某公之柩」「显考某公讳某之铭旌」；如有谥号、赠官一并书写。
- **相关文书**：铭旌文字与讣告、行状、墓志铭所载名号须一致。
