# 寿衣形制与讲究

## 一、释义

寿衣，又称「敛衣」「老衣」「送老衣」「装老衣裳」，是死者入殓时所着的衣物。古礼称「袭」（为死者换衣）与「小敛」「大敛」（为死者层层加衣），后世「寿衣」一词专指为死者预备的成套衣装。

**核心讲究**：民间寿衣以「**单数为吉、双数为忌**」为通行原则（三、五、七、九件成套），且忌用皮毛、忌用缎子（「缎」谐音「断」）、忌用黑色纽扣。礼制上则以「称家之有无」为节，不主张过度奢华（《礼记·檀弓》「丧具，称家之有无」）。

## 二、历史源流

- **先秦**：《仪礼·士丧礼》载「袭」与「小敛」「大敛」之衣，均以「称」计（如大敛「衣三十称」），衣数依身份等差；材质以丝、麻、布为常。
- **汉唐**：敛衣件数、材质有严格等级规定，出土实物（马王堆汉墓、唐墓）可见多层丝织衣物。
- **宋元明清**：《朱子家礼》主张依时俗简化，明清地方志多记「寿衣」件数与材质之讲究，民间形成「五领三腰」「七领五腰」等定式。
- **近代以来**：寿衣商品化，成衣铺、寿衣店专营；材质以棉、绸为主，颜色多为蓝、褐、灰、白。

## 三、仪节流程

1. **预备**：生前「做寿衣」（闰年闰月制作，取「闰」为吉），或以市售成套寿衣备置。
2. **沐浴后换衣**：即「袭」，在沐浴、饭含之后为死者换寿衣；民间多在断气后由孝子（女）为遗体更衣。
3. **层数**：依「单数」成规，通常「五领三腰」（上衣五件、下衣三件）或「七领五腰」。
4. **穿戴细节**：头戴寿帽，脚穿寿鞋（鞋底多绣莲花、云纹），身系腰带；忌露体、忌穿皮毛。
5. **入殓**：寿衣外再加衾被，然后入棺。

## 四、地域与民族变体

- **华北**：讲究「冬棉夏单」，寿衣以棉衣棉裤为主，颜色多为蓝、黑、褐。
- **江南**：寿衣多用绸料，喜用「万字纹」「团花」等吉祥纹样。
- **闽台**：寿衣件数讲究「上九下七」等定数，穿「寿鞋」时鞋底绣莲花。
- **广东**：讲究「五领三腰」，忌用缎、忌用皮毛，颜色忌大红。
- **少数民族**：多以本民族传统服装入殓（如苗族盛装、藏族氆氇袍），服饰本身即身份标识，与汉族寿衣礼俗不同源，须分别记录。

## 五、器物与文书

- **寿衣成套**：寿衣、寿裤、寿帽、寿鞋、腰带、衾被、枕。
- **材质**：棉、绸（忌缎、忌皮毛）。
- **颜色**：蓝、褐、灰、白、紫（依地方而异）。
- **相关文书**：寿衣件数与材质常记于「治丧单」、族谱家礼抄本。
