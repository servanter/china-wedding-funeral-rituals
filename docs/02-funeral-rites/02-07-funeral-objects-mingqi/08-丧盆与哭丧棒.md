# 丧盆与哭丧棒

## 一、释义

**丧盆**，又称「老盆」「孝盆」「瓦盆」，为丧家焚化纸钱、祭奠时所用的瓦盆；**哭丧棒**，又称「孝棒」「丧杖」「哀杖」「拄杖」，为孝子（及特定亲属）在丧期所执之杖。二者均为孝子以示哀毁、扶持身体的**丧具**。

- **哭丧棒（丧杖）**：《礼记·问丧》：「**孝子丧亲，哭泣无数，服勤三年，身病体羸，以杖扶病也**」——杖的本义是孝子哀伤体弱，需杖扶持。
- **丧盆**：民间用于焚化纸钱，并派生「**摔盆**」（起灵时将盆高摔于地）之俗。

**「摔盆」之礼**：出殡起灵时，长子（承重者）将丧盆高举摔碎，民间视为「摔碎忧患」「承继家业」的象征，亦有「盆摔得越碎越好」之说。摔盆者多为**承重孙或长子**，与宗法继承相关。

## 二、历史源流

- **先秦**：《礼记·问丧》《仪礼·丧服》载「杖」之制——杖有竹、桐之别（「苴杖，竹也；削杖，桐也」），斩衰用苴杖（竹），齐衰用削杖（桐）。
- **汉唐宋明**：杖制沿礼经，等级分明；《朱子家礼》定孝子执杖之节。
- **明清**：民间「哭丧棒」形式简化，多以柳木、竹、秫秸为杖，缠白纸。
- **近代以来**：丧盆与摔盆之俗在北方特别盛行，盆的形式与摔盆时机各地不同。

## 三、仪节流程

1. **备杖**：孝子制杖（竹、桐或柳），杖长多与胸齐，缠白纸或素布。
2. **执杖**：成服后孝子执杖，出入、跪拜、送葬皆扶杖而行。
3. **焚化**：丧期于丧盆内焚化纸钱。
4. **摔盆起灵**：出殡起灵时，承重者摔盆；盆碎后灵柩起行。
5. **置杖**：部分地区于葬后将杖置于墓侧，或在「复三」时焚化。

## 四、地域与民族变体

- **华北**：摔盆之礼最盛，摔盆者须为长子或承重孙；盆为瓦盆（俗称「老盆」）。
- **江南**：孝子执杖行丧，但摔盆之俗不如北方普遍，多以「焚纸盆」为名。
- **闽台**：「孝杖」与「麻杖」有别，孝男执杖，杖端包白布。
- **西南部分地区**：孝子持竹杖，讲究竹之节数。
- **少数民族**：部分民族有以杖、棍标示孝子身份的做法，其含义（如驱邪、引路）与汉族「扶病」之义不同，须分别记录。

## 五、器物与文书

- **丧盆**：瓦盆、陶盆（「老盆」），有的盆底钻孔。
- **哭丧棒（杖）**：竹杖（苴杖）、桐杖（削杖）、柳杖；缠白纸或白布。
- **焚化器物**：化钱炉、纸钱。
- **相关礼制**：杖的材质与使用依五服等第而定，与丧服制度相表里。
