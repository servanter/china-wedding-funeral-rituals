# 现代殡葬用品

## 一、释义

现代殡葬用品指**当代（主要为 20 世纪中期以来）丧事中使用的器物**，其构成已由「棺椁—明器」的传统体系转为「**殡仪—火化—公墓**」体系，并出现传统用品与西式用品、电子化用品并存的格局。

**主要类别**：

| 类别 | 代表用品 | 与传统之关系 |
| --- | --- | --- |
| **殓具** | 骨灰盒、寿衣、卫生棺（火化棺） | 骨灰盒取代棺的盛敛功能 |
| **陈设** | 遗像框、黑纱、白花、孝服（孝袖、孝带） | 黑纱、白花替代传统孝服 |
| **致哀礼品** | 花圈、花篮、挽联、挽幛 | 沿用近代挽礼 |
| **祭奠用品** | 纸扎、纸钱、冥币、香烛、电子祭品 | 纸扎、冥币延续焚烧习俗 |
| **服务用品** | 灵车、冷藏棺（冰棺）、遗体袋、礼仪用品 | 工业化、专业化产物 |
| **电子／网络** | 网上祭扫、电子香烛、二维码墓碑 | 全新形态 |

## 二、历史源流

- **1950 年代起**：推行殡葬改革，倡导火葬、简办丧事，公墓与殡仪馆制度建立。
- **1985 年**《殡葬管理暂行规定》、**1997 年**《殡葬管理条例》：确立火葬区与土葬区划分、丧葬用品管理规定。
- **1990 年代以来**：殡仪服务体系成熟，骨灰盒、冰棺、鲜花花圈普及；同时纸扎、冥币等传统用品在农村持续存在。
- **2000 年代以来**：出现禁烧纸钱、禁售冥币的城市管理措施；「电子祭品」「网上祭扫」「生态葬」（树葬、海葬、花坛葬）兴起。
- **当代并存格局**：城市以黑纱白花、鲜花花圈、骨灰盒为主；农村与部分宗族地区仍见孝服、纸扎、焚烧纸钱。

## 三、仪节流程

1. **殓**：遗体清洗、着寿衣，置入卫生棺（火化棺）或冷藏棺。
2. **设灵堂**：挂遗像、陈花圈、挽联，亲属佩黑纱、白花。
3. **告别仪式**：殡仪馆举行告别仪式（默哀、致悼词、献花、瞻仰遗容）。
4. **火化**：遗体火化，取骨灰装盒（骨灰盒）。
5. **安放或安葬**：骨灰存放于骨灰堂，或入公墓、实施生态葬。
6. **祭奠**：清明、中元、忌日于公墓祭扫，或网上祭扫。

## 四、地域与民族变体

- **城市**：殡仪馆—公墓体系完整，用品标准化，多以鲜花、黑纱为主。
- **农村**：传统用品（纸扎、冥币、孝服、孝幡）与殡仪服务并用，「厚养薄葬」与旧俗交织。
- **闽台**：慎终追远之风浓厚，公墓、祠堂祭祀与纸扎、金纸并存。
- **少数民族**：各民族殡葬方式（天葬、水葬、树葬、火葬、土葬）差异极大，其用品（如藏族「擦擦」、傣族祭品）与汉族现代殡葬用品不属同一体系，须分别记录。

## 五、器物与文书

- **殓具**：骨灰盒（木、石、玉、瓷）、卫生棺、寿衣、遗体袋。
- **陈设用品**：遗像框、黑纱、白花、孝袖、孝带、挽带。
- **祭奠用品**：纸扎、纸钱、冥币、香烛、电子香烛。
- **相关文书**：死亡证明、火化证明、讣告、悼词、公墓墓位证；网上祭扫页面。
- **管理依据**：《殡葬管理条例》及地方殡葬管理办法（含丧葬用品生产销售规定）。
