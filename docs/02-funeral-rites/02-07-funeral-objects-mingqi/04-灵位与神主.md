# 灵位、神主与木主

## 一、释义

**灵位**（亡灵牌位）是丧期中代表死者受祭的牌位，多书「先考某公讳某某之灵位」；**神主**（木主、牌位）是祔庙后长期奉祀的牌位。二者为同一系统的先后形态：

| 名目 | 使用阶段 | 形制 |
| --- | --- | --- |
| **灵位（灵牌）** | 初丧至除服 | 纸质或木板，白纸黑字，书「灵位」 |
| **神主（木主）** | 除服后入祠、入家庙 | 木质，栗木或柏木，书「神主」，有「陷中」（内层） |
| **魂帛** | 初丧「设重」阶段 | 以白绢结成人形，暂代死者之「重」 |

**「点主」**：又称「题主」，即在神主牌位上以朱笔点「主」字末笔（或点「王」为「主」），为丧礼中极隆重的一节，认为经点主后死者「有依归」。

## 二、历史源流

- **先秦**：《仪礼·士丧礼》有「重」（木制，悬于庭）、「依神」之制；《礼记·檀弓》论「重」与「主」的关系，为神主制度的礼经依据。
- **汉唐**：立「神主」于宗庙、家庙；品官之家神主形制有等级规定（如唐《开元礼》）。
- **宋代**：《朱子家礼》详定「作主」「题主」「点主」诸节，为后世民间丧礼的基本范本。
- **明清**：家庙（祠堂）制度成熟，神主入祠（「祔庙」「进主」）成为宗族大事；点主礼在民间演为隆重仪式，请「大宾」（乡绅、显者）点主。
- **近代以来**：祠堂制度衰落，家祭改用照片、牌位；「点主」礼在部分宗族地区（闽粤、赣皖）仍有遗存。

## 三、仪节流程

1. **设灵位**：初丧后设灵位（或魂帛）于灵堂，朝夕奠、上香、供饭皆面向灵位。
2. **作主**：葬前或葬后依《家礼》制作木主，内层（陷中）书死者生卒、姓名、行第，外层书「显考某公神主」。
3. **题主、点主**：请大宾题写神主；点主时以朱笔（有的以鸡血拌朱砂）点「主」字末笔。
4. **奉祀**：神主初奉于家，后「祔庙」（入祠堂）或入家庙，接受岁时祭祀。
5. **除服**：服丧期满（除服）后，灵位焚化或改换神主，完成由「灵」到「主」的过渡。

## 四、地域与民族变体

- **闽台**：祠堂（宗祠）祭祀发达，神主入祠称「进主」，仪式隆重；「点主」多请地方显者。
- **江南**：家庙、祠堂神主排列按昭穆，族谱详载神主之位。
- **华北**：多设灵牌于灵堂，葬后以「牌位」随葬或焚化，祠堂制度不及南方发达。
- **少数民族**：祖先崇拜形式各异（如彝族「祖灵筒」、苗族「鼓社」），其祖灵象征物与汉族神主不同源，须分别记录。

## 五、器物与文书

- **灵位牌**：纸、木（白底黑字）。
- **神主（木主）**：木质，分「陷中」（内层）与「粉面」（外层）。
- **魂帛、重**：白绢、木架。
- **题主文书**：死者讳、字、行第、生卒、葬所等，格式见于《家礼》及丧仪范式（详见「婚丧文书范本」板块）。
