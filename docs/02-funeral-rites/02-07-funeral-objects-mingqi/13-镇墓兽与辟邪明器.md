# 镇墓兽与辟邪明器

## 一、释义

镇墓兽、辟邪明器是**置于墓中以驱邪逐魅、护卫亡魂与生者的明器**，属「厌胜」（压胜）类器物。其共同观念基础是：墓圹幽暗，为鬼魅所聚，须以猛兽、神怪、镇物压制。

**主要类别**：

| 名目 | 形制 | 时代 |
| --- | --- | --- |
| **镇墓兽** | 蹲踞猛兽（人面兽身、兽面兽身等），独角或双角，有翼 | 战国至隋唐（尤盛于北魏—唐） |
| **辟邪、天禄** | 有翼神兽，似狮而有角 | 汉至南北朝 |
| **镇墓俑** | 武士俑、天王俑、力士俑（脚踏小鬼） | 北魏至唐宋 |
| **方相氏（开路神）** | 出殡时「方相」前导，后世演为纸扎「开路神」 | 先秦至近世 |
| **其他厌胜物** | 石敢当、桃符、镜、五色石、纸符 | 长期沿用 |

## 二、历史源流

- **先秦**：《周礼·夏官》有「**方相氏**」之职，「掌蒙熊皮，黄金四目，玄衣朱裳，执戈扬盾，帅百隶而时难（傩），以索室驱疫」；出殡时方相氏前导，为辟邪观念最早的礼制形态。
- **战国秦汉**：楚墓、汉墓出土「镇墓兽」「辟邪」「天禄」石刻与陶俑；墓室壁画绘神兽。
- **魏晋南北朝**：镇墓兽与镇墓俑成组出现，北魏墓葬典型配置为「镇墓兽一对＋武士俑一对」。
- **隋唐**：镇墓兽（狮、虎形，长角）与天王俑（脚踏小鬼）成定制，为唐墓等级标志之一。
- **宋以后**：实物镇墓兽减少，代之以**纸扎「开路神」「方相」**、买地券中的镇墓文、符箓等。
- **近代以来**：部分地区出殡仍有纸扎开路神；当代墓葬以石狮、石敢当为镇物。

## 三、仪节流程

1. **方相前导**：出殡时（先秦）由人扮方相氏前导，后世以纸扎开路神代替。
2. **置镇墓物**：下葬时于墓门、墓道或棺前放置镇墓兽、镇墓俑。
3. **书写镇墓文**：于墓内或买地券中书写「**镇墓文**」——告示地下鬼神「勿侵勿扰」，并载「如律令」等语（道教色彩浓厚）。
4. **封墓**：镇物布置完毕后封墓门。
5. **当代延续**：墓前立石狮、石敢当，或于骨灰盒旁置小件镇物。

## 四、地域与民族变体

- **中原**：北魏、唐墓镇墓兽镇墓俑出土集中，序列完整。
- **江南**：六朝墓葬有石辟邪（如南京、丹阳南朝陵墓石刻）。
- **华北**：近代丧俗保留纸扎开路神。
- **少数民族**：部分民族以宗教法器、护身符、动物头骨等辟邪（如藏族「切玛」「风马」、部分民族悬兽骨于墓），其信仰体系与汉族厌胜不同源，须分别记录。

## 五、器物与文书

- **镇墓兽、辟邪、天禄**：石、陶、瓷制，有翼有角。
- **镇墓俑**：武士俑、天王俑、力士俑。
- **镇墓文／解殃文**：刻石、朱书或墨书于墓内，多含「急急如律令」「天地使者」等语。
- **纸上镇物**：开路神纸扎、符箓、桃符。
