# 哭丧调与哭灵

## 一、释义

哭灵，是停灵期间在灵前哭唱之俗，其唱腔称「哭丧调」「哭灵调」「哭调」。

**与「哭丧与哭丧歌」条的分工**：后者以入殓环节的哭为主，重在哭的礼制分类与哭丧歌的内容类型；本条以停灵期间为主，重在**腔调的地域差异**与**职业哭丧人**这一特殊现象。

## 二、历史源流

- 挽歌之制起于汉代：《薤露》《蒿里》为通用挽歌，晋代有「挽歌」入礼的记载。
- 唐宋以后，哭灵渐形成地方性的腔调体系，并出现「唱哭」——把哭泣旋律化。
- 明清方志多记「哭灵」「哭七」「哭丧调」，如湘鄂一带「哭七」须按「头七」至「七七」逐段唱。
- **职业哭丧人**：部分地区出现雇人代哭的现象（「哭丧婆」「代哭」）。这类从业者以固定的哭词与娴熟的哭腔代替亲属哭丧，是丧事商业化与表演化的表现。历代士人多有批评，认为「哀不在己，则哭非其哭」，本条目作民俗记录并批判看待。
- 当代农村部分地区仍有哭灵之俗，城市已基本消失。

## 三、仪节流程

1. **起腔**：由主哭者（多为亡者的女儿、儿媳、妻）在灵前起腔，音高而长，呼死者称谓。
2. **述事**：按内容分段唱述——亡者生平、抚养之恩、持家之艰、临别之痛。
3. **和声**：在场女眷以哭声相和，形成集体的哭腔。
4. **定时序**：多在以下时刻哭灵：
   - 早、晚奠时；
   - 每「七」之日；
   - 吊客来吊时；
   - 出殡前夜（「哭别」）。
5. **哭七**：做七期间按七数分段哭唱，词句递进，至七七收束。
6. **哭别**：出殡前夜的哭灵最为激烈，称为「哭别」「辞灵」。
7. **收腔**：下葬后哭灵终止，转为祭日时的低声追念。

## 四、地域与民族变体

- **华北**：哭灵调高亢悲劲，起腔多用「我的×呀——」，尾音下坠。
- **江南**：哭灵调婉转，带吴语拖腔，「哭七」成套。
- **湘鄂川黔**：哭丧调体系最完整，与「哭嫁」同源，讲究词句工整与情节铺陈。
- **闽台**：哭灵与道士诵经交织，腔调带海风音色。
- **职业哭丧人**：多见于湘、鄂、川、黔与华北部分地区；须明确：**雇人代哭违背丧礼「哀由己出」的本义，属陋俗。**
- **少数民族**：彝族的「哭丧歌」、土家族的「丧鼓」（打丧鼓唱丧歌）、苗族的「丧歌堂」多为**集体歌唱**而非个人哭诉，参与者众多、有固定的歌堂组织，功能上兼有「慰灵」「送魂」「传承族史」三重作用，与汉族以女性亲属为主的哭灵在组织形态上不同。

## 五、器物与文书

- **哭丧歌抄本**：部分地方有传抄本。
- **丧鼓、锣**：土家族等跳丧时伴唱之器。
- **录音、歌词整理本**：当代非遗调查成果。
- **「哭帕」**：擦泪之巾。
