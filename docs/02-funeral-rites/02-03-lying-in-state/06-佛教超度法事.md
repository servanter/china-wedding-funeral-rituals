# 佛教超度法事

## 一、释义

佛教超度法事，是丧事中请僧人诵经、礼忏、施食，以「超度」亡者的仪式。

**教义依据**：佛教认为亡者死后进入「中有」（中阴）阶段，随业受生；亲属为其诵经、作福、布施，可回向功德，助其生于善道。《地藏菩萨本愿经》即以此为主题。

## 二、历史源流

- 佛教自汉代传入，魏晋以后逐渐参与丧葬。唐代「七七斋」之俗与佛教的「中有」观念密切相关——认为亡者在七七四十九日内受生，故每七日斋僧诵经一次（参见「做七」条）。
- 宋代以后佛事在民间丧礼中普及，《清稗类钞》记各地请僧诵经之俗。
- 主要法事类型：
  1. **诵经**：诵《阿弥陀经》《金刚经》《地藏经》等，为亡者回向。
  2. **礼忏**：礼拜《梁皇宝忏》《慈悲三昧水忏》，忏悔业障。
  3. **瑜伽焰口**：施食饿鬼道众生，规模较大的法事，须设坛、唱念、结手印、观想。
  4. **蒙山施食**：简化的施食仪轨，多与日常课诵结合。
  5. **佛七／念佛**：以念佛号回向，净土宗尤重，常在临终与初丧时进行（即「助念」）。
  6. **放焰口／放蒙山**：与「做七」结合，七期各做一次。
- 净土宗的「助念」（临终念佛）在当代最为流行，分临终助念与丧期助念两段。

## 三、仪节流程

1. **请僧／请法师**：丧家至寺院或请僧人到灵堂，商定法事的场次与日程。
2. **设坛**：在灵堂设佛坛，供佛像、香花、灯烛、供果，张贴疏文。
3. **告疏**：宣读「疏文」，向佛菩萨陈明亡者姓名、生卒、亲属心愿。
4. **诵经礼忏**：按场次诵经、拜忏，孝眷随拜。
5. **回向**：将诵经功德回向亡者，念回向偈。
6. **焰口（如设）**：搭台设座，法师唱念、结印、施食，通常在黄昏至夜间举行 3—5 小时。
7. **念佛助念**：在初丧与出殡前后，由助念团轮班念佛号，昼夜不停（部分地区）。
8. **谢僧**：法事毕，供僧、供养（「打斋」）、送僧。

## 四、地域与民族变体

- **华北**：以诵经、拜忏为主，多在「做七」时进行。
- **江浙**：佛事讲究「场次」（如「五个七」「七个七」），并有「放焰口」。
- **闽台**：佛道混融，常由「司公」与僧人共同做法事；「做功德」的规模可大至数日。
- **广东**：有「打醮」「做斋」，佛道兼行。
- **少数民族**：藏传佛教的超度（如「颇瓦法」「中阴闻教得度」诵念）由喇嘛主持，与汉传佛教的仪轨体系不同；傣族的丧事请佛寺僧侣诵经，属南传佛教系统；蒙古族旧有请喇嘛诵经之俗。**同属佛教，但宗派、语言、仪轨差异很大，不可一概而论。**

## 五、器物与文书

- **佛像、佛坛、香花、灯烛**：法事陈设。
- **经书、忏本、法器**（引磬、木鱼、铃、鼓、铛子）。
- **疏文**：陈明亡者信息与心愿的文书。
- **回向偈**：诵念文本。
- **供僧、打斋**：供养。
