# 道教科仪与破狱

## 一、释义

道教度亡科仪，是请道士为亡者行「炼度」「破狱」「召魂」「沐浴」等仪式，以「拔度亡魂、升入仙乡」的丧葬法事。

**教义依据**：道教认为人死后魂魄可能堕入地狱（「九幽」），受罪苦；通过科仪可破开地狱、召出魂灵、以水火炼度其魂魄，使之超升。

## 二、历史源流

- 道教度亡科仪自南北朝形成体系，唐代「黄箓斋」为国家级度亡大斋。
- 唐宋以后民间普遍请道士做「功德」「道场」。
- 主要科仪类型：
  1. **召魂（摄召）**：焚符、唱赞，召亡魂至坛前。
  2. **沐浴**：为亡魂「沐浴更衣」，与初丧沐浴是象征的对应。
  3. **破狱（破九幽）**：道士以剑、符破开「地狱」，引出亡魂。仪式中有象征性的「破狱」动作，场面激烈。
  4. **炼度**：以「水火」炼度亡魂，使其形神俱妙，脱化升仙。分「水炼」「火炼」。
  5. **过桥**：以布（或纸）搭「奈何桥」，引亡魂过桥。
  6. **施食（施斛）**：设斛食施予饿鬼。
  7. **送亡**：焚化「亡表」「灵屋」，送亡魂归位。
- 明清方志中「破狱」「炼度」之记载极多，尤以闽台、广东、江浙为盛。
- 当代闽台与部分农村地区仍有「做功德」「做司公」的做法。

## 三、仪节流程

1. **请道士**：丧家请道士（闽台称「司公」），商定科仪规模（「一昼夜」「三昼夜」）。
2. **设坛**：在灵堂或空场设道坛，挂神像（三清、太乙救苦天尊等），陈法器、符幡。
3. **发符通告**：发「符」通告城隍、土地等「冥界官府」。
4. **召魂**：唱赞、焚符，召亡魂至坛。
5. **沐浴更衣**：以象征性的水与巾为亡魂「沐浴」，并焚化「衣冠」。
6. **破狱**：道士持剑、符，行「破狱」科仪，象征破开地狱、拔出亡魂。此节通常在夜间进行。
7. **炼度**：行「水火炼度」，以符水与灯火象征炼化魂魄。
8. **过桥、施食**：引亡魂过桥，施食于饿鬼。
9. **送亡与焚化**：焚「亡表」「灵屋」「纸扎」，送亡魂升天。
10. **谢师**：供谢道士，法事毕。

## 四、地域与民族变体

- **闽台**：道教度亡最盛，「做功德」有严格的科仪本与传承系统，分「正一派」与「灵宝派」等不同科仪传统。
- **广东**：称「做斋」「打醮」，佛道兼行，规模宏大。
- **江浙**：称「做道场」，以「炼度」「破狱」为核心。
- **华北**：道教色彩相对弱，佛事占主导，但农村仍有请「阴阳先生」主持者。
- **少数民族**：土家族有「梯玛」主持的丧祭；彝族由「毕摩」主持「指路」仪式（与道教无关但有类似的「送魂」功能）；纳西族由「东巴」主持「神路图」仪式。**这些是本民族的宗教体系，与道教无关，不可混称「科仪」。**

## 五、器物与文书

- **神像、道坛**：法事陈设。
- **法器**：剑、印、令旗、朝简、法尺、铃、鼓、铛。
- **符、幡、榜文**：文书类。
- **亡表、疏文**：上呈「冥界官府」的文书。
- **纸扎灵屋、金桥银桥**：焚化用物。
- **斛食**：施食用物。
