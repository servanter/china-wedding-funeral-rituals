# 儒礼家奠（三献礼）

## 一、释义

家奠，是停灵期间由**家族成员**主持的祭奠仪式，以儒家礼制为准，与佛道法事并行而不相混。其核心形式为「三献礼」：**初献、亚献、终献**，三次献酒、献馔并行拜礼。

三献礼是儒礼祭仪通用格式，用于祭祖、家奠、公祭等场合；丧礼中的家奠由礼生主持，丧主主祭。

## 二、历史源流

- 三献之礼源于《仪礼》，祭礼中「三献」为基本结构（献酒三次）。《仪礼·士丧礼》所记诸奠已有多次献酒。
- 《礼记·祭义》阐发祭祀之义：「祭如在，祭神如神在。」
- 《朱子家礼》将家祭、家奠程序规范化，定「三献」与「读祝」的配合方式，成为后世家奠的基本范式。
- 《大明集礼》《大清通礼》对品官、士庶的家奠（丧礼）程序作了明确规定。
- 近代「公祭」沿用三献礼，主要用于国家典礼与公共追悼；民间则演为「家奠」「堂祭」「开奠」。
- 当代中式葬礼与非遗仪式中仍保留三献礼。

## 三、仪节流程

1. **设位**：灵前设供桌，陈香烛、酒樽、馔碗；设主祭位、陪祭位、与祭位（依亲疏次序）。
2. **击鼓鸣钟**：礼生（司仪）唱「击鼓三通、鸣钟三响」，示意开始。
3. **就位**：主祭人（丧主）就主祭位，陪祭、与祭依次就位。
4. **迎神**：礼生唱「迎神」，主祭上香、跪拜，象征迎请亡者之灵。
5. **初献**：主祭献酒、献馔，行跪拜礼；礼生唱「初献礼成」。
6. **亚献**：由另一亲属（如次子）献酒献馔，行拜礼。
7. **终献**：由第三位亲属献酒献馔，行拜礼。
8. **读祝文（祭文）**：宣读祭文，追述亡者生平德业，表达哀思。
9. **俯伏哭**：主祭俯伏，全场举哀。
10. **焚祝、望燎**：焚化祝文与纸钱。
11. **送神**：礼生唱「送神」，主祭再拜，礼成。
12. **撤馔**：撤去供品。

## 四、地域与民族变体

- **华北**：称「家奠」「堂祭」，由礼生主持，多在家中正厅举行。
- **江浙**：称「开奠」「家祭」，讲究「三献九叩」。
- **闽粤**：称「家奠」，与「做功德」并行；广东有「堂祭」之制。
- **台湾**：家奠在出殡前举行，程序依《家礼》而有地方化。
- **公祭**：当代用于公共人物与集体追悼，程序与三献礼相近但以鞠躬代替跪拜。
- **少数民族**：本民族丧礼多无「三献礼」形式，而有各自的祭献方式（如彝族的献牲、献酒由毕摩主持，苗族的献牲与歌堂）。三献礼是儒家礼制体系内的仪节，不宜外推。

## 五、器物与文书

- **供桌、酒樽、馔碗、香炉、烛台**：陈设。
- **祭文（祝文）**：核心文书，格式见「婚丧文书范本／祭文范本」条。
- **跪垫、盥洗器**：行礼之具。
- **击鼓鸣钟之器**。
- **火盆、焚祝器**：焚化用。
