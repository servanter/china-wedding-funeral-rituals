# 灵前上香与吊唁仪节

## 一、释义

本条记吊客至灵堂的**施行细则**：如何进门、如何上香、行几拜、如何慰唁、孝子如何答礼。

与「初丧／吊唁与开吊受吊」条的分工：后者记吊唁与开吊的制度与礼义；本条记灵堂内逐动作的执行规范，属操作层面的条目。

## 二、历史源流

- 《仪礼·士丧礼》记「宾入」「宾升」「宾拜」的次序，是吊仪的最早规范。
- 《礼记·曲礼》：「临丧不笑」「吊于人，是日不乐」「行吊之日，不饮酒食肉焉」——吊客的行为约束。
- 《朱子家礼》定「吊奠」之礼：吊客入门、上香、拜、慰丧主，丧主答拜。
- 明清方志记各地吊仪细节，如「三拜」「四拜」「跪灵」之别。
- 礼生（司仪）在吊仪中的角色是「唱礼」与「引客」，使吊客的动作有节可循。

## 三、仪节流程

### 吊客

1. **整衣**：至丧家门首，整肃衣冠；忌穿红衣、忌浓妆、忌嬉笑。
2. **入门**：由知客（引客）引入；旧时「报丧人不得进门」，吊客则可入。
3. **上香**：至灵前，双手举香（或由孝子递香），插入香炉。
4. **行礼**：依当地规定行礼数——**三拜**（华北常见）、**四拜**（闽台常见）、或有司仪唱「一鞠躬、再鞠躬、三鞠躬」（当代）。
5. **跪灵**（部分地区）：有「跪灵」之礼，吊客跪拜，孝子陪跪答礼。
6. **慰唁**：向孝子（丧主）致慰唁语，如「节哀」「保重」。忌说「死」字等刺激语。
7. **致赠**：送花圈、挽幛、赙金（白包），由司书登记礼簿。
8. **退**：退出灵堂，由知客引至客座（或直接告退）。

### 孝子答礼

1. **跪陪**：孝子在灵侧跪陪（男孝子在外、女眷在内帷）。
2. **答拜**：吊客下拜时，孝子以跪拜或叩首答礼（「孝子磕头不敢当」，实际多以俯伏答之）。
3. **递香**：向吊客递香。
4. **谢礼**：吊客告退时，孝子或家属致谢，赠孝巾、毛巾等（「散孝」）。

## 四、地域与民族变体

- **华北**：上香三拜，孝子跪灵，讲究「陪客叩首」。
- **江浙**：上香三拜，孝子俯伏答礼，讲究「不敢当」。
- **闽台**：上香四拜，由「司公」或礼生唱礼；孝子跪于灵侧。
- **广东**：上香三拜，另致送「金银衣纸」。
- **少数民族**：穆斯林民族的吊唁不设香烛与跪拜，吊客多为沉默致哀、诵经、与家属握手致慰；藏族吊唁多以献哈达、点酥油灯、诵经为礼；彝族吊唁则行献牲、献酒之礼。**吊唁的礼数由信仰决定，汉族的「上香三拜」不是通用规范。**

## 五、器物与文书

- **香、香炉、烛**：上香之具。
- **拜垫、跪垫**：行礼之具。
- **礼簿**：登记吊客与赙赠。
- **花圈、挽幛、挽联**：吊唁赠礼。
- **赙金（白包、白封）**：助丧财物，忌用红封。
- **孝巾、毛巾**：答礼回赠。
