# 朝夕奠与供饭

## 一、释义

朝夕奠，是停灵期间每日晨昏两次在灵前设奠之礼。**奠而不祭**——只陈设酒食而不行享用之实，因为死者「未葬」尚无「神」的资格（葬后虞祭始称「祭」）。

供饭是朝夕奠的民俗化形态：一日三餐把饭菜端到灵前，上香、跪拜、呼唤死者用饭。

## 二、历史源流

- 《仪礼·士丧礼》：「朝夕哭，不奠」——礼经原文规定朝夕**哭**而不另设奠；朝夕奠之制见于《礼记·檀弓》与后世礼家。
- 礼制的奠有等次：始死奠、小殓奠、大殓奠、朝夕奠、朔月奠、荐新奠、迁柩奠、祖奠、遣奠，构成完整的奠礼序列。
- 《礼记·檀弓》：「奠以素器，以生者有哀素之心也。」奠器须素朴，是哀情的规定。
- 《朱子家礼》简化为「朝夕奠」与「朔望奠」，并规定奠的品物（酒、果、脯、醢）。
- 民间「供饭」是朝夕奠与「事死如生」观念的合流：一日三餐照常供，饭菜须是死者生前所好。
- 当代丧事中「供饭」仍普遍，成为最日常的哀悼行为。

## 三、仪节流程

1. **朝奠**：日出时设奠。陈酒、果、饭、菜于灵前，主人上香、跪拜，主妇在内哭。
2. **夕奠**：日落时设奠（「夕奠逮日」），仪同朝奠。
3. **供饭**：一日三餐将饭菜端至灵前，摆碗筷、盛饭、斟酒，呼唤「×××吃饭了」，稍候撤下；部分地区供饭后将饭分给小孩吃（「吃寿饭」）。
4. **朔月奠**：每月初一设奠，比朝夕奠隆重，加牲、加酒。
5. **荐新奠**：以时令新物（新谷、新果、新菜）荐于灵前，如「尝新」。
6. **哭踊**：每次奠毕，主人哭，妇人哭踊；有吊客来时亦哭。
7. **焚纸**：多数地方在奠毕焚烧纸钱。
8. **撤奠**：撤下的供品，部分分食（「吃供」），部分散给邻里。

## 四、地域与民族变体

- **北方**：称「供饭」「上供」，一日三次，讲究「饭不过夜」。
- **江南**：称「朝夕奠」「供饭」，讲究供品热食、摆双筷。
- **闽台**：称「供饭」「捧饭」，由孝眷捧饭至灵前并呼唤，仪式感强。
- **广东**：称「供饭」，讲究「三餐不断」，另备茶、酒。
- **少数民族**：多数民族有向亡者供食之俗，但机制不同。彝族供饭须由「毕摩」念经「请亡灵用饭」；苗族供饭时唱丧歌；藏族以酥油、糌粑供于佛像与灵前；**穆斯林民族不设供饭**——教法认为亡者已不能饮食，唯凭生前善功，故不设供奉。这是教义规定的差别，不作「简省」理解。

## 五、器物与文书

- **供桌、供器**：酒器、碗筷、托盘。
- **供品**：酒、果、脯、醢、饭菜。
- **香、香炉、烛**：供奉之具。
- **火盆、纸钱**：焚化之用。
- **「奠」字、灵位**：供奉对象。
