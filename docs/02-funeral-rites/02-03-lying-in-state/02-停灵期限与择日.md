# 停灵期限与择日

## 一、释义

停灵期限，是自入殓（大殓）至出殡之间停柩待葬的时间长度。其确定涉及三方面依据：**礼制等级**、**择日吉凶**、**实际条件**（亲属到齐、墓地准备、天气）。

## 二、历史源流

- 礼制上的「殡」期依等级而定。《礼记·王制》：「天子七日而殡，七月而葬；诸侯五日而殡，五月而葬；大夫、士、庶人三日而殡，三月而葬。」「殡」即停柩，「葬」即下葬，二者期限都有等级差别。
- 先秦的停殡期极长（天子七月），是宗法等级制度的体现。
- 《朱子家礼》将殡期压缩，定「三月而葬」为通例，但民间实际多在三日、五日至七日内完成。
- 明清民间停灵的日数受「做七」影响：多停在「头七」之内，或等「七七」做完（49 天）方葬，视家境而定。富贵之家有停至百日、周年者。
- 停灵日数还有择日的要求：出殡日须择吉，忌「重丧日」「三丧日」。
- 当代火化制度下，停灵多为 3 天或 5 天（民谚「三、五、七」），个别地区因等待亲属而延长。

## 三、仪节流程

1. **定殡期**：入殓后，由丧主与族中长辈、阴阳先生共同商定停灵日数。
   - 常用：三日、五日、七日；
   - 延长：等远方亲属到齐、等墓地修好、等择得吉日。
2. **择出殡日**：依黄历与《协纪辨方书》择定吉日吉时，避开「重丧」「三煞」。
3. **排日程**：以出殡日为基准倒排：
   - 入殓日；
   - 开吊（受吊）日；
   - 家奠（三献礼）日；
   - 出殡下葬日；
   - 复三（圆坟）日；
   - 做七的各日。
4. **发讣告**：将排定的日程写入讣告，通知亲友。
5. **守灵**：停灵期内日夜守灵、朝夕设奠。
6. **调整**：遇特殊情况（天气、亲属未到）可延长，但须重新择日。

## 四、地域与民族变体

- **华北**：多为三日或五日；讲「三日入殓，五日下葬」。
- **江南**：多为三日至七日；讲究「出殡须择吉日，不可犯重丧」。
- **闽台**：停灵较短（一日至三日），讲究「看日子」；有「做完七再葬」的做法。
- **广东**：多在三日至七日；有「做斋」期间停灵的做法。
- **少数民族**：停灵期限差异极大。回族、维吾尔族等穆斯林民族**速葬**（当日或次日即葬，最长不超过三日），这是教法的要求，与汉族的「停灵数日」形成鲜明对比；藏族天葬多在死后三至五日内进行，由喇嘛依藏历定；苗族、彝族等停灵期从一至数日到数十日不等，且期间有整套歌唱与祭祀活动。**「停灵」不是普适环节。**

## 五、器物与文书

- **讣告**：载明日程，是停灵期限的对外公示。
- **黄历、择日书**：择定出殡日之用。
- **丧事日程表**：丧家内部使用。
- **孝灯、长明灯**：停灵期内昼夜不灭。
