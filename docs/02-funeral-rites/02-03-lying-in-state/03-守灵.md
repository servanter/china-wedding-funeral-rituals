# 守灵（守夜）

## 一、释义

守灵（守夜、伴灵），是停灵期间亲属在灵前昼夜陪守之礼。内容包括：**照看香火**（香不能断、灯不能灭）、**按例哭奠**、**接待来吊者**、**防止猫狗近棺**。

守灵是「孝」的最直观表达：停灵几日，亲属就守几日，夜不能寐。

## 二、历史源流

- 《仪礼·士丧礼》记「主人」在殡期内的居处：「居倚庐，寝苫枕块」——住在倚庐（棚屋）中，睡草席、枕土块，是居丧居处的礼制规定。
- 《礼记·丧大记》记殡期内「主人不说（脱）绖带」「不食」等约束，守灵是其中最具身体性的一项。
- 《礼记·问丧》：「三日不举火，故邻里为之糜粥以饮食之。」——三日不生火做饭，由邻里送粥。守灵与「不食」相连，是身体性的哀悼。
- 宋代《书仪》《家礼》定「朝夕哭」「夜则燃灯」，把守灵规范化。
- 明清以来守灵之俗普遍。方志记「孝子守灵，昼夜不离」「亲友陪灵，谓之陪夜」。
- 当代城市殡仪馆虽有守灵厅，但实际守灵时间大幅缩短。

## 三、仪节流程

1. **排班**：亲属排定守灵班次，通常子、女、媳为主，亲友可陪守。
2. **照看香火**：香要不断（「香火不断」喻家族延续），长明灯（孝灯、七星灯）昼夜不熄。
3. **按例哭奠**：朝夕奠时全体哭奠；夜间定时上香、烧纸。
4. **防猫狗**：忌猫、狗近棺，俗谓「猫跳尸」为大忌（此俗信源自对静电与尸僵现象的误解，属俗信，无科学依据）。
5. **接待吊客**：夜间来吊者，由守灵者引至灵前、陪拜。
6. **烧纸钱**：夜间定时焚烧纸钱，边烧边念死者称呼。
7. **供饭**：夜半供「夜饭」或夜宵于灵前。
8. **禁娱**：守灵期间不得娱乐、嬉笑、饮酒（部分地区允许以棋牌「解睡」，属于变通）。
9. **轮换**：白昼由他人替守，夜间以男性亲属为主力。

## 四、地域与民族变体

- **北方**：称「守灵」「陪灵」，讲究「香不断、灯不灭」，亲友「陪夜」是重要的情分。
- **江南**：称「守灵」，夜间以「打醮」「诵经」伴守。
- **闽台**：称「守灵」「伴灵」，由「司公」诵经，孝眷随拜，夜间有「哭灵」。
- **广东**：称「守夜」，讲究「七星灯不熄」。
- **少数民族**：部分民族有集体性的「守夜」活动，如苗族的「丧歌堂」、土家族的「跳丧」（丧鼓）、彝族的「跳脚」——众人通宵歌舞以慰亡灵。这类活动**不是「禁止娱乐」的守灵，而是以集体歌舞完成送别**，其形态与汉族守灵的严格禁娱形成鲜明对比，须分别理解。

## 五、器物与文书

- **长明灯、孝灯、七星灯**：昼夜不熄之灯。
- **香、香炉**：香火之物。
- **纸钱、火盆**：焚化之用。
- **倚庐、草席、土块**：古礼居丧之具。
- **供饭、夜宵**：灵前供奉。
- **守灵班次表**：大家族的排班记录。
