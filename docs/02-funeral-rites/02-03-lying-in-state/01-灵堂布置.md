# 灵堂布置

![灵堂布置 / The mourning hall](../../../assets/images/08-mourning-hall.png)


## 一、释义

灵堂是停灵期间陈放棺柩、设置灵位、供亲属守灵与宾客吊唁的场所。

其布置的功能有三：**隔**（以幔帐隔出生死两界，即古之「帷堂」）、**位**（以灵位确立死者之「在」与亲属之「位」）、**示**（以陈设向吊客显示丧家的身份与孝心）。

## 二、历史源流

- 古礼的「帷堂」「设奠于尸东」是灵堂的直接源头，见《仪礼·士丧礼》。
- 宋代《书仪》《家礼》把「灵座」「魂帛」引入家礼：以帛书死者姓名，作为神灵凭依的象征物，设于灵堂正中。
- 明清灵堂陈设定型，主要元素为：棺柩（居中或偏侧）、灵位／魂帛（正中）、香案（供器）、孝帐（幔帐）、挽联挽幛（两侧）、纸扎（前置或侧置）。
- 近代加入遗像（摄影术传入后），成为灵堂的核心视觉元素。
- 当代城市多在殡仪馆设「治丧厅」，布置标准化：遗像居中、花圈两侧、挽联悬壁、电子屏滚动逝者生平。

## 三、仪节流程

（灵堂的布置次序）

1. **择地**：以家中正厅为灵堂（农村多在堂屋），城市则租用殡仪馆厅房。
2. **设幔帐（孝帐）**：以白布或蓝布设幔帐，把灵柩与孝眷的哭位隔开，或在堂前设「孝帘」。
3. **陈棺柩**：棺柩置于灵堂正中或偏侧，头向依方位而定；棺下垫木或凳（忌直接着地）。
4. **设灵位**：在棺前设灵位（或魂帛、遗像），居中正对门外。
5. **设香案**：灵前设香案，摆香炉、烛台、供果、酒、茶、饭（「供饭」）。
6. **挂挽联挽幛**：两侧悬挂挽联、挽幛，正面上方悬「奠」字或「×××先生（女士）灵堂」横幅。
7. **设纸扎与花圈**：纸扎（纸屋、纸人、纸马）置于灵堂侧后方或门外；花圈置于门前两侧。
8. **设备用物**：备孝巾、孝服、礼簿、香烛、火盆（焚纸）等。
9. **布置孝眷位次**：男东女西，备跪垫。

## 四、地域与民族变体

- **北方**：称「灵棚」（院内搭棚），棚内设棺、灵位、香案；棚外悬白纸、挂「岁数纸」（按死者年龄挂纸条数）。
- **江南**：称「孝堂」，堂内设孝帘，讲究「灵前不空」（香火不断）。
- **闽台**：称「孝堂」，设「孝灯」「魂帛」，由「司公」布置，并有「灵厝」（纸扎大屋）。
- **广东**：称「孝堂」，设「灵屋」（纸扎）、「幡旗」；讲究灵位前的「七星灯」（七盏灯）。
- **少数民族**：多数民族不设「灵堂」这一空间形态。穆斯林民族的殡礼在清真寺或家中进行，遗体置于「塔布」（抬尸架）上，**不设香烛与供桌**；藏族设经堂诵经，由喇嘛主持；彝族的灵位设于屋内特定位置，并立「祖灵筒」。各族的「停灵空间」都有其宗教依据，不可与汉族的灵堂并列比较。

## 五、器物与文书

- **幔帐、孝帘**：隔断之物。
- **灵位、魂帛、遗像**：死者之「在」的象征。
- **香案、香炉、烛台、供器**：供奉之具。
- **挽联、挽幛、花圈**：吊唁赠礼。
- **纸扎**：纸屋、纸人、纸马（详见「丧葬器物明器」板块）。
- **礼簿、孝巾、火盆**：事务用物。
- **「奠」字、横幅**：标识。
