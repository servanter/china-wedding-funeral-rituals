# 灵堂禁忌

## 一、释义

灵堂禁忌是停灵期间对生者行为、言语与人员出入的限制。其分类可分四组：**行为禁忌**、**言语禁忌**、**人员禁忌**、**器物禁忌**。

禁忌的观念基础是「生死有别」与「忌冲犯煞」：灵堂是生死交界之处，生者若行为不当，可能「被亡者带走」或「冲犯煞神」。

（本条目作民俗记录，**不作提倡**；其中部分禁忌实有卫生与安全的合理内核。）

## 二、历史源流

- 《礼记·曲礼》已有丧期行为约束：「临丧不笑」「望柩不歌」「入临不翔」（不得伸展双臂行走）。
- 《礼记·檀弓》：「吊于人，是日不乐。」规定吊丧当日不得娱乐。
- 民间禁忌则在长期实践中积累形成，明清方志与笔记（《清稗类钞》等）记载甚多。
- 部分禁忌的合理内核：
  - 「忌猫狗近尸」——源于对动物触碰尸体引起变化（民间称「猫跳尸」）的恐惧，现代可用尸僵与静电现象部分解释；
  - 「忌孕妇、产妇入灵堂」——对免疫力较弱人群的保护性考虑；
  - 「忌小孩入灵堂」——避免儿童受惊；
  - 「忌泪落尸身」——防止泪水污染遗体、影响防腐。
- 当代城市丧事中多数禁忌已淡化，农村仍较普遍。

## 三、仪节流程

### 行为禁忌

1. **忌嬉笑、娱乐、饮酒划拳**。
2. **忌大声喧哗、争吵**。
3. **忌在灵堂内扫地（朝外扫）**——俗谓「扫走财气」；须从外向内或改在出殡后清扫。
4. **忌打碎器物**——视为凶兆，须立即以吉祥话破解。
5. **忌在灵堂睡觉、坐卧灵床**。
6. **忌背对灵位**、忌跨越灵前供品。
7. **忌未出殡前梳妆打扮、穿红戴绿**。

### 言语禁忌

1. **忌直说「死」字**，用「走了」「老了」「过去了」等婉辞。
2. **忌说「再来」「回头见」**——临别时忌告别语，多改说「保重」。
3. **忌在灵前谈论亡者过失**。
4. **忌说「不吉利」的话**（如「分」「散」「完」）。

### 人员禁忌

1. **忌属相相冲者在入殓、出殡时在场**。
2. **忌孕妇、产妇入灵堂**。
3. **忌服丧者之间互相串门**（服丧期内不得入他人之门）。
4. **忌「四眼人」（孕妇）看入殓**（部分地区）。

### 器物禁忌

1. **忌香火中断、长明灯熄灭**。
2. **忌猫、狗、家禽进入灵堂**。
3. **忌移动棺柩位置**（入殓后不得再挪）。
4. **忌灵前供品被外人先食**。

## 四、地域与民族变体

- **华北**：讲究「灵前不扫地、不泼水」；忌「属相相冲」者入殓在场。
- **江南**：忌「雨淋棺」；忌在灵堂打伞。
- **闽台**：忌「戴孝入他人之家」；忌「孝眷照镜」。
- **广东**：忌「白事见红」，忌穿红衣入灵堂。
- **说明**：以上禁忌均属民间俗信，**其中涉及孕妇、病人的限制可理解为保护性习俗，但不应引申为歧视性说法**；「冲煞」「猫跳尸」等无科学依据，本库作民俗记录，不作提倡。
- **民族差异**：穆斯林民族的丧事中无香烛、无灵堂陈设，相应地也无此类「香火禁忌」；藏族丧期的禁忌多与宗教规定相关（如某些日子不得动土、不得杀生）。各民族的丧期禁忌需分别记录，不可混用汉族的条目。

## 五、器物与文书

- **香炉、长明灯**：最需看护之物。
- **「忌××属相」告示**：贴于门口。
- **扫帚、门帘**：相关用物。
- **地方志·丧葬志**：禁忌记录的主要来源。
