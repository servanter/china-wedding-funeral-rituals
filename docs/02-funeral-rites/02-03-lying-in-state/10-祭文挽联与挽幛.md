# 祭文、挽联与挽幛

## 一、释义

停灵期间产生三类核心文书：

- **祭文（祝文）**：祭奠时宣读的哀悼之文，由丧家亲属或专人撰写。
- **挽联**：吊唁者撰写的对联，悬挂于灵堂两侧。
- **挽幛**：吊唁者赠予的整幅布帛（或纸），上书悼词，悬挂于灵堂内外。

三者同为哀悼的书面表达，但**作者不同**（祭文由丧家作，挽联挽幛由吊客作）、**陈放位置不同**、**文体要求不同**。

## 二、历史源流

- **祭文**：源流甚古。《文选》收有「诔」「哀」「祭文」诸体（如颜延之《陶徵士诔》、陆机《吊魏武帝文》），是哀祭文的经典样本。唐代韩愈《祭十二郎文》、宋代欧阳修《祭石曼卿文》为传世名篇。其文体讲究情感真挚、格式规范。
- **挽联**：由「挽歌」与「对联」结合而成。挽歌起于汉代《薤露》《蒿里》；对联在明清大盛，挽联随之普及。挽联讲究平仄对仗、上下联呼应，是文学性最强的丧俗文书。
- **挽幛**：由古代的「帛书」「赠襚」演变。明清以后以整幅绸布书写悼词，落款具名，悬挂于灵堂；民国以来多用纸制。当代多简化为花圈与挽条。
- **匾额、挽额**：书「××千古」「驾鹤西归」等字，悬于灵堂正中上方。
- 相关格式与范文详见「婚丧文书范本」板块。

## 三、仪节流程

1. **撰祭文**：丧家请人撰写祭文，内容为：时间、主祭人、亡者生平德行、哀悼之情、伏惟尚飨。
2. **定挽联挽幛**：吊客（或单位）撰联、书幛，讲究用词得体、称谓准确（依与亡者的关系选称谓）。
3. **陈放位置**：
   - **祭文**：由主祭人（或读祝者）在灵前捧读，读毕焚化。
   - **挽联**：悬于灵堂两侧（左右对挂，上联在右、下联在左，依传统书写习惯）。
   - **挽幛**：悬于灵堂内壁或外院；当代多用花圈挽条。
   - **挽额**：悬于灵堂正中上方，横书。
4. **宣读与焚化**：祭文在奠礼中宣读，礼毕与纸钱一同焚化（「焚祝」）。
5. **登记与答谢**：挽联挽幛由司书登记于礼簿，丧事毕发谢帖答谢。
6. **撤除**：出殡后在墓前焚化挽联挽幛，或由丧家保存（部分地区）。

## 四、地域与民族变体

- **华北**：挽幛多为绸布，讲究「幛子成对」；挽联用白纸黑字（或黄纸）。
- **江浙**：挽联文学性强，讲究对仗与用典；挽幛用白、蓝、黑布。
- **闽粤**：挽幛以绸布为主，书「××先生千古」；潮汕地区挽联讲究严格的平仄。
- **台湾**：挽联挽幛制度保存较完整，有专门的书幛规矩与称谓表。
- **少数民族**：多无挽联、挽幛之制。穆斯林民族不设此类文书，而以致送赙金、誦经、送葬表达哀悼；藏族以献哈达、供灯、请僧诵经为礼。**作为汉语文体产物的挽联挽幛，不适用于其他民族。**

## 五、器物与文书

- **祭文（祝文）**：纸本，宣读后焚化。
- **挽联**：白纸（或黄纸）黑字，两侧对挂。
- **挽幛**：绸布或纸，书悼词，具名落款。
- **挽额、匾额**：横书，悬于灵堂上方。
- **花圈、花篮**：当代常用。
- **礼簿**：登记挽联挽幛与赠者。
- **谢帖**：事后答谢。
