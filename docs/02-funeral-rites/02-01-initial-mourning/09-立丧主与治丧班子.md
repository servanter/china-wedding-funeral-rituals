# 立丧主与治丧班子

## 一、释义

**丧主**是主丧之人，通常由死者的嫡长子担任；嫡长子已死，则由承重孙（嫡长孙）任之，称「承重」。丧主负责主祭、受吊、率众成礼，是丧礼中所有仪式的中心人物。

**治丧班子**是协助丧主办理丧事的组织。宋代《书仪》《家礼》将其分工规范化，主要有「护丧」（总管）、「司书」（掌礼书文书）、「司货」（掌财物）以及礼生、知客等。

## 二、历史源流

- 《仪礼·士丧礼》以「主人」称丧主：「主人拜，稽颡。」「主人」即嫡长子。丧主制度与**宗法制度**、**五服制度**一体：宗法上「大宗」主祭，「小宗」分祭；丧礼上则嫡长主丧。
- 《礼记·丧服四制》：「丧之所以成礼也，其恩厚者其服重，故为父斩衰三年。」丧主的服制最重，其身份相应最尊。
- 若死者无子，则依「立后」之义择嗣（「过继」「立嗣」），由嗣子主丧，这一做法涉及继承，礼法上极为慎重。
- 宋代《书仪》首次系统列出治丧分工：「护丧」总揽丧事；「司书」掌讣告、礼书、祭文；「司货」掌财物出入。此为后世「总理—账房」之滥觞。
- 明清以来，民间治丧形成成熟的分工体系：总理（大老）、账房、礼生、知客、厨下、土工、杠房。
- 近现代出现专业殡仪服务，治丧班子部分职能外包给殡仪馆与殡葬服务公司。

## 三、仪节流程

1. **定丧主**：依法定或礼制顺序确定嫡长子（或承重孙、嗣子）为丧主。
2. **定主妇**：由丧主之妻（或死者之妻、冢妇）担任，主内帷哭祭、接待女宾。
3. **请护丧**：请族中或乡里有威望、懂礼者为「护丧」（俗称「总理」「大老」「总管」），总揽丧事。
4. **设账房（司货）**：管理丧事收支、赙赠登记、采买支应。
5. **设司书**：掌讣告、礼簿、祭文、挽联、谢帖。
6. **请礼生**：主持家奠（三献礼）、点主、成服等仪节。
7. **设知客**：接待吊客、引路、上香、登记。
8. **设厨下**：备丧宴。
9. **丧主工作**：守灵、哭祭、受吊答礼、领衔具名于讣告。

## 四、地域与民族变体

- **北方（含京津）**：有「大总理」之设；北京、天津旧有「杠房」「棚铺」行业，承办抬棺、搭棚、仪仗等事务。
- **江浙**：有「账房先生」「司仪」分工，讲究「丧事从简、礼数不缺」。
- **闽台**：有「司公」（道士）、「礼生」、「土公」（土工）、「大妗姐」之外的「婆姐」等角色，分工细致。
- **旧上海**：出现「殡仪馆」这一现代行业形态，治丧分工随之商业化。
- **少数民族**：多由族中长老或宗教人士主持。回族由阿訇主持殡礼；藏族由喇嘛主持；彝族、苗族多由「毕摩」「寨老」主持；纳西族由「东巴」主持。其组织形态与汉族「丧主＋护丧」的结构不同，须分别记述。详见各民族条目。

## 五、器物与文书

- **礼簿**：登记吊客与赙赠的册子，账房的依据。
- **讣告**：由司书撰写，丧主领衔具名。
- **账册**：司货掌管。
- **丧服、孝杖**：丧主及孝属所备。
- **谢帖**：丧事结束后的答谢文书（详见「婚丧文书范本／谢帖与答谢启范本」条）。
