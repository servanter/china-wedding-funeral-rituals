# 袭尸与易服

## 一、释义

「袭」是为死者穿衣之礼。沐浴、饭含之后，为死者穿上新制之衣（「袭衣」，士三称），并依次加「冒」（罩尸的布套）、「幎目」（覆面巾）、「掩」（裹头巾）、「幞巾」、「握手」（裹手之布囊）、「纩」（耳塞），最后以「组綦」束足，使死者形体安稳、面目不惊。

「易服」在此语境中有两重含义：一是为**死者**换着新衣；二是**生者**改换素服、去饰，进入服丧状态。两者在初丧阶段同时发生，故合称「袭尸与易服」。

## 二、历史源流

- 《仪礼·士丧礼》：「乃袭，三称。」郑玄注「三称」为「三套衣服」，即迁尸于床后为死者着三套衣。
- 《仪礼·士丧礼》又详记「设冒，櫜之」（以冒罩尸并束口）、「幎目，用缁，方尺二寸，赪里，著，组系」、「握手，用玄纁，里亲肤，系钩中指，结于腕」。
- 《礼记·丧大记》记君、大夫、士袭衣的等级差别（「君锦冒黼杀，缀旁七；大夫玄冒黼杀，缀旁五；士缁冒赪杀，缀旁三」）。
- 汉以后「袭衣」渐演为「寿衣／殓衣」。《明会典》定庶人殓衣五领（五件）；清代民间有「五领三腰」「七领五腰」「九领」之说，讲究件数为单数。
- 「幎目」「握手」在民间转化为「蒙脸纸／覆面巾」「手绢／手套」。

## 三、仪节流程

1. **陈衣**：将袭衣按次序陈设于房中。
2. **着衣**：为死者依次穿上三套（士礼）衣服，由内至外，束带系结。
3. **加冒**：先以「质」（方布，罩上身），后以「杀」（罩下身），在腰间打结，使尸形完整。
4. **设幎目**：以黑色方布（方一尺二寸）覆面，里用浅红，四角系带结于脑后。
5. **加掩、幞巾**：以「掩」裹头，以「幞巾」束发。
6. **塞耳**：以「纩」塞耳，取「不听无礼之声」之义。
7. **设握手**：以玄纁之布裹两手，系带钩于中指、结于手腕。
8. **结綦（束足）**：以组带系足，使尸身平正。
9. **生者易服**：亲属同时改换素服、去首饰，男子「括发」，女子「去笄」，进入服丧状态。

## 四、地域与民族变体

- **件数**：民间寿衣讲究单数（五、七、九件），忌双数。
- **材质**：多用棉、绸，忌用皮毛（俗谓恐来世堕入畜道），忌用缎子（谐「断子」）。
- **样式**：不用纽扣，改用带子系结（取「带子」即「带来子嗣」之义）。
- **颜色**：多为深蓝、褐色、枣红，忌纯黑（部分地区）与纯白（部分地区）。
- **北方**：讲究「五领三腰」；**江南**讲究「九领」；**闽台**寿衣由女儿置办，讲究「上七下五」。
- **少数民族**：回族、维吾尔族、哈萨克族等穆斯林民族以白布（「克凡」）裹身，不用缝制衣物；藏族有天葬、水葬等不同处置方式，衣着讲究因葬式而异；苗族、彝族等则以本民族盛装为殓服，并佩银饰。各族差异极大，详见各民族条目。

## 五、器物与文书

- **袭衣（寿衣）**：三称至十三领不等，按等级与财力。
- **冒**：分「质」（罩上身）与「杀」（罩下身），以布缝合、缀带。
- **幎目**（覆面巾）、**掩**（裹头巾）、**幞巾**（束发巾）。
- **握手**：裹手之布囊，玄纁色。
- **纩**：塞耳用绵。
- **组綦**：束足之带。
- **蒙脸纸、白布、孝巾**：民俗层面的替代物。
