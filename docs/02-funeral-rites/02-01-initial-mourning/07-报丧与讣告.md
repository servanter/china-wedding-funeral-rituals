# 报丧与讣告

## 一、释义

**报丧**是把死讯通知亲友的行为；**讣告**（又称讣闻、讣帖）是报丧所用的书面文书。「讣」通「赴」，取其奔赴相告之义。

讣告须载明：死者姓名与身份、卒日（部分地区载明生卒）、丧事日程（入殓、开吊、出殡时间）、丧居地址与联系方式、具名亲属（按服制顺序排列）。

讣告的用语有严格的等级与格式规范，古称「赴告之辞」，属凶礼文书系统的核心，详见「婚丧文书范本／讣告范本」条。

## 二、历史源流

- 《礼记·杂记》规定讣告用语：「凡讣于其君，曰：『君之臣某死。』父母、妻、长子，曰：『君之臣某之某死。』」——报丧对象与自称均有定制。
- 《仪礼·士丧礼》：「乃赴于君。」说明士死之后先告于君，是礼制上的第一顺位。
- 《礼记·檀弓》记「父之友」等不同关系的报丧方式，体现亲疏层次。
- 汉代以来讣告成为通用文书。唐宋有「讣帖」「讣状」，明清称「讣闻」，格式趋于定型：以「不孝男某等罪孽深重，不自殒灭，祸延显考……」的固定句式开篇。
- 近代出现报纸讣告（「登报讣闻」），当代出现电子讣告、微信群讣告。
- 报丧行为本身也有成俗：孝子报丧须跪告、不得入他人之门（在门外告之）等，各地规制不同。

## 三、仪节流程

1. **先告君主（或上级）**：礼制上士死先赴告于君；后世演为先报单位、主管或族中尊长。
2. **次告族亲**：派专人通知本族亲属，并按服制亲疏决定先后。
3. **拟写讣告**：写明死者讳、卒日、享年、丧事日程、丧居地址、具名亲属。
4. **分送**：由专人分送（「报丧帖」），或张贴、登报、发电子讣告。
5. **受报**：亲友接到讣告，或亲往吊唁，或致唁函、唁电、敬送花圈挽幛。
6. **孝子答礼**：对前来报丧处吊唁者，孝子跪谢（民俗）。

## 四、地域与民族变体

- **北方**：有「贴门纸」「挂白纸」报丧之俗；报丧人不得进门，须在门外呼唤。
- **江浙**：以「报丧帖」分送；有的地方在门前悬挂白布或白灯笼，标示服丧。
- **闽台**：称「报白」「报丧」，丧家门口贴白纸、悬「孝灯」；报丧人携「白帖」。
- **部分地方**：报丧时戴笠、持伞（「遮天」），且忌穿红衣。
- **民族差异**：回族、维吾尔族等穆斯林民族的丧事多在当日或次日即葬，报丧以口头、电话快速传达，**不设停灵与开吊环节**，讣告的形式与功能随之不同；藏族部分地区以请僧人通知、诵经代替报丧。详见各民族条目。

## 五、器物与文书

- **讣告（讣闻、讣帖）**：核心文书，白色纸张，格式固定。
- **门纸／白纸**：贴于门首以报丧。
- **白灯笼、孝灯**：标示丧家。
- **唁函、唁电、花圈、挽幛**：吊丧方的答礼物。
- **礼簿**：登记吊客与赙赠。
