# 属纩（临终与易箦）

## 一、释义

属纩是古人判定死亡的仪节。「属」为放置，「纩」为新绵。将一缕新绵置于临终者口鼻之上，观察其是否随气息拂动：绵不动，即为气绝。

与属纩相伴的是「易箦」：将病者从内寝之床迁至正寝之床（或地上）。男子终于正寝、女子终于内寝，是「善终」的标志，也是「寿终正寝」一词的由来。

## 二、历史源流

- 《礼记·丧大记》：「属纩以俟绝气。」这是属纩最早的明确记载。
- 《礼记·檀弓上》记曾子易箦：曾子病重，童子发现他睡的是大夫的华美床席（季孙所赐），曾子自省「吾得正而毙焉斯已矣」，命人扶起换席，「反席未安而没」。此典确立了「得正而毙」的临终伦理。
- 《仪礼·士丧礼》：「死于适室，幠用敛衾。」「适室」即正寝。
- 朱熹《家礼》强调「男子不绝于妇人之手，妇人不绝于男子之手」，将临终处置纳入家礼规范。
- 「属纩」一词由此成为「临终」的代称，如「属纩之际」。
- 民间实践中，「易箦」演为「搬铺」「移床」，「属纩」的验气功能被医学生命体征观察取代，但其礼义（正寝而终）仍在民间有影响。

## 三、仪节流程

1. **迁居正寝**：疾革，男子迁居正寝，女子迁居内寝。不住正寝者，视为「不得其死」，是旧时大忌。
2. **易箦**：撤去原床席，换为素朴之席，扶病者正身仰卧。
3. **属纩**：以新绵（纩）置口鼻之上，守候观察，绵不动则确认为气绝。
4. **举哀**：气绝后家人举哀。男子「括发」（束发去饰），女子「去笄」（拔去发簪）。
5. **撤衣设床**：撤去旧衣，设停尸之床，准备行「复」礼。
6. **延请执事**：请族中长者和执事者到场，分派丧事；民俗中此时焚烧纸钱（「烧倒头纸」「烧落地纸」），并鸣炮报丧。

## 四、地域与民族变体

- **北方（京津冀晋）**：称「搬铺」，将病者移至堂屋临时搭的板床上，俗称「太平床」。
- **江南**：称「移床」「上凉床」，多在堂屋正中或偏东位置。
- **闽台**：称「搬铺」，在正厅临时铺板，讲究「男左女右」；孝子须跪地「叫魂」。
- **四川**：称「上凉床」，并给临死者口中含银钱。
- **少数民族**：部分民族忌死于床上（如某些山地民族），须移至地上或屋外；藏族部分地区在临终时请喇嘛诵经，属宗教信仰层面的临终关怀。各族具体做法差异极大，详见「少数民族丧葬习俗」各条。

## 五、器物与文书

- **纩**（新绵）：验气之物，后成临终代称。
- **箦**（床席）：易箦所换之席，取素朴之义。
- **敛衾**：覆尸之被（《仪礼》「幠用敛衾」）。
- **烛、纸钱**：民俗层面的用品。
- **讣告底稿**：部分地区在此时开始拟写讣告，为报丧作准备。
