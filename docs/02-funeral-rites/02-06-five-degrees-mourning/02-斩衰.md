# 斩衰（三年）

## 一、释义

斩衰为五服中最重之服，服期三年（实为二十五月或二十七月）。「斩」指丧服不缉边、断处外露，以最粗的生麻制成，表示「哀痛至极，无暇修饰」。

**服斩衰三年者（依《仪礼·丧服》）：**

1. 子为父（含嫡子、庶子、在室女为父）；
2. 妻为夫；
3. 臣为君；
4. 父为长子（承重）；
5. 为人后者（嗣子）为所后之父；
6. 诸侯为天子；
7. 妾为夫（为君）；
8. 女子子在室为父；女嫁反在室（被出或无夫而归）为父；
9. 继母如母、慈母如母（在特定条件下）。

## 二、历史源流

- 《仪礼·丧服》开篇即「斩衰裳，苴绖、杖、绞带，冠绳缨，菅屦」——以器服的最粗劣标示服等的最重。
- 《礼记·三年问》专论「三年之丧」的礼义：以「天道三年成一闰」比附，说明「三年」为何为最长期。
- **母服的加隆**：唐以前「父在为母」服齐衰杖期；唐武则天时改为齐衰三年；明太祖定制后，**「子为母」不论父在与否皆为斩衰三年**（母服加隆），这是五服史上最重要的变动之一。
- **为人后者**：嗣子为所后之父斩衰三年，而为本生父母降服（齐衰不杖期），称「降服」，是宗法上「移宗」的体现。
- 清代《大清通礼》沿明制，斩衰三年的范围大体稳定。
- 近代服制废除，仅存民间孝服形态（孝子着粗白布衣、腰系麻绳）。

## 三、仪节流程

1. **成服**：大殓之后，服斩衰者换着斩衰服（粗生麻衣、不缉边），加苴绖（麻带）、绳缨冠、菅屦。
2. **居丧**：居「倚庐」（棚屋），寝苫枕块；不食酒肉，百日后方能食蔬果。
3. **哭位**：在殡期内守灵、朝夕哭，行三献礼时为主祭。
4. **变服**：一周年（小祥）改着练冠；二周年（大祥）改着素缟麻衣。
5. **除服**：大祥后一月（或三月）行禫祭，除服。
6. **期内限制**：不得婚娶、不得赴宴、不得作乐、不得为官（丁忧）、不处内室（「居丧不处内」）。

## 四、地域与民族变体

- **汉族各地**：民间多简化为「孝子穿粗白布孝服、戴孝帽、系麻绳、执孝杖」，服期由三年缩短为百日、周年或「三年」的象征期。
- **闽台**：孝子穿「粗白布孝服」（「麻衫」「孝衫」），服期至「除孝」为止；「三年」多以「合炉」之礼收束。
- **北方**：孝子孝女着「孝袍」，系麻绳，戴孝帽（糊白布），期限多为百日或周年。
- **少数民族**：五服为汉族宗法产物。彝族的家支服丧、藏族的宗教服丧各有规定，与斩衰三年不是同一制度。
