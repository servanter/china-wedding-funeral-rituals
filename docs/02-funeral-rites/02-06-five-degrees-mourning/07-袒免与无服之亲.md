# 袒免与无服之亲

## 一、释义

- **无服之亲**：超出缌麻范围、不再有服丧义务的亲属，即俗称「出了五服」。
- **袒免**：「袒」为袒露左臂（去外衣、露左臂），「免」（wèn）为以布束发（不戴冠而以布条束发）。袒免是**无服之亲参加丧礼时的标记性装束**——不服丧服，但以袒免表示「虽无服，犹有亲」。

《礼记·大传》：「四世而缌，服之穷也；五世袒免，杀同姓也；六世亲属竭矣。」清晰勾画出亲等渐疏的三级：缌麻（四世）→ 袒免（五世）→ 亲属关系终结（六世）。

## 二、历史源流

- 《礼记·大传》确立了「服制递减」的框架，是理解无服之亲的礼制依据。
- 《仪礼·丧服》规定「朋友」的吊服规格为「缌」，可与袒免参照理解：礼制对「有亲而无服」与「无亲而有义」的关系都给出了标记方式。
- 袒免的具体装束在历代礼书中有明确规定（「袒则去饰，免则以布束发」）。
- 明清民间「出了五服」的亲属仍须参加丧礼与婚礼，但不必着孝服，多以「白布条」「白纸花」表示。
- 宗族制度弱化后，「五服」的边界在实践中被「同宗」「同族」的概念替代：「出了五服便是同族，不出五服便是近亲」。

## 三、仪节流程

1. **确认亲等**：依族谱确认与死者的亲等，判断是否在五服之内。
2. **无服之亲**：不服丧服，但在丧礼中的义务包括：
   - 参与吊唁（可不跪灵）；
   - 参与出殡送葬（不执绋）；
   - 参与殡后的家族祭祀。
3. **袒免之礼（古制）**：五世之亲参加丧礼时，袒露左臂、以布束发，表示「有亲无服」。
4. **民俗形态**：民间以「白布条系腰」「白纸花佩胸」「穿素衣」作为轻服的替代标记。
5. **往来义务**：无服之亲仍须在婚丧、年节时往来，是「宗族共同体」的实际边界。
6. **入族谱**：无服之亲仍在族谱之内，是族人而非「亲戚」。

## 四、地域与民族变体

- **闽粤、徽州**：宗族制度严密，「出五服」的边界清晰（族谱载明房支），无服之亲的往来义务明确。
- **华北**：宗族相对松散，「五服」多按「本家」的口头范围认定。
- **江南**：宗族与义庄制度结合，服制边界与族产分配常有对应。
- **当代**：「五服」在民间仍作为「亲戚远近」的俗语使用（如「出了五服，不算近亲」），与法律的「三代以内旁系血亲」无直接对应关系。
- **少数民族**：五服为汉族宗法制度产物，各族有自己的亲属边界（如彝族的家支、藏族的氏族），不可混用。

## 五、器物与文书

- **族谱**：确认亲等的唯一依据。
- **袒免之服**（古制）：布条、束发布。
- **白布条、白纸花、黑纱**（民俗轻服标记）。
- **服制图**：标示五服边界。
- **礼书**：《礼记·大传》《仪礼·丧服》《大清通礼》。
