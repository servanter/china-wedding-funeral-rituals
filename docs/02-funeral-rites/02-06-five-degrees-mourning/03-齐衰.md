# 齐衰（三年、杖期、不杖期、三月）

## 一、释义

齐衰（zī cuī）为次于斩衰的服等。「齐」指丧服缉边（衣边缝齐），材质用生麻但较斩衰为细，故次于斩衰。

齐衰分**四等**，是五服中内部差别最大的一种：

| 等第 | 服期 | 典型适用关系 |
| --- | --- | --- |
| **齐衰三年** | 三年 | 父卒为母；母为长子（旧制） |
| **齐衰杖期** | 一年（执杖） | 父在为母（唐以前）；夫为妻 |
| **齐衰不杖期** | 一年（不执杖） | 为祖父母；为世父母、叔父母；为众子；为昆弟；为兄弟之子；孙为祖父母；为夫之父母（舅姑） |
| **齐衰三月** | 三月 | 为曾祖父母；为高祖父母（礼家所列不一）；为宗子、宗子之母妻 |

**杖**（丧杖）：杖期的「杖」表示服丧者的哀痛已至须扶杖而行，是服等轻重的一个标记。

## 二、历史源流

- 《仪礼·丧服》对齐衰四等的规定最为详密，历代注疏对「何者列入何等」多有讨论，各礼家所列略有出入。
- **变动最大的两处**：
  1. **「父在为母」**：唐以前为齐衰杖期；唐武则天时改为齐衰三年；明太祖定制后改为斩衰三年（母服加隆）。
  2. **「夫为妻」**：旧为齐衰杖期；明以后仍为齐衰杖期，但民间实际多加重。
- **「妇为舅姑」**：旧为齐衰不杖期；唐以后改为斩衰三年（与子为父母同），是「舅姑如父母」的体现。
- 清代《大清通礼》沿明制。
- 齐衰三月中的「为宗子」一项，是宗法制度在服制上的直接投影。

## 三、仪节流程

1. **成服**：按所属等第着齐衰服（缉边生麻衣），加绖、带、冠。
2. **执杖与否**：杖期者执杖；不杖期与三月者不执杖。
3. **居丧**：居丧程度较斩衰为轻，但仍须「居外寝」「不食酒肉」（初期）。
4. **变除**：一周年（小祥）变服；期满除服。
5. **居丧限制**：服期内不得婚娶、不得作乐；杖期与三年者限制最严。
6. **齐衰三月**：服期极短，多为象征性服丧，表示「有服而不重」。

## 四、地域与民族变体

- 民间实际服制简化为「孝服等第」：为祖父母、伯叔父母的孝服（白布、孝帽）与为父母的孝服（粗白布、麻绳）有明显区别，即齐衰与斩衰的区别在民间的投影。
- **闽台**：孝服分「麻衫」（重服）、「苎衫」（次服）、「白衫」（轻服）三等，与五服的三级简化对应。
- **华北**：孝服以「白布孝袍」为通用，仅以「系麻绳与否」「孝帽形制」区分轻重。
- **少数民族**：各有本族的服丧期与标记（如戴孝布、断发、禁饰），与齐衰等第无关。

## 五、器物与文书

- **齐衰服**：生麻衣，缉边。
- **丧杖**：杖期者所执（「削杖」——削去枝条，与斩衰之「苴杖」有别）。
- **绖、带、冠**。
