# 五服与宗法制度

## 一、释义

五服制度不是孤立的丧礼规定，而是**宗法制度的一个侧面**。宗法以「大宗小宗」「嫡长继承」组织宗族；五服则以「服等」把这一组织结构标记在个人的丧服与义务上。二者互为表里：

- **宗法定「位」**：谁是大宗、谁是宗子、谁有主祭权。
- **五服定「情」与「义务」**：谁为谁服何服、服多久、承担什么居丧限制。

## 二、五服与宗法的对应关系

### 1. 主祭权与「宗子」之服

《仪礼·丧服》规定「为宗子」服齐衰三月——即使宗子与己的亲等已远，仍须为其服丧，因为他是「继祖之宗」，代表宗族的连续性。这是**制度性的服丧**，与情感无关。

### 2. 嫡长与承重

- 父为**长子**服斩衰三年（长子为「正体于上」，将继己之宗）。
- 嫡孙承重：若长子已死，嫡长孙为祖父服斩衰三年（「承重孙」），因为他是宗祧的继承者。
- 这一规定使**丧礼中的主祭人（丧主）与继承人合为一体**，故有「摔盆打幡者继承」的民俗（见「摔盆」条）。

### 3. 「为人后」与降服

- 无子者立嗣（「为人后者」），嗣子为所后之父服斩衰三年，而为本生父母降服齐衰不杖期。
- 这是**宗祧继承**的服制表达：一旦「移宗」，血缘关系在礼制上就被重新排列。

### 4. 服制与财产继承、法律连带

- 服制是**继承顺序**的重要参照（近亲优先）。
- 服制也是**法律连带责任**的依据：唐代「同居」范围、明代「亲属相犯」的刑罚加减，多依服制亲等而定（「准五服以制罪」）。
- 《晋书·刑法志》载「准五服以制罪」的原则，标志服制进入法律体系。

## 三、历史源流

- 《礼记·大传》系统论述宗法与服制的关系（「别子为祖，继别为宗」等），是这一问题的纲领性文献。
- 汉代以后，服制与法律的结合日益紧密（「准五服以制罪」）。
- 唐律、明律、清律中大量条文按服制亲等决定刑罚轻重。
- 宋代《家礼》以祠堂制度重构宗族组织，五服成为宗族的日常运行规则。
- 明清宗族发达地区（闽粤、徽州），五服与族产（祭田）、族规、族学、赈济制度捆绑在一起。
- 近代以后，法律上的服制效力被废除（民国《民法》以亲等计算代替服制），宗法制度瓦解，五服退为民间习俗。

## 四、地域与民族变体

- **闽粤、徽州**：宗族组织严密，五服与族产、族规直接挂钩，是「服制—宗法」一体化最完整的地区。
- **华北**：宗族相对松散，「五服」更多是亲属称谓与往来范围的界线。
- **当代**：「五服」在民间仍作为「亲戚远近」的表述，但在法律上已完全失去效力（现行法律以「三代以内旁系血亲」等概念界定）。
- **少数民族**：彝族的「家支」制度、藏族的氏族结构有自己的亲属组织方式与服丧规范，与汉族宗法—五服的逻辑不同，不可混用。

## 五、器物与文书

- **族谱（宗谱）**：宗法的核心文书，记载房支、世系、服制关系。
- **五服图**：宗法的图示。
- **族规、祠规**：宗族运行规则。
- **祭田（祠田）契书**：族产凭证。
- **律典**：《唐律疏议》《大明律》《大清律例》中按服制定刑的条文。
