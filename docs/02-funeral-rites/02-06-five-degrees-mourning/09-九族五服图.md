# 本宗九族五服图

![本宗九族五服图 / The nine-generation mourning-degree chart](../../../assets/diagrams/本宗九族五服图.svg)

*图 8　本宗九族五服图（自高祖至玄孙的服制等第）。*

## 一、释义

「本宗九族五服图」是把本宗九族（自高祖至玄孙共九代）与五服等第对应起来绘制的图表，是传统宗族社会理解亲属关系的基本工具。

**「九族」**（自高祖至玄孙，纵九代）：

```
高祖 ─ 曾祖 ─ 祖 ─ 父 ─ 己 ─ 子 ─ 孙 ─ 曾孙 ─ 玄孙
```

**「五服」**：以「己」为中心，向上、向下、向旁逐级推演，服等随之递减。

## 二、服制对照（以「己」为中心）

## 三、历史源流

- 《仪礼·丧服》本身即以亲等递推的方式说明服制，虽未作图，但其结构已经可以图表化。
- 宋代《家礼》把服制简化为「四世」（高祖以下）的框架，并附「本宗五服图」，是后世通用「五服图」的直接来源（因《家礼》的影响，民间通行的是「高、曾、祖、父、己」五世之图）。
- 明清《大清通礼》等礼书详列服制图。
- 民间以「五服图」刻印于书后或族谱中，供族人在办丧事时查用。
- **实际影响**：五服图不仅是礼书内容，也是**界定「近亲」「同宗」「继承顺序」的实际依据**。

## 四、地域与民族变体

- **闽粤、徽州**：族谱中多附「五服图」，宗族按图办丧、定亲疏。
- **华北**：多以「本家」的口头范围替代图式。
- **少数民族**：五服图是汉族宗法制度的产物；各族的亲属结构不同（如彝族的家支、藏族的氏族），不适用此图。

## 五、器物与文书

- **五服图（本宗九族五服图、外亲服制图）**：刻印图或手绘。
- **族谱**：附五服图，是查找亲属关系的实际工具。
- **礼书**：《仪礼·丧服》《家礼》《大清通礼》。
