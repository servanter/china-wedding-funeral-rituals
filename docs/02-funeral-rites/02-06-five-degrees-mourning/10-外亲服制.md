# 外亲服制（母族、妻族、女族）

## 一、释义

「外亲」是指本宗九族之外的亲属，分三类：

- **母族**：外祖父母、舅、姨、舅表与姨表兄弟姊妹。
- **妻族**：妻之父母（岳父母）、妻之兄弟（内兄内弟）、妻之姊妹（姨姐姨妹）。
- **女族**：出嫁之姑、姊妹、女及其子女（外孙、外甥）。

外亲服制的基本原则是：**一律降本宗一等，且服等普遍较轻**。这是「亲亲以本宗为重」的宗法逻辑。

## 二、服制对照

| 外亲 | 与己的关系 | 服等（《仪礼》系统） |
| --- | --- | --- |
| 外祖父母 | 母之父母 | 小功五月 |
| 舅 | 母之兄弟 | 缌麻三月（唐以后有加服） |
| 从母（姨） | 母之姐妹 | 小功五月 |
| 舅表、姨表兄弟姊妹 | 母之兄弟及姐妹之子女 | 缌麻三月 |
| 妻之父母（岳父母） | 妻之父母 | 缌麻三月 |
| 妻之兄弟 | 姻亲 | 无服（后世有加服） |
| 女婿 | 女之夫 | 缌麻三月 |
| 外孙 | 女之子 | 缌麻三月 |
| 岳母 | 妻之母 | 缌麻三月 |

**说明**：外亲服制是五服中历代变动最多、礼家分歧最大的部分。唐《开元礼》以后对「舅」「姨」等有加服之举（如唐以后「为舅」加至小功），反映「恩义」对「宗法」的逐渐突破。

## 三、历史源流

- 《仪礼·丧服》确立「外亲降本宗一等」的原则，故外祖父母仅为小功，舅仅为缌麻。
- **唐代的加服**：唐《开元礼》对若干外亲有加服（如「为舅」加至小功），是外亲服制的重要变化。
- **明代的调整**：明《大明令》对「为外祖父母」「为舅」「为姨」等作了加隆，使之普遍提高一等。
- 清代《大清通礼》沿用明制而略有调整。
- **重要背景**：外亲服制的变化趋势是**「恩义加重」**——随着家族形态的变化与「母系亲属情感」的现实要求，礼制的宗法色彩逐渐被削弱。
- 近代服制废除后，民间「外祖父母、舅、姨」的孝服已与「伯叔」接近，反映出与礼制相反的方向。

## 四、地域与民族变体

- **闽台**：外亲（母族）的孝服在民俗中并不比本宗明显为轻，尤其外祖父母去世时，外孙须着「苎衫」。
- **华北**：外亲多戴「白孝帽」或臂戴黑纱，形式简单。
- **当代**：五服等第的区分在民间基本消失，「外亲」与「本宗」的服丧差异主要体现在礼俗习惯上。
- **少数民族**：部分民族（如纳西族、白族）有母系亲属的重要地位，其服丧规定与汉族「外亲降服」的原则不同，须分别记录。
