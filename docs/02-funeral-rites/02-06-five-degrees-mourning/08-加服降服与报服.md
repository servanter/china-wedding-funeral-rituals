# 加服、降服与报服

## 一、释义

五服的「正服」之外，还有三类使服等发生变动的规则：

| 规则 | 含义 | 典型例子 |
| --- | --- | --- |
| **加服** | 恩义加重，服等提高 | 为舅加服（唐以后）；为姨加服；母服加隆 |
| **降服** | 因宗法、外亲或特殊身份而降低 | 女子出嫁为本宗降一等；为人后者为本生父母降服 |
| **报服** | 双方相互对等的服制 | 姑为侄 ↔ 侄为姑；舅为外甥 ↔ 外甥为舅 |

**「从服」**：因所从之人而有服（如妻从夫服夫之亲属），是另一类特殊规则。

## 二、历史源流

- 《仪礼·丧服》以「正服／加服／降服／义服／从服／报服」六类统摄全部服制，体系极精密。
- **降服的宗法意义**：
  - **女子出嫁**：由本宗成员变为「外亲」，为本宗亲属一律降一等（如为父母由斩衰降为齐衰不杖期，为祖父母由齐衰降为大功）。
  - **为人后者（嗣子）**：为所后之父服斩衰三年，而为本生父母降服齐衰不杖期——「移宗」的服制表达。
  - **出母**：为被出的生母降服。
- **加服的历史**：唐以后对若干外亲（如舅、姨）有加服之举，反映了「恩义重于宗法」的趋势。
- **报服**：保证亲属间的服制对等，如「侄为姑」与「姑为侄」的服等相应。
- 《礼记·服问》专论各类变服的情形，是理解这一体系的关键文献。
- 明清礼书大体沿《仪礼》系统，而于外亲服制有较多调整。

## 三、仪节流程

1. **确定正服**：先依本宗九族的亲等确定「正服」。
2. **判断是否降服**：
   - 是否出嫁（女）？
   - 是否为人后（嗣子）？
   - 是否为出母之子？
3. **判断是否加服**：是否有恩义加重的特殊情形（如养母、继母、慈母）？
4. **判断报服与从服**：对方是否为我服丧？我是否因所从之人（夫、妻、子）而有服？
5. **成服**：依最终确定的服等着相应丧服。
6. **记录**：宗族发达地区在族谱或家礼抄本中记录服制变动。

## 四、地域与民族变体

- 「降服」的原则在民间仍有投影：**出嫁女为娘家亲属的孝服，普遍比自己兄弟所服的孝服为轻**。
- **闽台**：出嫁女为娘家长辈多着「苎衫」或「白衫」（轻服），即「降服」的民俗形态。
- **华北**：出嫁女回娘家戴孝，多用「白布孝帽」而不用重服。
- **当代**：五服的精细规则多不存，但「嫁出去的女儿戴孝要轻一些」这一民俗观念仍在部分地区流行。
- **少数民族**：各族有自己的亲属服丧规则，与「降服」「报服」的宗法逻辑不同，须分别记录。
