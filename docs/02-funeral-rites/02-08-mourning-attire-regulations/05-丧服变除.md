# 丧服变除（受服、变服、除服）

## 一、释义

服丧不是「一服到底」，而是**随时间的推移逐级由重转轻，直至除服**。三个关键概念：

| 概念 | 含义 | 时点 |
| --- | --- | --- |
| **受服** | 受以「成布」（加工过的较细布）之服，由粗转细 | 三月既葬后 |
| **变服** | 依节令改换冠、衣（练冠、练衣等） | 小祥、大祥 |
| **除服** | 服制期满，脱去丧服 | 禫祭之后 |

**变除的理论**：《礼记·间传》以「**哀之杀**」解释——哀情随时间递减，故丧服亦由粗而细、由重而轻，是「礼」对「情」的节度。

## 二、历史源流

- **先秦**：《仪礼·丧服》与《礼记·间传》《三年问》规定变除之节。
- **汉魏**：有「二十五月」「二十七月」之争（郑玄主二十七月，王肃主二十五月）。
- **唐宋**：《开元礼》确定「二十七月」之制（含禫），为后世所遵。
- **明清**：礼书详载小祥、大祥、禫的变服仪节。
- **近代以来**：民间以「百日」「周年」「三年」（合炉、脱孝）为变除节点。

## 三、仪节流程

1. **三月既葬·受服**：改服较细之布（如斩衰之裳改以成布）。
2. **十三月·小祥**：练冠、练衣（「练」谓煮练之布），去首绖之粗者。
3. **二十五月·大祥**：服「素缟麻衣」，去绖、杖，除重服。
4. **二十七月·禫**：行禫祭，除服、玄冠朝服，服制终了。
5. **除服**：禫后恢复正常生活与服色。

## 四、地域与民族变体

- **汉族各地**：以「五七」「百日」「周年」「三年」为脱孝节点；闽台以「合炉」为收束。
- **少数民族**：服丧期与解除标志各异（脱孝布、洗头、宴客等），不属变除之礼的体系，须分别记录。

## 五、器物与文书

- **练冠、练衣、素缟麻衣**。
- **禫祭陈设**：祭品、祝文。
- **相关文书**：讣告与谢帖中的「服制排行」（如「期服孙」），标示变除后的身份。
