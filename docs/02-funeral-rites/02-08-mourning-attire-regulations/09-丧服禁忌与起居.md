# 丧服禁忌与起居限制

## 一、释义

「服丧」不止于穿衣，更包括**整套生活的限制（居丧之礼）**。古人以「**居丧之礼**」约束身体与欲望，使哀情在外在行为上得到落实。

| 方面 | 限制内容 |
| --- | --- |
| **饮食** | 斩衰「三日不食」；「既殡，食粥」；「三月既葬，食疏食、水饮」；期、大功各有递减（《礼记·间传》） |
| **居处** | 「居倚庐，寝苫枕块」——住草棚、睡草席、枕土块；「不涂（不涂塞）」「不帷」 |
| **睡卧** | 「寝不脱绖带」（斩衰）；小祥始「居垩室」，大祥始「居复寝」 |
| **言语** | 「丧事不言」（唯言丧事）；不与人谈笑、不作乐 |
| **服饰** | 不服彩、不佩饰、不沐浴（初期） |
| **婚娶** | 「**父母之丧，三年不娶**」；丧期内不为子女议婚、不赴宴、不举乐 |
| **其他** | 不居内（不与妻妾同室）、不赴他人喜庆、不参与祭祀（「丧者不祭」） |

## 二、历史源流

- **先秦**：《礼记·间传》《丧大记》《曲礼》系统记载居丧限制与递减之节。
- **汉唐**：居丧之礼入律——「**居丧违礼**」可入罪（如汉代「不孝」之罪、唐代「居丧作乐」之律）。
- **宋明**：理学强化居丧规范，《家礼》规定丧期行为。
- **明清**：法律对居丧嫁娶、作乐、赴宴等有明确处罚条文。
- **近代以来**：法律条文废止，民间保留部分禁忌（如丧期内不办喜事、不串门拜年）。

## 三、仪节流程

1. **成服后**：开始居丧生活，入住「倚庐」。
2. **饮食递减**：三日不食 → 食粥 → 疏食水饮 → 小祥后食菜果 → 大祥后复常。
3. **居处迁移**：倚庐 → 垩室 → 复寝。
4. **言语与交往**：唯言丧事，不作乐、不赴宴。
5. **除服**：禫后起居复常，婚娶解禁。

## 四、地域与民族变体

- **汉族各地**：民间保留「孝期内不办喜事」「不贴红对联」「不拜年」等禁忌；华北有「孝子守灵不食荤」之说。
- **闽台**：守丧期（「孝期」）内禁嫁娶、禁赴喜庆，丧家「不做热闹」。
- **少数民族**：各族丧期禁忌内容差异大（禁猎、禁歌舞、禁婚娶、禁某些食物），其依据多为本族信仰，须分别记录。

## 五、器物与文书

- **居丧陈设**：倚庐（草棚）、苫块（草席、土块）、垩室。
- **饮食器物**：粥器、疏食之具。
- **法律条文**：历代律令中「居丧违礼」条。
- **礼书依据**：《礼记·间传》《丧大记》《曲礼》。
