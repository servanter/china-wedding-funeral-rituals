# 丧服与身份等级

## 一、释义

除亲属关系外，**政治身份（爵）** 也是决定丧服等差的要素——五服制度同时是「亲亲」与「**尊尊**」两条原则的结合。

**主要的身份性服制**（依《仪礼·丧服》）：

| 关系 | 服等 |
| --- | --- |
| 臣为君 | 斩衰三年（先秦） |
| 诸侯为天子 | 斩衰三年 |
| 天子为三公、诸侯为大夫等 | 依爵有「锡衰」「缌衰」之制 |
| 庶人为国君 | 齐衰三月 |
| 大夫为旧君 | 齐衰三月 |
| 士为所仕之大夫 | 齐衰三月（有「不反兵」诸条） |

**「爵」与「降」**：同一亲属关系，因双方爵位不同而**降服**（如「大夫为士者」降一等），故有「**以爵降**」的原则。地位愈高，所服范围与等第愈有特殊规定。

## 二、历史源流

- **先秦**：分割据诸侯、大夫、士、庶人的等级社会，故《仪礼·丧服》有大量以爵定服之条。
- **秦汉以降**：随着官僚制取代封建制，「臣为君斩衰三年」的实际施行范围收缩，多以「旧君」之服代之。
- **唐宋**：官方礼典（《开元礼》）保留等级性服制规定，同时精简。
- **明清**：《大明令》《大清通礼》对品官丧礼（谥、碑、明器、坟茔）有等差规定，服制本身趋于统一。
- **近代以来**：身份等级性服制消失，仅亲属服制以民俗形式留存。

## 三、仪节流程

1. **定身份**：据死者与服者的爵位、官职确定适用服等。
2. **定服**：依礼书条目选择服制（含降服、加服）。
3. **成服行礼**：与亲属服制同时成服。
4. **特别服制**：如「锡衰」（诸侯为卿大夫）等特殊材质之服。
5. **除服**：依相应服期变除。

## 四、地域与民族变体

- **汉族各地**：民间实际只保留亲属服制，身份性服制未见施行。
- **宗族社会**：族长、宗子之丧在族内被赋予更重的服制与更高的丧仪规格，是「尊尊」原则的民间遗存。
- **少数民族**：土司、头人等身份性丧仪有其自身制度，与汉族「以爵定服」不属同一体系，须分别记录。

## 五、器物与文书

- **等级性丧服**：锡衰、缌衰、疑衰（先秦等级丧服）。
- **品官丧礼规定**：谥法、碑碣、明器、坟茔尺寸的等级限额（历代令式）。
- **相关文书**：官爵、封赠、谥号文书（行状、碑志）。
