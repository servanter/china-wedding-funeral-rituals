# 女性丧服规制

## 一、释义

女性服制以「**在室（未嫁）**」与「**出嫁**」为分野，是五服「**从服**」「**降服**」原则最集中的体现。

| 关系 | 在室之女 | 出嫁之女 |
| --- | --- | --- |
| 为父 | 斩衰三年 | 齐衰不杖期（降） |
| 为母 | 齐衰三年（明以后「父在为母」亦斩衰） | 齐衰不杖期（降） |
| 为兄弟 | 齐衰不杖期（父在）/ 大功 | 大功（降） |
| 为祖父母 | 齐衰不杖期 | 大功（降） |
| 为夫 | — | **斩衰三年** |
| 为夫之父母（舅姑） | — | 齐衰不杖期 |
| 为长子 | 齐衰三年（明代改不杖期） | 同 |
| 为众子 | 齐衰不杖期 | 同 |
| 为人后者之妻、妾为嫡妻 | 依从服之例 | — |

**两个核心原则**：
1. **「未嫁从父，既嫁从夫」**——出嫁之女归入夫家服制体系，于本宗「降一等」。
2. **「夫者，妻之天也」**——妻为夫服最重的斩衰三年，体现夫妇之间的绝对等级。

## 二、历史源流

- **先秦**：《仪礼·丧服》定女子在室、出嫁服制；「妇人不杖」与「妇人亦有杖」诸条有争论。
- **唐代**：「父在为母」一度改为齐衰三年，后又复旧。
- **明代**：「父在为母」定为斩衰三年（母服加隆）；「母为长子」改齐衰不杖期。
- **清代**：沿明制，女子服制规定详备。
- **近代以来**：男女服制差异消退，仅存「女儿孝服较儿子为轻」等民间观念。

## 三、仪节流程

1. **定在室／出嫁**：首先判定女子婚否，以定服等。
2. **成服**：依服等着相应丧服。
3. **出继与归宗**：出嫁女子归宁本宗丧事，依降服之例。
4. **变除**：依夫家或本宗服期变除。

## 四、地域与民族变体

- **汉族各地**：民间多以「女儿孝服较轻、媳妇服重」的做法保留礼制痕迹；闽台「孝女」「孝媳」服色、孝带各有别。
- **少数民族**：女性丧服形式与服丧义务多由各族传统与宗教信仰决定，与汉族「在室／出嫁」之降服原则不同源，须分别记录。

## 五、器物与文书

- **女性丧服**：衰、裳、冠（或「孝头」）、绖、带。
- **相关文书**：讣告中的「服制排行」区分「孝男」「孝女」「孝媳」。
- **礼书依据**：《仪礼·丧服》妇人服条、《家礼》、《大清通礼》。
