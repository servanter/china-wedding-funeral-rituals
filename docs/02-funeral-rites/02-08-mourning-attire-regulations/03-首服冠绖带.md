# 首服：冠、绖、带

## 一、释义

「首服」指丧服中的头饰，与裹束身体的「绖」「带」同为一套。名目如下：

| 名目 | 位置 | 材质 |
| --- | --- | --- |
| **丧冠** | 头顶 | 布制；斩衰「绳缨」（以麻绳为冠缨），齐衰「布缨」 |
| **首绖** | 额上、绕头 | 以麻为之，斩衰首绖最粗（「绖大摇」） |
| **腰绖** | 腰间 | 以麻为之，绞结 |
| **绞带** | 腰间，束身 | 斩衰以苴麻绞成，齐衰以下以布为带 |
| **布带** | 腰间 | 布制 |

**礼义**：绖、带以麻之粗细别尊卑——「**绖也者，实也**」（《礼记·间传》），谓以麻实心束身，示哀之实在；冠缨、带之精粗随服等递减。

## 二、历史源流

- **先秦**：《仪礼·丧服》详定冠、绖、带的形制与尺寸（如首绖之围、腰绖之围各有等差）。
- **汉唐**：注疏考订尺寸；《大唐开元礼》颁为定制。
- **宋明**：《家礼》记「冠、绖、带、屦」之节，民间多简化。
- **近代以来**：仅存「孝帽」「孝带」「孝箍」等形式。

## 三、仪节流程

1. **加冠**：成服时先戴丧冠。
2. **系首绖**：以麻绕额。
3. **束腰绖、绞带**：束于腰间，绞带结于前。
4. **变除**：小祥改易（练冠），大祥去绖。
5. **除服**：服满去之。

## 四、地域与民族变体

- **华北**：以「孝帽」（白布缝制）、「孝带」（束腰白布带）为通行形态。
- **闽台**：孝男「麻冠」，妇人「孝头」（白布包头），区分明显。
- **江南**：多戴白布孝帽，腰间束白带。
- **少数民族**：丧期头饰形式多样（包头、束发、断发），其含义与汉族冠绖之制不同源，须分别记录。

## 五、器物与文书

- **丧冠**、**首绖**、**腰绖**、**绞带**、**布带**。
- **孝帽、孝箍、孝带**（近世形态）。
