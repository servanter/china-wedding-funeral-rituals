# 丧服材质与规格

## 一、释义

丧服的等差主要落实在**麻布的粗细**上，而粗细以「**升数**」计量：布幅二尺二寸（约 50 厘米），其间经线八十缕为「一升」。**升数越少，布越粗疏**；升数越多，布越细密。

| 服等 | 麻布升数 | 生熟 | 说明 |
| --- | --- | --- | --- |
| **斩衰** | 三升 | 生麻，不锻濯 | 最粗，几乎不成布 |
| **齐衰** | 四升、五升、六升 | 生麻（齐衰三年四升，杖期五升，不杖期六升） | 依等递增 |
| **大功** | 七升、八升、九升 | 熟麻（锻濯灰治） | 加工较粗 |
| **小功** | 十升、十一升、十二升 | 熟麻 | 较细 |
| **缌麻** | 十五升去其半（约十四升半） | 熟麻 | 疏细如朝服而抽去半数经线 |

**关键原理**：丧服材质与服期长短成反比——**哀之杀（递减）**，服越轻则布越细、加工越精（《礼记·间传》「斩衰三升……缌麻十五升去其半」）。

## 二、历史源流

- **先秦**：升数之制确立于《仪礼·丧服》经文与传文，为等级最精细的量度标准。
- **汉唐**：注疏详辨「升」「缕」「幅」的尺度换算；唐《开元礼》以令式形式规定丧服材质。
- **宋明**：实际服丧多不严格按升数制作，《家礼》从俗简化；明清礼书仍保留升数记载以备稽考。
- **近代以来**：升数概念仅存于礼学研究；民间丧服材质以「粗白布／细白布」的直观分别替代。

## 三、仪节流程

1. **备布**：按服等备相应升数的麻布（或白布）。
2. **制衣**：裁剪衰、裳，斩衰不缉边。
3. **锻濯**：齐衰以下、大功以上依礼「锻濯灰治」（水洗捶打、以灰水煮练）使麻柔软。
4. **成服**：着服行礼。

## 四、地域与民族变体

- **汉族各地**：民间以「粗布为重服、细布为轻服」的直观原则替代升数；闽台以麻、苎、白布三级区分。
- **少数民族**：多以本地织物（麻、羊毛、氆氇、土布）制作丧服，其材质体系不以「升数」为量度，须分别记录。

## 五、器物与文书

- **麻布**：苴麻（生麻）、牡麻（熟麻）。
- **量度术语**：升、缕、幅（二尺二寸）。
- **礼书依据**：《仪礼·丧服》经文与传文、《礼记·间传》《大唐开元礼》。
