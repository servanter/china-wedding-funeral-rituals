# 现代孝服（孝布、黑纱、白花）

## 一、释义

现代孝服是传统五服服制的**民间简化形态**，以「**孝布**」为核心材料，配属孝帽、孝带、黑纱、白花等，标志服丧者身份与亲疏。

| 形态 | 形式 | 亲疏标示 |
| --- | --- | --- |
| **孝布** | 白布条，系于腰或臂 | 布之宽窄长短别亲疏 |
| **孝帽／孝箍** | 白布帽或以白布包头 | 直系亲属用 |
| **孝带** | 束腰白布带 | 孝子孝女 |
| **黑纱** | 黑布臂章 | 一般亲友、城市通用 |
| **白花** | 纸花或绢花，佩于胸前 | 通用 |
| **孝鞋** | 白布蒙鞋（「封孝鞋」） | 子女 |

**分级**：民间分「大孝」（孝子孝女：孝袍、孝帽、孝带）、「小孝」（孙辈、侄辈：白布、白花）、「轻孝」（其他亲友：黑纱、白花）。

## 二、历史源流

- **1930 年《民法》**：以亲等制取代服制，五服丧失法律效力。
- **1950 年代后**：殡葬改革与移风易俗，孝服、孝期简化，城市以黑纱、白花为主。
- **1980 年代以来**：农村传统孝服（孝袍、孝帽、孝带）重新普及；同时旧式繁复服制未恢复。
- **当代**：城市殡仪馆采用统一「孝服租赁」（孝袍、孝帽），并推行黑纱、白花、胸花。

## 三、仪节流程

1. **成服（戴孝）**：大殓后按亲疏分发孝布、孝帽、黑纱。
2. **佩戴**：孝子系麻绳或白带，孝帽覆顶；一般亲友佩黑纱、白花。
3. **行礼**：以佩戴孝服标识行礼次序与身份。
4. **脱孝（除服）**：以出殡、百日、周年、三年为节点；闽台以「合炉」为终。
5. **孝服处理**：部分地区将孝布、孝服焚化或保存留念。

## 四、地域与民族变体

- **华北**：孝袍、孝帽、系麻绳、白鞋「封孝鞋」。
- **闽台**：麻衫、苎衫、白衫三级，配「孝顺带」。
- **广东**：白布孝服、孝杖，孝布以宽窄别亲疏。
- **城市**：黑纱、白花、臂章；殡仪馆统一孝服租赁。
- **少数民族**：服丧标记多样（孝布、断发、禁饰、特定颜色衣物），与汉族孝服体系无继受关系，须分别记录。

## 五、器物与文书

- **孝服类**：孝袍、孝帽（孝箍）、孝带、孝鞋、孝袖。
- **标志类**：黑纱、白花、胸花、臂章。
- **相关文书**：讣告中的「服制排行」（如「不孝男某、期服孙某」），为五服在文书上的残留。
