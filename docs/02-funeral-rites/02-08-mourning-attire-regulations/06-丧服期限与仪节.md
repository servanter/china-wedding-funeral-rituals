# 丧服期限与仪节

## 一、释义

服丧期限以月计，是五服等差最直观的尺度：

| 服等 | 名义服期 | 实计（含变除） |
| --- | --- | --- |
| **斩衰** | 三年 | 二十七月（含禫） |
| **齐衰三年** | 三年 | 二十七月 |
| **齐衰杖期** | 期（一年） | 十三月 |
| **齐衰不杖期** | 期 | 十三月 |
| **齐衰三月** | 三月 | 三月 |
| **大功** | 九月（有七月者） | 九月 |
| **小功** | 五月 | 五月 |
| **缌麻** | 三月 | 三月 |

**「三年之丧」实为二十五／二十七月**：《礼记·三年问》释「三年」为「**加隆**」之数——「三年之丧，二十五月而毕」，因「哀痛未尽，思慕未忘」，故取「三年」之名为至极之服（「**三年者，天下之达丧也**」）。

## 二、历史源流

- **先秦**：《仪礼·丧服》定月数，《礼记·三年问》阐释三年之丧的礼义。
- **汉魏**：二十五月／二十七月之争（郑玄、王肃两说）。
- **唐代**：《开元礼》定二十七月制（含禫），并调整「父在为母」之服。
- **明代**：「父在为母」亦服斩衰三年（母服加隆）；「母为长子」改为齐衰不杖期。
- **清代**：《大清通礼》沿明制。
- **近代以来**：实际丧期简化为至出殡、百日、周年。

## 三、仪节流程

1. **成服**：大殓明日成服，服期自此起算（或自死日起算，各代有异）。
2. **既葬（三月）**：受服、卒哭。
3. **小祥（十三月）**：练冠练衣，行小祥祭。
4. **大祥（二十五月）**：除重服，行大祥祭。
5. **禫（二十七月）**：行禫祭，除服。
6. **吉祭**：禫后行吉祭，恢复正常生活。

## 四、地域与民族变体

- **汉族各地**：民间以「至出殡」「五七」「百日」「周年」「三年」为节点，与礼制大略对应。
- **少数民族**：服丧期长短与起算方式各异，多以宗教仪式或生产节令为准，须分别记录。

## 五、器物与文书

- **祭仪陈设**：小祥、大祥、禫之祭品、祝文。
- **计时术语**：期、九月、五月、三月、禫、小祥、大祥。
- **相关文书**：讣告「服制排行」、族谱丧礼记载。
