# 河南丧俗

## 一、释义

河南地处中原，丧俗被视为**保存古礼较多**的一类，以「**守灵、报庙、摔盆、做七**」为骨干。主要特色：

1. **「守灵」与「坐夜」**——孝子守灵，亲友坐夜陪灵。
2. **「报庙」**——赴土地庙（或城隍庙）报丧。
3. **「摔盆打幡」**——长子摔丧盆、打幡，出殡起灵之要节。
4. **「做七」严谨**——头七至七七，以「五七」为重。
5. **「送寒衣」**——农历十月初一（寒衣节）上坟送寒衣，为中原盛行习俗。

## 二、历史源流

- **先秦以降**：河南为《仪礼》《礼记》所记礼制的核心区域，民间丧俗有较深的礼制投影。
- **北宋**：汴京（开封）丧俗载于《东京梦华录》，「做七」「纸马」之俗可考。
- **明清**：方志「风俗」门详载丧仪。
- **当代**：火葬推行，殡仪馆治丧；农村仍存报庙、做七之俗。

## 三、仪节流程

1. **初丧**：净身、更衣、停尸正屋、设灵。
2. **报丧与报庙**：讣告亲友；孝子赴庙报丧、烧纸。
3. **入殓**：小殓、大殓、盖棺。
4. **守灵坐夜**：孝子守灵，亲友陪夜。
5. **做七**：每七日设祭，五七隆重。
6. **出殡**：摔盆、起棺、送葬、下葬。
7. **葬后**：圆坟、「五七」「百日」「周年」；寒衣节、清明、中元祭扫。

## 四、地域与民族变体

- **豫东（开封、商丘）**：近山东、安徽，报庙、送盘缠可见。
- **豫西（洛阳、三门峡）**：近陕西，重「做七」与道场。
- **豫南（南阳、信阳）**：近湖北，兼有楚俗影响（如坐夜唱孝歌）。
- **豫北（安阳、新乡）**：近河北，习俗相类。
- **各民族**：河南回族丧俗（郑州、开封、南阳）自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、丧盆、引魂幡、纸扎、锡箔、寒衣。
- **文书**：讣闻、丧榜、礼单。
- **节令物**：寒衣、纸钱、包袱。
