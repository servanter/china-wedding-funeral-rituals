# 海南丧俗

## 一、释义

海南汉族以**闽南移民后裔**为主（讲海南话，属闽方言），丧俗因而**近似闽南**而有热带岛屿特色。主要特色：

1. **「做旬／做七」**——以旬或七为祭期，兼请僧道做斋。
2. **「哭丧」**——亲属以哭丧歌致哀，女性哭丧尤为突出。
3. **「二次葬（拾骨）」**——土葬数年后拾骨入金瓮再葬，与闽台同系。
4. **「游村」出殡**——出殡队伍绕行村道，与乡邻告别。
5. **宗族祠堂**——琼北（海口、文昌）宗族与祠堂制度较发达。

## 二、历史源流

- **宋元明清**：闽南人陆续渡琼，带来闽南丧俗；琼北汉族聚落定型。
- **明清**：方志（琼州府志、各县志）「风俗」门详载丧仪。
- **近代**：南洋华侨（琼侨）影响，丧事有「侨汇办丧」现象。
- **当代**：火葬渐推，农村仍行做旬、拾骨之俗。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：大殓、棺内置随葬。
3. **做旬／做七**：每旬（或七日）设祭，请僧道诵经。
4. **出殡**：起棺、游村、送葬、下葬。
5. **葬后**：圆坟、拾骨再葬；「百日」「周年」；清明祭扫。

## 四、地域与民族变体

- **琼北（海口、文昌、澄迈）**：闽南色彩最浓，宗族祠堂发达。
- **琼东（琼海、万宁）**：习俗相类。
- **琼南（三亚、陵水）**：兼有本土与黎族影响痕迹。
- **琼西（儋州、东方）**：方言与习俗较复杂，有「儋州话」民系。
- **各民族**：黎族、苗族（海南苗族）丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、金瓮（拾骨用）、孝服、纸扎、纸钱、法器。
- **文书**：讣告、谢帖、礼单、族谱。
- **宗族物**：祠堂、祖坟。
