# 青海汉族丧俗

## 一、释义

青海汉族集中于**河湟地区（西宁、海东）**，多为明代江南、江淮移民后裔，其丧俗保存明代原籍遗风，又受藏、回、土、撒拉等族影响。主要特色：

1. **「做七」「做道场」**——做七严谨，兼请道士行法事。
2. **「唱孝歌」「念经」**——守灵唱孝歌，兼有佛教诵经（受藏传佛教影响）。
3. **「土葬为主」**——河湟谷地以土葬为常，坟茔依山。
4. **「社火与丧仪并行」**——河湟「社火」民俗与丧礼同属村落公共活动。
5. **多民族杂居**——与回、藏、土、撒拉族长期杂居，习俗互有渗透。

## 二、历史源流

- **明代**：洪武年间移民实边（江南、江淮军民入青），带来原籍丧俗与「社火」传统。
- **明清**：方志（西宁府志、各县志）「风俗」门载丧仪。
- **近代**：交通不便，旧俗保存较多。
- **当代**：火葬渐推，农村保留做七、周年之祭。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **守灵唱孝歌**：亲友守夜、唱孝歌。
4. **做七／做道场**：每七日设祭，请道士或僧人诵经。
5. **出殡**：起棺、送葬、下葬。
6. **葬后**：圆坟、「百日」「周年」；清明、中元祭扫。

## 四、地域与民族变体

- **西宁、海东（河湟）**：汉族集中，明代移民习俗明显。
- **湟中、大通**：与藏族村落相邻，兼有藏俗影响。
- **海西、海南**：汉族人口较少，多与蒙古、藏族杂居。
- **各民族**：藏族（天葬、塔葬等）、回族（速葬）、土族、撒拉族丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、纸扎、纸钱、法器、经卷。
- **文书**：讣告、谢帖、礼单、族谱。
