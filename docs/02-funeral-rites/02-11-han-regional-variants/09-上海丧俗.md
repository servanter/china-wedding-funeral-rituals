# 上海丧俗

## 一、释义

上海丧俗由**本地（松江、嘉定、浦东）习俗**与**移民（宁波、苏北、广东等）习俗**叠合而成，近代又受都市殡仪制度塑造，形成「**海派丧俗**」。主要特色：

1. **「大殓」与「做七」**——大殓为要节；「做七」完整（头七至七七），以「五七」为重。
2. **「豆腐饭」**——丧宴以豆腐为主菜，故称「吃豆腐饭」。
3. **僧道法事与「宣卷」**——请僧道诵经，郊县有唱「宣卷」之俗。
4. **近代殡仪**——会馆、殡仪馆、公墓制度最早在此成形（如万国公墓）。
5. **「落葬」「周年」**——骨灰安放公墓后，清明、冬至、忌日祭扫。

## 二、历史源流

- **明清**：上海县与松江府习俗载于方志；会馆（如宁波会馆）承办同乡丧事。
- **近代开埠后**：租界殡仪制度、公墓、火葬渐次引入；报刊讣告、追悼会通行。
- **当代**：火葬与殡仪馆体系全国领先；习俗趋于简办，「做七」多在殡仪馆或家中简化举行。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵。
2. **报丧**：讣告（旧用白帖）。
3. **大殓**：入棺（或入卫生棺），亲属瞻仰。
4. **做七**：头七、五七、七七设祭诵经。
5. **出殡（发引）**：昔日抬棺至墓地，今以灵车送殡仪馆。
6. **火化与落葬**：骨灰盒安放或落葬公墓。
7. **葬后**：清明、冬至、忌日祭扫；「百日」「周年」设祭。

## 四、地域与民族变体

- **市区**：海派丧俗，仪节简省，殡仪馆治丧为主。
- **浦东、松江、嘉定**：本地习俗保留较多，「做七」「宣卷」可见。
- **郊县（青浦、金山）**：多依村落习俗，兼有苏州、嘉兴影响。
- **各民族**：上海回族（清真葬礼）及其他民族丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木（旧）、骨灰盒、孝服（或黑纱白花）、纸扎、锡箔。
- **文书**：讣告、哀启、谢帖、礼单。
- **行业物**：会馆义庄、殡仪馆（近代新式机构）。
