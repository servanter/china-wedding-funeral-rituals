# 湖北丧俗

## 一、释义

湖北丧俗兼有**中原古礼与楚地巫风**，最鲜明的特点是**守夜唱丧歌（「跳丧」「坐丧」）**。主要特色：

1. **「坐夜」与「唱孝歌」**——守灵之夜亲友陪坐、击鼓唱孝歌，鄂东、鄂中盛行。
2. **「打丧鼓」**——以鼓伴唱，唱亡者生平与孝道故事。
3. **「做七」与「做道场」**——做七严谨，兼请道士做道场。
4. **「出殡上山」**——下葬称「上山」，反映丘陵山区葬俗。
5. **「灵屋」纸扎**——焚化纸扎灵屋、纸人纸马。

## 二、历史源流

- **先秦**：楚地巫风与《楚辞·招魂》的招魂传统影响深远。
- **唐宋**：丧歌、鼓乐之俗见于文献；《荆楚岁时记》记荆楚风俗。
- **明清**：方志「风俗」门详载「坐夜」「唱孝歌」等俗。
- **当代**：火葬推行，殡仪馆治丧；鄂西、鄂东农村仍有唱孝歌、打丧鼓之俗。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **坐夜唱孝歌**：亲友守夜，击鼓唱孝歌。
4. **做七／做道场**：每七日设祭，请道士行法事。
5. **出殡**：起棺、送葬、上山（下葬）。
6. **葬后**：圆坟、「五七」「百日」「周年」；清明、中元祭扫。

## 四、地域与民族变体

- **鄂东（黄冈、黄石）**：唱孝歌、坐夜最盛。
- **鄂中（武汉、孝感、荆州）**：兼有古礼与楚俗。
- **鄂西北（襄阳、十堰）**：近陕西、河南，重做七。
- **鄂西南（恩施、宜昌）**：土家族等民族聚居，汉族丧俗兼受「跳丧」影响。
- **各民族**：土家族、苗族等丧俗自成体系（如「撒叶儿嗬」跳丧），须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、丧鼓、纸扎（灵屋）、纸钱、法器。
- **文书**：讣告、谢帖、礼单。
- **歌本**：孝歌、丧歌抄本。
