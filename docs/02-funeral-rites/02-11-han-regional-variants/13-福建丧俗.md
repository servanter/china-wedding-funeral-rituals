# 福建丧俗

## 一、释义

福建丧俗是**汉族传统丧礼保存最完整**的地区之一，宗族、祠堂、僧道法事与「**做旬**」「**拾骨**」等特色并存。主要特色：

1. **「做旬」**——以「旬」（十日）为祭期单位（头旬至七旬），闽南称「做旬」，与北方「做七」相类而自有体系；「**六旬**」多由女儿主祭。
2. **「师公做功德」**——请道士（师公）行度亡法事，规模盛大。
3. **「哭路头」**——女儿闻丧归家，于路头哭迎，为闽南特有。
4. **「拾骨葬」**——初次土葬数年后「拾骨」（捡骨），装入金瓮择地再葬，为闽台通行的二次葬。
5. **「纸厝」与「烧库钱」**——纸扎屋宅精巧，焚化「库钱」（冥间财库）。
6. **祠堂与「进主」**——除服后神主入祠堂奉祀。

## 二、历史源流

- **唐宋**：中原移民入闽，带来礼制传统；闽南、福州民系在宋以后形成。
- **明清**：宗族制度高度发达，族谱、家礼抄本、祠堂制度完备；丧俗载于方志与族谱。
- **近代**：闽南人渡台，将「做旬」「拾骨」等俗带入台湾（见台湾条）。
- **当代**：火葬推行，但「做旬」「拾骨」之俗在闽南农村、金门及台湾仍有留存。

## 三、仪节流程

1. **初丧**：净身、更衣、搬铺（移尸于正厅）、「哭路头」。
2. **报丧**：讣告亲友（白帖）。
3. **入殓**：大殓、棺内置随葬。
4. **做旬／做功德**：每十日设祭，请师公做功德。
5. **出殡**：起棺、路祭、送葬；孝眷执孝杖。
6. **初葬与拾骨**：土葬数年后拾骨，装入金瓮。
7. **葬后**：除服「合炉」、神主「进主」；清明、忌日祭扫。

## 四、地域与民族变体

- **闽南（泉州、厦门、漳州）**：「做旬」「拾骨」「纸厝」最典型，宗族祠堂发达。
- **福州（闽东）**：礼数古雅，「做十旬」之俗；「拗九节」与孝亲习俗相关。
- **莆仙**：风俗独特，有「做七」「谢恩」等仪。
- **闽北、闽西（客家）**：闽西客家行二次葬，宗族色彩亦浓。
- **各民族**：福建畲族丧俗自成体系（如「做功德」「功德歌」），须分别记录。

## 五、器物与文书

- **器物**：棺木、金瓮（拾骨用）、孝服（麻衫、苎衫、白衫）、孝杖、纸厝、库钱、冥币。
- **文书**：讣告（白帖）、谢帖、礼单、族谱家礼抄本、进主文书。
- **宗族物**：祠堂、神主、族规。
