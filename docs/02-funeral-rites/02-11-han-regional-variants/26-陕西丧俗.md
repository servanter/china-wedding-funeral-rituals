# 陕西丧俗

## 一、释义

陕西是**周秦汉唐礼制故地**，关中的丧俗被视为**古礼遗存较多**的一类，陕北、陕南则各承其邻。主要特色：

1. **「守灵坐草」**——孝子于灵旁「坐草」（坐卧于草荐），示哀痛劳苦。
2. **「报庙」「送盘缠」**——赴土地庙（或城隍庙）报丧，出殡前夜送盘缠。
3. **「做七」与「过周年」**——做七严谨，「五七」「百日」「周年」设祭。
4. **「摔盆打幡」**——出殡起灵之要节，长子主之。
5. **「看地」与坟茔**——请地理先生择地；关中坟茔多成族葬之形（祖坟排列）。

## 二、历史源流

- **周秦汉唐**：关中为礼制中心，《仪礼》《礼记》所载之礼在此有较深投影。
- **明清**：方志（陕西通志、各府州县志）「风俗」门详载丧仪。
- **近代**：关中大旱、战乱使部分习俗从简。
- **当代**：火葬推行，殡仪馆治丧；农村仍存报庙、做七、周年之祭。

## 三、仪节流程

1. **初丧**：净身、更衣、停尸、设灵；孝子「坐草」。
2. **报丧报庙**：讣告亲友，赴庙报丧。
3. **入殓**：小殓、大殓、盖棺。
4. **做七**：每七日设祭，五七隆重。
5. **送盘缠**：焚化纸扎财物。
6. **出殡**：摔盆、起棺、送葬、下葬。
7. **葬后**：圆坟、「百日」「周年」；清明、十月一祭扫。

## 四、地域与民族变体

- **关中（西安、咸阳、宝鸡）**：古礼保存较多，讲究「坐草」「三日圆坟」。
- **陕北（榆林、延安）**：窑居环境，习俗质朴，兼有「转九曲」等地方活动。
- **陕南（汉中、安康、商洛）**：近川楚，兼有四川、湖北习俗影响。
- **各民族**：陕西回族丧俗（西安、安康等地）自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、丧盆、引魂幡、纸扎、草荐（坐草用）。
- **文书**：讣闻、丧榜、礼单、族谱。
- **坟茔物**：石碑、墓表、族葬坟地。
