# 宁夏丧俗

## 一、释义

宁夏汉族主要分布于**北部引黄灌区（银川、吴忠、中卫）与南部山区（固原）**，其丧俗近甘肃、陕西，并因与回族长期杂居而有交融痕迹。主要特色：

1. **「做七」「做道场」**——做七严谨，兼请道士行法事。
2. **「守灵唱孝歌」**——守夜唱孝歌。
3. **「土葬为主」**——灌区与山区均以土葬为常。
4. **回汉风俗互见**——汉族家庭在饮食、待客礼仪上受回族影响（如忌猪肉菜品不出席，视村落而异）。
5. **「送寒衣」「清明祭扫」**——节令祭祀通行。

## 二、历史源流

- **明代**：宁夏为九边重镇，军屯移民（江淮、陕西籍）带来丧俗。
- **清代**：方志（宁夏府志、各县志）「风俗」门载丧仪。
- **近代**：移民与商业交往使习俗趋同于甘陕。
- **当代**：火葬渐推，农村保留做七、周年之祭。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **守灵唱孝歌**：亲友守夜。
4. **做七／做道场**：每七日设祭；请道士行法事。
5. **出殡**：起棺、送葬、下葬。
6. **葬后**：圆坟、「百日」「周年」；清明、中元、十月一祭扫。

## 四、地域与民族变体

- **北部灌区（银川、吴忠、中卫）**：习俗近甘肃、陕西，仪式适中。
- **南部山区（固原、西吉、海原）**：近甘肃陇东，习俗质朴。
- **各民族**：宁夏回族丧俗（速葬、清水洗、白布裹、不用棺）自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、纸扎、纸钱、寒衣、法器。
- **文书**：讣告、谢帖、礼单、族谱。
