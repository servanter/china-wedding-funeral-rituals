# 辽宁丧俗

## 一、释义

辽宁汉族多为**「闯关东」移民后裔**（以山东、河北籍为主），丧俗因而承袭**山东、河北型**，并在东北环境中定型，最显著的标志是「**报庙·送浆水**」。主要特色：

1. **「报庙」「送浆水」**——亡故后到土地庙报丧，一日三次「送浆水」（送水饭至庙前），为东北丧俗的典型标志。
2. **「烧大纸」**——出殡前夜或特定之日集中焚化大量纸扎、纸钱。
3. **「摔盆」**——长子摔丧盆，承继主丧之权。
4. **停灵三日**——通例三日或五日、七日，视季节与家力。

## 二、历史源流

- **清**：封禁渐弛，鲁冀移民涌入，带来原籍丧俗。
- **民国**：「闯关东」高峰，东北汉族社会定型，丧俗成俗。
- **当代**：火葬普及，殡仪馆集中治丧；农村「报庙」「送浆水」遗俗仍有留存。

## 三、仪节流程

1. **初丧**：更衣、停尸、设灵；孝子赴土地庙「报庙」。
2. **送浆水**：一日三次（或早晚两次）送水饭至庙前。
3. **入殓**：大殓、盖棺。
4. **守灵受吊**：孝子跪灵，亲友吊唁。
5. **烧大纸**：焚化纸扎车马、包袱。
6. **出殡**：摔盆、起棺、送葬、下葬。
7. **葬后**：圆坟、「五七」「百日」「周年」。

## 四、地域与民族变体

- **辽南（大连、营口）**：近山东，习俗与胶东相类。
- **辽西（锦州、朝阳）**：近河北，兼有「送盘缠」之俗。
- **辽北与辽东山区**：村落习俗，仪式从简。
- **各民族**：辽宁满族、蒙古族、朝鲜族、回族丧俗各有体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、丧盆、引魂幡、纸扎、浆水桶。
- **文书**：讣闻、丧榜、礼单。
- **地方特点**：土地庙（多已不存，以路口、庙址代之）。
