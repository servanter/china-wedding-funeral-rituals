# 湖南丧俗

## 一、释义

湖南丧俗以**法事隆重、丧歌盛行**著称，湘东北与湘西各有面貌。主要特色：

1. **「做道场」**——请道士行度亡法事，长沙、湘潭一带尤盛。
2. **「唱夜歌」**——守夜唱夜歌（孝歌），以长沙、益阳等地著名。
3. **「做七」与「拜忏」**——做七严谨，兼请僧尼拜忏。
4. **「烧灵屋」**——焚化纸扎灵屋、纸人纸马。
5. **「上山」**——下葬俗称「上山」；湘西山区有「绕棺」之俗。

## 二、历史源流

- **先秦**：楚地巫风与招魂传统（《楚辞·招魂》）影响深远。
- **宋明**：《家礼》与道教仪式并行；方志载「夜歌」「道场」之俗。
- **清代**：方志「风俗」门详载丧仪。
- **当代**：火葬推行，殡仪馆治丧；长沙、益阳等地夜歌之俗仍有留存（部分进入非遗名录）。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **唱夜歌**：守夜唱夜歌、击鼓伴唱。
4. **做道场**：请道士行法事（三五日不等）。
5. **出殡**：起棺、送葬、上山。
6. **葬后**：圆坟、「五七」「百日」「周年」；清明、中元祭扫。

## 四、地域与民族变体

- **湘中北（长沙、益阳、湘潭）**：夜歌、道场最盛。
- **湘南（衡阳、郴州）**：近广东、江西，兼有客家色彩。
- **湘西（湘西州、怀化）**：土家、苗、侗族聚居，汉族丧俗受「跳丧」「绕棺」影响。
- **湘东（株洲、醴陵）**：近江西，习俗相类。
- **各民族**：土家族、苗族、侗族、瑶族丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、灵屋（纸扎）、纸钱、法器、丧鼓。
- **文书**：讣告、谢帖、礼单。
- **歌本**：夜歌、孝歌抄本。
