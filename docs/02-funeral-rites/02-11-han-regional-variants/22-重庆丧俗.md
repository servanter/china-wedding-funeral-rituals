# 重庆丧俗

## 一、释义

重庆丧俗属**巴渝型**，以**守夜唱孝歌、法事隆重**为特点，山地环境也塑造了「**抬棺爬坡**」等仪节形态。主要特色：

1. **「坐夜」「打丧火」**——守灵之夜亲友陪坐、击鼓唱孝歌，川渝称「坐夜」。
2. **「唱孝歌」**——以歌代哭，唱亡者生平与孝道。
3. **「做道场」**——请道士行度亡法事，三五日不等。
4. **「做七」**——头七至七七，以「五七」为重。
5. **山城特色**——出殡「爬坡上坎」，抬棺路线多循山径；「看地」多为坡地。

## 二、历史源流

- **先秦**：巴地巫风与《楚辞·招魂》的招魂传统相互影响。
- **宋明**：《家礼》与道教仪式并行；方志载孝歌、道场之俗。
- **清代**：「湖广填四川」移民带来湖北、湖南、江西丧俗，与本土习俗融合。
- **当代**：火葬推行，殡仪馆治丧；农村仍存坐夜、唱孝歌之俗。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **坐夜唱孝歌**：亲友守夜，击鼓唱孝歌。
4. **做道场／做七**：请道士行法事，每七日设祭。
5. **出殡**：起棺、送葬、上山。
6. **葬后**：圆坟、「五七」「百日」「周年」；清明、中元祭扫。

## 四、地域与民族变体

- **主城与近郊**：城居丧俗趋简，殡仪馆治丧为主。
- **渝西（江津、永川）**：近川南，习俗相类。
- **渝东北（万州、奉节）**：近湖北，兼有楚俗影响。
- **渝东南（黔江、秀山）**：土家、苗族聚居，汉族丧俗受「跳丧」「绕棺」影响。
- **各民族**：土家族、苗族丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、丧鼓、纸扎（灵屋）、纸钱、法器。
- **文书**：讣告、谢帖、礼单。
- **歌本**：孝歌抄本。
