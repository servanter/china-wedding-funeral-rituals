# 四川丧俗

## 一、释义

四川丧俗以**守夜唱孝歌、法事铺张、丧宴隆重**为特点，川西坝子与川东山区略有差别。主要特色：

1. **「坐夜（打丧火）」**——守灵之夜亲友聚集，击鼓唱孝歌、说唱助哀。
2. **「做道场」**——请道士行度亡法事，三日、五日、七日不等。
3. **「做七」与「回煞」**——做七严谨；旧有「回煞」（亡魂返家）之忌。
4. **「丧宴（坝坝宴）」**——丧事办席，亲友乡邻齐集，规模可观。
5. **「上山」与「看地」**——下葬称「上山」，多请地理先生择地。

## 二、历史源流

- **先秦**：巴蜀巫风与招魂传统。
- **明清**：「湖广填四川」移民将湖北、湖南、江西、广东丧俗带入，与本土融合，形成「川派丧俗」。
- **清代**：方志「风俗」门详载孝歌、道场、丧宴之俗。
- **当代**：火葬推行，殡仪馆治丧；农村仍存坐夜、做七之俗。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **坐夜唱孝歌**：亲友守夜、击鼓唱孝歌。
4. **做道场／做七**：请道士行法事；每七日设祭。
5. **出殡**：起棺、送葬、上山。
6. **葬后**：圆坟、「五七」「百日」「周年」；清明、中元祭扫。

## 四、地域与民族变体

- **川西坝子（成都、德阳、眉山）**：礼数较规整，法事与丧宴并重。
- **川东（达州、广安）**：近重庆，习俗相类。
- **川南（宜宾、泸州、自贡）**：兼有滇黔影响。
- **川北（绵阳、广元）**：兼有陕甘影响。
- **各民族**：羌族、藏族、彝族、苗族等丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、丧鼓、纸扎（灵屋）、纸钱、法器。
- **文书**：讣告、谢帖、礼单。
- **歌本**：孝歌抄本。
