# 河北丧俗

## 一、释义

河北（冀）丧俗属**华北型丧俗**，以「**停灵三日、入土为安**」为基本框架，礼数朴实而禁忌绵密。主要特色：

1. **「报庙」与「送盘缠」**——死后到土地庙「报庙」（或称「报丧」），出殡前夜烧「盘缠」（纸扎财物）。
2. **「摔盆打幡」**——长子摔丧盆、打引魂幡，为继承与主丧身份的象征。
3. **孝服讲轻重**——白衣白帽、腰系麻绳；亲属依亲疏分发孝布。
4. **「圆坟」**——葬后三日圆坟，是继下葬之后第一个重要节点。

## 二、历史源流

- **明**：河北为直隶，丧礼仪注多依《大明会典》与《家礼》。
- **清**：直隶民俗载于各府州县志「风俗」门；纸扎、杠房行业兴盛。
- **近代**：移民闯关东将此型丧俗带至东北（见辽宁、吉林、黑龙江条）。
- **当代**：推行火葬，平原地区土葬已禁，仪节简化为遗体告别、骨灰安放。

## 三、仪节流程

1. **初丧**：穿寿衣、停尸、设灵。
2. **报庙**：孝子赴土地庙（或十字路口）报丧、烧纸。
3. **入殓**：大殓入棺、盖棺。
4. **守灵与开吊**：孝子守灵、跪棚受吊。
5. **送盘缠**：出殡前夜焚化纸扎车马、财物。
6. **出殡**：摔盆、起棺、送葬、下葬。
7. **葬后**：圆坟、「五七」「百日」「周年」；「寒衣节」送寒衣。

## 四、地域与民族变体

- **冀中（保定、石家庄）**：礼数较繁，「报庙」「送盘缠」齐备。
- **冀南（邯郸、邢台）**：近河南，重「做七」。
- **冀东（唐山、秦皇岛）**：近东北，有「送浆水」等俗。
- **坝上（张家口、承德）**：近内蒙古，习俗从简，兼有蒙汉交融痕迹。
- **各民族**：河北回、满、蒙古等族丧俗自成一系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、丧盆、引魂幡、纸扎（盘缠）、纸钱。
- **文书**：讣闻、丧榜、礼单、孝服分单。
- **节令祭祀**：清明、中元、寒衣节之祭扫文书。
