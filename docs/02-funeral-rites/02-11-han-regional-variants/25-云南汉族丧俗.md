# 云南汉族丧俗

## 一、释义

云南汉族多为**明初屯垦移民（「调北征南」「洪武移民」）后裔**，丧俗保存明代江南、江西遗风，又与云南多民族环境交融。主要特色：

1. **「做七」「做道场」**——做七严谨，兼请道士行度亡法事。
2. **「绕棺」与「唱孝歌」**——守灵绕棺、唱孝歌，滇中一带盛行。
3. **「洞经会」**——部分地区请「洞经会」奏乐诵经（兼具儒道色彩），为云南特有。
4. **「送丧队伍」**——出殡队伍有仪仗、吹打，规模可观。
5. **「山向」与择地**——请地理先生择地，坟茔多依山而建。

## 二、历史源流

- **明初**：大军入滇并屯垦，江南、江西、湖广移民定居，带来原籍丧俗。
- **明清**：方志（云南通志、各府州县志）详载丧仪；洞经会等民间乐社在丧仪中承担奏乐。
- **近代**：滇越铁路与商路带来的文化影响。
- **当代**：火葬推行，殡仪馆治丧；农村仍存做七、绕棺之俗。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **守灵绕棺／唱孝歌**：亲友守夜，绕棺而歌。
4. **做七／做道场**：每七日设祭；请道士、洞经会行法事。
5. **出殡**：起棺、送葬、下葬。
6. **葬后**：圆坟、「百日」「周年」；清明、中元祭扫。

## 四、地域与民族变体

- **滇中（昆明、玉溪）**：洞经会、绕棺之俗可见。
- **滇东北（昭通、曲靖）**：近贵州、四川，习俗相类。
- **滇西（大理、保山）**：多民族杂居，汉族丧俗受白、彝、回族影响。
- **滇南（红河、文山）**：兼有壮、苗、瑶族习俗影响。
- **各民族**：白、彝、哈尼、傣、苗、壮等族丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、纸扎、纸钱、法器、洞经乐器。
- **文书**：讣告、谢帖、礼单、族谱。
- **乐社物**：洞经会乐谱、经卷。
