# 香港澳门丧俗

## 一、释义

港澳居民以**广府人（讲粤语）** 为主体，丧俗承**广府传统**，又因近代城市化与中西交汇而形成「**都市型传统丧礼**」。主要特色：

1. **「守夜」与「大殓」**——在殡仪馆设灵堂守夜，翌日大殓、出殡。
2. **道教「破地狱」**——香港最具标志性的道教度亡仪式，道士以「破地狱」象征为亡者解脱冥途（已被列为非物质文化遗产）。
3. **「打斋」**——请僧尼或道士做斋、诵经度亡。
4. **「回魂夜」**——依推算亡魂返家之夜，家人备祭品、铺灰验迹。
5. **「解秽酒」**——出殡后设素宴款客，称「解秽酒」（类似其他地区的豆腐饭）。
6. **「帛金」与「吉仪」**——赙金称「帛金」（须单数），丧家回赠「吉仪」（含糖、利是）以化解。
7. **火葬普及**——骨灰龛位（公营、私营灵灰安置所）为安放主流。
8. **澳门中西并行**——天主教葬礼（弥撒、圣水、十字架）与中式丧礼并存，殡仪设施沿用旧式。

## 二、历史源流

- **明清**：香港、澳门属广州府、香山县，丧俗与广府一致。
- **开埠后**：港英、澳葡管治下引入西式殡葬制度（坟场、火葬场、殡仪馆）。
- **20 世纪**：殡仪馆（如香港殡仪馆、世界殡仪馆）成为治丧中心；道教仪式与殡仪服务结合。
- **当代**：火葬与骨灰龛位为主；传统仪式由专业「堂倌」（礼仪师）主持。

## 三、仪节流程

1. **初丧**：移至殓房（公众殓房），讣告亲友。
2. **设灵（守夜）**：殡仪馆设灵堂，亲友致祭；道教「破地狱」或佛教诵经。
3. **大殓**：入棺、亲属瞻仰、封棺。
4. **出殡**：辞灵、送殡至坟场或火葬场。
5. **火化与安放**：骨灰安放龛位或择地安葬。
6. **「解秽酒」**：出殡后设素宴；丧家回赠「吉仪」。
7. **葬后**：清明、重阳、忌日祭扫；「回魂夜」设祭。

## 四、地域与民族变体

- **香港市区**：殡仪馆—火葬场—骨灰龛位体系完整，仪式由礼仪师主持。
- **新界（元朗、大埔、沙田）**：原居民（围头、客家）保留宗族丧俗与土葬遗迹，有「太公分猪肉」等宗族祭祖活动。
- **离岛（长洲、南丫岛）**：岛屿习俗，仪式较简。
- **澳门**：中式与天主教葬礼并行，殡仪设施近广府。
- **各民族**：港澳另有南亚裔、菲律宾裔等族群丧俗，不属汉族体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服（白衣麻带）、金银纸、纸扎、破地狱法坛陈设、吉仪封包。
- **文书**：讣告（报刊讣闻常见）、谢帖、帛金封包、墓碑刻文。
- **设施**：殡仪馆、公众殓房、坟场、骨灰龛场（灵灰安置所）。
