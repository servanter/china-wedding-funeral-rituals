# 天津丧俗

## 一、释义

天津丧俗以**「出大殡」**著称——旧时富商、盐商云集，丧事竞相铺张，「**大殡**」（仪仗、纸扎、僧道、杠夫队伍庞大）为天津卫民俗的显著标签。主要特色：

1. **「大殡」仪仗**——纸扎「文官执事」「武官执事」、幡伞、锣鼓一应俱全。
2. **「接三」「送路」**——第三日接三、晚间「送路」（送纸扎至路口焚化）。
3. **「拦棺祭」**——出殡途中亲友设路祭拦截，孝子答礼。
4. **僧道法事**——「打醮」「放焰口」盛行，与码头文化中的尚武、尚气派相合。

## 二、历史源流

- **明清**：天津为漕运枢纽、盐业中心，商人云集，丧事竞奢，形成「卫派丧俗」。
- **清末民国**：租界与华界并存，中西丧俗交汇；报刊讣告、公祭形式出现。
- **当代**：火葬普及，殡仪馆集中治丧；「大殡」之俗消失，部分纸扎、路祭遗风在郊县可见。

## 三、仪节流程

1. **初丧**：移尸、沐浴、着寿衣、设灵。
2. **报丧**：讣告、贴门报。
3. **入殓**：大殓、棺内随葬。
4. **接三、送路**：第三日接三，夜间焚化纸扎车马。
5. **开吊**：设棚受吊，僧道诵经。
6. **出殡**：起杠、「拦棺祭」、送葬至墓地。
7. **葬后**：圆坟、「五七」「百日」「周年」。

## 四、地域与民族变体

- **市内六区与老城厢**：旧俗讲究，纸扎、执事最为繁复。
- **滨海（塘沽、汉沽）**：渔盐业者习俗，兼有海祭痕迹。
- **蓟州、宝坻等郊县**：近京畿农村习俗，从简。
- **各民族**：天津回族丧俗（速葬、清水洗、白布裹）与汉族不同，须分别记录。

## 五、器物与文书

- **器物**：纸扎执事、幡伞、棺罩、杠具、丧盆、孝服。
- **文书**：讣闻、丧榜、礼单、挽联挽幛。
- **行业物**：杠房、棚铺、冥衣铺旧业制品。
