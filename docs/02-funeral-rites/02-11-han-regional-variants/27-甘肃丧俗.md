# 甘肃丧俗

## 一、释义

甘肃地形狭长，汉族丧俗**东西差异**明显：陇东近陕西、陇南近四川、河西走廊兼有移民与绿洲特色。主要特色：

1. **「做七」「做道场」**——做七严谨，兼请道士行法事。
2. **「守灵唱孝歌」**——守夜唱孝歌，陇中、陇东可见。
3. **「土葬为主」**——传统以土葬为常；干旱地区坟茔形式质朴。
4. **「送寒衣」**——十月一送寒衣之俗通行。
5. **多民族文化影响**——与回、藏、东乡、保安、裕固等族杂居，习俗互有影响。

## 二、历史源流

- **汉唐**：河西走廊为丝绸之路孔道，汉唐礼俗与佛教仪轨交会。
- **明清**：方志（甘肃通志、各府州县志）「风俗」门载丧仪。
- **近代**：战乱与灾荒使丧仪趋简。
- **当代**：火葬渐推，农村保留做七、周年之祭。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **守灵唱孝歌**：亲友守夜。
4. **做七／做道场**：每七日设祭，请道士行法事。
5. **出殡**：起棺、送葬、下葬。
6. **葬后**：圆坟、「百日」「周年」；清明、中元、十月一祭扫。

## 四、地域与民族变体

- **陇东（庆阳、平凉）**：近陕西，习俗相类。
- **陇中（兰州、定西）**：河谷农业区习俗，仪式适中。
- **陇南（天水、陇南）**：近四川、陕西，兼有川陕色彩。
- **河西（武威、张掖、酒泉）**：绿洲农业与移民习俗，兼有敦煌民俗遗风。
- **各民族**：回、藏、东乡、保安、裕固、撒拉等族丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、纸扎、纸钱、寒衣、法器。
- **文书**：讣告、谢帖、礼单、族谱。
