# 黑龙江丧俗

## 一、释义

黑龙江汉族以**清末民初移民**为主（山东、河北、辽宁籍），丧俗为**东北型**，因气候严寒而别具特点。主要特色：

1. **报庙·送浆水**——与辽宁、吉林相类的核心仪节。
2. **冬季「打冻土」**——冻土掘穴须以柴火化冻，故有「烤地」之俗；亦因此忌讳冬季择葬。
3. **停灵期短**——因寒冷与居住条件，多三日出殡。
4. **「烧大纸」与「送盘缠」**——焚化纸扎、纸钱。
5. **垦区与林区特色**——国有农场、林场的职工丧俗偏向从简、集体化。

## 二、历史源流

- **清末放荒**：移民涌入（闯关东），带来原籍鲁冀丧俗。
- **民国**：中东铁路沿线工商业城镇兴起，城居丧俗趋简。
- **当代**：火葬全面推行；农垦、林区以殡仪馆治丧为主，旧俗遗存于偏远农村。

## 三、仪节流程

1. **初丧**：更衣、停尸、报庙。
2. **送浆水**：早晚送水饭至庙前。
3. **入殓**：大殓、盖棺。
4. **守灵受吊**：孝子跪灵。
5. **烧大纸**：焚化纸扎。
6. **出殡**：摔盆、起棺、送葬；冬季须先「烤地」掘穴。
7. **葬后**：圆坟、「五七」「百日」「周年」。

## 四、地域与民族变体

- **哈尔滨、齐齐哈尔**：城居丧俗近代化，仪式简省。
- **松嫩平原农垦区**：农场职工丧事集体化，旧俗较少。
- **大兴安岭、小兴安岭林区**：林区习俗，仪式从简。
- **各民族**：满族、朝鲜族、蒙古族、达斡尔族、鄂伦春族、赫哲族等丧俗各有体系，须分别记录。

## 五、器物与文书

- **器物**：棺木（或火化棺）、孝服、丧盆、纸扎、浆水桶。
- **地方特点**：冬季掘穴所用柴薪与工具（「烤地」）。
- **文书**：讣闻、丧榜、礼单。
