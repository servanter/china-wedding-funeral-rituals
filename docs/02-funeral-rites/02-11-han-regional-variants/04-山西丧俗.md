# 山西丧俗

## 一、释义

山西（晋）丧俗以**礼数古厚、仪节繁复**见长，晋商富户的「大丧」尤其讲排场。主要特色：

1. **停殡久**——富家停灵可至「七七」四十九日甚至更久，「殡仪」郑重。
2. **「点主」隆重**——请显者题主、点主，红笔点主之礼为晋中一带盛典。
3. **「送灯」「烧纸」**——出殡前后沿指定路线送灯、焚纸，夜行如队伍。
4. **鼓吹与戏剧**——丧事请鼓吹班，富家搭台唱戏（「丧戏」「祭戏」）。

## 二、历史源流

- **明清**：晋商称雄，晋中（太谷、祁县、平遥）富商以厚葬显家势，形成「晋中丧俗」的奢华形态。
- **礼制依据**：《家礼》与地方礼书（如乡约、族谱家规）。
- **近代**：晋商衰落，奢华之风渐敛；抗战后从简。
- **当代**：火葬推行，晋中、晋南民间仍有「五七」「周年」之祭，仪式简省。

## 三、仪节流程

1. **初丧**：移尸、沐浴、着寿衣、设灵。
2. **报丧**：讣告亲友，门首贴白纸。
3. **入殓**：小殓、大殓，棺内置随葬。
4. **停殡与开吊**：设灵棚、受吊；富家请礼生赞礼。
5. **点主**：请大宾题主、点主。
6. **出殡**：摔盆、起杠、送葬；「送灯」引路。
7. **葬后**：圆坟、「五七」「百日」「周年」，寒食清明上坟添土。

## 四、地域与民族变体

- **晋中（太原、晋中）**：旧时最为奢华，「点主」「停殡」讲究。
- **晋南（临汾、运城）**：礼数古厚，近关中风俗。
- **晋北（大同、忻州）**：近内蒙古与河北，习俗较为简省。
- **晋东南（长治、晋城）**：山地区域，多依村落惯例，兼有「赛社」遗风。
- **各民族**：山西回族丧俗独立成系，须分别记录。

## 五、器物与文书

- **器物**：棺木（讲究柏木、独板）、孝服、棺材罩、鼓吹乐器、纸扎。
- **文书**：讣闻、丧榜、礼单、族谱家礼抄本、点主文书。
- **其他**：冥币、锡箔、纸扎院落。
