# 内蒙古汉族丧俗

## 一、释义

内蒙古汉族多源于**清代「走西口」移民及其后裔**（晋陕为主），其丧俗因而带有明显的**晋陕底色**（报庙、送盘缠、摔盆、做七），又在草原生计与蒙汉杂居环境中趋于简省。主要特色：

1. **晋陕底色**——「报庙」「送盘缠」「摔盆」「点主」诸节与山西、陕西相类。
2. **从简务实**——地广人稀、游牧生计影响，丧期较短，仪式简省。
3. **蒙汉交融**——部分汉族家庭行祭时受蒙古族「献祭」「祭火」观念影响。
4. **冬季「打冻土」**——寒冷地区土葬时须烧柴化冻掘穴。

## 二、历史源流

- **清代**：口外放垦，晋陕移民「走西口」，在归化城（今呼和浩特）、包头、河套一带形成汉族聚落。
- **民国**：移民续增，村落礼俗随原籍州县而别（同一村内晋南、陕北风俗并存）。
- **当代**：火葬与殡仪馆制度普及；农村保留「五七」「周年」之祭。

## 三、仪节流程

1. **初丧**：着寿衣、停尸、设灵。
2. **报丧（报庙）**：孝子赴土地庙或路口报丧、烧纸。
3. **入殓**：大殓、盖棺。
4. **守灵开吊**：孝子守灵、受吊。
5. **出殡**：摔盆、起棺、送葬。
6. **下葬与葬后**：圆坟、「五七」「百日」「周年」。

## 四、地域与民族变体

- **河套与归绥（呼和浩特、包头）**：晋陕移民集中，晋俗最明显。
- **东部（赤峰、通辽）**：近辽宁、吉林，东北型丧俗色彩浓。
- **西部（阿拉善、鄂尔多斯）**：与宁夏、陕西相邻，兼有回汉杂居影响。
- **各民族**：蒙古族传统丧俗（野葬、火葬、石堆墓等）及回族丧俗均自成体系，不属汉族丧俗，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、丧盆、纸扎、纸钱。
- **文书**：讣闻、丧榜、礼单。
- **地方特点**：冬季「打冻土」所用柴薪、掘具。
