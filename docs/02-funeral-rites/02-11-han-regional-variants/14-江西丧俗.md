# 江西丧俗

## 一、释义

江西丧俗以**宗族祠堂与佛道法事并重**为特点，赣中、赣南、赣东北各有面貌。主要特色：

1. **「做七」与「做功德」**——做七严谨，兼请僧道行「做功德」「放焰口」。
2. **「哭丧歌」「孝歌」**——守灵时唱孝歌、哭丧歌，赣中、赣西尤盛。
3. **祠堂主丧**——宗族发达地区由祠堂、族长主持，族规约束丧仪。
4. **「烧纸扎」「包袱」**——出殡前后焚化纸扎与「包袱」（书写收件者的纸钱封包）。
5. **二次葬（部分地区）**——赣南客家地区有拾骨再葬之俗。

## 二、历史源流

- **宋明**：江西为理学重镇（朱熹、陆九渊），《家礼》影响深；宗族制度发达。
- **明清**：方志「风俗」门详载丧仪；赣南客家二次葬成俗。
- **近代**：战乱影响下丧事从简。
- **当代**：火葬推行，殡仪馆治丧；农村保留「做七」「五七」之祭。

## 三、仪节流程

1. **初丧**：净身、更衣、设灵、报丧。
2. **入殓**：小殓、大殓。
3. **守灵唱孝歌**：亲友守夜，唱孝歌致哀。
4. **做七／做功德**：每七日设祭，请僧道诵经。
5. **出殡**：起棺、路祭、送葬、下葬。
6. **葬后**：圆坟、「百日」「周年」；清明、中元祭扫；赣南「拾骨」再葬。

## 四、地域与民族变体

- **赣中（南昌、抚州）**：礼数适中，孝歌、做七并行。
- **赣东北（上饶、景德镇）**：近徽州与浙江，宗族色彩较浓。
- **赣南（赣州）**：客家地区，二次葬与宗族习俗明显。
- **赣西（宜春、萍乡）**：近湖南，兼有湘俗影响。
- **各民族**：江西畲族丧俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：棺木、孝服、纸扎、锡箔、包袱、孝歌本。
- **文书**：讣告、谢帖、礼单、族谱家礼抄本、包袱封包文字。
- **宗族物**：祠堂、族规。
