# 北京丧俗

## 一、释义

北京丧俗是**都城礼制传统与市井民俗相结合**的丧俗，因旗汉杂居、官民共处，仪节讲究「有谱有派」，旧京尤重「**礼数**」与「**排场**」。主要特色：

1. **「接三」「送三」**——死后第三日举行「接三」，晚间「送三」（送纸扎车马、烧「包袱」），为旧京最隆重的节点。
2. **杠房与棺罩**——出殡由专业「杠房」承办，杠夫多少（八杠、十六杠、三十二杠）标示身份。
3. **「喜丧」观念**——高龄寿终者丧事办得热闹，鼓吹、戏曲、说唱皆可。
4. **庙中停灵**——旧时多在寺庙（如嘉兴寺、贤良寺）停灵、做佛事。

## 二、历史源流

- **元明**：大都、北京为都城，丧礼依《大明会典》而行，兼收各地移民习俗。
- **清代**：旗汉丧俗交融，杠房、棚铺、冥衣铺（纸扎铺）成为专营行业，形成「京派丧俗」。
- **民国**：新旧并存，报刊讣告、公祭等新式丧仪兴起。
- **当代**：火葬普及，八宝山与各区殡仪馆承担主要殡仪功能；旧俗在郊区与老城区部分保留。

## 三、仪节流程

1. **初丧**：易箦（移尸）、属纩、沐浴、饭含、着寿衣。
2. **报丧**：讣告亲友；门首贴白纸（「丧榜」「门报」）。
3. **入殓**：小殓、大殓，棺内放随葬小件。
4. **接三与送三**：第三日接三，晚间送三，焚化纸扎车马、包袱。
5. **开吊受吊**：设灵棚，孝子跪棚受吊；富家请礼生唱礼。
6. **出殡（发引）**：摔盆、起杠、棺罩送葬，沿途撒纸钱。
7. **下葬与葬后**：落葬、圆坟；「五七」「百日」「周年」祭扫。

## 四、地域与民族变体

- **老城区（东西城）**：规矩多、讲排场，杠房、棚铺、冥衣铺旧业集中。
- **海淀、朝阳等近郊**：礼数较简，多依村落习惯。
- **远郊（门头沟、房山、密云）**：保留「送盘缠」「跑方」等旧俗。
- **旗人旧俗**：有「满礼」痕迹（如孝服形制、祭祀方式）。
- **各民族**：北京另有回族（清真葬礼）、满族、蒙古族等族丧俗，不属汉族丧俗体系，须分别记录。

## 五、器物与文书

- **器物**：棺罩、杠具、冥衣（纸扎）、包袱、丧盆、孝袍孝帽。
- **文书**：讣告（讣闻）、丧榜、礼单（登记赙赠）、挽联簿。
- **旧京行业物**：杠房杠具、棚铺席棚、冥衣铺纸活。
