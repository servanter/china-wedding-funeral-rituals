# 合葬与迁葬

## 一、释义

- **合葬**：将夫妇（或母子、家族成员）葬于同一墓穴或同一墓区。
- **祔葬**：附葬于祖墓之旁（「祔」意为「附」），是宗族葬制的一部分。
- **迁葬（改葬）**：将已葬的棺柩或骨殖迁往他处安葬。
- **二次葬（捡骨葬）**：初葬若干年后拾取骨殖、装入骨瓮（金斗瓮）再葬，是南方部分地区的特有制度。

## 二、历史源流

- 《礼记·檀弓》：「葬于北方北首，三代之达礼也。」并记合葬之礼：「卫人之祔也离之，鲁人之祔也合之，善夫！」——说明「合葬」（同穴）与「离葬」（同墓区而不同穴）在先秦已并存，孔子称赞鲁人的合葬。
- 《诗经·王风·大车》「死则同穴」是夫妻合葬的最早文学表达。
- 《仪礼·丧服》的服制中，「祔」有明确位置：新死者之主附于祖庙，与葬制的祔葬相应。
- 汉以后夫妻合葬成为通例。考古所见汉墓多为一穴双棺或并列双室。
- **二次葬（捡骨葬）**：在客家、广府及闽粤部分地区普遍，明清方志记载甚多，与「择吉地再葬」及「客家人迁徙频繁」的历史背景相关。
- 近代以来因城市公墓制度，合葬多表现为「同穴合葬」（骨灰合葬）或「同碑双穴」。

## 三、仪节流程

### 合葬

1. **留穴**：先葬者下葬时预留后葬者的穴位（「留穴」）。
2. **择日**：后葬者去世后择吉日。
3. **开穴**：小心开挖先葬者之墓（旧俗有「开棺见骨」之礼）。
4. **安葬**：将新棺（或骨灰）放入留穴，方位与先葬者相对（多为「男左女右」或「男先女后」）。
5. **合封**：填土、封土成一个坟头。
6. **立碑（或改碑）**：墓碑上补刻后葬者姓名，或另立新碑。
7. **祭奠**：在墓前设奠，两魂「同居」之礼成。

### 迁葬（改葬）

1. **请告**：先告于祖庙（或坟前），陈明迁葬之由（择新地、修工程、族人合议等）。
2. **择日**：择吉日破土开棺。
3. **开棺（捡骨）**：开棺拾取骨殖（或在世者遗骨），以白酒洗骨、擦拭、晾干。
4. **装瓮**：骨殖按「屈肢蹲坐」或「直肢」方式装入骨瓮（金斗瓮），头骨置最上。
5. **择新地**：另择吉地（参见「墓地选择与阴宅堪舆」条）。
6. **再葬**：依下葬之礼葬入新穴，封土、立碑。
7. **祭奠与谢土**：设奠、谢土、烧纸。
8. **服制**：《仪礼·丧服》规定「改葬」的服制为「缌」（三月），因「已葬者，服已尽」，唯重缌以尽哀。

### 二次葬（捡骨葬）

1. **初葬**：先以棺木土葬（「初葬」「凶葬」）。
2. **等待**：三至七年（视各地而定），待尸体腐化。
3. **捡骨**：择吉日开棺，拾取骨殖，以酒清洗、擦拭。
4. **装瓮**：骨殖装入「金斗瓮」（陶瓮），依固定次序安放。
5. **再葬**：另择吉地（「吉葬」「金葬」），葬入骨瓮。
6. **祭奠**：设奠、立碑、焚纸。

## 四、地域与民族变体

- **华北**：夫妻合葬为通例，「留穴」之俗普遍；二次葬罕见。
- **江南**：讲究「同穴合葬」，墓碑双刻。
- **客家**：二次葬（捡骨葬）为核心制度，「金斗瓮」是最具代表性的器物。
- **广府及闽粤部分地区**：同样盛行二次葬，讲究「先凶后吉」。
- **少数民族**：部分民族有多人合葬（家族墓）之制；藏族天葬后不存骨殖，无合葬；穆斯林葬制中夫妇虽邻近埋葬，但各占一穴（不设合穴）。**合葬的具体形态须依各族葬制而定。**

## 五、器物与文书

- **骨瓮（金斗瓮）**：二次葬的核心器物。
- **骨灰盒**：当代火化后的合葬载体。
- **墓碑（双刻）**：合葬的标识。
- **酒、白布、刷子**：捡骨用具。
- **迁葬告文／改葬告文**：迁葬时的告神文书。
- **墓地契书、族谱墓图**：记录葬位的文书。
