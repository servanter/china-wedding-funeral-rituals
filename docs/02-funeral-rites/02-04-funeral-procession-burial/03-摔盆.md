# 摔盆

## 一、释义

摔盆（摔丧盆、摔瓦盆、摔老盆），是出殡起灵时，由丧主（或承重之孙）将灵前烧纸用的瓦盆举过头顶摔碎于地之俗。

其表层功能是「送葬的信号」——盆一碎，队伍即起行；其深层功能是**继承权的公开宣示**：在华北等地，摔盆者是「摔盆打幡」之人，被公认为遗产的主要继承人。故旧时无子者常「过继」子侄以「摔盆」，摔盆与继承、立嗣直接挂钩。

## 二、历史源流

- 摔盆在礼经中无载，属民俗层面的仪式。其源头可能有三：
  1. 与「毁器」的古老丧俗有关：以破坏器物表达「生者与死者永绝」；
  2. 与火盆的使用有关：灵前烧纸，纸灰盛于瓦盆，出殡时盆不再用，摔碎以「送走」；
  3. 与继承制度有关：摔盆作为「承嗣」的公开行为，被宗族所承认。
- 明清方志与笔记中「摔盆」记载甚多，与「摔盆者分家产」的说法并存。
- 各地对摔盆者身份的认定有明确规定：有子者由长子摔；无子而有嗣子者由嗣子摔；无嗣子者由侄辈之义子摔（并常因此引发纠纷）。
- 在部分地区，「摔盆」的碎瓦要在出殡后扫起，埋于特定位置，不得任人践踏。
- 当代城市火化制度下，摔盆作为仪式环节仍有保留（尤其在北方），但已不再与继承直接绑定。

## 三、仪节流程

1. **备盆**：灵前备一瓦盆（「丧盆」），守灵期间烧纸用，盆内积纸灰。
2. **择人**：确定摔盆者（长子／承重孙／嗣子）。
3. **置盆**：启灵前，将盆置于丧主身前（或门外指定位置），并盛满纸灰。
4. **跪祷**：摔盆者跪于盆前，向灵柩叩拜，念祈祷语。
5. **摔盆**：将盆举过头顶（或平举），用力摔于地上，须一次摔碎（若未碎，忌再摔，由人代碎，否则为不吉）。
6. **起灵**：盆碎即起灵，队伍出发，哭声大作。
7. **扫碎**：事后扫起碎瓦，埋于门外或坟旁。
8. **后续地位确认**：在旧制中，摔盆者即被承认为「承嗣人」，于族中载明。

## 四、地域与民族变体

- **华北**：摔盆之俗最盛，「摔老盆」是丧礼中最关键的动作之一，与「打幡」并称「摔盆打幡」。
- **东北**：多由长子摔盆，讲究「一摔到底」。
- **江南**：部分地区不摔盆，而摔「碗」「罐」或改以「焚盆」（连盆带纸灰一起焚化）。
- **闽粤**：多行「烧纸盆」，少摔盆之俗。
- **当代**：北方农村与部分城市葬礼仍保留，成为仪式符号；其与继承权的法律关联已不再成立（《民法典》继承编以法定继承与遗嘱为准）。
- **少数民族**：摔盆是汉族（尤其北方）的习俗，其他民族多无此俗。彝族的「献牲分肉」、苗族的「分牛」，形式上虽也与继承相关，但属民族习惯法体系，与摔盆不是同一种机制。

## 五、器物与文书

- **丧盆（瓦盆）**：核心器物，多为粗陶瓦盆。
- **纸灰**：盆中所盛。
- **孝杖、灵幡**：与摔盆配合之物（「摔盆打幡」）。
- **族谱、分家文书**：旧时与摔盆连带使用的文书（今已无此法律效力）。
