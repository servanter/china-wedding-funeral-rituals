# 引路幡、招魂幡与撒纸钱

## 一、释义

- **铭旌**：书亡者姓名、官爵、享年的旗幡，礼经所定，为送葬队伍前导。
- **引路幡（引魂幡、招魂幡）**：引导亡魂前往墓地的旗幡，由长孙或指定者举持。其形制多为长条白纸（或白布）剪成，上写「引魂幡」等字。
- **纸钱（买路钱）**：出殡沿途撒放的纸片，象征为亡魂「买路」通行。分为两类：
  - **撒纸钱**：沿路抛撒，不焚烧；
  - **焚纸钱**：在路口、桥头焚烧。
- 另有**打钱**（以纸凿孔做出的钱形纸），是纸钱的最古形制。

## 二、历史源流

- **铭旌**：《仪礼·既夕礼》明文所载，为送葬前导之旗，书「某氏某之柩」。
- **纸钱**：起源甚早。唐代已有「纸钱」之用（《封氏闻见记》记「纸钱」为「魏晋以来始有其事」）；「打钱」以纸凿孔成钱形，是唐宋常见形态。
- **买路钱**：其观念与「路途有鬼神把守」的民间信仰相关。撒纸钱既是「买路」，也是「打发沿途野鬼」。
- **引魂幡**：是「复礼」（招魂）与「铭旌」的结合体，唐宋以后逐渐固定为「引魂幡」形态。
- 明清方志记「撒纸钱」「举幡前导」之俗甚多。当代农村仍行撒纸钱，城市多以纸钱焚化替代。
- **观念说明**：纸钱、买路钱等属民间信仰的物化形式，本库作民俗记录，不作提倡。

## 三、仪节流程

1. **备幡**：出殡前备引魂幡，写明亡者姓名，由长孙（或指定者）举持。
2. **备钱**：备纸钱若干（撒用与焚用两类）。
3. **前导**：队伍出发，引魂幡在队伍前部（铭旌之后或之前，各地不同）。
4. **沿途撒钱**：专人沿路抛撒纸钱，逢以下地点必撒：
   - **路口**（岔路处，防亡魂迷路）；
   - **桥头**（过桥须「买路」）；
   - **庙、祠、牌坊前**；
   - **墓地入口**。
5. **焚钱**：在路口、桥头另设小堆焚烧纸钱。
6. **落葬后**：在墓前焚化纸钱与纸扎。
7. **回程**：返程时不再撒纸钱（部分地区反之，须依地方记录）。

## 四、地域与民族变体

- **华北**：撒纸钱多用「打钱」形（圆孔纸片），讲究「一路撒到坟头」。
- **江南**：撒纸钱与冥币并用；在桥头必焚。
- **闽台**：纸钱分「银纸」（给亡者）、「金纸」（给神明）、「库钱」（还阴债）等多种，用途严格区分，是最为精细的纸钱体系。
- **广东**：纸钱种类繁多，「金银衣纸」一整套，另有「溪钱」（撒路用）。
- **少数民族**：纸钱是汉族的产物。藏族以「风马旗」（经幡）与酥油灯代替；傣族以赕佛、献花代替；穆斯林民族不用纸钱（教法视为无益）。**纸钱体系不适用于其他民族。**

## 五、器物与文书

- **铭旌**：书亡者姓名、官爵、享年的旗幡。
- **引魂幡（引路幡）**：长条白纸或白布，剪成齿状，上书字样。
- **纸钱**：打钱、冥币、库钱、银纸、溪钱等，形制与用途因地区而异。
- **火盆、火柴**：焚化之用。
- **竹竿、木杆**：举幡之具。
