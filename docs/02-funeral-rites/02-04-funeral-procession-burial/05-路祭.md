# 路祭

## 一、释义

路祭，是送葬队伍行经通衢、街口或亲友住处时，亲友在路旁设香案供品、拦路致祭之礼。

路祭的特点是**「以路为坛」**：不讲究场地，只须设一张香案、几样供品，即可行祭。它把丧礼从「家中」扩展到「公共空间」，让更多不便于到灵堂的邻里、同业者得以致哀。因此路祭也是丧事社会性的重要体现。

## 二、历史源流

- 《仪礼·既夕礼》记送葬途中有「奠」的环节，但未详述「路祭」之名。
- 汉代送葬有「祖道」（出行前祭路神）之礼，与丧葬的「路祭」有渊源上的关联。
- 唐宋以后「路祭」通行，宋《东京梦华录》记出殡途中有「路祭」「拦路祭」之俗。
- 明清路祭极盛，方志记「亲友于路设祭，丧家须下车拜谢」「大户人家路祭多至数十处」。
- 路祭也有「人情压力」的一面：路祭的处数与规模被用来衡量丧家的社会地位，形成铺张之风，故历代有「禁路祭」之令（如明代曾禁民间路祭过奢）。
- 当代城市已基本不设路祭；农村仍有「路口祭」「拦路祭」的遗俗。

## 三、仪节流程

1. **约祭**：亲友事先告知丧家欲在何处设路祭，丧家予以同意（亦有临时设祭者）。
2. **设案**：于路旁设香案，陈香烛、供果、酒、纸钱，挂挽联。
3. **候队**：设祭者于路旁等候送葬队伍。
4. **拦祭**：队伍行至，设祭者上前拦祭，上香、跪拜。
5. **答礼**：丧主（孝子）下车（或停步）跪拜答谢，孝眷陪同哭拜。
6. **焚纸**：设祭者焚化纸钱，鸣炮。
7. **再行**：礼毕，队伍继续前行。
8. **登记**：路祭的处数与设祭者在事后记入礼簿，备作谢礼。

## 四、地域与民族变体

- **华北**：称「路祭」「拦路祭」，讲究「孝子下车跪谢」。
- **江南**：称「路祭」，多在街口、桥头设祭。
- **闽台**：称「路祭」，与「辞客」相连；送葬至某处，送客者在此告别。
- **广东**：称「路祭」，多在村口设祭。
- **当代变体**：城市中「遗体告别」与「沿路鸣炮」部分承接了路祭的功能。
- **少数民族**：苗族的送葬途中设「拦路酒」迎送；彝族的送葬途中有「指路」歌唱；藏族天葬途中不设路祭。**路祭这一形式主要存在于汉族与部分南方民族中。**

## 五、器物与文书

- **香案、香烛、供果、酒**：路祭陈设。
- **纸钱、炮竹**：焚化与鸣放。
- **挽联、祭幛**：设祭者的赠礼。
- **礼簿**：登记路祭处数与设祭者。
- **谢帖**：事后答谢。
