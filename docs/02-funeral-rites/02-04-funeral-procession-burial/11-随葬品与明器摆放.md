# 随葬品与明器摆放

## 一、释义

随葬品是随死者一同葬入墓中的器物，分两类：

- **明器**：专为殉葬而制、不能实际使用的器物（「备物而不可用」）。
- **用器（生器）**：死者生前所用之器，入葬以「象生」。

明器与用器的比例与摆放，是丧葬礼制中等级与观念的双重表达。

## 二、历史源流

- 《礼记·檀弓》：「其曰明器，神明之也。」又：「孔子谓：为明器者，知丧道矣，备物而不可用也。」明器的定义由此确立。
- 《仪礼·既夕礼》详记随葬器物的品类与陈放：**苞**（包鱼肉之苇包）、**筲**（盛黍稷之器）、**瓮**（盛醯醢）、**甒**（盛酒）、**弓矢**、**耒耜**（农具）、**甲胄**（武具）等，各有其位，随葬的器物「文具」有清单式的陈设次序。
- 商周墓葬的青铜礼器、车马坑，秦汉的兵马俑、玉衣，唐宋的「明器神煞」（如陶俑、镇墓兽），明清的「五谷囤」「宝瓶」，构成随葬品的长期演变。
- 汉以后纸明器（纸扎）兴起，实物随葬减少；唐宋以后「纸扎」与「实物随葬」并行。
- 当代火化制度下，随葬品多为骨灰盒内的小件（生前爱物、照片）。

## 三、仪节流程

1. **备器**：按家境与等级备随葬器物，分「明器」与「用器」两类。
2. **开列清单**：部分地区开列随葬品清单（考古所见的「遣册」即此类文书）。
3. **入棺陈放**（详见「装殓仪节与铺陈」条）：
   - 死者手中：元宝、铜钱、五谷袋；
   - 遗体旁：生前爱物、梳、镜、剪刀；
   - 棺角：五谷囤、宝瓶。
4. **穴内陈放**（棺柩入穴后）：
   - 棺前：陶器、釉陶罐（「粮罐」）；
   - 棺旁：灯（长明灯）、镜、镇墓之物；
   - 穴底：五谷、铜钱（「垫背钱」）。
5. **焚化纸明器**：纸扎（纸屋、纸人、纸马、纸箱）在墓前焚化，不埋入。
6. **填土**：随葬品安放就位后填土。
7. **祭奠**：在墓前设奠，告知亡者随葬已备。
8. **登记**：随葬品清单随葬（「遣册」）或由家族保存（「册」）。

## 四、地域与民族变体

- **华北**：讲究「五谷囤」「宝瓶」「垫背钱」。
- **江南**：讲究「粮罐」「长明灯」「铜镜」。
- **闽粤**：讲究「金斗」「七星钱」，纸明器尤其丰富。
- **客家（二次葬）**：初葬从简，拾骨入瓮时另置随葬（银饰、铜钱）。
- **少数民族**：随葬内容反映本族信仰。彝族随葬农具与银饰（「在祖界继续劳作」）；苗族以银饰随葬（兼具财富与族群标记）；藏族天葬不置随葬品；**回族、维吾尔族因教法规定不设任何随葬品**（教法认为死者唯凭善功，随葬无益）。**这是教义层面的差别，不作「简省」理解。**

## 五、器物与文书

- **明器**：陶俑、陶器、镇墓兽、瓷罐、粮罐、宝瓶。
- **用器**：生前所用之器（梳、镜、笔、烟斗等）。
- **纸明器（纸扎）**：纸屋、纸人、纸马、纸箱。
- **五谷囤、五谷袋、垫背钱**。
- **长明灯、铜镜**。
- **遣册／随葬品清单**：记录随葬品目的文书（考古所见为「遣册」）。
