# 棺罩与抬棺（杠房）

## 一、释义

- **棺罩**：覆盖在棺柩之上的绣罩，以绸缎绣制，覆住棺盖与四壁，起遮蔽、装饰与等级显示的作用。
- **抬棺**：以杠（木杠）与绳（抬索）将棺柩抬起行进，抬棺者称「杠夫」。
- **杠房**：旧时专门承办抬棺、仪仗、花轿租赁的行业，以北京最为著名。

抬棺的人数与规格（「几抬」）是丧事规模的直接标志：**八抬、十六抬、二十四抬、三十二抬**，甚至「六十四抬」为帝王之制。

## 二、历史源流

- 《仪礼·既夕礼》记「輁轴」「輴」等载柩之具，以及「执绋」之制，是抬棺制度的礼制源头。
- 汉以后用「輀车」（灵车），也有以人力抬棺者。
- 明清抬棺制度成熟，「杠房」成为城市中的重要行业。北京的杠房有「大杠」「小杠」之分，各有固定的规格与价格。
- 杠房的业务包括：出杠（抬棺）、执事（旗牌伞扇）、棺罩、鼓乐、棚铺（搭灵棚），即「一条龙」服务，是近代殡葬业的前身。
- 抬棺途中讲究「棺不落地」：途中若须停歇，须用木凳垫起（「打垫」），不得使棺木直接触地。
- 当代城市以车载棺（或遗体）为主，抬棺成为仪式性动作（如从灵堂抬至灵车）。

## 三、仪节流程

1. **约杠房**：丧家按规格（八抬、十六抬等）与杠房约定日期、价格。
2. **备杠**：杠房备大杠、小杠、抬索、棺罩、执事器具。
3. **罩棺**：起灵前以棺罩覆盖棺柩，系结牢固。
4. **上杠**：杠夫将棺柩抬起上杠，前后左右各就各位。
5. **起杠**：鸣炮，杠夫齐声起杠（有「起杠号子」）。
6. **行进**：杠夫步调一致，遇路口、桥头由「杠头」喊号调整。
7. **打垫**：途中歇息时以木凳垫杠，棺不落地。
8. **落杠**：至墓地落杠，将棺柩移至墓穴旁。
9. **下葬**：行下葬之礼（详见「下葬与封土」条）。
10. **赏钱**：丧家向杠夫、执事发赏钱。

## 四、地域与民族变体

- **北京、天津**：杠房行业最成体系，规格与价格有行业惯例，「十六抬」「二十四抬」为常见规格。
- **华北农村**：多以村中青壮年担任杠夫，不雇杠房，讲究「本家人抬」。
- **江南**：多用车载（灵车），抬棺距离短。
- **闽粤**：由「土公」及专业抬棺人负责；水乡有船运灵柩之俗。
- **少数民族**：藏族天葬由「背尸人」背负遗体至天葬台，无棺无杠；苗族、彝族等有本族的抬棺方式（如「独木棺」由数人抬行）；回族、维吾尔族以「塔布」（抬尸架）抬运，由四人抬，中途不停。**「杠房」是汉族城市的特定行业形态。**

## 五、器物与文书

- **大杠、小杠**：抬棺之木杠。
- **抬索、杠绳**：系结之绳。
- **棺罩**：绣罩（龙、鹤、云纹等）。
- **打垫木凳**：途中垫杠之用。
- **执事器具**：旗、牌、伞、扇。
- **杠房单据**：租赁与结算文书。
