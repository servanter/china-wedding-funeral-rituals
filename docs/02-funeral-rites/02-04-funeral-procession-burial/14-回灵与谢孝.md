# 回灵与谢孝

## 一、释义

- **回灵**：下葬之后，丧家将「灵位」（或魂帛）接回家中安设，称「回灵」。
- **安灵**：将灵位安设于堂中，继续供奉，直至除服（或至百日、周年）。
- **谢孝**：丧事办毕后，丧家向参与丧事的亲友、邻里、执事者致谢，称「谢孝」。

下葬不等于丧事的结束：**「葬」之后还有「祭」。** 回灵正是把祭祀从墓前接回家中的过渡环节。

## 二、历史源流

- 《仪礼·既夕礼》记下葬之后有「反哭」之礼：送葬者返回祖庙痛哭，称为「反哭」。这是回灵最早的礼制形态。
- 《礼记·问丧》：「送形而往，迎精而反也。」——形体送到墓地，精神（魂）迎回家中，正是回灵之礼义。
- 《朱子家礼》规定下葬后「反哭于庙」，并设灵座、行「虞祭」（葬后首次正式之祭，共三虞）。**虞祭之后。「奠」改称「祭」。**
- 明清方志记「回灵」「安灵」之俗，有的地方灵位在家供奉至百日，有的供奉至三年除服。
- 「谢孝」在明清方志中记载颇多，如「丧事毕，孝子登门谢孝」「谢孝之日，吊客受孝子之拜」。
- 当代城市丧事多在殡仪馆完成，「回灵」简化为在家中设遗像与香案，供奉至百日或周年。

## 三、仪节流程

### 回灵与安灵

1. **反哭**：下葬毕，送葬者返回（先至祠堂或家中），痛哭。
2. **虞祭**：葬后当日设「虞祭」（首虞），为葬后第一次正式之祭；此后有「再虞」「三虞」。虞祭之后，丧礼的「奠」转为「祭」。
3. **迎灵位**：将灵位（或魂帛、遗像）迎回家中。
4. **安灵**：将灵位安设于堂中（或专设「灵位桌」），设香烛、供品。
5. **朝夕祭**：直至除服前，仍行朝夕上香供饭（仪式程度较停灵期减）。
6. **择期除灵**：择日（如百日、周年、三年）行「除灵」「除服」之礼（详见「除服与禫祭」条）。

### 谢孝

1. **择日**：丧事办毕后择日谢孝（多在葬后三日至七日内，或「复三」之后）。
2. **备礼**：备谢礼（糕点、糖果、毛巾、酒），或手持「谢帖」。
3. **登门**：孝子依次登门拜谢：
   - 先谢族中尊长与操办丧事者（总理、账房、礼生）；
   - 再谢吊客、赙赠者；
   - 再谢邻里、帮工；
   - 另谢路祭者、送葬者。
4. **行礼**：孝子至门，跪拜或鞠躬致谢；受谢者多还礼、安慰。
5. **贴谢帖**：部分地方在自家门上贴「谢帖」，表示感谢各方。
6. **谢孝宴**：部分地区设「谢孝宴」，宴请操办丧事的帮工与执事者。
7. **结束**：谢孝毕，丧事的社会往来自此恢复正常（除服前仍受某些交往限制）。

## 四、地域与民族变体

- **华北**：谢孝多在「复三」之后，孝子登门跪谢，受谢者「扶起不受」。
- **江南**：称「谢孝」「谢客」，多在葬后七日内完成。
- **闽台**：称「谢孝」「谢客」，另有「脱孝」之礼（见「除服与禫祭」条）。
- **广东**：称「谢孝」，多在「做七」之后陆续进行。
- **少数民族**：部分民族在葬后有本族的「谢客」礼，如彝族的「酬客」、苗族的「谢寨」；藏族葬后以请僧诵经回向为谢；穆斯林民族葬后向参加殡礼者致谢，但无「谢孝」之礼制名称。**具体形态须依各族习俗记录。**

## 五、器物与文书

- **灵位、魂帛、遗像**：回灵与安灵的对象。
- **灵位桌、香烛、供品**。
- **谢帖**：答谢文书，格式见「婚丧文书范本／谢帖与答谢启范本」条。
- **谢礼**：糕点、糖果、毛巾、酒。
- **礼簿**：作为逐一登门致谢的依据。
