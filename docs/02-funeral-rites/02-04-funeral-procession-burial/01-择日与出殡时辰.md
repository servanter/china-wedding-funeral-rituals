# 择日与出殡时辰

## 一、释义

出殡（发引、出丧、送葬）须择吉日吉时，是丧事中最受重视的择日环节。择日的内容包括：**出殡日期**、**起灵时辰**、**出门方位**、**下葬时辰**。

其忌避的核心是「重丧」：民间认为在不吉之日出殡，会招致家中再有人去世（「重丧」「三丧」「复日」）。

## 二、历史源流

- 礼制上的葬期依等级：《礼记·王制》「天子七日而殡，七月而葬；诸侯……五月而葬；大夫、士、庶人三日而殡，三月而葬」。
- 《仪礼·既夕礼》记出殡前一日的「迁柩」「祖奠」，出殡当日的「遣奠」「发引」，均有定时。
- 唐宋以后择日术介入，形成「忌重丧日」「忌三煞方」「忌黄沙日」等具体规则，系统整理见《协纪辨方书》。
- 明清方志大量记载出殡择日之俗，如「必请阴阳先生看日子，犯重丧则不能出殡」。
- 破解之法：民间有「以公鸡压棺」「加一道士（或僧人）」「写「解煞符」等法，谓可化解重丧。
- 当代火化制度下，出殡日多为殡仪馆排期与择日结合，传统禁忌影响减弱。

## 三、仪节流程

1. **请人看日子**：由阴阳先生依黄历、亡者八字、坟山坐向择定。
2. **定四要素**：
   - **出殡日**（须避重丧日、三丧日）；
   - **起灵时辰**（多在凌晨或上午，忌午后）；
   - **出门方向**（出门先向何方，忌直冲某方位）；
   - **下葬时辰**（落葬与封土的时辰）。
3. **列回避单**：写明须回避的属相与人员，贴于门口。
4. **通知亲友**：将日程写入讣告。
5. **备解煞物**（如犯忌出门）：备公鸡、符箓、五谷、镜子等。
6. **鸣炮起灵**：到定时辰，鸣炮示意，开始出殡。
7. **中途禁忌**：忌走回头路、忌棺柩落地、忌在桥上停留。

## 四、地域与民族变体

- **华北**：讲究「出殡不过午」，多在清晨；忌「重丧日」，以公鸡压棺。
- **江南**：讲究「看时辰」，起灵多在「寅卯时」或「辰时」。
- **闽台**：出殡时辰极严，由「司公」与「土公」共同确定；忌「黄沙日」。
- **广东**：讲究「出殡不逢三煞」，并有「三朝」「五朝」「七朝」之期。
- **少数民族**：出殡（送葬）时机多由宗教人士决定。彝族由毕摩占卜；藏族天葬的日期由喇嘛依藏历择定；苗族、侗族另有本族的择日方式（如看鸡卦）。**穆斯林民族则不择日**——速葬是教法要求，唯避日落后埋葬，与汉族的干支择日完全不同。

## 五、器物与文书

- **黄历、择日书、罗盘**：择日定向之具。
- **讣告**：载明日程。
- **公鸡、符箓、五谷、镜子**：解煞之物。
- **回避单**：贴门告示。
- **炮竹**：起灵信号。
