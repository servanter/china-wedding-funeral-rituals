# 葬式类型

## 一、释义

葬式（埋葬方式）是对遗体的最终处置形式。本条对中国境内的主要葬式作横向比较，说明其地理分布、族群归属与观念依据。

**重要说明**：葬式与民族、宗教直接绑定，**不可作「先进—落后」的评价**，也不可把汉族的土葬视为通用标准。

## 二、主要葬式

### 1. 土葬

- **分布**：汉族（除火化区）、回族、维吾尔族等多数民族。
- **形态**：汉族为「棺葬＋封土成坟＋立碑」；**回族、维吾尔族等穆斯林民族为「白布裹身＋不用棺＋不封丘＋不立碑」**，坟不高于地面一拃。
- **观念**：汉族「入土为安」，「身体发肤归之于土」；穆斯林「来自土，归于土」。

### 2. 火葬

- **分布**：历史上为部分佛教僧侣与西南部分民族（如彝族旧有火葬）所行；当代因殡葬改革成为汉族地区的主流。
- **观念**：佛教以「荼毗」（火化）为常规，与「四大离散」的教义相符；当代以节约土地与卫生为主要考虑。

### 3. 天葬

- **分布**：藏族、蒙古族部分地区。
- **形态**：遗体由「背尸人」送至天葬台，由喇嘛诵经，供鹫（神鸟）啄食。骨须一并处理（捣碎拌糌粑供鹫）。
- **观念**：**「舍身布施」**——以最后的肉身布施众生，是藏传佛教慈悲观的极致表达。**此葬式有严格宗教含义，不得以「野蛮」评价。**

### 4. 水葬

- **分布**：藏族部分地区（多为夭折者、传染病死者），门巴族、珞巴族部分地区。
- **形态**：遗体投入江河。
- **观念**：多见于「非正常死亡」者的处置，也含「随水而逝」的观念。

### 5. 树葬

- **分布**：藏族部分地区（婴孩）、东北部分民族（如鄂温克族旧有「风葬」）、部分南方民族。
- **形态**：遗体置于树上（或树间搭架），任其自然分解。
- **观念**：与「回归自然」和林中生活的生产方式相关；藏族婴孩树葬含「早归」之意。

### 6. 悬棺葬

- **分布**：历史上分布于长江三峡、四川、福建武夷山、江西、广西等地，属古代南方民族（僚人、百越等）的葬式。
- **形态**：棺木置于悬崖洞穴中或钉于崖壁之上。
- **观念**：有「升高近天」「避兽防扰」「祖先崇拜」等多种解释，学界尚无定论。当代已不存。

### 7. 塔葬

- **分布**：藏传佛教高僧、汉传佛教高僧。
- **形态**：遗体经防腐处理后置于塔中（灵塔），或火化后骨灰入塔。
- **观念**：以塔为「法身」安住之所，具宗教尊崇意义。

### 其他

- **塔葬／龛葬**：僧人专属。
- **二次葬（捡骨葬）**：汉族客家、广府部分地区，及部分南方民族；初葬后若干年拾骨入瓮再葬（详「合葬与迁葬」条）。
- **树葬（风葬）与石棺葬**：西南部分民族与古代民族所行。

## 三、仪节流程

不同葬式的流程差别极大，本条只作比较，具体仪节见各相关条目：

## 四、地域与民族变体

| 葬式 | 主要族群 | 主要分布 |
| --- | --- | --- |
| 土葬（棺葬＋封土） | 汉族 | 全国（农村为主） |
| 土葬（白布裹身、不封丘） | 回族、维吾尔族、哈萨克族等 | 西北及全国穆斯林聚居区 |
| 火葬 | 当代汉族；历史上部分僧人、彝族等 | 全国（城镇为主） |
| 天葬 | 藏族、蒙古族部分地区 | 青藏高原、内蒙古 |
| 水葬 | 藏族部分地区、门巴族、珞巴族 | 藏南、雅鲁藏布江流域 |
| 树葬／风葬 | 鄂温克族、藏族（婴孩）等 | 东北、青藏 |
| 悬棺葬 | 古代南方民族（僚、百越等） | 三峡、武夷山、川滇 |
| 塔葬 | 藏传与汉传佛教高僧 | 藏区、汉地寺院 |

## 五、器物与文书

- **天葬台、天葬师（背尸人）用具**：天葬。
- **塔（灵塔、舍利塔）**：塔葬。
- **棺、椁、骨灰盒、骨瓮（金斗瓮）**：土葬与二次葬。
- **各民族志与民族学调查**：主要文献来源。
