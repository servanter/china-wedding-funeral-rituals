# 阴阳五行与择吉文化

## 一、释义

**阴阳**以对立统一解释事物变化，**五行**（金、木、水、火、土）以相生相克说明关系与流转。二者与**干支**纪时结合，衍生出择吉之术，为婚丧择日的理论依据。

| 概念 | 内容 |
| --- | --- |
| **阴阳** | 天地、男女、生死之分 |
| **五行相生** | 木生火、火生土、土生金、金生水、水生木 |
| **五行相克** | 木克土、土克水、水克火、火克金、金克木 |
| **天干** | 甲乙丙丁戊己庚辛壬癸 |
| **地支** | 子丑寅卯辰巳午未申酉戌亥 |
| **常用神煞** | 喜神、三煞、岁破、月破、冲煞 |

## 二、历史源流

- 先秦阴阳家（邹衍）倡五德终始之说。
- 汉《淮南子·天文训》系统论阴阳五行，出土《日书》已见择日之术。
- 唐宋通书与术数流行，婚丧择日成俗。
- 清《协纪辨方书》为官方编纂的择吉集成，择吉术由此规范化。

## 三、仪节流程

1. **排八字**：依出生年月日时列四柱干支。
2. **定五行喜忌**：以日主为基，判五行之喜忌。
3. **择日**：依通书定黄道吉日，避月破、三煞等。
4. **定向**：择「喜神方」，定迎亲出发所朝之方。
5. **避煞**：绕开推算所得凶方与凶时。
6. **书于日单**：将所选日期、时辰、方位书于日单与请柬、讣告。

## 四、地域与民族变体

- **汉族地区**：择日之术普遍，婚丧尤重。
- **少数民族地区**：另有占卜体系（如彝族毕摩占卜、藏族星算、苗族鸡卜），原理与汉制不同，须分别记录。

## 五、器物与文书

- **文书**：通书、黄历、日单、庚帖。
- **器物**：罗盘、算盘、命书。
