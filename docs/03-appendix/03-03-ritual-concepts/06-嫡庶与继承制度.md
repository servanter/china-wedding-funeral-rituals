# 嫡庶与继承制度

![嫡庶与继承关系图 / Legitimate and secondary descent](../../../assets/diagrams/嫡庶与继承关系图.svg)

*图 15　嫡庶之分与继承顺位关系图。*

## 一、释义

**嫡**指正妻所生之子，**庶**指妾所生之子。继承含**宗祧继承**（承袭宗祀与身份）与**财产继承**（析分家产）两层。宗祧继承以「立嫡以长不以贤」为原则。

| 名目 | 释义 |
| --- | --- |
| **嫡子** | 正妻所生之子 |
| **庶子** | 妾所生之子 |
| **嗣子** | 无子者立同宗昭穆相当者之子为嗣 |
| **养子** | 收养异姓或同宗之子 |
| **兼祧** | 一子兼承两房之祀（清代明定） |

## 二、历史源流

- 周代确立立嫡之制，《春秋》有「立嫡以长不以贤」之义。
- 秦汉以降以律令规定继承次序。
- 唐宋明清律例详载：《唐律疏议》有「立嫡违法」条，《大明律》《大清律例》沿之。
- 清代并定「兼祧」之制，以解决独子承两房之难题。

## 三、仪节流程

1. **定嫡庶**：依生母身份确定嫡庶。
2. **立嗣**：无子者择同宗昭穆相当者之子为嗣，须族人同意。
3. **告庙**：立嗣之事禀告祖先。
4. **书谱**：载入族谱，明其世次。
5. **析产**：分家时依律例与族规分配，北方多「诸子均分」，南方常见长子、长孙另留份额。

## 四、地域与民族变体

- **华北**：财产上多行诸子均分。
- **华南**：常见「长子长孙田」，宗祧继承仍受重视。
- **少数民族**：多依习惯法分配（如彝族的「长子承业」、部分民族的「幼子继承」），与汉制律例不同，须分别记录。

## 五、器物与文书

- **文书**：族谱、遗嘱、分家单（「阄书」）、婚书（辨嫡庶）。
- **器物**：宗祠神主、族印、契券。
