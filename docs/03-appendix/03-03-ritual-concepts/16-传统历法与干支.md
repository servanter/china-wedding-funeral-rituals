# 传统历法、干支与二十四节气

![二十四节气与干支图 / The 24 solar terms and the sexagenary cycle](../../../assets/diagrams/二十四节气与干支图.svg)

*图 18　二十四节气与干支纪时对应示意图。*

## 一、释义

中国传统历法为**阴阳合历**（今称农历）：以朔望定月，以回归年定岁，以置闰协调二者。**干支**六十循环，用以纪年、纪日、纪时。**二十四节气**为太阳周年视运动的划分，指导农事与礼俗。

| 名目 | 内容 |
| --- | --- |
| 干支 | 十天干与十二地支相配，六十为一周 |
| 节气 | 立春、雨水、惊蛰……大寒，共二十四 |
| 常用历注 | 建除十二神、黄道黑道、宜忌 |

婚丧择日即以农历、干支与历注为据。

## 二、历史源流

- 夏商已有历法，殷墟甲骨见干支纪日。
- 汉《太初历》确定正月为岁首与置闰之法。
- 唐宋《大衍历》《授时历》历法渐精。
- 明清行《时宪历》，民国后公历与农历并行。
- 民间通书、黄历将历法与择吉宜忌合刊，行用至今。

## 三、仪节流程

1. **查农历**：先据公历查对农历日期。
2. **定节气**：确定节气与月令。
3. **择日**：避月破、岁破、无春之年等，择吉成礼。
4. **定时辰**：定迎亲、入殓、出殡之时辰。
5. **书于文书**：将公历、农历、时辰一并书于请柬或讣告。

## 四、地域与民族变体

- **汉族地区**：「无春年」（俗称「寡妇年」）忌嫁之说流行于部分地区，实为历法现象附会而成。
- **少数民族地区**：多用本族历法（如藏历、傣历、彝历）定婚丧日期，须分别记录。

## 五、器物与文书

- **文书**：通书、黄历、万年历、日单。
- **器物**：历板、算盘。
