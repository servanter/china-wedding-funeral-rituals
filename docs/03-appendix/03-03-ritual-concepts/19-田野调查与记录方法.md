# 民俗田野调查与记录方法

## 一、释义

田野调查是获取活态民俗资料的基本手段，含**参与观察**、**深度访谈**、**口述史**、**影像记录**与**实物采集**五种方法。对本资料库而言，其目的是印证文献、补足细节、记录地域与民族变体。

**基本原则**：尊重被访者意愿、如实记录不加推断、注明时间地点与讲述人、对敏感内容作匿名化处理。

## 二、历史源流

- 早期风俗调查以《中华全国风俗志》一类志书为代表，多凭文献与见闻。
- 20 世纪中叶开展大规模民族社会历史调查，积累大量婚丧资料。
- 当代民俗学、人类学确立田野工作规范，强调长期驻留与民族志写作。
- 近二十年来录音、影像与数字化手段广泛用于民俗记录。

## 三、仪节流程

1. **选点**：依研究问题选取代表村寨或社区。
2. **报备与联络**：向当地与事主说明来意，取得同意。
3. **参与观察**：全程跟踪婚丧过程，记录时序、参与者、器物与用语。
4. **访谈**：分层访谈（长者、执事者、当事者、妇女与青年），留意不同说法。
5. **记录**：笔记、录音、影像、器物测绘与文书抄录并行。
6. **整理与核对**：整理为调查记录，回访求证存疑之处。

## 四、地域与民族变体

- **民族地区**：注意语言障碍与翻译的准确性，尽量记录本族语称谓与祭词原文并注音译义。
- **城乡差异**：城市礼俗变化快，须记录新旧两套做法。
- **伦理要求**：丧事现场须谨慎拍摄，忌干扰仪式进程。

## 五、器物与文书

- **文书**：调查表、访谈提纲、田野日志、口述记录稿、抄录的文书范本。
- **器物**：录音笔、相机、测绘工具、录音与影像存储设备。
