# 凶礼概说

## 一、释义

凶礼为「哀邦国之忧」之礼，其内涵分五类：

| 类别 | 内容 |
| --- | --- |
| **丧** | 丧礼，哀死亡（**丧葬属此**） |
| **荒** | 救灾荒，哀凶札 |
| **吊** | 吊问灾祸与不幸 |
| **禬** | 祈福消灾，祓除祸患 |
| **恤** | 赈济贫弱与穷困 |

五者之中，**丧礼**仪节最繁、影响最广，为本资料库丧葬一编之所本。

## 二、历史源流

- 《周礼》立凶礼五目，《仪礼》存《士丧礼》《既夕礼》《士虞礼》三篇，丧礼仪节详备。
- 《礼记》之《丧大记》《间传》《服问》诸篇，专论丧礼与服制。
- 历代礼典置凶礼门，《大唐开元礼》《大清通礼》皆然。
- 《仪礼·丧服》所立五服制度，为后世服制的根本依据。

## 三、仪节流程

丧礼仪节的整体链条如下：

1. **初丧**：属纩、招魂（复）、沐浴、饭含、袭尸。
2. **入殓**：小殓、大殓、盖棺。
3. **停灵**：设灵堂、守灵、朝夕奠、佛事或道场。
4. **出殡下葬**：启灵、送葬、路祭、落葬、封土。
5. **葬后祭祀**：复三、做七、百日、周年、除服。

## 四、地域与民族变体

- **汉族地区**：丧礼各地细节差异显著，详见「汉族各地域丧俗变体」。
- **少数民族地区**：葬式多样（土、火、天、水、树、塔、悬棺等），丧礼体系与汉制不同源，详见「少数民族丧葬习俗」。

## 五、器物与文书

- **文书**：讣告、祭文、哀启、墓志、挽联。
- **器物**：棺椁、明器、纸扎、铭旌、丧服、丧杖。
