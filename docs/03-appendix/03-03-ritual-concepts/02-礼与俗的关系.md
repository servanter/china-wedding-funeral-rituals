# 礼与俗的关系

## 一、释义

**礼**是上层社会制定、具有经典依据的规范体系；**俗**是民间长期沿袭、具有地方色彩的生活惯习。二者并非截然两分，其关系可归纳为四种：

| 关系 | 说明 | 例 |
| --- | --- | --- |
| **以礼化俗** | 以礼制规范民间习俗 | 历代禁「冲喜」「冥婚」 |
| **以俗入礼** | 民间习尚被采入礼典 | 「拜堂」「闹房」入庶民婚礼 |
| **礼俗并行** | 礼制与民俗各行其道 | 官方丧礼与民间超度并存 |
| **礼失求诸俗** | 礼制废弛而俗尚犹存 | 古礼细节赖民俗得存 |

## 二、历史源流

- 《礼记·王制》：「修其教不易其俗，齐其政不易其宜。」主张因俗施教。
- 汉魏施行「以礼化俗」，以乡约、家训导民。
- 唐宋出现「礼下庶人」的转向：司马光《书仪》、朱熹《家礼》为庶民制礼。
- 明清家礼普及，礼与俗趋于合一，民间婚丧在礼制框架内自行增损。
- 近代以来礼制瓦解，习俗保存较多，二者渐离。

## 三、仪节流程

1. **制礼**：依据经典制定仪注。
2. **颁行**：通过礼典、乡约、家训向下推行。
3. **士绅示范**：以士绅之家为榜样，上行下效。
4. **民间因袭**：民间依自身条件增减，形成地方变体。
5. **反哺采入**：行之既久的民俗被礼典或家礼采录，完成「俗—礼」的循环。

## 四、地域与民族变体

- **汉族地区**：礼俗叠合紧密，婚丧多为「半礼半俗」。
- **边地与民族地区**：礼制影响较弱，本族习俗为主，部分借用汉制名目。
- **须分别记录**：不得以汉礼之目套用民族习俗。

## 五、器物与文书

- **文书**：乡约、家训、家礼、方志·风俗志。
- **器物**：祠规、族规碑、乡约碑。
