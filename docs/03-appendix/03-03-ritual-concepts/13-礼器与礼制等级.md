# 礼器与礼制等级

![青铜礼器（鼎、簋、爵）/ Ancient bronze ritual vessels](../../../assets/images/14-bronze-ritual-vessels.png)


![列鼎礼器等级图 / Ding-tripod ranking chart](../../../assets/diagrams/列鼎礼器等级图.svg)

*图 17　列鼎礼器等级：天子九鼎至士一鼎的等差。*

## 一、释义

礼器为行礼所用之器物，其形制、数量与组合依身份等级而定，所谓「藏礼于器」——器数即等级。

| 身份 | 鼎（列鼎） | 簋 |
| --- | --- | --- |
| 天子 | 九鼎 | 八簋 |
| 诸侯 | 七鼎 | 六簋 |
| 大夫 | 五鼎 | 四簋 |
| 士 | 三鼎 | 二簋 |

此外，玉帛、钟磬、笾豆之数亦然。婚丧礼器则随礼俗下移，演为粢盛器、香案供器等。

## 二、历史源流

- 商周青铜礼器与「列鼎制度」为考古所见（如周代墓葬所出成组列鼎）。
- 《周礼》详列器数与官掌，与考古发现大体相合。
- 汉唐以降，礼器由青铜转用陶、瓷、漆、木，趋向实用。
- 宋《三礼图》等考订古礼器形制，影响后世礼器制作。
- 明清民间婚丧礼器以香案、供器、烛台等为主。

## 三、仪节流程

1. **依身份定器数**：行礼之先，按品级确定用器多少。
2. **陈设**：设馔、陈器于神前或堂上。
3. **献器**：行礼时依次奉献。
4. **撤器**：礼毕撤器，祭器储于专处。
5. **守器之规**：祭器不假于人，为礼制所重。

## 四、地域与民族变体

- **汉族地区**：古器数之制已不严格，民间仍有「成双」「成套」之讲究。
- **少数民族地区**：礼器体系各异（如彝族的祭器、藏族供器），须分别记录。

## 五、器物与文书

- **器物**：鼎、簋、笾、豆、玉帛、钟磬、香案、烛台。
- **文书**：礼器图（《三礼图》）、礼典、墓葬随葬品清单。
