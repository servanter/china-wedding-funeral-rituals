# 嘉礼概说

## 一、释义

嘉礼为「亲万民」之礼，取「吉事」之义，与凶礼相对。依《周礼·春官·大宗伯》，含六类：

| 类别 | 内容 |
| --- | --- |
| **饮食之礼** | 燕飨、乡饮酒 |
| **冠昏之礼** | 冠礼与婚礼（**婚嫁属此**） |
| **宾射之礼** | 射礼、投壶 |
| **飨燕之礼** | 飨礼、燕礼 |
| **脤膰之礼** | 颁赐祭肉 |
| **贺庆之礼** | 贺喜、庆贺 |

本资料库婚嫁一编，即嘉礼中「昏礼」一门。

## 二、历史源流

- 《周礼》立嘉礼六目，《仪礼》存《士冠礼》《士昏礼》《乡饮酒礼》《乡射礼》《燕礼》《大射礼》诸篇。
- 历代礼典皆置嘉礼门：《大唐开元礼》《宋政和五礼新仪》《大明集礼》《大清通礼》均然。
- 宋《家礼》将冠昏之礼简化，推及庶民。
- 近代冠礼式微，婚礼独盛。

## 三、仪节流程

以嘉礼中最要者为例：

1. **冠礼**：筮日—筮宾—三加冠（缁布冠、皮弁、爵弁）—醴宾—见母、见兄弟—谒庙。
2. **昏礼**：纳采—问名—纳吉—纳征—请期—亲迎，婚后庙见、见舅姑。
3. **乡饮酒礼**：谋宾—迎宾—献酢酬—旅酬—送宾，以序长幼、明尊卑。

## 四、地域与民族变体

- **汉族地区**：婚礼纳采、拜堂、合卺、回门诸节广泛保存。
- **少数民族地区**：各有本族礼俗，不以嘉礼分类，须分别记录其婚礼体系。

## 五、器物与文书

- **文书**：婚书、礼单、请柬、赞礼词。
- **器物**：冠服、合卺杯、喜秤、燕礼器、乡饮酒器。
