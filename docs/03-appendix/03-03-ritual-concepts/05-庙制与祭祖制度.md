# 庙制与祭祖制度

![祠堂（宗庙）/ The ancestral hall](../../../assets/images/15-ancestral-hall.png)


![庙制层级图 / Hierarchy of ancestral temple regulations](../../../assets/diagrams/庙制层级图.svg)

*图 14　庙制层级：自天子七庙至士一庙的祭祖等级。*

## 一、释义

庙制规定自天子至庶人各立庙的数量，核心原则是「亲尽则毁」——世代既远，即迁其神主于祧庙。

| 身份 | 庙数 | 说明 |
| --- | --- | --- |
| 天子 | 七庙 | 始祖 + 二祧 + 四亲庙 |
| 诸侯 | 五庙 | 始祖 + 二祧 + 二亲庙 |
| 大夫 | 三庙 | 曾祖、祖、祢 |
| 士 | 一庙 | 祢庙 |
| 庶人 | 无庙，祭于寝 | 后世得立祠堂 |

宋《家礼》变通古制，许士庶立**祠堂**于正寝之东，祭祖制度自此下移民间。

## 二、历史源流

- 《礼记·王制》《祭法》载庙数与「亲尽则毁」之义。
- 汉唐立庙之制屡有更定，太庙制度渐趋完备。
- 宋代《家礼》定祠堂之制，为庶民祭祖提供规范。
- 明清庶民皆得立祠，宗祠遍布城乡，祭祖制度民间化。

## 三、仪节流程

1. **立庙或祠堂**：择地建祠，设神主。
2. **设神主**：按昭穆位次排列。
3. **四时祭**：春祠、夏禴、秋尝、冬烝，依时设馔致祭。
4. **忌日祭与朔望参**：忌日致祭，朔望上香。
5. **亲尽祧迁**：世次既远，迁神主于祧庙或埋于墓侧。

## 四、地域与民族变体

- **闽粤**：祠堂林立，春祭秋祭隆重，族祭规模宏大。
- **华北**：家庙小祠为主，祭祀简朴。
- **少数民族**：祖先崇拜形式多样（如彝族的祖灵筒、景颇族的「南坎」祭），与汉制庙制不同源，须分别记录。

## 五、器物与文书

- **文书**：祠规、祭祀簿、族谱、祝文。
- **器物**：神主牌位、香案、供器、祭田契、祭器。
