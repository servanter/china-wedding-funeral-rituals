# 婚丧礼俗中的信仰元素（儒、释、道、民间）

## 一、释义

中国传统婚丧礼俗是多重信仰叠合的产物：儒主礼义与宗法，释主超度与因果，道主科仪与驱邪，民间信仰主鬼神、禁忌与趋吉。

| 信仰 | 在婚丧中的表现 |
| --- | --- |
| **儒家** | 家礼、六礼、五服、祭祖、三献礼 |
| **佛教** | 超度、焰口、诵经、素食、拴线（与南传佛教习俗结合） |
| **道教** | 破狱、炼度、召魂、符箓、择日 |
| **民间信仰** | 择吉、辟邪（桃枝、朱砂）、纸扎、冲喜、哭嫁 |

## 二、历史源流

- 汉魏以儒礼为丧葬之本，礼制与宗法相维。
- 南北朝佛教流行，超度法事渐入丧礼。
- 唐宋道教科仪进入民间丧事，与佛事并行。
- 明清三教合流，民间丧事常见「儒礼家奠 + 佛事 + 道场」并列，婚俗亦兼采择吉、辟邪之俗。

## 三、仪节流程

1. **儒礼家奠**：行三献礼、读祭文，为丧礼之主干。
2. **佛事**：请僧诵经、放焰口、做七，超度亡者。
3. **道场**：请道士行破狱、炼度等科仪。
4. **民间辟邪**：以桃枝、符箓、朱砂等趋吉避凶。
5. **择吉贯穿**：自入殓、出殡至婚礼各节，皆择日择时。

## 四、地域与民族变体

- **汉族地区**：佛道并用，各地侧重不同（如闽台重佛事，湖南重道场）。
- **少数民族地区**：多以本族宗教（如萨满教、苯教、南传佛教、原始宗教）为主导，并与汉制仪式部分叠合，须分别记录。

## 五、器物与文书

- **文书**：祭文、经卷、科仪本、符箓、祝文。
- **器物**：法器（引磬、木鱼、铃）、纸扎、香烛、桃枝、朱砂。
