# 婚丧礼俗的当代变迁

## 一、释义

当代婚丧礼俗的变迁由三股力量共同塑造：**城市化与人口流动**（仪式场所由宅院转向酒店、殡仪馆）、**移风易俗与简办**（革除铺张与旧俗）、**非遗保护与文化自觉**（传统仪式的展演与复兴）。

| 面向 | 传统形态 | 当代形态 |
| --- | --- | --- |
| 婚礼场所 | 宅院、祠堂 | 酒店、婚庆场馆、旅行结婚 |
| 婚礼仪节 | 六礼、拜堂、合卺 | 中西合璧，保留拜堂、敬茶 |
| 丧事场所 | 家中停灵 | 殡仪馆告别厅 |
| 葬式 | 土葬 | 火葬、骨灰安葬、生态葬 |
| 通知方式 | 讣告、登门报丧 | 微信群、短信、电子讣告 |
| 记录方式 | 族谱、礼簿 | 电子相册、线上追思页 |

## 二、历史源流

- 20 世纪中期起推行殡葬改革，逐步以火化替代土葬。
- 1950 年《婚姻法》废除包办婚、童养媳等旧俗，确立婚姻自主。
- 21 世纪以来非遗保护制度建立，多项婚丧相关民俗列入各级名录（如京族「哈节」）。
- 近十年移风易俗持续推进，婚丧简办、生态安葬渐成共识。

## 三、仪节流程

1. **仪节简省**：繁复环节精简，保留象征性核心（拜堂、鞠躬告别）。
2. **新式婚礼**：集体婚礼、旅行结婚、公益婚礼等新形式涌现。
3. **葬式转型**：火化普及，骨灰安葬、海葬、树葬等生态葬式推广。
4. **电子礼俗**：电子请柬、线上追思、电子挽联渐成常态。
5. **非遗展演**：传统仪式在节庆与非遗活动中被复原与展演。

## 四、地域与民族变体

- **城市**：仪式简化、场所外移、电子化程度高。
- **乡村**：传统仪节保存较多，与简办要求之间常有张力。
- **民族地区**：传统仪式在非遗保护下受到重视，部分仪式由生活实践转为文化展演。
- **须如实记录**：变迁中的新旧并存状态，正是当代民俗研究的重要对象。

## 五、器物与文书

- **文书**：结婚证、电子请柬、电子讣告、追思函、火化证明。
- **器物**：骨灰盒、生态葬具、婚庆布置、线上追思页面。
