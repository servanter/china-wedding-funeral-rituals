# 命理合婚基础

## 一、释义

合婚即依男女双方生辰推判婚配吉凶。常见方法有四种：

| 方法 | 依据 |
| --- | --- |
| **八字合婚** | 男女四柱干支的生克与喜忌 |
| **属相合婚** | 生肖之六合、六冲、三合 |
| **纳音合婚** | 六十甲子纳音五行之相生相克 |
| **星命合婚** | 星宿方位与命宫 |

| 生肖关系 | 内容 |
| --- | --- |
| **六合** | 子丑、寅亥、卯戌、辰酉、巳申、午未 |
| **六冲** | 子午、丑未、寅申、卯酉、辰戌、巳亥 |
| **三合** | 申子辰、亥卯未、寅午戌、巳酉丑 |

## 二、历史源流

- 汉代已有「纳音」之说，见于乐律与术数。
- 宋代「合婚」成俗，《东京梦华录》载「换帖」「合婚」之礼。
- 明清以「八字」合婚为正宗，命理书盛行。
- 当代多简化为「属相相配」，合八字之俗在乡村仍存。

## 三、仪节流程

1. **换庚帖**：两家交换生辰八字。
2. **排八字**：列四柱干支，定日主与五行喜忌。
3. **查生克**：核属相、纳音、日主之相生相克。
4. **定宜忌**：判婚配吉凶，议回避之法（如择日、改期）。
5. **出文书**：以「婚书」「日单」书明所选吉日吉时。

## 四、地域与民族变体

- **华北**：重「属相相合」，忌「六冲」。
- **江南**：重八字与纳音，讲究「合婚单」。
- **少数民族地区**：多依本族占卜法（如鸡卜、羊骨卜、请巫师看卦）择婚，与汉制命理不同，须分别记录。

## 五、器物与文书

- **文书**：庚帖、婚书、日单、命书。
- **器物**：算盘、通书、命盘。
