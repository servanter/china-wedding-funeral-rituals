# 直系与旁系称谓对照

## 一、释义

**直系**指一脉相承的血亲（祖—父—己—子—孙）；**旁系**指同出一源而不同支的亲属（伯叔、兄弟、堂侄等）。同一亲属关系在「上称下」与「下称上」两个方向上有不同称谓，须对照掌握。

| 关系 | 己称之（下称上） | 彼称己（上称下） |
| --- | --- | --- |
| 父之兄 | 伯父 | 侄 |
| 父之弟 | 叔父 | 侄 |
| 兄弟之子 | 侄（侄子） | 伯／叔 |
| 父之姊妹 | 姑母 | 侄 |
| 母之兄弟 | 舅父 | 外甥 |
| 夫之父 | 公公（舅） | 媳 |
| 妻之父 | 岳父 | 婿 |

直系与旁系的界限直接决定五服等差：直系服重，旁系服轻，愈疏愈轻。

## 二、历史源流

- 《仪礼·丧服》以「上杀、下杀、旁杀」三原则区分直系与旁系的服等。
- 《尔雅·释亲》已见「侄」「甥」等方向性称谓。
- 明清家礼对「上称下」「下称上」的称谓作了系统规定。
- 当代对向称谓（侄、甥、媳、婿）仍完整沿用。

## 三、仪节流程

1. **辨直旁**：先定直系或旁系。
2. **定方向**：分「下称上」（尊称）与「上称下」（卑称）。
3. **落文书**：请柬、讣告中自称须辨方向（如讣告署「孤子」）。
4. **排序次**：座次与行礼次序，先直系后旁系，先尊后卑。
5. **称谓升级**：子辈出生后，长辈对己身的称谓随之升级（如「哥」升为「伯」）。

## 四、地域与民族变体

- **华北**：旁系分「堂」「表」清楚。
- **华南**：对向称谓常加「阿」字（阿伯、阿侄）。
- **民族地区**：舅甥、姑侄关系称谓与权利相连（舅权、姑权），须分别记录。

## 五、器物与文书

- **文书**：九族五服图、世系表、请柬、讣告。
- **器物**：神主、牌位（题名须辨直旁尊卑）。
