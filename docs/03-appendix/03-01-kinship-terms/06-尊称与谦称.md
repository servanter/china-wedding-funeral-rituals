# 尊称与谦称

## 一、释义

亲属交往与婚丧文书中，称他人亲属用**尊称**，自称己方亲属用**谦称**，此即「尊人谦己」之礼。

| 对象 | 尊称 | 谦称 |
| --- | --- | --- |
| 父 | 令尊、尊公 | 家父、家严 |
| 母 | 令堂、尊慈 | 家母、家慈 |
| 兄 | 令兄 | 家兄 |
| 子 | 令郎、令嗣 | 小儿、犬子 |
| 女 | 令爱、令媛 | 小女 |
| 妻 | 尊夫人、嫂夫人 | 拙荆、内人 |
| 婿 | 令婿、东床 | 小婿 |
| 已故尊长 | 令先尊 | 先父、先慈 |

**「家大、舍小、令尊人」**是三条最基本规则：称己之尊长用「家」（家父、家兄），称己之卑幼用「舍」（舍弟、舍侄），称对方亲属用「令」（令尊、令郎）。

## 二、历史源流

- 《礼记·曲礼》已见「自称曰某」「称人曰子」等敬谦之别。
- 汉魏书札（如《月仪》《书仪》）奠定家书称谓格式。
- 唐宋以降，「令」「家」「舍」体系在尺牍中定型。
- 明清日用类书（《尺牍大全》一类）广载婚丧文书的各种称谓。
- 当代口头尊谦称淡化，书面（讣告、请柬）仍须遵循。

## 三、仪节流程

1. **分对象**：对他人亲属用「令」，对己之尊长用「家」，对己之卑幼用「舍」。
2. **分生死**：称已故亲属冠「先」（先父、先慈），称在世亲属冠「家」。
3. **入文书**：请柬、讣告、祭文的称谓与自称按行款排列。
4. **落款**：写信、送礼单时署名自称（如「姻弟」「眷侄」）。
5. **口称**：面称仍以亲属称谓为主，尊谦称主要用于书面。

## 四、地域与民族变体

- **华北**：口语中有「您」「他老人家」等尊语。
- **江南**：书面尊谦称保留最完整。
- **闽粤**：口语多重叠式昵称（阿爸、阿母），书面仍用尊谦称。
- **少数民族**：各有本族语言的敬语体系，与汉语尊谦称的对应关系须分别记录。

## 五、器物与文书

- **文书**：请柬、婚书、讣告、祭文、尺牍。
- **器物**：帖式用纸、名刺。
