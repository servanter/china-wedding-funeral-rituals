# 亲属称谓的古今演变

## 一、释义

亲属称谓随家庭结构、社会制度与语言变迁而更替：或改雅、或趋俗、或合并、或消亡。

| 今称 | 古称 | 演变 |
| --- | --- | --- |
| 父亲 | 考、严亲、大人 | 「爹／爸」取代书面「考」 |
| 母亲 | 妣、慈亲 | 「娘／妈」通行 |
| 岳父 | 外舅 | 宋元后「岳父」取代 |
| 妻之母 | 外姑 | 「岳母」取代 |
| 夫之兄 | 兄公 | 「大伯子」通俗化 |
| 堂兄弟 | 从父兄弟 | 「堂」取代「从」 |
| 表兄弟 | 外兄弟 | 「表」统一 |
| 媳 | 子妇 | 「媳妇」通行 |

**两大趋势**：一是书面雅称为口语音称所取代；二是世次称谓随宗族瓦解而收缩，今人普遍只知曾祖以下。

## 二、历史源流

- **先秦**：《尔雅·释亲》确立古典称谓体系。
- **汉唐**：以「外舅」「外姑」「兄公」等为正式称谓。
- **宋元**：市井口语称谓（丈人、岳父、老公）上升为通行称谓。
- **明清**：家礼与族谱并行，称谓呈雅俗两套系统。
- **近现代**：宗族解体、普通话推广与独生子女家庭，使称谓大幅简化。

## 三、仪节流程

1. **辨新旧**：依文书性质选用古今称谓（讣告用古雅称，日常用今称）。
2. **定层级**：宗族场合用世次称谓，日常用口语称谓。
3. **记录口述**：田野调查须记录不同年龄层的称谓差异。
4. **标注变迁**：族谱续修时注明今昔称谓对应关系。
5. **存古**：祠堂与祭祀场合保留古称（如「显考」「显妣」）。

## 四、地域与民族变体

- **城市**：多用「爸」「妈」「岳父」「岳母」。
- **乡村**：保留「爹」「娘」「丈人」等旧称。
- **闽粤、客家**：保留大量古称（家姐、细佬、阿婆）。
- **少数民族**：本族称谓与汉语称谓并用，代际差异明显，须分别记录。

## 五、器物与文书

- **文书**：族谱、讣告（用「显考」「先妣」等古称）、祭文。
- **器物**：神主牌位（古称用字）。
