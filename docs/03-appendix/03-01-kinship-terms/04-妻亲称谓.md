# 妻亲称谓（姻亲）

## 一、释义

妻亲（姻亲）指因婚姻连带产生的亲属，含妻族与夫族两面。

| 关系 | 称谓 |
| --- | --- |
| 妻之父 | 岳父（泰山、丈人） |
| 妻之母 | 岳母（泰水、丈母娘） |
| 妻之兄／弟 | 内兄／内弟（大舅子、小舅子） |
| 妻之姊／妹 | 大姨子／小姨子（姨姐、姨妹） |
| 兄之妻／弟之妻 | 嫂／弟妇（妯娌互称） |
| 姊妹之夫 | 姐夫／妹夫（连襟，俗称「一担挑」） |
| 女之夫 | 女婿（谓「半子」） |
| 子之妻 | 媳妇（儿媳） |
| 两姻亲之家长 | 亲家、亲家公、亲家母 |

## 二、历史源流

- 《尔雅·释亲》「妻党」「婚姻」两篇载妻族称谓（外舅、外姑等）。
- 汉唐以「外舅」「外姑」为妻父母正称，宋元以降「岳父」「岳母」渐行。
- 「泰山」之称出唐段成式《酉阳杂俎》所载玄宗封禅故事。
- 明清以降「丈人」「丈母」通俗化，今多并用「爸」「妈」。
- 当代姻亲称谓趋于简化，「亲家」仍为通用互称。

## 三、仪节流程

1. **议亲**：媒人往来说合，双方家长互称「亲家」。
2. **行礼**：下聘、迎娶时姻亲互送「姻礼」。
3. **改口**：婚后新妇改称夫之父母为「爸」「妈」，婿亦如之。
4. **认亲**：婚后「认亲」「走亲」，姻亲依序拜访。
5. **往来**：年节、生育、丧葬时姻亲往来有定则，谓之「姻亲不废」。

## 四、地域与民族变体

- **华北**：女婿称「姑爷」，视同半子。
- **江南**：姻亲往来讲究「走亲」节令。
- **闽粤**：以「外家」为重，婚宴设「外家席」。
- **少数民族**：入赘婚（门巴、布朗、德昂等）中夫居妻家，妻族称谓占据主导，须分别记录。

## 五、器物与文书

- **文书**：婚书、礼单、请柬（署「姻弟」「眷弟」等）。
- **器物**：聘礼与嫁妆（姻亲往来的实体凭证）。
