# 外亲称谓（母族）

## 一、释义

外亲指母族亲属（母之父母、兄弟、姊妹及其子女）以及出嫁姊妹夫家所涉亲属。其称谓多冠「外」「表」字，以别于宗亲。

| 亲属 | 称谓 | 己身之称 |
| --- | --- | --- |
| 母之父 | 外祖父（外公、姥爷） | 外孙 |
| 母之母 | 外祖母（外婆、姥姥） | 外孙 |
| 母之兄弟 | 舅父（舅舅） | 外甥 |
| 母之姊妹 | 姨母（姨妈） | 姨甥 |
| 舅父之子女 | 舅表兄弟姊妹 | 表兄弟姊妹 |
| 姨母之子女 | 姨表兄弟姊妹 | 表兄弟姊妹 |
| 姊妹之子女 | 外甥、外甥女 | 舅、姨 |

**「表」与「堂」之别**：同祖父者为「堂」，不同祖父而相涉者为「表」；故舅表、姨表、姑表统称「表亲」。

## 二、历史源流

- 《尔雅·释亲》以「母党」一篇专载外亲称谓（外王父、外王母、舅、从母等）。
- 五服中外亲服制最轻：外祖父母服小功，舅、姨服缌麻；唐《开元礼》略有加隆。
- 明清以后外亲服制更轻，民间却因「舅权」而厚其礼。
- 当代独生子女家庭中外祖父母称谓（外公、姥姥）使用频繁，实际地位上升。

## 三、仪节流程

1. **认亲**：初次相见依母族序次称呼，先舅后姨。
2. **行礼**：婚丧时外亲致送「外礼」，位次列于宗亲之后。
3. **分「表」「堂」**：婚宴座次与请柬署名须分「堂」「表」。
4. **称谓递变**：舅表、姨表成婚后，其配偶称「表嫂」「表弟妇」。
5. **舅权场合**：西南地区婚丧中舅父主礼（见「地域与民族变体」）。

## 四、地域与民族变体

- **华北**：冠「表」为常，「姑表亲」最重。
- **西南民族（彝、纳西、普米、怒、阿昌）**：舅权显著，舅父于婚丧居主位，外甥婚配须征舅同意。
- **闽粤**：外家（娘家）于议婚时话语权较大。
- **须分别记录**：各民族以舅权为核心的外亲称谓体系与汉制不同源。

## 五、器物与文书

- **文书**：请柬、礼单（分列「堂」「表」）。
- **器物**：外家致送的礼担、喜幛。
