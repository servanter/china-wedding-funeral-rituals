# 悼词与哀启范本

## 一、释义

**悼词**于追悼会（告别仪式）上宣读，述亡者生平行谊、表达哀思，兼有告慰亲属之意。**哀启**（或称「行状」）为详述亡者生平事略之文，供撰墓志、祭文之取材，随讣告发送亲友。

**区别**：悼词重情，口语宣读；哀启重事，书面传世。

## 二、历史源流

- 古代以「诔」（累列德行以定谥）、「哀辞」为追述亡者之文。
- 汉魏有「行状」，为请谥、撰传所据。
- 明清讣闻附哀启之俗流行。
- 民国以来追悼会制度确立，悼词成为通用文体。

## 三、仪节流程

1. **撰文**：家属或治丧机构撰悼词、哀启。
2. **审定**：会前送家属审定事实与称谓。
3. **默哀**：追悼会开始，全体默哀。
4. **宣读**：由主祭或单位代表宣读悼词。
5. **家属答谢**：家属代表致答谢词。
6. **归档**：哀启与人名簿一并存档。

## 四、地域与民族变体

- **城市**：悼词多由单位或殡仪服务机构代撰，格式统一。
- **乡村**：仍以读祭文、行三献礼为主。
- **少数民族**：多以本族祭词、挽歌表达哀思（如壮族「哭丧歌」、哈尼族「送葬调」），须分别记录。

## 五、器物与文书

- **文书**：悼词、哀启、行状、祭文、挽联。
- **器物**：遗像、灵位、哀乐设备、人名簿。

**范式示例（悼词）**：

```text
各位亲友、各位来宾：

  今天，我们怀着无比沉痛的心情，
  在此送别 〇〇〇 先生（女士）。

  〇〇〇 先生（女士）〇年〇月〇日生于〇〇，
  〇年〇月〇日〇时〇分因病逝世，享年〇〇岁。
  他（她）一生勤勉笃实，待人诚恳，
  对家庭尽责，对乡邻友善，为后辈之表率。

  斯人已逝，音容宛在。
  愿 〇〇〇 先生（女士）一路走好！
  望家属节哀顺变，保重身体。

  〇〇〇〇年〇月〇日
```
