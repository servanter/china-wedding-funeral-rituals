# 庚帖（八字帖）范本

## 一、释义

庚帖又称「八字帖」「年庚帖」「龙凤帖」，书男女双方生辰八字（年、月、日、时之干支）以付合婚。男家所出称「男庚」或「乾造」，女家所出称「女庚」或「坤造」。庚帖一经交换，即称「换帖」，婚事遂有凭据。

**格式**：红笺，右起直书；上列籍贯、姓名、行第，中列生辰四柱，下列年月日与具名。

## 二、历史源流

- 《仪礼·士昏礼》有「问名」，即问女子之名与生辰以归卜吉凶，为庚帖之源。
- 唐代敦煌书仪中已见「通婚书」与年庚格式。
- 宋元以降，「换庚帖」「合八字」成为定婚前置程序。
- 明清以木版刻印龙凤帖式，随类书流行，格式趋于统一。

## 三、仪节流程

1. **男家具帖**：男家先书男庚，装入帖匣。
2. **媒氏传送**：请媒人送至女家。
3. **女家回帖**：女家书女庚回覆。
4. **合婚**：请日者（算命者）推算双方八字之生克宜忌。
5. **得吉定亲**：卜得吉兆，即行「换帖」定亲。
6. **不合退帖**：卜之不吉，婉辞退回，另议。

## 四、地域与民族变体

- **华北**：庚帖多直书四柱，附籍贯、三代。
- **江南**：帖上加龙凤、八卦纹，讲究双帖对开。
- **闽粤**：写「大吉」「天作之合」于帖端。
- **少数民族**：多不通用庚帖，而以占卜、对歌或族内仪式定婚，须分别记录。

## 五、器物与文书

- **庚帖**：红笺、龙凤纹、泥金；装入帖匣。
- **配套文书**：婚书、礼单。
- **器物**：帖匣、笔墨。

**范式示例**：

```text
乾造  〇年〇月〇日〇時  建生
坤造  〇年〇月〇日〇時  瑞生
```
