# 讣告范本

## 一、释义

讣告又称「讣闻」「讣帖」，为告知亲友丧事之文书。内容包含亡者名讳、身份、生卒年月日时、享年、治丧日程（入殓、开吊、出殡、安葬）与亲属署名。亲属署名须依服制用「孤子」「哀子」「孤哀子」等自称。

| 自称 | 适用 |
| --- | --- |
| **孤子** | 父亡而母在 |
| **哀子** | 母亡而父在 |
| **孤哀子** | 父母俱亡 |

## 二、历史源流

- 《礼记·檀弓》载「讣于君」「讣于乡」之礼，报丧须及时而有序。
- 汉魏以降，报丧以口传为主，兼用简牍。
- 明清讣闻格式定型，白纸直书，「讣」字居首，亲属署名严整。
- 民国以后增「哀启」「行状」，今有电子讣告（见「现代电子讣告与追思函」条）。

## 三、仪节流程

1. **定丧主**：立丧主、主妇与治丧班子。
2. **具讣告**：撰讣闻，标名讳、生卒、享年、治丧日程。
3. **署名**：孝子、孝女、孝孙依服制依长幼列名。
4. **投送**：分送亲友、邻里与单位。
5. **张贴**：于宅门或公共场所张贴。
6. **答谢**：丧毕具谢帖（见「谢帖与答谢启范本」条）。

## 四、地域与民族变体

- **华北**：讣闻简略，重口头通知。
- **江南**：讣闻详载行状，附哀启。
- **闽粤**：白纸黑字，讲究「讣」字书法。
- **少数民族**：多以鸣枪、吹号、击鼓、专人报丧等方式告知，纸讣为后起，须分别记录。

## 五、器物与文书

- **文书**：讣告、哀启、行状、谢帖。
- **器物**：白纸、素封、讣告牌。

**范式示例**：

```text
              訃  聞

  先父〇公諱〇〇，因病醫治無效，
  於〇年〇月〇日〇時〇分  壽終正寢，
  享年〇〇歲。
  謹擇於〇月〇日〇時入殮，
  〇月〇日〇時開吊，
  〇月〇日〇時出殯安葬於〇〇。

  謹此訃聞

                孤子  〇〇  泣血謹告
                孝女  〇〇
                孝孫  〇〇

                      〇年〇月〇日
```
