# 墓碑文与墓志铭范本

## 一、释义

**墓碑文**立于墓前，题亡者姓氏、讳名、生卒、享年与立石子孙，文辞简短。**墓志铭**埋于墓中（或置于墓侧），含「志」（散文，叙世系、生平、卒葬）与「铭」（韵语，致哀颂德）两部分，古称「埋铭」。

**格式**：碑文居中一行题名讳，两侧记生卒与立石人；墓志首题讳字、世系，次叙生平，末系铭辞。

## 二、历史源流

- 汉代立碑之俗大兴，碑文多由名手撰书。
- 魏晋禁厚葬立碑，遂有埋志于墓中之风，墓志铭由此而盛。
- 唐宋墓志极盛，韩愈、欧阳修等皆有撰作，文体渐定。
- 明清墓碑、墓志沿用旧体，形制与行款整齐化。

## 三、仪节流程

1. **撰志**：由亲属或托人撰墓志、碑文。
2. **书丹**：请善书者以朱墨书于石上。
3. **刻石**：刻工依书丹镌刻。
4. **择日立碑**：依择日立碑、覆土。
5. **祭告**：立碑后设馔祭告。
6. **存拓**：拓片留存，收入族谱或家集。

## 四、地域与民族变体

- **华北**：碑文简略，重生卒与子孙。
- **江南**：墓志长篇，文辞典雅。
- **闽粤**：碑上加「显考」「显妣」与郡望。
- **少数民族**：有立石堆、刻木、悬幡等标记方式，亦有借用汉式碑制者，须分别记录。

## 五、器物与文书

- **文书**：墓碑文、墓志铭、行状、哀启。
- **器物**：碑石、志盖、志石、朱墨、拓包、拓纸。

**范式示例（墓碑文）**：

```text
            顯考〇公諱〇〇之墓

  公生於〇年〇月〇日，卒於〇年〇月〇日，
  享年〇〇歲。
  葬於〇〇山之陽，坐〇向〇。

        孝子  〇〇  孝女  〇〇
        孝孫  〇〇        立石

              〇年〇月〇日
```

**范式示例（墓志铭）**：

```text
【志】
  公諱〇〇，〇〇人。曾祖諱〇，祖諱〇，父諱〇。
  公性淳厚，勤於治家，鄉里稱善。
  娶〇氏，生男二、女一。
  以〇年〇月〇日卒，享年〇〇，葬於〇〇。

【銘】
  山高水長，德音不忘；
  勒石幽宮，永示後昆。
```
