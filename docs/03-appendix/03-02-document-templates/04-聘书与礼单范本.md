# 聘书与礼单范本

## 一、释义

聘书为纳征（下聘、过大礼）时所具之书，表明「纳币以成婚礼」之意。礼单（又称「礼目」「妆奁单」「回帖单」）逐项开列聘礼与回礼之名目、数量，为财物往来之凭。

**格式**：礼单直书右起，逐条列举，末记总成与具名；聘书冠「伏以」、末系年月与具名。

## 二、历史源流

- 《仪礼·士昏礼》纳征用「玄纁束帛、俪皮」，为聘礼中最重之节，然无礼单。
- 汉唐以降，士庶婚嫁财礼渐丰，遂有开列名目之需。
- 宋代「下财礼」「回盘」并具礼单，见《东京梦华录》所载。
- 明清日用类书刊载礼目范文，「四色礼」「八色礼」等名目定型。

## 三、仪节流程

1. **议定礼目**：两家先议财礼多寡与回礼名目。
2. **具礼单**：男家开列聘礼清单，誊清备用。
3. **写聘书**：具聘书一函，说明纳征之意。
4. **送礼**：由媒人引送，礼担依单点验。
5. **女家回帖**：女家受礼，具回帖（谢帖）并回赠礼物。
6. **存档对账**：礼单双方各存一份，以备日后核对。

## 四、地域与民族变体

- **华北**：讲究「四色礼」（酒、肉、面、糖），礼单简略。
- **江南**：礼担称「盘担」，讲究「盘」数，礼目细密。
- **闽粤**：称「过大礼」，礼单用红笺直书，外加「回礼」单。
- **少数民族**：多以实物当场交付，以歌代言；如以刻木、结绳记数者，须分别记录。

## 五、器物与文书

- **文书**：聘书、礼单、回帖。
- **器物**：礼担、食盒、红纸、笔墨。

**范式示例（礼单）**：

```text
謹具 聘禮 開列於後：
  喜餅      〇〇斤
  酒        〇〇罈
  豬肉      〇〇斤
  綢緞      〇疋
  金飾      成對
  茶葉      〇〇包
  右具 呈
  〇府 尊親家 收執
            某 謹具
```

**范式示例（聘书）**：

```text
伏以  婚姻之禮，納幣為重。
今具不腆之儀，敬獻  尊府，
以成  兩姓之好。
伏惟  鑒納。
       〇年〇月〇日  某 謹具
```
