# 祭文范本

## 一、释义

祭文为祭奠亡者或祭祀神灵时所读之文。按场合分家祭文、公祭文、时祭文、忌日祭文；按文体多为散文，或四言、骚体、骈体。其要在于述德、叙哀、致奠。

**格式**：首书「维〇年〇月〇日」，次书主祭人（孝子／某）与祭品（清酌庶羞之奠），再叙亡者名讳与哀情，末系「尚飨」。

## 二、历史源流

- 《仪礼·士丧礼》《既夕礼》有「祝」辞与「读赗」「读遣」之仪，为祭文之祖。
- 汉魏盛行「哀辞」「吊文」，潘岳《哀永逝文》著称。
- 唐宋韩愈《祭十二郎文》、欧阳修《祭石曼卿文》为散文祭文典范。
- 《朱子家礼》定家祭「三献礼」读祭文之节，明清沿用。

## 三、仪节流程

1. **具文**：先期撰具祭文，楷书誊清。
2. **设馔**：陈设供品、香烛。
3. **上香**：主祭上香、跪拜。
4. **三献**：初献、亚献、终献，各就位。
5. **跪读祭文**：主祭跪读，众属举哀。
6. **焚文**：读毕焚化，或与纸钱同焚。

## 四、地域与民族变体

- **华北**：多用四言，简短。
- **江南**：散文长篇，述事详尽。
- **闽粤**：保留骈体，掺方言韵语。
- **少数民族**：多以本族语言唱诵（如彝族的「指路经」、景颇族「送魂词」），与汉式祭文体系不同，须分别记录。

## 五、器物与文书

- **文书**：祭文、哀启、行状、挽联。
- **器物**：香案、供器、纸钱、焚文盆。

**范式示例（家祭文）**：

```text
維  〇年〇月〇日，孝子〇〇 謹以清酌庶羞之奠，
敢昭告於
   先考〇公諱〇〇 之靈前曰：

   嗚呼！先考棄養，忽已〇日。
   追惟平生，勤儉持家，孝友睦鄰，
   教誨子女，恩德難忘。
   今者靈前致奠，罄述哀忱，
   伏惟  鑒格。

   尚饗！
```
