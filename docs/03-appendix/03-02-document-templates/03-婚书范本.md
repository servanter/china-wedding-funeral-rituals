# 婚书（龙凤帖）范本

![婚书范本（静物）/ A traditional marriage contract](../../../assets/images/13-marriage-contract-stilllife.png)


## 一、释义

婚书为定婚之凭，因常绘龙凤纹并称「龙凤帖」。订婚阶段所具者称「草帖」（小定），纳征阶段所具者称「定帖」（大定）。男家致女家者称「求书」，女家答男家者称「允书」，两方各执一纸，合成全璧。明清婚书具法律效力，为「定婚」要件。

## 二、历史源流

- 周代婚礼无婚书，而有媒氏通言之礼与「约」。
- 唐代婚书已见，敦煌书仪中存有「通婚书」「答婚书」格式。
- 宋《东京梦华录》载「下聘」「换帖」之仪，婚书渐成常制。
- 《大清律例》明定「男女定婚之初，各立婚书」，并规定悔婚罚则。
- 民国以后婚书改称「结婚证书」，今为法定婚姻登记。

## 三、仪节流程

1. **议定**：媒人往来，双方议定婚事与财礼。
2. **具草帖**：小定时先立草帖，示婚约初定。
3. **纳征立书**：行纳征礼时男女两家各具婚书。
4. **签押**：婚书具男妇（或婚主）姓名、媒人姓名，加印。
5. **交换**：两纸交换，各执为凭。
6. **存档**：与礼单、庚帖一并收存。

## 四、地域与民族变体

- **华北**：婚书文辞直白，重财礼数额。
- **江南**：多用骈体四六，讲究辞藻。
- **闽粤**：加「天作之合」等吉语，贴「囍」字。
- **少数民族**：多数民族传统上不以婚书为凭，而依习惯法、寨老与仪式认定婚约，须分别记录。

## 五、器物与文书

- **婚书**：红笺或龙凤纹笺，可贯以泥金、朱印。
- **配套**：庚帖、礼单、请柬。
- **器物**：帖匣、朱印、笔墨。

**范式示例（求书）**：

```text
伏以  秦晉聯姻，姻緣天定。謹憑媒氏，
敬求  令愛  為  某  之室。
仰祈  俯允，曷勝榮幸。
       〇年〇月〇日  某  謹具
```

**范式示例（允书）**：

```text
伏承  尊命，蒙媒氏說合，
許以  令郎  為  小女  之婿。
敬遵  台命，敢不祗從。
       〇年〇月〇日  某  謹具
```
