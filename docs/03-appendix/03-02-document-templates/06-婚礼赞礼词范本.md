# 婚礼赞礼词范本

## 一、释义

赞礼词又称「司仪词」「礼生赞词」，为婚礼各环节由司仪（通赞、引赞、礼生）唱赞之辞。其体多以四言、对句为主，讲究节奏朗朗、言辞吉祥，兼有指挥仪节行进与渲染气氛之用。

## 二、历史源流

- 《仪礼·士昏礼》设有「赞者」之职，佐主人行礼、传辞，为礼生之滥觞。
- 唐宋以降，家礼定「通赞」「引赞」分工，赞礼逐节唱名。
- 明清乡礼、祠堂礼中礼生赞礼极为讲究，类书载有赞词。
- 近现代司仪承袭礼生之职，赞词趋白话，仍保留「一拜天地」等套语。

## 三、仪节流程

赞词依婚仪时次第唱赞：

1. **启户迎亲**：「吉日良辰，喜气盈门，请新人入堂。」
2. **拜堂**：「一拜天地，再拜高堂，夫妻对拜，礼成。」
3. **合卺**：「同牢而食，合卺而饮，夫妇一体，永结同心。」
4. **撒帐**：「撒帐东，撒帐西，早生贵子，五男二女。」
5. **挑盖头**：「喜秤挑盖头，称心又如意。」
6. **礼成送客**：「礼成！敬请各位嘉宾入席。」

## 四、地域与民族变体

- **华北**：赞词简明，重在「喊礼」。
- **江南**：赞词典雅，多用四六。
- **闽台**：司仪以方言唱赞，掺吉祥俚语。
- **少数民族**：多以对歌、说唱与祭词代赞礼词（如苗族「接亲歌」、赫哲族「伊玛堪」），须分别记录。

## 五、器物与文书

- **文书**：赞礼仪注、执事单、礼单。
- **器物**：喜秤、合卺杯、撒帐果品。

**范式示例**：

```text
【入堂】
  吉日良辰，喜氣盈門；
  新人入堂，百福駢臻。

【拜堂】
  一拜天地，感天地之覆載；
  再拜高堂，謝父母之劬勞；
  夫妻對拜，結百年之好合。

【合卺】
  同牢而食，合卺而飲；
  夫婦一體，永結同心。

【禮成】
  禮成！恭請諸位嘉賓入席。
```
