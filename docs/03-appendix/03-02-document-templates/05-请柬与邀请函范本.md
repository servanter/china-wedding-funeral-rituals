# 请柬与邀请函范本

## 一、释义

请柬（俗称「喜帖」）为邀请宾客赴宴与会之帖。形式上分「单帖」（一人一纸）、「双帖」（对开）、「合帖」（数人共一帖）。婚宴请柬以外，丧事则有「报丧帖」。现代另有印刷邀请函、电子请柬。

**格式**：红笺直书右起，先书事由（谨订于……），次书地点，再「敬备喜筵 恭候 光临」，末署具名与日期。称谓须依尊谦规范（见「尊称与谦称」条）。

## 二、历史源流

- 宋代已有具名邀客之「帖子」，见《东京梦华录》所记筵会。
- 明清类书刊载各类帖式范文，请柬格式定型，讲究「帖必楷书、文必雅驯」。
- 民国以后西式邀请函传入，与中式帖式并行。
- 当代电子请柬普及，但正式场合仍重纸质帖式。

## 三、仪节流程

1. **拟具名单**：按亲疏、辈分排定邀请名单。
2. **定席次**：据名单排定座次与席位。
3. **写帖**：一帖一人或一户；称谓、行款依《书仪》规范。
4. **投送**：专人投送，忌请人转交；长辈须亲自登门送帖。
5. **收帖与回执**：受帖者或口头致意，或具回帖。

## 四、地域与民族变体

- **华北**：帖文简质，重口头再邀。
- **江南**：帖式雅致，多套封、烫金。
- **闽粤**：喜帖必「全红」，「合帖」可邀一家。
- **少数民族**：多以口头通知或以对歌、乐器通知（如吹芦笙通报），纸帖为后起，须分别记录。

## 五、器物与文书

- **文书**：请柬、报丧帖、回帖。
- **器物**：红笺、封套、烫金、帖匣。

**范式示例（传统请柬）**：

```text
        謹訂於  〇年〇月〇日（農曆〇月〇日）
        為  小兒  〇〇  完婚
        是日午刻  敬備喜筵
        恭候
        〇〇先生  闔第  光臨

                                某 〇〇 謹訂
```

**范式示例（现代邀请函）**：

```text
尊敬的〇〇先生／女士：
  谨定于〇〇〇〇年〇月〇日（星期〇）中午〇时，
  在〇〇酒店〇〇厅为  子〇〇  与  〇〇女士  举行婚礼，
  敬备喜筵，恭候光临。

                                  〇〇〇  敬邀
```
