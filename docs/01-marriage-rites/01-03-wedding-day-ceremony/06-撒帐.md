# 撒帐

## 一、释义

撒帐，是新婚夫妇入帐（入洞房坐帐）之后，众人向帐中抛撒枣、栗、花生、桂圆、莲子等物，并唱「撒帐歌」，以祝早生贵子、多子多福之俗。

其核心机制是**谐音祝吉**：枣谐「早」、栗谐「立」、桂圆谐「贵」、莲子谐「连子」，合为「早立贵子」「连生贵子」。

## 二、历史源流

- 撒帐之俗在唐宋已大盛。宋《东京梦华录·娶妇》记新婚夫妇「坐虚帐」时撒帐；《梦粱录·嫁娶》记以「五色纸钱、花果」撒帐。
- 宋代有专门的《撒帐歌》，以韵语唱出吉祝，可视为婚礼仪式歌的早期形态。
- 撒帐的前身有「撒谷豆」之俗：迎娶时以谷、豆撒于门前，用以「压青羊、乌鸡、青牛」三煞，属辟邪性质；后世「撒帐」则由辟邪转向祈嗣。
- 明清民间撒帐普遍，撒物因地而异；闽粤并撒铜钱、糖，兼有「撒钱」之意。
- 当代婚礼多以撒花瓣、撒彩纸、撒糖果替代，祝吉之意尚存。

## 三、仪节流程

1. **入帐**：新婚夫妇入洞房，坐于帐中（男左女右）。
2. **备果**：预先备枣、栗、花生、桂圆、莲子（或五谷、铜钱、糖）。
3. **撒帐**：由全福人（或亲友）向帐中抛撒，边撒边唱祝语。
4. **唱撒帐歌**：如「一撒金，二撒银，三撒早生贵子跳龙门」。
5. **拾果**：儿童争抢所撒之果，俗谓「抢喜果」得福。
6. **撤帐**：礼毕，新人合床安寝。

## 四、地域与民族变体

- **华北**：撒「枣、栗、花生」，讲究「成双成对」；有的地方并撒麦、谷。
- **江浙**：撒「枣、栗、桂圆、莲子」，唱撒帐歌，歌辞有固定句式。
- **闽台**：撒「糖、钱、米」，兼取「钱米丰足」之义。
- **广东**：撒「莲子、百合」（取「百年好合」）、红枣、花生。
- **少数民族**：部分民族有撒谷、撒水、撒米的祝吉仪式，但其对象多为神灵或祖先而非新人，意涵机制不同，须分别理解，不宜统称为「撒帐」。

## 五、器物与文书

- **枣、栗、花生、桂圆、莲子**：核心撒物。
- **五谷（麦、谷、黍、稷、稻）**：部分地区的撒物。
- **铜钱、糖**：闽粤等地的补充撒物。
- **帐、喜被、喜枕**：撒帐之所在。
- **撒帐歌辞**：口传韵语，部分地方有抄本。
