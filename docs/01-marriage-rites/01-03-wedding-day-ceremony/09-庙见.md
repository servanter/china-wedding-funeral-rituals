# 庙见（拜舅姑）

## 一、释义

「见舅姑」是新妇拜见公婆（舅姑）之礼；「庙见」是新妇随夫谒见家庙祖先之礼。二者相连而次序分明：

- **见舅姑**在婚后**次日**（《仪礼》：「质明，赞见妇于舅姑」）。
- **庙见**在婚后**三月**（《礼记·曾子问》：「三月而庙见，称来妇也」）。

礼制规定：**未庙见而死，则不成妇**——女方不被视为夫家的正式成员，葬与祭的规格都不同。可见庙见是「成妇」的法定仪式，其地位高于婚礼当日的一切仪节。

## 二、历史源流

- 《仪礼·士昏礼》：「夙兴，妇沐浴，𬘬笄，宵衣以俟见。质明，赞见妇于舅姑。」新妇以枣、栗献舅，以腶修（加姜桂的干肉）献姑。
- 《礼记·曾子问》记曾子问「三月庙见」之义，孔子答以「三月而庙见，称来妇也」，明确庙见是「称妇」的前提。
- 朱熹《家礼》把庙见改为婚后三日，理由是「三月太久」，反映了宋以后婚礼日程的压缩。
- 《清稗类钞》记各地「拜祖先」「见公婆」「分大小」等俗，皆为见舅姑与庙见的民间形态。
- 当代婚礼中「拜祖先」「敬茶改口」即此礼之遗留。

## 三、仪节流程

### 见舅姑（次日）

1. **新妇沐浴**：婚次日晨，新妇早起沐浴、束发加笄、着素服（「宵衣」）。
2. **赞者引见**：由赞者（引导者）引新妇至舅姑处。
3. **献贽**：献枣、栗于舅，献腶修于姑（均为贽见之礼）。
4. **舅姑礼妇**：舅姑以醴酒、菜肴款待新妇（「醴妇」「飨妇」）。
5. **妇馈舅姑**：新妇亲自为舅姑进食（「馈」，即奉食），表示承担妇职。
6. **舅姑飨妇**：舅姑以酒食回敬，礼成。

### 庙见（三月或三日）

1. **择日**：择吉日行庙见（《家礼》定为三日）。
2. **陈祭**：于家庙（或祠堂）陈设供品、香烛。
3. **告祖**：新妇随夫入庙，向祖先牌位行礼，宣读告祖之辞，正式「称来妇」。
4. **见族亲**：依次拜见族中尊长（详见「见亲戚与分大小」条）。
5. **入族**：新妇自此列为夫家族谱中的一员。

## 四、地域与民族变体

- **华北**：称「认亲」「分大小」「拜三代」，婚后次日或当日进行。
- **江浙**：称「见亲」「见大小」，讲究「敬茶改口」。
- **闽粤**：称「拜祖先」「告祖」，在正厅祖先牌位前举行，仪式隆重。
- **台湾**：婚后「拜祖先」为必行之礼，另有「舅姑赠金饰」之俗。
- **少数民族**：许多民族没有庙见制度（无家庙、无宗族祭祀制度），代之以本民族的「认亲」或宗教性仪式。如藏族婚后有「拜佛、拜长辈」之仪；傣族以「拴线」确认新人与家族的关系。其社会结构不同，庙见的「成妇」功能由其他机制承担。

## 五、器物与文书

- **枣、栗、腶修**：见舅姑时所献之贽。
- **醴酒、肴馔**：舅姑礼妇所用。
- **香烛、供品、祖先牌位**：庙见所用。
- **族谱**：新妇入族后可载于谱。
- **告祖之辞（祝文）**：庙见时诵读，详见「婚丧文书范本／祭祖祝文范本」条。
