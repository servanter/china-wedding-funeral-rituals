# 满月、百日与周岁礼

## 一、释义

婚后添丁，随之而来的是一系列**育儿礼**，是婚姻「传宗接代」功能的仪式确认。

| 仪节 | 时点 | 主要内容 |
| --- | --- | --- |
| **洗三** | 出生第三日 | 以艾水、槐条水为婴儿洗浴，亲友致贺 |
| **满月** | 出生一月 | 剃胎发（「剃满月头」）、「挪窝」（抱婴至外婆家）、宴客 |
| **百日** | 出生百日 | 拍照（「百天照」）、宴客、赠「长命锁」 |
| **周岁（抓周）** | 出生一岁 | 「抓周」（试儿）：陈列书籍、笔墨、算盘、秤、食物、玩具，以婴儿所取卜其志趣 |
| **命名、入谱** | 视家族而定 | 取名、按辈分入族谱 |

**核心观念**：「长命百岁」「多子多福」；「抓周」为最具象征意味的一节。

## 二、历史源流

- **南北朝**：《颜氏家训·风操》已有「试儿」（抓周）之记载，为最早文献之一。
- **唐宋**：洗三、满月、周岁之俗普及，笔记、方志载录渐多。
- **明清**：育儿礼定型，地方志「风俗」门详载「抓周」「剃头」「送长命锁」。
- **当代**：满月酒、百天照、周岁宴与抓周在城市与农村均普遍保留。

## 三、仪节流程

1. **洗三**：出生三日以药水洗浴，亲友致贺。
2. **满月**：剃胎发、抱婴见客、设宴（「满月酒」）；外婆家送「满月礼」。
3. **百日**：设宴、摄影、赠「长命锁」「手镯」。
4. **周岁抓周**：陈列诸物于盘，任婴儿抓取，众人围观道贺。
5. **入谱**：按族规取名、入族谱。

## 四、地域与民族变体

- **华北**：「满月酒」「百天」讲究，外婆家送「百家衣」「长命锁」。
- **江南**：有「剃头礼」「周岁宴」，抓周以书籍、笔墨为吉。
- **闽台**：「做满月」「做度晬」（周岁），并有「收涎」（四个月）之俗。
- **广东**：有「开灯」（男婴）、「百日」「对岁」之礼。
- **少数民族**：育儿礼形式各异（如命名礼、剃发礼、入族仪式），不属汉族之礼制系统，须分别记录。

## 五、器物与文书

- **器物**：长命锁、手镯、百家衣、抓周盘及陈列物（书、笔、算盘、秤、印章、食品）。
- **相关文书**：庚帖后续的「添丁报喜帖」「请帖（满月酒、周岁宴）」、族谱入谱记录。
