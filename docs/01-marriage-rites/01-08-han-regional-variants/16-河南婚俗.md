# 河南婚俗

## 一、释义

河南地处中原，婚俗被视为**保存古礼较多**的一类，以「提亲、换帖、定亲、娶亲」为骨干。主要特色：

1. **「换帖」（换庚帖）**——议婚核心程序。
2. **「压床」**——婚前请男童压床。
3. **「铺床」「撒帐」**——请全福人铺床、撒枣栗。
4. **「拜堂、坐帐、闹房」**——程序齐全。
5. **「回门」**——三朝归宁。
6. **「喜宴」排场大**——中原宴客之风较盛。

## 二、历史源流

- **北宋**：汴京婚俗载于《东京梦华录》，「换帖」「坐帐」之俗可考。
- **明清**：方志「风俗」门详载婚仪。
- **当代**：酒店婚礼与乡村宴席并行，旧俗留存。

## 三、仪节流程

1. 提亲、合婚、换帖。
2. 定亲（过小礼）。
3. 过礼（大聘、礼单）。
4. 铺床、压床。
5. 娶亲：花轿鼓乐，拜堂、坐帐、闹房。
6. 回门。

## 四、地域与民族变体

- **豫东（开封、商丘）**：近山东、安徽，礼数相类。
- **豫西（洛阳、三门峡）**：近陕西，礼数古厚。
- **豫南（南阳、信阳）**：近湖北，兼有楚俗影响。
- **豫北（安阳、新乡）**：近河北。
- **各民族**：河南回族婚俗（郑州、开封、南阳）自成体系，须分别记录。

## 五、器物与文书

- **器物**：花轿、龙凤烛、盖头、喜秤、嫁妆箱笼、喜被。
- **文书**：庚帖、礼单、请柬、婚书。
