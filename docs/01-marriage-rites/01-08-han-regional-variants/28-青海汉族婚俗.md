# 青海汉族婚俗

## 一、释义

青海汉族集中于**河湟地区（西宁、海东）**，多为明代江南、江淮移民后裔，婚俗保存明代原籍遗风，又受藏、回、土、撒拉等族影响。主要特色：

1. **「提亲—定亲—过礼—娶亲」**——程序清楚，近明代江南做法。
2. **「社火」与婚事**——河湟「社火」民俗与婚庆活动同属村落公共生活。
3. **「坐帐」「闹房」**——程序齐全。
4. **「回门」**——三朝归宁。
5. **多民族杂居影响**——宴席食俗受回、藏族影响（如奶茶、手抓肉）。

## 二、历史源流

- **明代**：洪武年间移民实边（江南、江淮军民入青），带来原籍婚俗与「社火」传统。
- **明清**：方志（西宁府志、各县志）「风俗」门载婚仪。
- **当代**：城居婚礼为主，农村保留旧礼与社火民俗。

## 三、仪节流程

1. 提亲、合婚。
2. 定亲（换帖）。
3. 过礼（聘礼、礼单）。
4. 娶亲：花轿鼓乐，拜堂、坐帐、闹房。
5. 回门。
6. 会亲。

## 四、地域与民族变体

- **西宁、海东（河湟）**：汉族集中，明代移民习俗明显。
- **湟中、大通**：与藏族村落相邻，兼有藏俗影响。
- **海西、海南**：汉族人口较少，多与蒙古、藏族杂居。
- **各民族**：藏族、回族、土族、撒拉族婚俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：花轿、龙凤烛、盖头、嫁妆箱笼。
- **文书**：庚帖、礼单、婚书、族谱。
