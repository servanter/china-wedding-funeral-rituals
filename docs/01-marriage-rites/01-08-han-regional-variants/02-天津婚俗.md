# 天津婚俗

## 一、释义

天津婚俗承华北礼制，又有**码头商埠的排场风格**，讲究「热闹」「体面」。主要特色：

1. **「说媒」「换帖」**——媒人说合，互换庚帖（「换帖」）。
2. **「过礼」（「大帖」「小帖」）**——男家送聘礼，礼单列明。
3. **「催妆」**——婚前一日男家送「催妆礼」（衣物、首饰、食品），催促女家备嫁。
4. **「大娶」「小娶」**——大娶用花轿鼓乐全套；小娶从简。
5. **「迎娶—拜堂—坐帐—闹房」**——程序齐全，坐帐「撒帐」用枣栗。
6. **「回四」**——婚后四日回门（天津称「回四」）。

## 二、历史源流

- **明清**：天津为漕运枢纽、盐业中心，商民富庶，婚礼竞奢。
- **清末民国**：租界与华界并存，西式婚礼与新式婚礼在此较早出现。
- **当代**：以酒店婚礼为主，旧礼在婚俗展演与郊县留存。

## 三、仪节流程

1. **议婚**：说媒、合婚。
2. **换帖**：互换庚帖定亲。
3. **过礼**：送聘礼、礼单。
4. **催妆**：婚前一日送催妆礼。
5. **迎娶**：花轿鼓乐，行三拜礼，坐帐。
6. **回四**：婚后四日回门。

## 四、地域与民族变体

- **老城厢**：旧礼讲究，程序齐备。
- **滨海（塘沽、汉沽）**：渔盐业者婚俗，兼有海事色彩。
- **蓟州、宝坻等郊县**：近京畿农村习俗。
- **各民族**：天津回族婚俗（宗教仪式、证婚）与汉族不同，须分别记录。

## 五、器物与文书

- **器物**：花轿、锣鼓、龙凤烛、盖头、喜秤、嫁妆箱笼。
- **文书**：庚帖、礼单、请柬、婚书。
