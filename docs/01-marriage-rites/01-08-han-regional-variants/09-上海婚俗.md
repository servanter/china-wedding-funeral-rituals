# 上海婚俗

## 一、释义

上海婚俗由**本地（松江、嘉定、浦东）习俗**与**移民（宁波、苏北、广东）习俗**叠合，近代又受都市化塑造，形成「**海派婚俗**」。主要特色：

1. **「拿八字」「定亲」「过门」**——议婚至迎娶程序清楚。
2. **「三朝回门」**——婚后三日回门。
3. **「吃喜酒」**——婚宴称「吃喜酒」，排场与礼数讲究。
4. **近代「文明结婚」**——20 世纪初上海率先出现新式婚礼（证婚、交换戒指、鞠躬礼）。
5. **「会亲」「认亲」**——双方亲族相见，确立姻亲。

## 二、历史源流

- **明清**：上海县、松江府婚俗载于方志。
- **近代开埠后**：会馆承办同乡婚事；报刊征婚、文明结婚、教堂婚礼并见。
- **当代**：酒店婚礼、婚纱摄影为主，旧礼在中式婚礼中复原。

## 三、仪节流程

1. **议婚**：媒人提亲，拿八字合婚。
2. **定亲**：过小定、大定（首饰、聘礼）。
3. **过门（迎娶）**：花轿或喜车迎娶，拜堂、坐帐、闹房。
4. **吃喜酒**：设宴款待宾客。
5. **三朝回门**：归宁省亲。
6. **会亲**：双方亲族相见认亲。

## 四、地域与民族变体

- **市区**：海派婚俗，仪节简约，酒店婚礼为主。
- **浦东、松江、嘉定**：本地习俗保留较多。
- **郊县（青浦、金山）**：兼有苏州、嘉兴习俗影响。
- **各民族**：上海回族婚俗（宗教仪式）自成体系，须分别记录。

## 五、器物与文书

- **器物**：花轿、龙凤烛、盖头、喜秤、嫁妆箱笼、婚戒（近代）。
- **文书**：庚帖、礼单、请柬、婚书、婚约（近代「文明结婚」证书）。
