# 云南汉族婚俗

## 一、释义

云南汉族多为**明初屯垦移民后裔**，婚俗保存明代江南、江西遗风，又与云南多民族环境交融。主要特色：

1. **「六礼」遗意**——提亲、定亲、过礼、迎娶清楚。
2. **「洞经会」奏乐**（大理、昆明一带）——婚礼中请洞经会奏乐（兼具儒道色彩）。
3. **「哭嫁」**——部分地区女子出嫁前哭嫁。
4. **「迎娶、拜堂、坐帐」**——程序齐备。
5. **「回门」**——三朝归宁。
6. **「六合同春」式宴席**——婚宴规模大，宴客礼数讲究。

## 二、历史源流

- **明初**：大军入滇并屯垦，江南、江西、湖广移民定居，带来原籍婚俗。
- **明清**：方志（云南通志、各府州县志）详载婚仪；洞经会在婚丧仪中承担奏乐。
- **当代**：城居婚礼为主，农村保留旧礼与洞经乐传统。

## 三、仪节流程

1. 提亲、合婚。
2. 定亲（换帖、过礼）。
3. 哭嫁（婚前）。
4. 迎娶：花轿鼓乐（或洞经乐），拜堂、坐帐。
5. 回门。
6. 会亲。

## 四、地域与民族变体

- **滇中（昆明、玉溪）**：洞经乐与传统礼俗并行。
- **滇东北（昭通、曲靖）**：近贵州、四川，习俗相类。
- **滇西（大理、保山）**：多民族杂居，汉族婚俗受白、彝、回族影响。
- **滇南（红河、文山）**：兼有壮、苗、瑶族习俗影响。
- **各民族**：白、彝、哈尼、傣、苗、壮等族婚俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：花轿、龙凤烛、盖头、嫁妆箱笼、洞经乐器。
- **文书**：庚帖、礼单、婚书、族谱。
