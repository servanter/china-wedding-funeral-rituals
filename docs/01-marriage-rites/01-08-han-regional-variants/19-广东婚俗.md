# 广东婚俗

## 一、释义

广东三大民系（**广府、潮汕、客家**）婚俗各有面貌，共同点是**宗族参与、「三书六礼」遗意完整**。主要特色：

1. **「三书六礼」遗意**——议婚、定亲、行聘、迎娶程序分明。
2. **「上头」**——婚前为新郎、新娘「上头」（梳髻、开面），为要紧环节。
3. **「过大礼」**——送聘礼（礼饼、海味、三牲、金饰）。
4. **「大妗姐」**——婚礼随行协助的女性（兼具礼生之职）。
5. **「回门（三朝）」**——婚后三日归宁；并以「烧猪」回门（视为贞洁与否的标志，今渐变）。
6. **「谢媒」与「利是」**——婚嫁往来以「利是」（红包）为常。

## 二、历史源流

- **唐宋**：中原与闽赣移民南下，广府、潮汕、客家族群在宋明间定型。
- **明清**：宗族祠堂、族产发达；方志与族谱详载婚仪。
- **近代**：港澳与南洋往来密切，婚俗杂糅中西。
- **当代**：酒店婚礼与中式仪式结合，「过大礼」「上头」仍普遍。

## 三、仪节流程

1. **议婚（说媒、合八字）**。
2. **定亲（文定、过文定）**：送聘礼、礼饼。
3. **上头**：婚前择吉时为新人梳头开面。
4. **迎娶**：花轿或喜车，拜堂、敬茶。
5. **回门**：三朝归宁，携「烧猪」等礼。
6. **谢媒**：以「媒人利是」与礼饼致谢。

## 四、地域与民族变体

- **广府（广州、佛山、东莞）**：三书六礼遗意完整，「大妗姐」随行。
- **潮汕（汕头、潮州、揭阳）**：婚仪隆重，出殡式仪仗亦见其礼俗之盛。
- **客家（梅州、惠州、河源）**：宗族主持，重视族谱与祭祖。
- **雷州半岛、粤西**：兼有闽南与本土色彩。
- **各民族**：广东瑶族、壮族、畲族婚俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：花轿、礼饼、金饰、龙凤褂、上头用具（梳、红绳）、烧猪。
- **文书**：庚帖、礼单（过大礼单）、婚书、族谱。
