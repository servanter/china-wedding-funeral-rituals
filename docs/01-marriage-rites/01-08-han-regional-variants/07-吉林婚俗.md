# 吉林婚俗

## 一、释义

吉林汉族以**闯关东移民后裔**为主体，婚俗属**东北型**，与辽宁、黑龙江基本一致。主要特色：

1. **「提亲—换帖—过礼—娶亲」**——程序承鲁冀。
2. **「离娘肉」与「催妆」**——实物礼俗齐备。
3. **「搭棚摆席」**——院落搭棚设宴，宴客规模大。
4. **「压床」「坐帐」「闹房」**——程序齐全。
5. **「回门」**——三朝回门。
6. **朝汉杂居影响**——部分汉族婚俗在服饰、食俗上受朝鲜族影响。

## 二、历史源流

- **清**：吉林中期以后鲁冀移民渐入；清末放荒，汉族人口猛增。
- **民国**：农业垦殖，村落定型，婚俗与辽宁、黑龙江趋同。
- **当代**：城居婚礼以酒店宴席为主，乡村保留旧礼。

## 三、仪节流程

1. 提亲、合婚。
2. 换帖定亲。
3. 过礼（聘礼、离娘肉）。
4. 催妆（婚前送衣物）。
5. 娶亲（花轿或车马），拜堂、坐帐、闹房。
6. 回门（三朝）。

## 四、地域与民族变体

- **中部（长春、吉林）**：城居婚俗近代化较早。
- **东部（延边、通化）**：朝汉杂居，汉族婚俗受朝鲜族影响。
- **西部（白城、松原）**：近内蒙古，兼有蒙汉交融痕迹。
- **各民族**：朝鲜族、满族、蒙古族、回族婚俗自成体系，须分别记录。

## 五、器物与文书

- **器物**：花轿或车马、龙凤烛、盖头、离娘肉、嫁妆箱笼。
- **文书**：庚帖、礼单、请柬、婚书。
