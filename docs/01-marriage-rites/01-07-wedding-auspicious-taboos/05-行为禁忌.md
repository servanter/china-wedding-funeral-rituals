# 婚礼行为禁忌（忌扇、忌伞、忌打破）

## 一、释义

婚礼行为禁忌以**谐音**与**象征**为依据，构成一整套「趋吉避凶」的规矩。

| 禁忌 | 缘由 |
| --- | --- |
| **忌扇扇子** | 「扇」谐「散」，忌「散」 |
| **忌打伞** | 「伞」谐「散」；亦忌「遮天」 |
| **忌打破器物** | 打碎碗碟为「破」，忌「破镜」「破家」 |
| **忌说「散」「离」「分」「完了」「没了」** | 语讳 |
| **忌中途歇轿（落轿）** | 「轿不落地」，落地不吉 |
| **忌新娘回头张望** | 「回头」主「退婚」之说 |
| **忌踩门槛** | 门槛为「门限」，忌「过不去」 |
| **忌空房** | 新婚夜忌新房无人（「不空房」） |
| **忌孕妇坐婚床、忌丧服者入新房** | 忌「冲喜」 |
| **忌吹灭喜烛** | 吹灭为「断」 |
| **忌用单数** | 单数为「孤」，故礼物、件数成双 |

**化解**：若不慎打破器物，须说「岁岁（碎碎）平安」以解；忌语出口则「呸呸」以解。

## 二、历史源流

- **唐宋**：婚俗语讳与谐音禁忌见于笔记。
- **明清**：方志「风俗」门详载婚礼禁忌，形成体系。
- **近代**：部分禁忌淡化，但「忌扇」「忌伞」「忌打破」仍普遍。
- **当代**：城市婚礼保留语讳与「成双」讲究，其他禁忌多已不拘。

## 三、仪节流程

1. **整装**：忌用扇、伞，慎用药（部分地区忌「药」字）。
2. **上轿／上车**：忌踏门槛、忌回头。
3. **行进**：忌落轿、忌「走回头路」。
4. **入门**：跨火盆，忌踩门槛。
5. **洞房**：忌空房、忌吹烛、忌说不吉语。

## 四、地域与民族变体

- **华北**：忌「扇」「伞」最深，语讳普遍。
- **江南**：忌「散」音，礼品成双。
- **闽台**：忌「四月」（死月）、忌「伞」。
- **少数民族**：各族婚礼禁忌内容不同（忌特定食物、忌特定人入内），须分别记录。

## 五、器物与文书

- **相关器物**：火盆、红毡、喜烛。
- **文书**：喜帖、礼单（礼品以双数记）。
- **文献依据**：各省地方志·风俗志、《玉匣记》。
