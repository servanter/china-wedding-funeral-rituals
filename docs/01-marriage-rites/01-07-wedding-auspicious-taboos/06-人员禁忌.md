# 婚嫁人员禁忌（孕妇、寡妇、属相相冲者）

## 一、释义

婚礼中某些人员因**身份、状态或属相**被认为不宜参与特定环节，须回避或另作安排。

| 人员 | 禁忌环节与缘由 |
| --- | --- |
| **孕妇（四眼人）** | 忌触及新娘嫁妆、忌坐婚床、忌入新房（「喜冲喜」） |
| **寡妇** | 忌充任「全福人」（铺床、缝被、扶新人） |
| **属相相冲者** | 上轿、下轿、进房时回避（见「属相冲克」条） |
| **「孝」服者** | 服丧期内者忌参加婚礼（「凶冲喜」） |
| **不洁者（身体不适、经期妇女）** | 部分地区忌其参与（旧说不一） |
| **「童男童女」** | 反而为吉：压床、提子孙桶、滚床多用孩童 |
| **「全福人」** | 需父母健在、夫妻和顺、儿女双全的妇女充任 |

**「全福人」的要求**是禁忌的正面表述：以「完美的人生状态」的人来充当礼仪执行者，借其「福气」加持新人。

## 二、历史源流

- **先秦以降**：婚礼助手的选择在礼俗中有讲究（《仪礼》有「老」与「姆」之职）。
- **明清**：方志多载「避四眼人」「请全福人」之俗。
- **近代**：医学观念普及后，孕妇禁忌之说渐淡。
- **当代**：婚礼避孕妇坐床等习俗在农村仍有留存；城市多不拘。

## 三、仪节流程

1. **选全福人**：婚前请全福人缝被、铺床、扶新人。
2. **避冲**：属相相冲者于上轿、下轿、进房时回避。
3. **避四眼**：孕妇不触嫁妆、不入新房（部分地区）。
4. **避孝服**：服丧者不参加婚礼。
5. **用童**：请童男童女「压床」「滚床」「提子孙桶」。

## 四、地域与民族变体

- **华北**：重「避四眼人」与「请全福人」。
- **江南**：铺床须请全福人；孕妇忌坐床。
- **闽台**：属相相冲者回避；「压床」用男童。
- **少数民族**：各族有不宣参与婚礼的人员规定（如特定亲属回避），须分别记录。

## 五、器物与文书

- **相关器物**：喜床、嫁妆、子孙桶。
- **文书**：婚书、礼单、执事单（列「全福人」等人名）。
