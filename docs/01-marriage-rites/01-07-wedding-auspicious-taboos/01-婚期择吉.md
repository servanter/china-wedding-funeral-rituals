# 婚期择吉（黄道吉日与周堂图）

## 一、释义

婚期择吉（「看日子」「择日」「拣日」）以**黄道吉日**为原则，并须避开与新人命理相冲之日。

**主要判定法**：

| 名目 | 内容 |
| --- | --- |
| **黄道／黑道** | 十二值日（建、除、满、平、定、执、破、危、成、收、开、闭）与六黄道（青龙、明堂、金匮、天德、玉堂、司命）之别 |
| **周堂图** | 以「夫、姑、堂、翁、第、皂、妇、厨」八卦位逐日推移，落在吉位（如「夫」「堂」「第」）为宜，忌落「翁」「姑」「妇」「皂」等位 |
| **吉日通例** | 通书标注「宜嫁娶」之日；忌「月破」「岁破」「四离四绝」「杨公忌」 |
| **时辰** | 迎娶多择辰时、巳时（上午），忌午后 |
| **「三书六礼」配日** | 纳采、纳征、请期、亲迎各择吉日 |

## 二、历史源流

- **汉代**：择日之术见于《日书》，婚嫁宜忌已具雏形。
- **唐宋**：通书、历日普及，择日成为婚仪通例。
- **清代**：《协纪辨方书》为官方择吉依据；《玉匣记》为民间常用通书。
- **近代**：通书（黄历）仍广泛使用。
- **当代**：城乡多查黄历择「宜嫁娶」之日，或选节假日、纪念日；婚礼公司与「选日子」服务并行。

## 三、仪节流程

1. **报生辰**：新人将出生年月日时报知择日者。
2. **推日**：以通书、周堂图推算，避冲、避破。
3. **开具日单**：「送日子帖」，送达女家。
4. **依期行礼**：各仪节依定日进行。
5. **变通**：若日期难避，行「化解」之法（贴符、择时避冲）。

## 四、地域与民族变体

- **华北**：多用《玉匣记》体系择日，讲究「周堂图」。
- **江南**：查黄历「宜嫁娶」，并择「黄道吉时」。
- **闽台**：「看日子」请择日馆，合「周堂」「嫁娶周书」。
- **少数民族**：各族择吉依据不同（如以本族历法、占卜、月相定婚期），不属汉族通书体系，须分别记录。

## 五、器物与文书

- **择吉依据**：《协纪辨方书》《玉匣记》、黄历通书、周堂图。
- **文书**：日子帖（婚期帖）、日单。
- **器物**：历书、罗盘（择方位）。
