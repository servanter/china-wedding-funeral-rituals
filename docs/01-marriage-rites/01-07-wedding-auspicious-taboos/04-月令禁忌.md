# 婚嫁月令禁忌（无春年、寡妇年）

## 一、释义

月令禁忌指依**年、月、节气的配合**判定婚嫁宜忌之说。

| 名目 | 内容 | 民间说法 |
| --- | --- | --- |
| **无春年（盲年、寡妇年）** | 农历全年无「立春」节气 | 忌婚嫁，谓不利 |
| **双春年** | 农历年内有两次立春 | 宜婚嫁，谓「双春双喜」 |
| **本命年** | 与本人属相相同之年 | 忌婚嫁或须「系红」化解 |
| **忌月** | 农历三月（清明）、七月（鬼月）、九月等 | 部分地区忌婚嫁 |
| **忌「四离四绝」** | 二分二至前后一日 | 忌婚嫁 |
| **忌「三娘煞」** | 每月初三、初七、十三、十八、廿二、廿七（说法不一） | 忌婚嫁 |

**「寡妇年」之说**：因农历与回归年差数造成某些年份无立春，民间附会为「寡年」，属**历法现象与民俗附会**，并无科学依据。

## 二、历史源流

- **汉代以降**：历法与择日之说结合，月令宜忌见于《日书》《月令》系统。
- **唐宋明清**：通书将「无春」「三娘煞」等纳入择吉体系。
- **近代**：报刊曾多次讨论「寡妇年不宜婚嫁」之说的无据。
- **当代**：仍有部分家庭避「无春年」办婚；亦有人以「双春年」为吉。

## 三、仪节流程

1. **查历**：查当年农历有无立春。
2. **择年**：避「无春年」，或选「双春年」。
3. **择月**：避开清明月、七月等忌月。
4. **择日**：避「三娘煞」「四离四绝」。
5. **化解**：如不便避让，行「系红」「择吉时」等化解。

## 四、地域与民族变体

- **华北**：「无春年」之说最盛，多改为次年办婚。
- **江南**：重「忌月」与节气，无春之说影响较小。
- **闽台**：忌「孤鸾年」（无春年），婚嫁多避之。
- **少数民族**：各族以本族历法与农时定婚期，不适用汉族月令禁忌，须分别记录。

## 五、器物与文书

- **择吉依据**：黄历通书、《协纪辨方书》《玉匣记》。
- **文书**：日子帖、择日单。
