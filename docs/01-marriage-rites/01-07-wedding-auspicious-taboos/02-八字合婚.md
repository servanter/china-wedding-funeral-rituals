# 八字合婚与命理宜忌

## 一、释义

「合婚」又称「合八字」「合庚」，是**以男女双方生辰八字（年、月、日、时四柱）判断婚配吉凶**的做法，属传统婚俗中「问名」环节的核心内容。

**主要判定法**：

| 名目 | 内容 |
| --- | --- |
| **八字／四柱** | 年、月、日、时各配干支，共八字 |
| **纳音** | 六十甲子配五行纳音，论相生相克 |
| **生肖六合三合** | 六合（子丑、寅亥等）、三合（申子辰等）为吉 |
| **神煞** | 「桃花」「孤辰寡宿」「羊刃」等神煞论宜忌 |
| **「合婚帖」** | 将双方八字写在庚帖上，请先生批断 |
| **「换庚帖」** | 双方交换庚帖，为「问名」的程序 |

**民间俗谚**：「男怕属鸡女怕属羊」（属相俗忌）等，属民间说法，并无统一依据。

## 二、历史源流

- **唐代**：命理（李虚中以年为主）之说渐备，合婚之俗随之发展。
- **宋代**：以「子平术」（徐子平，以日为主）为基础的八字说成熟。
- **明清**：合婚成为婚仪必经环节，通书、命书大量印行。
- **近代**：命理书籍与「批八字」行业延续。
- **当代**：部分家庭仍行合婚，多作参考；亦有人依星座、生肖游戏化参照。

## 三、仪节流程

1. **问名**：媒人向女家求取生辰八字。
2. **换庚帖**：双方交换庚帖（或女方回帖）。
3. **合八字**：请先生排四柱、论纳音神煞。
4. **批断**：得出「合」「不合」之论；不合者有「化解」之说。
5. **归帖**：合则「定帖」（订婚），不合则「退帖」。

## 四、地域与民族变体

- **华北**：重「属相合婚」，忌「六冲」。
- **江南**：重八字四柱与纳音配合。
- **闽台**：「合婚」请命馆批「八字」，讲究「三合」「六合」。
- **少数民族**：部分民族以占卜、属相或本族历法判断婚配，体系不同，须分别记录。

## 五、器物与文书

- **文书**：庚帖（龙凤帖）、合婚单、婚书。
- **文献**：《协纪辨方书》《玉匣记》、命理书籍（子平术类）。
- **器物**：历书、罗盘。
