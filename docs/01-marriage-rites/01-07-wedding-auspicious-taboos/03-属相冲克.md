# 属相冲克与六冲

![属相六合六冲三合图 / Zodiac compatibility chart](../../../assets/diagrams/属相六合六冲三合图.svg)

*图 4　十二属相六合、六冲、三合关系图。*

## 一、释义

十二生肖与地支相配，其**冲、合、害、刑**关系被用于判断婚配与婚礼宜忌。

| 关系 | 组合 | 吉凶 |
| --- | --- | --- |
| **六合** | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 吉（「六合婚」） |
| **三合** | 申子辰、亥卯未、寅午戌、巳酉丑 | 吉（「三合婚」） |
| **六冲** | 子午、丑未、寅申、卯酉、辰戌、巳亥 | 忌（「六冲婚」） |
| **相害（六害）** | 子未、丑午、寅巳、卯辰、申亥、酉戌 | 忌 |
| **相刑** | 寅巳申、丑戌未、子卯、辰午酉亥（自刑） | 忌 |

**等级**：以**六冲**为最忌（主「不和」「离散」），其次为相害、相刑。此外新娘上轿、进门时，与新人属相相冲者亦须回避（见「婚嫁人员禁忌」条）。

## 二、历史源流

- **汉代**：地支与生肖相配完成，冲合之说见于《日书》与术数文献。
- **唐宋**：属相婚配之说普及，笔记小说多有「属相不合」的记载。
- **明清**：通书与俗谚系统化，「六冲」「六合」成为家喻户晓的说法。
- **当代**：民间仍流行「属相婚配表」；许多人以娱乐态度对待。

## 三、仪节流程

1. **问属相**：议婚时先问双方属相。
2. **判冲合**：以六合、三合为吉，六冲、相害为忌。
3. **婚礼回避**：属相与新人相冲者，上轿、下轿、进新房时回避。
4. **化解**：必要时行「系红绳」「佩符」等化解之法。
5. **择日**：择日时亦避与新人属相相冲之日。

## 四、地域与民族变体

- **华北**：重「六冲」之忌，尤忌「龙虎斗」（辰寅）、「鸡猴不到头」等俗谚。
- **江南**：属相之说与八字合婚结合判断。
- **闽台**：婚礼中属相相冲者回避，尤重「煞方」与「属相」。
- **少数民族**：部分民族有以动物名纪年与婚配禁忌的制度，须分别记录。

## 五、器物与文书

- **文书**：庚帖（载属相生辰）、择日单。
- **文献**：《协纪辨方书》《玉匣记》、通书。
- **器物**：符纸、红绳（化解用）。
