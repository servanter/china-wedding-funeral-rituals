# 婚嫁路线与方位禁忌

![择吉方位图 / Auspicious directions diagram](../../../assets/diagrams/择吉方位图.svg)

*图 5　择吉方位与迎亲路线示意。*

## 一、释义

迎亲的**路线与方位**须事先商定，以「顺」「吉」「不相冲」为原则。

| 规矩 | 内容 |
| --- | --- |
| **不走回头路** | 迎亲去路与回路不同，忌原路返回 |
| **避开凶方（煞方）** | 依择日推算的三煞、岁破之方，忌经行或朝该方 |
| **避开不吉之地** | 忌经祠堂、庙宇、坟地、医院、监狱等（各地不一） |
| **「喜神方」迎亲** | 迎亲出发时朝向「喜神」所在之方（依日干支定） |
| **忌「冲巷」** | 忌与他家婚车相撞（见「喜冲喜」条） |
| **「进路出」与门向** | 忌由「凶门」出、由「吉门」入（视房屋朝向） |
| **忌涉水、过桥的讲究** | 部分地区过桥须放钱、撒喜果 |

## 二、历史源流

- **汉代以降**：出行择方与「喜神」「三煞」之说见于《日书》与术数文献。
- **唐宋明清**：择方之术纳入通书，婚嫁出行须择吉方。
- **近代**：交通方式改变后，路线禁忌多转为「避讳之地」的选择。
- **当代**：婚礼车队多按交通便利安排，但仍避走回头路、避经殡仪馆等。

## 三、仪节流程

1. **定路线**：婚前踏勘，定去路与回路。
2. **择吉方**：依通书定「喜神方」，迎亲出发朝之。
3. **避煞方**：绕开推算所得凶方。
4. **行进**：撒喜果、放鞭炮，忌停车（「不停轿」）。
5. **返程**：走另一条路返回，不入夫家「凶门」。

## 四、地域与民族变体

- **华北**：重「不走回头路」与「避煞方」。
- **江南**：路线踏勘仔细，忌经坟地、庙宇。
- **闽台**：迎亲队伍「阵头」按方位行进，忌「煞方」。
- **少数民族**：迎亲方向多由占卜决定，体系不同，须分别记录。

## 五、器物与文书

- **择吉依据**：《协纪辨方书》《玉匣记》、通书。
- **文书**：迎亲路线单、日单。
- **器物**：罗盘、喜果、鞭炮。
