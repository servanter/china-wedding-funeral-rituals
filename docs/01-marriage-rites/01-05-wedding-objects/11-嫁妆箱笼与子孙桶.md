# 嫁妆箱笼与子孙桶

## 一、释义

嫁妆（妆奁）的**承载器物**以箱笼为主，另有若干具有象征意义的器物。

| 器物 | 说明 | 寓意 |
| --- | --- | --- |
| **箱笼（樟木箱）** | 盛衣物、被褥 | 樟木防虫，贵重实用 |
| **子孙桶（马桶）** | 漆红木桶，内放枣栗、红蛋、卫生用品 | 「多子多孙」；桶谐「统」 |
| **红脚桶（浴桶／脚盆）** | 婚嫁必备桶具 | 生活富足 |
| **首饰盒、梳妆台** | 妆奁 | 妆饰齐备 |
| **「聚宝盆」** | 嫁妆陈设 | 财源聚积 |

**「子孙桶」**为嫁妆中最具象征意味者：桶内放置红蛋、枣、栗、花生，由男家小孩「提桶」（讨吉），提桶钱归小孩，称「**提子孙桶**」。

## 二、历史源流

- **先秦以降**：嫁妆（「媵」「妆奁」）之制见于礼经与史籍。
- **唐宋**：妆奁随嫁之风盛，笔记载「铺房」陈设。
- **明清**：樟木箱、子孙桶之俗定型，方志多载。
- **近代**：箱笼渐为皮箱、衣柜替代，子孙桶之俗在城市消失。
- **当代**：嫁妆以家电、家具、首饰为主；「子孙桶」在婚俗展演中保留。

## 三、仪节流程

1. **备妆**：女家备箱笼、桶具、衣物、首饰。
2. **发妆（送嫁妆）**：婚前一日或当日送至男家，列单点交。
3. **铺房陈设**：将妆奁陈列于新房。
4. **提子孙桶**：男家小孩提桶讨吉，得「提桶钱」。
5. **收存**：器物归入新家使用。

## 四、地域与民族变体

- **华北**：樟木箱成对，嫁妆讲究「四铺四盖」。
- **江南**：妆奁精细，有「垫箱底」（箱底置银钱）之俗。
- **闽台**：嫁妆称「妆奁」，子孙桶之俗常见。
- **广东**：嫁妆有「龙凤被」「子孙桶」「聚宝盆」。
- **少数民族**：嫁妆形式各异（如牲畜、银饰、织物），不属汉族妆奁器物体系，须分别记录。

## 五、器物与文书

- **器物**：樟木箱、子孙桶、红脚桶、首饰盒、梳妆台、聚宝盆。
- **相关文书**：妆奁单（嫁妆单）、礼单、婚书。
