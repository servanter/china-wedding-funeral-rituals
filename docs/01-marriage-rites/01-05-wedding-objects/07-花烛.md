# 花烛与龙凤喜烛

## 一、释义

花烛又称「喜烛」「龙凤烛」，是**婚礼中点燃于天地桌、洞房的成对蜡烛**，上绘或镂刻龙凤、双喜、牡丹。「洞房花烛夜」一语即由此而来。

**要点**：
- **成对**：龙凤烛一龙一凤，象征夫妇；须同时点燃、同时熄灭。
- **点烛仪节**：拜堂时点「天地烛」，入洞房点「洞房烛」。
- **禁忌**：忌中途熄灭（不吉，「断烛」为忌）；忌用单支；忌用白烛。

## 二、历史源流

- **南北朝**：婚仪已有「烛」之用（《世说新语》载婚礼场面）。
- **唐宋**：「花烛」成为婚仪常用语（唐诗「洞房花烛」）。
- **明清**：龙凤喜烛定型，方志多载「点花烛」「守烛」之俗。
- **当代**：中式婚礼点龙凤烛；西式婚礼点「同心烛」（unity candle），功能相近。

## 三、仪节流程

1. **备烛**：购备成对龙凤烛。
2. **点烛**：拜堂时点天地烛；洞房中点燃洞房烛。
3. **守烛**：烛须燃尽或整夜不灭（「守喜烛」）。
4. **熄灭**：忌吹灭，多以罩盖或以指捏灭（避免「吹散」）。
5. **存烛**：部分地区将残烛保存，作纪念。

## 四、地域与民族变体

- **华北**：龙凤烛加「长明灯」，讲究「一夜不熄」。
- **江南**：花烛配「守烛」「看新娘」之俗。
- **闽台**：拜堂点「龙凤烛」，并配「香火」延续。
- **少数民族**：部分民族婚礼有特定的火与灯习俗（如火塘、松明），含义与汉族花烛有别，须分别记录。

## 五、器物与文书

- **花烛**：龙凤烛、双喜烛、烛台。
- **配套物**：天地桌、香炉、长明灯。
- **相关文书**：婚书、礼单。
