# 喜秤与吉祥器物

## 一、释义

婚仪中使用的**吉祥器物**多取谐音与象征，构成一套「吉祥语汇」的物化系统。

| 器物 | 用途 | 寓意 |
| --- | --- | --- |
| **喜秤（秤杆）** | 挑盖头 | 「秤」谐「称」，取「称心如意」 |
| **如意** | 挑盖头、陈设 | 事事如意 |
| **斗（喜斗）** | 陈设、盛谷 | 「日进斗金」、丰足 |
| **尺** | 置嫁妆、量床 | 有「规矩」「法度」之意 |
| **剪刀、镜子** | 嫁妆、镇物 | 辟邪、「明镜高悬」 |
| **算盘** | 嫁妆 | 会当家、善理财 |
| **弓箭（箭）** | 「射箭」仪（部分北方） | 驱邪、镇宅 |
| **升、斗、秤、尺、剪刀、镜子** | 合称「六证」或「五证」 | 嫁妆之「镇物」组合 |

## 二、历史源流

- **先秦以降**：礼器与婚仪器物并存（「笲」「笥」等见于礼经）。
- **唐宋**：婚仪吉祥器物的谐音用法渐成体系。
- **明清**：方志与笔记详载「喜秤挑盖头」「嫁妆六证」之俗。
- **当代**：中式婚礼用喜秤、如意挑盖头；「六证」用于婚俗展演与陈列。

## 三、仪节流程

1. **备器**：备喜秤、如意等；嫁妆中置「六证」（斗、秤、尺、剪、镜等）。
2. **陈设**：置于天地桌或新房。
3. **挑盖头**：新郎以喜秤（或如意）挑开盖头。
4. **用器仪节**：「射箭」（部分地区）、「过斗」「量床」等。
5. **收存**：器物随嫁妆留存。

## 四、地域与民族变体

- **华北**：有「射箭」（三箭射轿或射门）之俗。
- **江南**：嫁妆「六证」讲究；喜秤挑盖头通行。
- **闽台**：嫁妆器物以「针线、剪刀、尺、镜」为常。
- **少数民族**：部分民族婚仪的器物象征体系不同（如刀、弓箭、马鞍），须分别记录。

## 五、器物与文书

- **器物**：喜秤、如意、斗、升、尺、剪刀、镜子、算盘。
- **嫁妆文书**：妆奁单。
- **相关文书**：婚书、礼单。
