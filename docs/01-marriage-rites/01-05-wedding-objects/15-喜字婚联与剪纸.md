# 喜字、婚联与剪纸窗花

## 一、释义

婚庆装饰以**「喜」字、喜联、剪纸窗花**为主体，构成视觉上的「红火喜庆」。

**主要形式**：
- **「囍」（双喜）**——由「喜」字并写而成，贴于门、窗、墙、器物，为婚庆最典型的文字符号（相传与王安石「双喜临门」故事相关，属民间传说）。
- **喜联（婚联）**——张贴于门、堂两侧，如「百年好合，五世其昌」「龙凤呈祥，鸳鸯比翼」。
- **剪纸窗花**——龙凤、鸳鸯、石榴、葡萄、莲花、娃娃等纹样。
- **其他**——红绸挂彩、红灯笼、喜幛。

## 二、历史源流

- **宋代**：「囍」字与婚庆装饰的记载渐多。
- **明清**：喜联、窗花剪纸普及，剪纸形成地域流派（如河北蔚县、陕西剪纸）。
- **近代**：印刷品替代手工剪纸，城市多用印刷喜字。
- **当代**：纸质喜字、气球拱门、LED 灯饰并用；剪纸作为非遗受到保护。

## 三、仪节流程

1. **备字联**：请人书写喜联、剪制窗花。
2. **张贴**：婚前一日布置，贴喜字、喜联、窗花，挂红绸、灯笼。
3. **装饰新房**：床、柜、镜、门把手贴小喜字。
4. **礼成保留**：喜字保留一段时间（有的地区至满月或春节后）。
5. **揭除**：忌随意撕扯（有地区讲究保留至褪色）。

## 四、地域与民族变体

- **华北**：喜字贴满门、窗、院，配窗花与红灯笼。
- **江南**：喜联讲究书法，剪纸纹样精细。
- **闽台**：喜字与「八仙彩」「彩绸」并用。
- **少数民族**：部分民族以刺绣、织锦、彩带作婚庆装饰，须分别记录。

## 五、器物与文书

- **装饰品**：双喜字、喜联、剪纸窗花、红灯笼、彩绸、喜幛。
- **相关文书**：婚联文本、喜幛题词。
