# 婚庆吉祥纹样（龙凤、鸳鸯、石榴、双喜）

## 一、释义

婚庆吉祥纹样是**以图像表达祝福的语言系统**，广泛出现于婚服、被枕、轿帷、嫁妆、糕点、窗花、器皿之上。

| 纹样 | 寓意 | 载体 |
| --- | --- | --- |
| **龙凤** | 「龙凤呈祥」，男女相配 | 婚服、喜烛、轿帷 |
| **鸳鸯** | 夫妇和合、形影不离 | 被枕、绣品 |
| **石榴／葡萄** | 多子 | 被面、剪纸、糕点 |
| **双喜（囍）** | 双喜临门 | 门窗、器物、喜帖 |
| **牡丹** | 富贵 | 婚服、绣品 |
| **并蒂莲** | 同心 | 绣品、剪纸 |
| **鱼** | 「年年有余」，又谐「裕」 | 器皿、糕点模 |
| **蝙蝠／鹿** | 「福」「禄」 | 嫁妆器物、木雕 |
| **喜鹊登梅** | 「喜上眉梢」 | 窗花、绣品 |
| **瓜蝶绵绵** | 「瓜瓞绵绵」，子孙繁盛 | 绣品、剪纸 |

**组合原则**：以**谐音**（鱼—余、蝠—福、鹿—禄）与**象征**（石榴—多子、鸳鸯—和合）为主，构成「有图必有意，有意必吉祥」的谱系。

## 二、历史源流

- **汉唐**：吉祥纹样在织锦、铜镜中已有雏形（「长宜子孙」镜等）。
- **宋元**：花鸟纹与谐音寓意系统成熟。
- **明清**：婚庆纹样定型并广泛用于婚服、器物，「图必有意」成为通例。
- **当代**：传统纹样在中式婚礼、文创产品与非遗工艺中延续。

## 三、仪节流程

1. **选样**：依用途选择纹样（婚服用龙凤、被面用鸳鸯石榴）。
2. **制作**：刺绣、织锦、剪纸、印刷各依工艺。
3. **陈设**：按「成双」「对称」原则布置。
4. **赠予**：作为嫁妆、贺礼赠予新人。
5. **传承**：纹样经工匠、绣娘、剪纸艺人代代相传。

## 四、地域与民族变体

- **华北**：剪纸窗花以「喜鹊登梅」「榴开百子」为多。
- **江南**：绣品（苏绣、顾绣）纹样精细。
- **闽台**：「八仙彩」「龙凤」并用，绣工讲究。
- **广东**：裙褂金线绣龙凤、祥云、蝙蝠。
- **少数民族**：各民族纹样自成体系（如苗族银饰与刺绣的蝴蝶妈妈、龙凤几何纹），与汉族婚庆纹样不同源，须分别记录。

## 五、器物与文书

- **载体**：婚服、被枕、轿帷、嫁妆器物、窗花、喜帖、糕点模。
- **相关文书**：纹样谱（绣样、剪纸花样）、婚书装饰。
- **藏品著录**：博物馆藏织绣、剪纸实物。
