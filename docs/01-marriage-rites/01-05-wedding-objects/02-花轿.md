# 花轿（喜轿）

## 一、释义

花轿，又称「喜轿」「彩轿」「花轿子」，是**婚礼亲迎时载运新娘的轿子**，为传统婚礼最具标志性的器物之一。

**形制与装饰**：
- 木制轿身，围以红绸、绣片；轿顶饰「轿顶花」「宝盖」。
- 装饰讲究「**红、金、彩**」：缎绣轿帷、流苏、绒球、玻璃镜片。
- 轿内设坐褥、脚踏；并置「**轿饭**」或「暖（手炉）」等。

**抬轿规制**：以抬轿人数定等级——**二人轿（小轿）、四人轿（花轿通行）、八人轿（豪富）**；官宦之家有「官轿」形制的「**八抬大轿**」。轿班由专门的「**轿房**」（花轿铺）出租并配轿夫、仪仗。

## 二、历史源流

- **唐宋**：轿（「肩舆」）渐用于婚礼；南宋时迎亲乘轿已普遍。
- **明清**：花轿礼俗定型，「轿房」成为专营行业；方志多载「花轿」「轿夫」。
- **近代**：自行车、马车、汽车渐入；20 世纪后期城市改用轿车（「花车」）。
- **当代**：婚礼偶见「花轿迎亲」（多为中式婚礼展演或景区婚庆）。

## 三、仪节流程

1. **租轿**：婚前向轿房订轿，定轿色、仪仗与轿夫人数。
2. **发轿**：吉时发轿，鼓乐前导至女家。
3. **上轿**：新娘由「喜娘」或兄长背上轿，盖头覆面。
4. **起轿**：放鞭炮、撒喜果，抬轿回程（忌落轿，一说「轿不落地」）。
5. **落轿**：至夫家门，行「过火盆」「踢轿门」等仪，新娘下轿。

## 四、地域与民族变体

- **华北**：抬花轿吹打迎亲，讲究「八抬大轿」。
- **江南**：花轿装饰精细，有「轿饭」「上轿团」之俗。
- **闽台**：花轿配全套仪仗（「迎亲阵头」），并「轿前置青铜镜」。
- **广东**：花轿加「龙凤褂」，仪仗以「大妗姐」随行。
- **少数民族**：部分民族婚礼用轿（受汉族影响），另有马、船、牛车等迎亲方式，须分别记录。

## 五、器物与文书

- **花轿**：轿身、轿帷、轿顶花、流苏。
- **配套物**：盖头、手炉、轿饭、喜果、鞭炮、仪仗（旗牌、伞扇）。
- **相关文书**：订婚书、婚书、仪仗单（「执事单」）。
