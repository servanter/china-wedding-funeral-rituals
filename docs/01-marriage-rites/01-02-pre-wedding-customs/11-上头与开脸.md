# 上头与开脸

## 一、释义

- **上头**：为出嫁女子改变发式——由少女的发辫改为成人的发髻，并加笄、插饰。亦称「加笄」「梳头」「冠笄」。
- **开脸**（绞面、挽面）：用双股细线绞去脸上的汗毛、修整鬓角与眉形，是女子出阁前的「修容」之礼。

二者均在婚前一日（或当日晨）举行，由「全福人」（父母双全、夫妻和睦、有子女的妇女）主持。其礼制背景是**古代的笄礼**：女子十五而笄，示成年；出嫁则是一个「成年」的标志性节点。

## 二、历史源流

- 《仪礼·士昏礼》：「母施衿结帨，曰：『勉之，敬之，夙夜无违尔舅姑之命。』」母亲为临嫁之女系带、佩巾，是「上头」的礼制原型。
- 古代女子十五行「笄礼」，束发加笄以示成年；出嫁时改髻加饰，是笄礼在婚姻语境中的重演。
- 「开脸」的记载较晚，多见于明清方志与笔记：「女将嫁，先以线绞面，谓之开脸」「开脸后方成妇人」。
- 开脸在民俗中有「界限」的意义：开脸之前为「姑娘」，开脸之后为「媳妇」。故未出嫁的女子终身不得开脸（部分地区），寡妇改嫁亦须再开脸。
- 当代此俗多见于农村与传统婚礼复原场景。

## 三、仪节流程

### 上头（多在婚前一夜）

1. **择时**：多在迎娶前一日夜间（「上头夜」），择吉时（如子时）举行。
2. **设位**：在堂屋设案，点香烛、供果品，摆梳、篦、簪、钗、镜。
3. **告祖**：由父母或长嫂上香，告于祖先。
4. **改髻**：全福人为新娘解开辫发、梳理、绾髻、加笄插饰。
5. **念祝语**：边梳边念「一梳梳到尾，二梳白发齐眉，三梳儿孙满地」等祝辞。
6. **叩拜**：新娘向父母、祖先叩拜，感念养育之恩。
7. **接发**：部分地区新娘剪下一缕发交母保存，或与新郎发相结（见「结发」条）。

### 开脸（婚前一日或当日）

1. **备线**：备双股棉线、滑石粉（或胭脂粉）。
2. **绞面**：全福人以线交叉绞动，逐处绞去汗毛，自额、颊至下颌。程序讲究「先上后下、先左后右」。
3. **修眉**：修整眉形，有的地方将眉毛修成细弯的「新月眉」。
4. **敷粉**：绞毕敷粉、抹胭脂。
5. **红包**：新娘或女家向开脸者赠红包致谢。

## 四、地域与民族变体

- **华北**：称「上头」「开脸」，讲究「上头日不动针线」「开脸须双日」。
- **江浙**：称「上头」「绞面」，讲究「上头夜不点灯」（部分地区）。
- **闽台**：称「上头」「开面」，由「好命婆」（全福人）主持，须念成套的吉祥话。
- **广东**：称「上头」，在婚前一日夜举行，同时行「穿嫁衣」，由母亲或大妗姐主持。
- **少数民族**：改髻与修容在各民族中皆有，但含义不同。如彝族的「梳头」仪式标示族群身份；瑶族的「绾髻」有已婚妇女的发式标记；苗族的银饰冠戴即其「上头」的对应物，但与汉族「加笄」的礼制含义不同，多与族群认同和婚姻地位绑定。

## 五、器物与文书

- **梳、篦**：梳理用具。
- **簪、钗、花**：加笄插饰。
- **镜**：照容。
- **双股棉线、滑石粉**：开脸之用。
- **香烛、供品**：告祖所用。
- **祝辞（上头歌、开面歌）**：口传韵语。
- **红包**：酬谢开脸者。
