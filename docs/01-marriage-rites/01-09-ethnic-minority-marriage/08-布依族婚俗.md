# 布依族婚俗

## 一、释义

布依族分布于贵州南部、西南部及云南、四川部分地区。婚前社交以**「浪哨」（对歌交友）**为特色，婚后部分家庭行**「不落夫家」**。

**核心要素**：
1. **「浪哨」（赶表）**——青年男女在节日、集市以对歌交友。
2. **「提亲」「订婚」**——托媒提亲，送聘礼（酒、肉、布、银饰）。
3. **「迎亲对歌」**——迎亲时门内门外对歌，以歌迎客。
4. **「不落夫家」**——婚后新妇暂住娘家，待生育或约定期满后住夫家。
5. **「哭嫁」**——新娘哭嫁。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋**：布依族先民（「僚」等）婚俗见于史籍。
- **明清**：方志（贵州通志、兴义府志等）「风俗」门载婚仪。
- **近代**：与汉族、苗族杂居，婚俗交融。
- **当代**：传统婚俗在乡村保存，仪式简化。

## 三、仪节流程

1. **浪哨交友**：对歌相识。
2. **提亲**：托媒说合。
3. **订婚**：送聘礼、定婚期。
4. **哭嫁**：婚前哭嫁。
5. **迎亲**：对歌迎客、拜堂、宴客。
6. **不落夫家／回门**：婚后暂住娘家或归宁。

## 四、地域与支系变体

- **黔南（黔南州）**：布依族集中，「浪哨」「不落夫家」可见。
- **黔西南（兴义、安龙）**：与苗、彝族杂居，习俗互渗。
- **黔中（贵阳、安顺）**：近汉族，婚俗汉化程度较高。
- **云南（曲靖、文山）**：与壮族支系习俗相近。
- **与其他民族关系**：布依族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、肉、布、银饰）、米酒、糯米饭。
- **服饰**：布依族服饰（蓝靛染布、蜡染）。
- **文书**：聘礼单、婚约（今为结婚证）。
