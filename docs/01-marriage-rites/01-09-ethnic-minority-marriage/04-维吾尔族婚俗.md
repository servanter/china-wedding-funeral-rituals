# 维吾尔族婚俗

## 一、释义

维吾尔族婚礼以**伊斯兰教婚姻规范**与本民族歌舞传统结合，核心是**阿訇念「尼卡」、共食盐水馕**。

**核心要素**：
1. **「尼卡」仪式**——由阿訇主持，念经文、询问双方自愿，新人共食蘸盐水的馕（「盐」象征牢不可破，「馕」为生命食粮），为最具象征性的仪节。
2. **「提亲」「订婚」**——男方托媒提亲，送彩礼（衣料、首饰、羊）。
3. **「麦西热甫」**——婚礼中的歌舞晚会，亲友弹唱起舞，气氛热烈。
4. **婚宴（「托依」）**——设席待客，以抓饭、烤馕、羊肉为主。
5. **「三日礼」**——婚后三日行「回门」之礼。

## 二、历史源流

- **喀喇汗王朝时期**：伊斯兰教传入，婚姻规范与本地礼俗融合。
- **明清**：叶尔羌汗国等时期，婚礼中的歌舞传统（十二木卡姆）发达。
- **近现代**：城市婚礼简化，宗教仪轨与歌舞庆典并行。
- **当代**：念「尼卡」与婚姻登记并行；麦西热甫列入非遗保护。

## 三、仪节流程

1. **提亲**：男方托媒提亲，女方「应允」后议彩礼。
2. **订婚（下定）**：送彩礼、订亲、定婚期。
3. **尼卡**：阿訇念尼卡，新人共食盐水馕。
4. **麦西热甫**：歌舞晚会，亲友道贺。
5. **婚宴**：设席待客（抓饭、羊肉、馕）。
6. **三日礼／回门**：婚后三日归宁。

## 四、地域与支系变体

- **南疆（喀什、和田、阿克苏）**：宗教生活浓厚，麦西热甫隆重。
- **北疆（乌鲁木齐、伊犁）**：城镇婚礼简化，歌舞仍盛。
- **与其他民族关系**：同遵伊斯兰婚礼诸族细节有异；与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：盐水馕、抓饭、彩礼（衣料、首饰、羊）、乐器（都塔尔、热瓦甫、手鼓）。
- **服饰**：艾德莱斯绸裙、小花帽（朵帕）。
- **文书**：彩礼单、结婚证。
