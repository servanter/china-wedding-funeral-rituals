# 独龙族婚俗

## 一、释义

独龙族主要聚居于云南怒江贡山独龙族怒族自治县独龙江流域。婚俗以**「木刻」为凭、剽牛宴客与旧式包办婚**为特色。

**核心要素**：
1. **「木刻记事」**——婚约、聘礼以刻木为凭，为无文字社会的信物。
2. **「族内婚与包办婚」**——旧俗多由父母包办，族内婚为主（旧俗，须作批判性说明）。
3. **「妻姊妹婚与转房婚」**——旧有「妻姊妹婚」（姊妹共夫）、「转房婚」等俗。
4. **「剽牛宴客」**——婚礼剽牛分食，全寨共庆。
5. **「火塘与卡雀哇」**——婚礼围火塘举行，「卡雀哇」（年节）为说亲节点。
6. **「文面旧俗」**——旧时妇女文面，为族别标志（旧俗，不作提倡）。

## 二、历史源流

- **清代**：独龙族（「俅人」「曲人」）婚俗散见《皇清职贡图》与滇西北方志。
- **近代**：木刻记事、剽牛等俗见于民族调查资料。
- **当代**：独龙江公路贯通后，传统婚俗与外界交融。

## 三、仪节流程

1. 说亲（父母议婚）。
2. 定亲、刻木为凭。
3. 送聘（牲畜、铁器、珠饰）。
4. 迎娶。
5. 剽牛宴客。
6. 围火塘歌舞。

## 四、地域与支系变体

- **独龙江上游（孔当、献九当）**：独龙族聚居核心区，婚俗保存较完整。
- **贡山县城一带**：与怒族、傈僳族杂居，婚俗交融。
- **与其他民族关系**：独龙族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：木刻（婚约凭证）、铁器、珠饰、牛。
- **服饰**：独龙族麻布毯（「约多」）、藤篾饰。
- **文书**：木刻、结绳（旧无文字）。
