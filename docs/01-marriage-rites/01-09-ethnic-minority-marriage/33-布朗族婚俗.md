# 布朗族婚俗

## 一、释义

布朗族主要聚居于云南西双版纳（勐海）、临沧（双江、耿马）等地，信仰**南传佛教**，兼有传统鬼神信仰。婚俗以**「串姑娘」对歌、「从妻居」与佛教祈福**为特色。

**核心要素**：
1. **「串姑娘」**——青年男女夜晚对歌交友（部分村寨有「公房」形式）。
2. **「提亲」「订婚」**——托媒提亲，聘礼为茶、酒、米、蜡条。
3. **「从妻居」**——婚后男子先至女家居住（一至数年），再携妻回夫家。
4. **「拴线」与「滴水」**——请僧侣诵经，以白线拴手、滴水祈福。
5. **「寨老主持」**——村寨头人参与议婚与仪节。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋至明清**：布朗族先民（「濮人」）婚俗见于史籍与方志。
- **近代**：南传佛教影响加深，佛寺承担诵经祈福职责。
- **当代**：传统婚俗在山区保存，城镇渐简。

## 三、仪节流程

1. 串姑娘对歌交友。
2. 提亲、议聘礼。
3. 婚礼：僧侣诵经、拴线、滴水祈福。
4. 从妻居：男子先入女家居住。
5. 婚宴：村寨共贺。
6. 回夫家／回门。

## 四、地域与支系变体

- **西双版纳（布朗山、勐海）**：聚居核心区，南传佛教影响深。
- **临沧（双江、耿马）**：与傣、佤、拉祜族杂居，习俗互渗。
- **与其他民族关系**：布朗族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：蜡条、白线、彩礼（茶、酒、米）、滴水器。
- **服饰**：布朗族服饰（黑红为主的织锦、银饰）。
- **文书**：彩礼单、婚约。
