# 哈萨克族婚俗

## 一、释义

哈萨克族主要分布于新疆北部及甘肃、青海。婚配实行**部落外婚**，婚礼依**伊斯兰教规范**并保留游牧特色（**赛马、叼羊、对歌**）。

**核心要素**：
1. **「提亲」「订婚」**——男方托媒提亲，送彩礼（马、羊、布匹、银饰）。
2. **「阿訇念尼卡」**——婚礼请阿訇念「尼卡」（证婚），共饮「尼卡水」（或食盐水）。
3. **「对歌」（「阿依特斯」）**——婚礼中青年男女对歌，热烈欢快。
4. **「赛马、叼羊、姑娘追」**——婚庆期间的竞技活动。
5. **「毡房迎亲」**——新娘至夫家毡房，行「揭面纱」（「别塔沙尔」）仪式。
6. **「回门」**——婚后归宁。

## 二、历史源流

- **伊斯兰教传入后**：婚礼规范与草原游牧旧俗结合。
- **清代**：哈萨克部众迁入伊犁、阿勒泰等地，婚俗与宗教信仰相应。
- **近代**：部落结构与婚事紧密相关。
- **当代**：城市婚礼简化，竞技与对歌在牧区婚庆中保留。

## 三、仪节流程

1. 提亲、订婚。
2. 送彩礼（「卡拉库依」等，视部落而定）。
3. 念「尼卡」：阿訇证婚。
4. 揭面纱：新娘入毡房行揭面纱礼。
5. 婚庆竞技与对歌：赛马、叼羊、阿依特斯。
6. 回门。

## 四、地域与支系变体

- **伊犁、阿勒泰、塔城**：哈萨克族聚居区，传统婚俗保存较好。
- **甘肃阿克塞、青海海西**：与回、蒙古族杂居，习俗相类。
- **城市哈萨克族**：婚礼简化，家族宴饮延续。
- **与其他民族关系**：同遵伊斯兰婚礼诸族细节有异；与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：彩礼（马、羊、布匹）、毡房、马具、冬不拉。
- **服饰**：哈萨克族服饰（银饰、羽毛帽）。
- **文书**：彩礼单、婚约（结婚证）。
