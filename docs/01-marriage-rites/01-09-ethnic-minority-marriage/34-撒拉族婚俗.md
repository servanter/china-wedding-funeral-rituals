# 撒拉族婚俗

## 一、释义

撒拉族主要聚居于青海循化撒拉族自治县及化隆、甘肃积石山等地，信仰伊斯兰教。婚礼依**宗教规范**并含本民族特色。

**核心要素**：
1. **「提亲」「订婚」**——男方托媒提亲，送「定茶」（茶、糖、衣料）为定礼，议定聘礼。
2. **「念尼卡」**——婚礼请阿訇念「尼卡」证婚。
3. **「婚宴」**——设席待客（忌酒）。
4. **「唱「花儿」」**——撒拉族「花儿」民歌在婚庆等场合演唱。
5. **「认亲」**——新娘拜见公婆长辈。
6. **「回门」**——婚后归宁。

## 二、历史源流

- **元代**：撒拉族先民自中亚东迁至循化，伊斯兰教在社区生活中居核心地位。
- **明清**：清真寺与门宦拱北承担婚礼与纪念事务。
- **当代**：仪轨沿袭，寺坊参与婚礼。

## 三、仪节流程

1. 提亲。
2. 订婚（送定茶、议彩礼）。
3. 念尼卡：阿訇证婚。
4. 婚宴：设席待客。
5. 认亲：拜见公婆长辈。
6. 回门。

## 四、地域与支系变体

- **青海循化**：聚居核心区，仪轨规范。
- **化隆、甘肃积石山**：与回、东乡、保安族杂居，习俗相类。
- **与其他民族关系**：同遵伊斯兰婚礼诸族细节有异，与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：定茶、彩礼、婚宴用品。
- **宗教器物**：《古兰经》、清真寺、拱北。
- **文书**：彩礼单、婚约（结婚证）。
