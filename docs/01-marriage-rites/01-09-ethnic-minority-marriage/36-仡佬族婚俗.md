# 仡佬族婚俗

## 一、释义

仡佬族主要聚居于贵州（务川、道真、遵义、安顺等）及广西、云南部分地区。婚俗以**「对歌」「打牙」旧俗文献记载与「三幺台」待客**为特色。

**核心要素**：
1. **「对歌择偶」**——节日、赶场以对歌交友。
2. **「提亲」「订婚」**——托媒提亲，聘礼为酒、肉、布、银饰。
3. **「打牙」旧俗（文献）**——古代「打牙仡佬」有凿去门牙的婚俗（已废），古籍记载较多。
4. **「三幺台」待客**——以「三幺台」（三道席：茶席、酒席、饭席）款待宾客。
5. **「拜堂」「宴客」**——程序近汉俗。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **先秦至唐宋**：「僚人」婚俗见于《华阳国志》等记载。
- **明清**：方志（遵义府志、安顺府志等）载「仡佬」婚俗与「打牙」旧俗。
- **近代**：与汉、苗族杂居，婚俗汉化程度较高。
- **当代**：传统婚俗在黔北乡村保存。

## 三、仪节流程

1. 对歌交友。
2. 提亲、订婚。
3. 迎娶；拜堂、宴客（三幺台）。
4. 宴请亲族。
5. 回门。

## 四、地域与支系变体

- **黔北（务川、道真）**：聚居区，习俗保存较完整。
- **黔中（安顺、平坝）**：与布依、汉族杂居，习俗交融。
- **渝南、川南**：与汉族杂居程度深。
- **广西隆林**：与壮、彝族杂居。
- **与其他民族关系**：仡佬族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、肉、布、银饰）、三幺台席具。
- **服饰**：仡佬族服饰（贯头衣、筒裙）。
- **文书**：聘礼单、婚约。
