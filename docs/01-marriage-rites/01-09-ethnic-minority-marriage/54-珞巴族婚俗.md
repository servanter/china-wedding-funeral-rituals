# 珞巴族婚俗

## 一、释义

珞巴族主要分布于西藏米林、墨脱、隆子、察隅等地。婚俗以**旧式买卖婚、巫师主持与等级内婚**为特色。

**核心要素**：
1. **「买卖婚」旧俗**——旧以牛、刀、珠饰等为聘，聘礼多寡定婚姻（旧俗，须作批判性说明）。
2. **「等级内婚」**——旧俗上层与平民之间不通婚（旧俗，不作提倡）。
3. **「巫师主持」**——婚礼由「纽布」「米剂」（巫师）主持祭神。
4. **「杀牲宴客」**——婚礼杀猪宰牛，全寨分食。
5. **「抢婚遗存」**——旧俗迎亲有象征性「抢婚」。
6. **「一夫多妻遗存」**——旧俗富户间有一夫多妻之例。

## 二、历史源流

- **清代**：珞巴族（「珞渝」等）婚俗散见藏文文献与《西藏志》。
- **近代**：买卖婚、等级内婚等俗见于民族调查资料。
- **当代**：珞巴族传统婚俗在非遗保护与民族调查中受到记录。

## 三、仪节流程

1. 说亲、议聘。
2. 定亲、送聘（牛、刀、珠饰）。
3. 择期、备礼。
4. 迎娶（含象征性「抢婚」）。
5. 巫师主持祭神、杀牲。
6. 宴客歌舞。

## 四、地域与支系变体

- **米林南伊**：珞巴族聚居区，婚俗保存较完整。
- **墨脱、隆子、察隅**：与门巴、藏族杂居，婚俗交融。
- **与其他民族关系**：珞巴族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：牛、珞巴刀、珠饰（「巴角」）、祭神器物。
- **服饰**：珞巴族氆氇长袍、藤帽、竹饰。
- **文书**：婚约、礼单（旧无文字，以口头与实物为凭）。
