# 达斡尔族婚俗

## 一、释义

达斡尔族主要聚居于内蒙古呼伦贝尔（莫力达瓦等）及黑龙江齐齐哈尔、新疆塔城等地。婚配实行**氏族外婚**，婚礼以**「察恩特」（彩礼）「拦门」「对歌」**为特色。

**核心要素**：
1. **「提亲」「订婚」**——托媒提亲，送「察恩特」（彩礼，含马、牛、猪、酒）。
2. **「拦门对歌」**——迎亲时女方设拦门之礼，男方对歌方得入门。
3. **「拜天地与祭祖」**——行拜礼，祭告祖先。
4. **「萨满祈福」**（旧俗）——请萨满祈福，后受佛教影响亦有请喇嘛诵经。
5. **「回门」**——三朝归宁。
6. **「入赘」**——无子之家多有招婿之俗，赘婿地位明确。

## 二、历史源流

- **明清**：达斡尔族（「达呼尔」）分布于黑龙江流域，婚俗载于方式与民族志。
- **清代**：南迁嫩江流域；与满、汉、鄂温克族交往，婚俗互有影响。
- **新疆达斡尔族（塔城）**：乾隆年间西迁戍边，婚俗与当地民族习俗相邻。
- **当代**：传统婚俗在聚居区留存。

## 三、仪节流程

1. 提亲、订婚（送察恩特）。
2. 定婚期。
3. 迎亲：拦门对歌。
4. 婚礼：拜天地、祭祖、宴客。
5. 回门：三朝归宁。
6. 入赘（无子之家）。

## 四、地域与支系变体

- **内蒙古莫力达瓦、黑龙江齐齐哈尔**：聚居区，旧俗保存较多。
- **新疆塔城**：西迁支系，婚俗与哈萨克、蒙古族习俗相邻。
- **与其他民族关系**：达斡尔族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：彩礼（马、牛、猪、酒）、大轱辘车、马具。
- **服饰**：达斡尔族服饰（皮袍、绣花）。
- **文书**：彩礼单、婚约（结婚证）。
