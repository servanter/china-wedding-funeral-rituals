# 瑶族婚俗

## 一、释义

瑶族支系众多（盘瑶、布努瑶、白裤瑶、茶山瑶等），分布于广西、湖南、广东、云南、贵州。婚俗以**对歌择偶、拦门饮酒、部分支系「不落夫家」**为特色。

**核心要素**：
1. **「对歌择偶」**——节日、歌堂中以对歌交友。
2. **「提亲」「订婚」**——托媒提亲，聘礼以银饰、酒、肉为主。
3. **「拦路歌」「拦门酒」**——迎亲时设拦门之礼，须对歌、饮酒方得入门。
4. **「不落夫家」**（部分支系）——婚后新妇暂住娘家。
5. **「度戒」关联**——瑶族男子「度戒」（成年礼）与婚配资格相关（部分支系）。
6. **「入赘」较普遍**——部分支系赘婿不改姓，地位与亲子相当。

## 二、历史源流

- **唐宋**：「莫徭」等称谓见于史籍，瑶族先民婚俗载于方志。
- **明清**：方志与《过山榜》等文书反映其婚俗与族群规矩。
- **近代**：各支系习俗差异稳固。
- **当代**：传统婚俗在乡村保存，部分列入非遗。

## 三、仪节流程

1. **对歌择偶**：歌堂对歌相识。
2. **提亲**：托媒说合。
3. **订婚**：送聘礼、定婚期。
4. **迎亲**：拦路对歌、拦门饮酒。
5. **婚礼**：拜见长辈、宴客。
6. **不落夫家／入赘／回门**：视支系与家庭约定。

## 四、地域与支系变体

- **广西金秀（大瑶山）**：茶山瑶、盘瑶、坳瑶等支系习俗各别。
- **广西南丹（白裤瑶）**：婚俗另有特色。
- **湖南（江永、江华）**：与汉族杂居，婚俗汉化较深。
- **云南、贵州**：与苗、壮、布依族杂居。
- **与其他民族关系**：瑶族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：银饰、酒、肉、歌堂用品。
- **服饰**：瑶族盛装（盘瑶的「盘王」纹饰、白裤瑶的白裤）。
- **文书**：《过山榜》等族群文书、聘礼单、婚约。
