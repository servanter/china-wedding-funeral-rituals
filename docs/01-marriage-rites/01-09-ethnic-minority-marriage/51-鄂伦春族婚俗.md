# 鄂伦春族婚俗

## 一、释义

鄂伦春族主要分布于内蒙古呼伦贝尔鄂伦春自治旗及黑龙江塔河、呼玛、黑河等地。婚俗以**族外婚、猎马为聘与篝火歌舞**为特色。

**核心要素**：
1. **族外婚**——同氏族不婚，由媒人求婚说合。
2. **「猎马为聘」**——聘礼以猎马、猎获物为主。
3. **「求婚与订婚」**——男方携酒、猎获物至女家求婚。
4. **「篝火与歌舞」**——婚礼围绕篝火举行歌舞。
5. **「抢婚遗存」**——旧俗迎亲有象征性「抢婚」。
6. **「萨满祈福」**——旧俗请萨满为新人祈福。

## 二、历史源流

- **清代**：鄂伦春族（「俄伦春」）婚俗见于《黑龙江外记》与方志。
- **近代**：猎民婚俗见于民族调查资料。
- **当代**：鄂伦春自治旗传统婚礼在文化活动与非遗保护中呈现。

## 三、仪节流程

1. 媒人求婚。
2. 订婚、议彩礼（猎马）。
3. 迎亲。
4. 篝火仪式、萨满祈福。
5. 婚宴歌舞。
6. 回门。

## 四、地域与支系变体

- **鄂伦春自治旗**：鄂伦春族聚居核心区，婚俗保存较完整。
- **黑龙江塔河、呼玛、黑河**：与汉、满族杂居，婚俗交融。
- **与其他民族关系**：鄂伦春族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：猎马、猎枪、桦皮器、兽皮。
- **服饰**：鄂伦春族狍皮袍、皮靴、头饰。
- **文书**：婚约、礼单（旧以口头约定为主）。
