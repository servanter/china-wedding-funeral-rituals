# 畲族婚俗

## 一、释义

畲族主要分布于福建、浙江、江西、广东、安徽等地山区。婚俗以**「对歌」「做表姐」「凤凰装」**为特色。

**核心要素**：
1. **「对歌」**——婚嫁过程全程伴以对歌（「歌场」）。
2. **「做表姐」**——婚前新娘到舅家、姑家「做表姐」与表兄弟对歌，为特色婚俗。
3. **「提亲」「订婚」**——托媒提亲，聘礼以酒、肉、糕、银饰为主。
4. **「凤凰装」**——新娘着「凤凰装」（凤冠、花边衫、彩裙），为畲族婚服标志。
5. **「男拜女不拜」**——拜堂时畲族有「男拜女不拜」之俗（传说不一，为民族特色）。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋**：畲族先民（「畲民」）见于史籍，迁徙与山区定居相关。
- **明清**：方志（福建、浙江各县志）载其婚俗。
- **近代**：与汉族长期杂居，婚俗汉化较深，但婚歌与「凤凰装」保留畲族特色。
- **当代**：「畲族婚俗」「畲族民歌」列入非遗名录。

## 三、仪节流程

1. 对歌交友。
2. 提亲、订婚。
3. 「做表姐」：婚前与表亲对歌。
4. 迎娶：对歌迎客、拜堂（男拜女不拜）。
5. 婚宴：歌场对唱。
6. 回门。

## 四、地域与支系变体

- **闽东（宁德、福安）**：畲族聚居区，婚歌与凤凰装最典型。
- **浙南（景宁、丽水）**：与汉族杂居，仪式简化。
- **闽西、粤东**：与客家习俗互渗。
- **与其他民族关系**：畲族婚俗与汉族交融较深，但对歌与凤凰装属自有传统，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、肉、糕、银饰）、凤冠、花边衫、彩裙。
- **服饰**：畲族凤凰装。
- **文书**：聘礼单、婚歌抄本、婚约。
