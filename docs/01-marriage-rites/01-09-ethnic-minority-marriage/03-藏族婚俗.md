# 藏族婚俗

## 一、释义

藏族主要分布于西藏及青海、四川、甘肃、云南藏区。婚配形式在历史上较多样（**一夫一妻为主**，部分地区曾有一妻多夫、一夫多妻形态），核心礼俗是**献哈达、请僧人择吉与诵经**。

**核心要素**：
1. **「提亲」献哈达**——男家托媒携哈达、青稞酒至女家提亲。
2. **择吉与诵经**——请僧人择吉日、诵经祈福。
3. **迎亲「拦门」**——女方设「拦门」之礼，迎亲者以酒、歌相应。
4. **「唱求婚歌」「对歌」**——婚礼中歌舞（「锅庄」等）。
5. **敬酒与献哈达**——婚礼全程以青稞酒、酥油茶、哈达为礼。
6. **「从妻居」与「从夫居」**——视家庭安排而定（入赘在藏区较常见，赘婿地位不低）。

## 二、历史源流

- **吐蕃时期**：藏文文献载王室与贵族联姻之礼，盟誓与献礼并重。
- **后弘期以降**：藏传佛教深入社会，婚礼多请僧人诵经。
- **明清至近代**：地方政教体制下的婚配形态多样。
- **当代**：一夫一妻制普遍，传统礼俗在农牧区保存。

## 三、仪节流程

1. **提亲**：媒人献哈达、青稞酒提亲。
2. **订婚**：议定彩礼（牛马、氆氇、银饰）与婚期。
3. **迎亲**：男方组成迎亲队前往，女方设「拦门」、设宴。
4. **婚礼**：念经祈福、献哈达、敬酒、歌舞（锅庄）。
5. **入夫家**：新娘入夫家拜见长辈与佛龛。
6. **回门**：婚后归宁省亲。

## 四、地域与支系变体

- **卫藏（拉萨、日喀则）**：礼俗规整，僧俗并重。
- **安多（青海、甘肃、川西北）**：牧区婚礼，歌舞与馈赠隆重。
- **康区（四川甘孜、云南迪庆）**：婚礼兼有康区特色（锅庄、弦子）。
- **与其他民族关系**：藏族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：哈达、青稞酒、酥油茶、氆氇、银饰、佛龛。
- **服饰**：藏袍、邦典（围裙）、头饰（珊瑚、松石）。
- **文书**：婚约、彩礼单、结婚证。
