# 侗族婚俗

## 一、释义

侗族分布于贵州、湖南、广西毗邻地区。婚前社交以**「行歌坐月」**为特色，婚礼以**对歌、拦路**为仪节核心。

**核心要素**：
1. **「行歌坐月」（走寨）**——青年男女夜晚聚会对歌交友。
2. **「提亲」「订婚」**——托媒提亲，送聘礼（酒、肉、糯米、布）。
3. **「拦路对歌」**——迎亲时女方以歌设阻（「拦路」），男方对歌方得入门。
4. **「不落夫家」**（部分地区）——婚后新妇暂住娘家。
5. **「合拢宴」**——婚宴长桌共食，气氛热烈。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋**：侗族先民（「僚」「峒」）婚俗见于史籍。
- **明清**：方志（黎平府志等）「风俗」门载婚仪。
- **近代**：与汉族、苗族杂居，婚俗交融。
- **当代**：传统婚俗在侗寨保存；「侗族大歌」「行歌坐月」进入非遗保护。

## 三、仪节流程

1. **行歌坐月**：对歌交友。
2. **提亲**：托媒说合。
3. **订婚**：送聘礼、定婚期。
4. **迎亲**：拦路对歌、接亲。
5. **婚宴**：合拢宴待客、唱歌。
6. **不落夫家／回门**：婚后暂住娘家或归宁。

## 四、地域与支系变体

- **黔东南（黎平、从江、榕江）**：侗族聚居核心区，对歌传统浓厚。
- **湘西南（通道、靖州）**：与苗族、汉族杂居，习俗互渗。
- **桂北（三江、龙胜）**：与壮、瑶族相邻。
- **与其他民族关系**：侗族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、肉、糯米、布）、芦笙、琵琶、牛腿琴。
- **服饰**：侗布、银饰、侗族盛装。
- **文书**：聘礼单、款词（侗族习惯法，含婚俗规范）。
