# 赫哲族婚俗

## 一、释义

赫哲族主要分布于黑龙江同江、饶河、抚远及佳木斯一带。婚俗以**彩船迎亲、杀生鱼待客与「伊玛堪」祝福**为特色。

**核心要素**：
1. **「说亲」**——由媒人提亲，男女两家相看。
2. **「过小礼、过大礼」**——订婚分两次行礼，称「过小礼」「过大礼」。
3. **「彩船迎亲」**——以彩船（桦皮船）迎娶，为渔猎民族特色。
4. **「杀生鱼待客」**——婚宴以「杀生鱼」（凉拌生鱼）为上品。
5. **「伊玛堪」说唱**——婚礼中以「伊玛堪」说唱祝福。
6. **「鱼皮嫁衣」**——旧时女嫁衣用鱼皮、鹿皮缝制。

## 二、历史源流

- **清代**：赫哲族（「黑斤」「赫哲」）婚俗见于《皇清职贡图》与方志。
- **近代**：渔猎婚俗见于民族调查资料。
- **当代**：同江街津口、饶河四排等赫哲族乡传统婚俗在非遗保护中传承。

## 三、仪节流程

1. 说亲。
2. 过小礼、过大礼。
3. 择期、备嫁。
4. 彩船迎亲。
5. 婚宴（杀生鱼）。
6. 伊玛堪祝福、回门。

## 四、地域与支系变体

- **同江街津口**：赫哲族聚居区，婚俗保存较完整。
- **饶河四排**：与汉、满族杂居，婚俗交融。
- **与其他民族关系**：赫哲族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：桦皮船（彩船）、渔网、鱼皮、鹿皮。
- **服饰**：鱼皮衣、鹿皮衣（嫁衣）、狍皮帽。
- **文书**：婚约、礼单。
