# 羌族婚俗

## 一、释义

羌族主要聚居于四川阿坝（茂县、汶川、理县、黑水等）。婚俗以**「释比主持」「花夜对歌」与「咂酒」**为特色。

**核心要素**：
1. **「提亲」「订婚」**——托媒提亲，聘礼为酒、肉、布、银饰。
2. **「花夜」**——婚前一晚女方家设「花夜」，亲友对歌、跳萨朗舞。
3. **「释比主持」**——请羌族祭司「释比」祈福、祭告祖先与白石神。
4. **「咂酒」待客**——以咂酒（青稞酿）待客。
5. **「白事红事并重」**——羌族「坐花夜」「跳萨朗」与丧俗「跳丧」同属歌舞传统。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **先秦**：羌人婚俗见于《荀子》《吕氏春秋》等文献。
- **明清**：方志（汶川县志、茂州志等）载其婚俗。
- **近代**：受汉文化影响，婚礼兼有汉俗。
- **当代**：传统婚俗与「羌年」等节庆结合；2008 年汶川地震后重建与文化保护同时推进。

## 三、仪节流程

1. 提亲、订婚。
2. 花夜：婚前对歌、跳萨朗。
3. 迎娶：释比祈福、祭祖。
4. 婚礼：拜堂、咂酒待客、歌舞。
5. 祭白石神。
6. 回门。

## 四、地域与支系变体

- **茂县、汶川**：羌族聚居区，释比系统与歌舞传统保存较多。
- **理县、黑水**：与藏、汉族杂居，婚礼兼有藏汉因素。
- **与其他民族关系**：羌族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：咂酒、彩礼、释比法器、白石（崇拜物）。
- **服饰**：羌族服饰（绣花围腰、头帕）。
- **文书**：聘礼单、婚约。
