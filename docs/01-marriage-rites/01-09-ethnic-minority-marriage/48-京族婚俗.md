# 京族婚俗

## 一、释义

京族主要聚居于广西东兴市（巫头、山心、澫尾三岛，习称「京族三岛」）。婚俗以**「哈节」对歌择偶、踢沙与独弦琴**为特色。

**核心要素**：
1. **「哈节」择偶**——「唱哈节」中青年男女对歌、以歌传情择偶。
2. **「对歌定情」**——以「唱哈」山歌传情，歌定婚姻。
3. **「提亲与定亲」**——媒人提亲，送糕饼、糖、布定亲。
4. **「拜堂敬茶」**——婚礼行拜堂礼、敬茶认亲。
5. **「独弦琴」**——婚礼奏独弦琴、唱哈助兴。
6. **「木屐迎娶」**——旧俗新娘穿木屐成礼，为京族特色。

## 二、历史源流

- **明末清初**：京族先民自越南涂山等地迁入，婚俗带越南风情。
- **近代**：三岛渔村婚俗见于方志与民族调查资料。
- **当代**：东兴京族「哈节」列入国家级非物质文化遗产名录。

## 三、仪节流程

1. 哈节对歌、择偶。
2. 提亲、定亲。
3. 送彩礼、择期。
4. 迎娶、拜堂。
5. 婚宴（唱哈、独弦琴）。
6. 回门。

## 四、地域与支系变体

- **澫尾、巫头、山心**：京族聚居区，婚俗保存较完整。
- **东兴市镇**：与汉族杂居，婚礼趋于汉化。
- **与其他民族关系**：京族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：独弦琴、木屐、歌本（唱哈词）、糕饼糖布。
- **服饰**：京族长衣、斗笠、绣花鞋。
- **文书**：婚约、礼单。
