# 门巴族婚俗

## 一、释义

门巴族主要分布于西藏墨脱、错那、林芝及山南一带。婚俗以**藏传佛教礼俗、「上门婚」与「舅权」**为特色。

**核心要素**：
1. **「上门婚」**——男方入赘女家（从妻居）较为常见。
2. **「提亲与定亲」**——由媒人提亲，献哈达、送酒定亲。
3. **「舅权」**——舅舅在婚礼中地位尊崇，须送「舅礼」。
4. **「献哈达、敬酒」**——婚礼中献哈达、敬青稞酒。
5. **「诵经祈福」**——受藏传佛教（宁玛派）影响，婚礼请喇嘛诵经。
6. **「唱歌跳舞」**——婚礼中唱歌、跳民间舞，通宵欢庆。

## 二、历史源流

- **清代**：门巴族婚俗见于《西藏志》与藏文文献。
- **近代**：上门婚、舅权等俗见于民族调查资料。
- **当代**：墨脱公路贯通后，门巴族传统婚俗与藏族交融。

## 三、仪节流程

1. 提亲、说媒。
2. 定亲（献哈达、送酒）。
3. 议彩礼、择期。
4. 迎娶（或入赘上门）。
5. 婚礼诵经、献哈达、敬酒。
6. 唱歌跳舞、回门。

## 四、地域与支系变体

- **墨脱**：门巴族聚居区，婚俗保存较完整。
- **错那、林芝**：与藏族、珞巴族杂居，婚俗交融。
- **与其他民族关系**：门巴族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：哈达、青稞酒、酥油茶、供佛器物。
- **服饰**：门巴族氆氇长袍、「巴尔霞」帽。
- **文书**：婚约、礼单（藏文文书）。
