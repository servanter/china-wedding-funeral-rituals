# 裕固族婚俗

## 一、释义

裕固族主要聚居于甘肃张掖肃南裕固族自治县，并分布于酒泉黄泥堡等地。婚俗以**「帐房戴头」、对歌敬酒与佛教祈福**为特色。

**核心要素**：
1. **「帐房戴头」**——姑娘十五至十七岁行「戴头面」仪式，此后可自由社交，为婚俗重要前奏。
2. **「提亲与定亲」**——媒人提亲，送酒、茶、哈达定亲。
3. **「对歌敬酒」**——婚礼中男女双方歌手对唱、敬酒，常通宵达旦。
4. **「送亲与迎亲」**——送亲队伍骑马赴男家，沿途对歌。
5. **「拜佛祈福」**——婚礼前后礼佛，请喇嘛诵经祝福。
6. **「回门」**——婚后归宁省亲。

## 二、历史源流

- **元明**：裕固族（「撒里畏兀儿」）婚俗见于《明史》与河西方志。
- **近代**：「帐房戴头」等俗见于民族调查资料。
- **当代**：肃南裕固族传统婚礼在非遗保护中受到重视。

## 三、仪节流程

1. 帐房戴头（成年礼）。
2. 提亲、定亲。
3. 送彩礼、择期。
4. 送亲、迎亲（骑马对歌）。
5. 拜佛、婚宴敬酒。
6. 回门。

## 四、地域与支系变体

- **肃南（康乐、皇城）**：裕固族聚居核心区，婚俗保存较完整。
- **酒泉黄泥堡**：与汉、蒙古族杂居，婚俗交融。
- **与其他民族关系**：裕固族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：头面（头饰）、哈达、酒、茶、马匹。
- **服饰**：裕固族高领长袍、头面、靴帽。
- **文书**：婚约、礼单。
