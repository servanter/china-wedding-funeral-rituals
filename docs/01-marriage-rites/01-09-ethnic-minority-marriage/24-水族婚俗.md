# 水族婚俗

## 一、释义

水族主要聚居于贵州黔南（三都、荔波、独山）及广西、云南部分地区。婚俗以**「水书择吉」「对歌」与「不落夫家」**为特色。

**核心要素**：
1. **「水书择吉」**——婚期、婚配合否依水族文字典籍「水书」（水书先生掌握）判定。
2. **「对歌」**——婚嫁过程伴以对歌。
3. **「提亲」「订婚」**——托媒提亲，聘礼为酒、米、猪、银饰。
4. **「不落夫家」**——婚后新妇暂住娘家，待生育或约定期满后住夫家。
5. **「端节」与婚俗**——端节（水族年节）为说亲、成婚的常见节点。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋**：水族先民（「僚」等）婚俗见于史籍。
- **明清**：方志（独山州志、三合县志等）载婚俗；水书文献在民间传承。
- **近代**：与汉、布依、苗族杂居，婚俗交融。
- **当代**：水书入选《世界记忆名录》；传统婚俗在三都、荔波保存。

## 三、仪节流程

1. 对歌交友。
2. 提亲（请水书先生合婚）。
3. 订婚：送聘礼、定婚期（依水书择吉）。
4. 迎娶：对歌迎客、婚宴。
5. 不落夫家：婚后暂住娘家。
6. 长住夫家／回门。

## 四、地域与支系变体

- **三都、荔波**：水族聚居核心区，水书传承最完整。
- **独山、都匀**：与汉、布依族杂居，婚俗汉化较深。
- **广西（南丹、环江）**：与壮、毛南族相邻。
- **与其他民族关系**：水族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **典籍**：水书（水文抄本）。
- **器物**：聘礼（酒、米、猪、银饰）、马尾绣服饰（水族特色）。
- **文书**：聘礼单、婚约（结婚证）。
