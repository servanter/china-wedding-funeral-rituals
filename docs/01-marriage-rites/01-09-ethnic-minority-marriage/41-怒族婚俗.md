# 怒族婚俗

## 一、释义

怒族主要分布于云南怒江傈僳族自治州（贡山、福贡、泸水）及迪庆、丽江西部。婚俗以**族外婚、对歌定情与「同心酒」**为特色。

**核心要素**：
1. **对歌择偶**——青年男女弹「达比亚」（琵琶）对歌，以歌传情。
2. **「以酒定亲」**——提亲、订婚以酒为礼，饮「同心酒」表信守。
3. **「族外婚」**——同氏族不婚，旧有「转房婚」（兄死弟娶其嫂）之俗。
4. **「抢婚遗存」**——旧俗迎亲时有象征性「抢婚」仪式。
5. **「竹楼火塘」**——婚礼在竹楼火塘边举行，拜火塘、敬长辈。
6. **「支系差异」**——怒苏、阿侬、柔若、贡山怒等支系婚俗各异。

## 二、历史源流

- **元明清**：怒族（「怒」「潞」）婚俗散见《元一统志》与滇西北方志。
- **近代**：转房婚、抢婚等俗见于民族调查资料。
- **当代**：贡山、福贡传统婚俗在非遗保护中受到记录。

## 三、仪节流程

1. 弹「达比亚」对歌交友。
2. 提亲、送酒定亲。
3. 订婚、议彩礼。
4. 迎亲（含象征性「抢婚」）。
5. 拜火塘、饮同心酒。
6. 婚宴、回门。

## 四、地域与支系变体

- **福贡、泸水**：怒苏等支系与傈僳族杂居，婚俗交融。
- **贡山**：贡山怒与独龙族关系密切，婚俗相近。
- **与其他民族关系**：怒族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：达比亚（琵琶）、竹筒酒、「同心酒」器皿。
- **服饰**：怒族麻布衣、竹饰与银饰。
- **文书**：婚约、礼单（旧以刻木、结绳为凭）。
