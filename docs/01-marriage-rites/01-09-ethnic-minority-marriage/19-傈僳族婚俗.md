# 傈僳族婚俗

## 一、释义

傈僳族主要分布于云南怒江、丽江、迪庆及四川凉山等地。婚前社交以**「串姑娘」「对歌」**为特色，婚礼以**「射箭」「对歌」**为仪节。

**核心要素**：
1. **「对歌择偶」**——节日、村寨相聚时以对歌交友。
2. **「提亲」「订婚」**——托媒提亲，聘礼以酒、布、牲畜为主（历史上「以牛为聘」）。
3. **「迎亲射箭」**——迎亲者至女家时，女方女方亲属有「射箭」相迎之礼（象征性）。
4. **「不落夫家」**（部分地区）——婚后新妇暂住娘家。
5. **基督教影响**——怒江部分傈僳族信仰基督教，婚礼行教会仪式（祈祷、唱赞美诗）。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋**：「栗粟」等称谓见于史籍。
- **明清**：方志（永昌府志、丽江府志等）载其婚俗。
- **近代**：基督教在怒江传播，形成两种并行的婚礼形态。
- **当代**：传统婚俗在怒江、丽江乡村保存。

## 三、仪节流程

1. 对歌交友。
2. 提亲、订婚（议聘礼）。
3. 迎亲：射箭相迎、对歌。
4. 婚礼：宴客、唱歌跳舞。
5. 不落夫家（部分地区）。
6. 回门。

## 四、地域与支系变体

- **怒江（泸水、福贡、贡山）**：基督教影响明显，婚礼有教会形式。
- **丽江、迪庆**：与纳西、藏族杂居，习俗互渗。
- **四川（凉山、攀枝花）**：与彝族杂居，习俗相近。
- **与其他民族关系**：傈僳族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、布、牲畜）、弩弓、口弦。
- **服饰**：傈僳族服饰（麻布衣、银饰）。
- **文书**：聘礼单、婚约；教会婚礼有祈祷仪式文本。
