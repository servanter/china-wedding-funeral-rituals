# 蒙古族婚俗

## 一、释义

蒙古族分布以内蒙古自治区为主，兼及东北、西北各省。传统婚配以**部落外婚、族外婚**为原则，仪式重「献哈达、敬奶酒、祭火」。

**核心要素**：
1. **哈达与奶酒为礼**——求婚、订婚、迎亲皆以哈达、奶酒、整羊为礼。
2. **「拦门」与「抢亲」遗俗**——迎亲时女方「闭门」设阻，双方以对歌、嬉闹相应；婚礼中有「抢哈达」「夺帽」等象征性「抢婚」游戏。
3. ****「拜火」**（祭火礼）**——新娘入夫家后绕火三圈、向火神献祭，为婚礼核心仪节。
4. **「全羊席」（乌查）**——婚宴以整羊待客，配奶食奶茶。
5. **骑马迎亲**——新郎率伴郎骑马前往女家，仪仗按部落规矩。

## 二、历史源流

- **蒙元时期**：草原婚俗载于使臣行记与史书；「献哈达」习俗随藏传佛教传播而普及。
- **明清**：各盟旗婚俗渐定型，部落差异显著（如鄂尔多斯、科尔沁、巴尔虎婚礼各具特色）。
- **近代**：定居化与牧业变迁使婚事趋简。
- **当代**：牧区传统婚礼在文化保护中重现；城市婚礼多中西结合。

## 三、仪节流程

1. **求婚（提亲）**：男家托媒携带哈达、奶酒至女家提亲。
2. **订婚**：女家应允后献哈达、议彩礼（马、牛、羊、布匹）。
3. **迎亲**：新郎率伴郎骑马前往，女方「拦门」对歌。
4. **拜火、拜天**：新娘绕火三圈、祭火祭天，行拜礼。
5. **婚宴**：设「全羊席」，歌舞宴饮（唱长调、跳安代）。
6. **回门**：婚后择日归宁省亲。

## 四、地域与支系变体

- **科尔沁（东部）**：受满汉影响较深，仪式兼有汉俗。
- **鄂尔多斯**：婚礼保留「求名问庚」「献羊祝酒」等古俗。
- **巴尔虎、布里亚特（呼伦贝尔）**：部落特色明显，仪式古朴。
- **青海、甘肃蒙古族**：受藏传佛教影响更深，婚礼带藏俗色彩。
- **与其他民族关系**：蒙古族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：哈达、奶酒、整羊（乌查）、马具、蒙古包（婚礼场所）。
- **服饰**：蒙古袍、腰带、头饰（新娘「头戴」）。
- **文书**：彩礼单、婚约（今为结婚证）。
