# 乌孜别克族婚俗

## 一、释义

乌孜别克族主要分布于新疆伊宁、乌鲁木齐、喀什、莎车等地。婚俗以**伊斯兰教「尼卡」、揭盖头与「麦西热甫」**为特色。

**核心要素**：
1. **「尼卡」**——阿訇主持念「尼卡」，为婚姻成立之要件。
2. **「提亲与定亲」**——男方母亲携礼物至女家提亲，定亲后送彩礼。
3. **「揭盖头」**——婚礼中唱「揭盖头歌」，新郎揭去新娘盖头。
4. **「麦西热甫」**——婚宴举行歌舞聚会，伴手鼓、热瓦甫。
5. **「抓饭婚宴」**——以「波糯」（抓饭）、馕、奶茶待客。
6. **「三日礼程」**——婚礼含迎娶、揭盖头、回门等环节。

## 二、历史源流

- **明清**：乌孜别克商人经丝路入居新疆，婚俗见于《西域闻见录》等。
- **近代**：聚居伊宁、喀什等地，婚礼沿伊斯兰教法办理。
- **当代**：城市乌孜别克族婚礼多从简，传统仪节见于家族传承。

## 三、仪节流程

1. 提亲（男方母亲率亲友送茶、糖）。
2. 定亲、议彩礼。
3. 尼卡（阿訇主持）。
4. 迎娶、婚宴（麦西热甫）。
5. 揭盖头。
6. 回门。

## 四、地域与支系变体

- **伊宁**：乌孜别克族聚居区，婚俗保存较完整。
- **喀什、莎车**：与维吾尔族往来密切，婚俗相近。
- **乌鲁木齐**：城市婚礼趋于简化。
- **与其他民族关系**：乌孜别克族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：手鼓、热瓦甫、抓饭（波糯）、馕、首饰。
- **服饰**：绣花小帽、长裙、坎肩。
- **文书**：宗教婚约（尼卡书）、礼单。
