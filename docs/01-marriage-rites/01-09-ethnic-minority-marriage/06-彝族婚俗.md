# 彝族婚俗

## 一、释义

彝族分布以四川凉山、云南、贵州、广西为主。传统婚配实行**家支外婚**（同一家支不得通婚），仪式中「哭嫁」「泼水」「打歌」并存。

**核心要素**：
1. **「家支外婚」**——婚姻须跨家支缔结，违者受家支规矩制裁。
2. **「提亲」「订婚」**——托媒提亲，聘礼以牛、羊、银饰为主；聘礼（「彩礼」）厚重。
3. **「哭嫁」与「泼水」**——新娘哭嫁；迎亲者至女家常被「泼水」相待（嬉闹之礼）。
4. **「背新娘」**——新娘由兄长或背亲人背出家门。
5. **「打歌」「跳左脚」**——婚礼中众人歌舞（滇西彝族「打歌」）。
6. **「不落夫家」（部分地区）**——婚后新妇暂住娘家，后长住夫家。

## 二、历史源流

- **汉唐**：彝族先民（「叟」「爨」等）婚俗见于史籍。
- **元明清**：土司制度与家支制度并行，婚俗载于方志「夷俗」门。
- **近代**：凉山家支制度与婚事紧密结合，婚姻具有家支联盟的意义。
- **当代**：凉山婚俗在文化保护中保存，婚配自主性提高。

## 三、仪节流程

1. **说亲（提亲）**：托媒说合，须为家支外婚。
2. **订婚**：议聘礼（牛、羊、银饰、布）、定婚期。
3. **哭嫁**：婚前新娘哭嫁、与女友对歌。
4. **迎亲**：迎亲队至女家，受「泼水」之礼；新娘由人背出。
5. **婚礼**：拜见长辈、宴客、歌舞（打歌）。
6. **回门／不落夫家**：婚后归宁或暂住娘家。

## 四、地域与支系变体

- **四川凉山**：家支制度与聘礼规制最典型。
- **云南（楚雄、红河、大理）**：与白、哈尼族习俗互有影响，「打歌」盛行。
- **贵州（毕节、六盘水）**：近汉族，婚俗兼有汉俗痕迹。
- **广西、云南边境**：与壮、苗族杂居，习俗互渗。
- **与其他民族关系**：彝族家支婚制与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（牛、羊、银饰）、披毡、酒、火塘（婚礼场所）。
- **服饰**：彝族服饰（查尔瓦、头帕）。
- **文书**：聘礼单、婚约（今为结婚证）。
