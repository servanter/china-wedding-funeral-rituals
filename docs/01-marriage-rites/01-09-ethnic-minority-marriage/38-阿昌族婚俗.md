# 阿昌族婚俗

## 一、释义

阿昌族主要聚居于云南德宏（陇川、梁河、芒市）及保山、大理一带。婚俗以**「串姑娘」对歌、姑舅表优先婚与「坐帐房」**为特色。

**核心要素**：
1. **「串姑娘」与对歌**——青年男女夜聚歌场对歌择偶。
2. **「姑舅表优先婚」**——舅家之子有优先娶姑家之女之权，旧谓「还舅家债」。
3. **「坐帐房」**——婚后新郎到女家「坐帐房」（从妻居）一段时间，而后携妻返家。
4. **「说亲与送聘」**——媒人提亲，聘礼含槟榔、酒肉及「户撒刀」。
5. **「拴线祝福」**——受南传佛教影响，婚礼中由长者拴线祝福。
6. **「嚼槟榔待客」**——婚宴以槟榔、茶待客。

## 二、历史源流

- **明清**：阿昌族先民（「峨昌」「阿昌」）婚俗散见《云南志》与滇西方志。
- **近代**：「串姑娘」「坐帐房」等俗见于 1950 年代西南民族调查资料。
- **当代**：陇川户撒、梁河等地传统婚俗保存。

## 三、仪节流程

1. 串姑娘、对歌交友。
2. 提亲、说媒。
3. 定亲、送聘（槟榔、酒肉、户撒刀）。
4. 迎亲、坐帐房。
5. 拜堂、拴线祝福。
6. 婚宴、回门。

## 四、地域与支系变体

- **陇川户撒**：阿昌族聚居区，以「户撒刀」与南传佛教婚俗著称。
- **梁河、芒市**：与傣、景颇族杂居，婚俗交融。
- **与其他民族关系**：阿昌族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（槟榔、酒、肉、户撒刀）、婚宴器皿。
- **服饰**：阿昌族服饰（黑、蓝布为主，配银饰）。
- **文书**：婚约、礼单。
