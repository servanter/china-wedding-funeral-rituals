# 保安族婚俗

## 一、释义

保安族主要聚居于甘肃临夏积石山保安族东乡族撒拉族自治县（大河家一带）。婚俗以**伊斯兰教「尼卡」、撒核桃红枣与「花儿」对唱**为特色。

**核心要素**：
1. **「尼卡」**——由阿訇主持念「尼卡」，婚姻据此成立。
2. **「提亲与送麦海勒」**——媒人提亲，男家致送「麦海勒」（彩礼）。
3. **「撒核桃、红枣」**——婚礼中撒核桃、红枣，寓多子多福。
4. **「花儿对唱」**——婚礼中唱「保安花儿」助兴。
5. **「保安腰刀」**——腰刀为特色器物，常作礼品。
6. **「三日礼程与回门」**——婚礼含迎娶、宴客、回门。

## 二、历史源流

- **元明清**：保安族先民婚俗沿伊斯兰教法，见于河州方志。
- **近代**：大河家聚居，婚礼与东乡、撒拉族相近。
- **当代**：积石山保安族传统婚礼在民族节庆中呈现。

## 三、仪节流程

1. 提亲、说媒。
2. 定亲、送麦海勒。
3. 尼卡（阿訇主持）。
4. 迎娶、撒核桃红枣。
5. 婚宴、花儿对唱。
6. 回门。

## 四、地域与支系变体

- **积石山大河家**：保安族聚居核心区，婚俗保存较完整。
- **临夏、青海循化**：与回族、撒拉族往来密切，婚俗相近。
- **与其他民族关系**：保安族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：保安腰刀、核桃、红枣、麦海勒礼。
- **服饰**：绸袍、盖头、绣花帽。
- **文书**：宗教婚约、礼单。
