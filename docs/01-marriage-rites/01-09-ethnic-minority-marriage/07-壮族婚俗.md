# 壮族婚俗

## 一、释义

壮族是人口最多的少数民族，主要分布于广西。婚姻实行**族外婚**，以**歌圩对歌择偶**与**部分地区的「不落夫家」**为显著特色。

**核心要素**：
1. **「歌圩」**——以「三月三」歌圩为盛，青年男女对歌择偶。
2. **「提亲」「订婚（定命）」**——托媒提亲，合八字（「定命」），送聘礼。
3. **「拦路歌」「封门」**——迎亲时女方以歌设阻，须对歌方得入门。
4. **「哭嫁」**——新娘出嫁前哭嫁。
5. **「不落夫家」**（部分地区）——婚后新妇长住娘家，待生育或数年后再住夫家。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **先秦至唐宋**：「骆越」「西瓯」先民婚俗见于史籍与考古。
- **唐宋以降**：道教与汉族礼俗传入，与本土习俗结合。
- **明清**：方志（广西通志、各府州县志）「风俗」门载婚仪与「不落夫家」。
- **当代**：婚礼保留对歌、拦门等形式；「三月三」成为重要节庆。

## 三、仪节流程

1. **歌圩相识**：对歌择偶。
2. **提亲**：托媒提亲。
3. **订婚（定命）**：合八字、送聘礼、定婚期。
4. **哭嫁**：婚前哭嫁。
5. **迎亲**：拦路对歌、拜堂、宴客。
6. **不落夫家／回门**：婚后暂住娘家或归宁。

## 四、地域与支系变体

- **桂中（南宁、来宾、柳州）**：歌圩、拦路歌盛行。
- **桂西（百色、河池）**：与瑶、侗、布依族杂居，习俗互渗。
- **桂北（桂林）**：近湖南，兼有湘俗痕迹。
- **云南壮族（文山）**：与苗、瑶、哈尼族杂居。
- **与其他民族关系**：壮族婚俗与汉族互有影响，但亲属制度不采「五服」体系，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、肉、布、银饰）、绣球、铜鼓、歌圩用品。
- **服饰**：壮锦、壮服（蓝靛染布）。
- **文书**：聘礼单、八字帖、结婚证。
