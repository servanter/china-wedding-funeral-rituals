# 仫佬族婚俗

## 一、释义

仫佬族主要聚居于广西河池（罗城仫佬族自治县等地）。婚俗以**「走坡」对歌、「不落夫家」与「依饭」祭祖**为特色。

**核心要素**：
1. **「走坡」**——青年男女于坡地、节日对歌择偶。
2. **「提亲」「订婚」**——托媒提亲，聘礼为酒、肉、布、银饰。
3. **「不落夫家」**——婚后新妇暂住娘家，待生育或约定期满后住夫家。
4. **「依饭节」与婚俗**——依饭节（祭祖节）为说亲、成婚的常见节点。
5. **「受汉壮影响」**——行对歌、拜堂等形式，兼有汉壮婚俗痕迹。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋至明清**：仫佬族先民（「僚」「伶」等）婚俗见于史籍与方志（庆远府志等）。
- **近代**：与壮、汉族杂居，婚俗汉化程度较高。
- **当代**：传统婚俗在罗城乡村保存。

## 三、仪节流程

1. 走坡对歌交友。
2. 提亲、订婚。
3. 迎娶：对歌迎客、拜堂、宴客。
4. 不落夫家：婚后暂住娘家。
5. 长住夫家。
6. 回门。

## 四、地域与支系变体

- **罗城**：仫佬族聚居核心区，婚俗保存较完整。
- **宜州、柳城**：与壮、汉族杂居，习俗交融。
- **与其他民族关系**：仫佬族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、肉、布、银饰）、歌圩用品。
- **服饰**：仫佬族服饰（蓝靛染布）。
- **文书**：聘礼单、婚约。
