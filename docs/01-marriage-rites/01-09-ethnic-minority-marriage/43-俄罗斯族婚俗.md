# 俄罗斯族婚俗

## 一、释义

俄罗斯族主要分布于新疆伊犁、塔城、阿勒泰、乌鲁木齐及内蒙古额尔古纳（恩和、室韦）等地。婚俗以**东正教婚礼、「面包与盐」迎客及歌舞婚宴**为特色。

**核心要素**：
1. **东正教婚礼**——于教堂举行，由神父主持，新人戴婚礼冠、交换戒指。
2. **「说媒」「相亲」**——由「斯瓦哈」（媒人）撮合，双方父母相看。
3. **「面包与盐」**——以面包蘸盐迎接新人，为俄式最高礼遇。
4. **订婚与结婚分办**——订婚（「斯瓦坦尼耶」）与结婚分两次举行。
5. **「手风琴与踢踏舞」**——婚宴以手风琴伴奏，跳俄罗斯民间舞。
6. **节令与婚礼相联**——「巴斯克节」（复活节）等节庆与婚俗相互关联。

## 二、历史源流

- **清代**：俄罗斯族自西伯利亚及俄境迁入，婚俗随东正教传入。
- **近代**：伊犁、额尔古纳形成聚居，教堂婚礼与俄式婚宴并行。
- **当代**：传统婚礼在民族乡节庆与文化活动中复原。

## 三、仪节流程

1. 说媒、相亲。
2. 订婚（斯瓦坦尼耶）。
3. 教堂婚礼（戴婚礼冠、交换戒指）。
4. 迎入新家，行「面包与盐」礼。
5. 婚宴歌舞（手风琴、踢踏舞）。
6. 回门。

## 四、地域与支系变体

- **新疆伊犁、塔城**：俄罗斯族聚居区，东正教婚礼保存较完整。
- **内蒙古额尔古纳（恩和、室韦）**：华俄后裔村落，婚俗融合汉俄。
- **与其他民族关系**：俄罗斯族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：面包与盐、婚礼冠、戒指、手风琴、彩蛋。
- **服饰**：俄式长裙、头巾（新娘）、绣花衬衫。
- **文书**：婚约、教堂婚礼登记。
