# 朝鲜族婚俗

## 一、释义

朝鲜族主要分布于吉林、黑龙江、辽宁，其婚俗**受朱子家礼影响最深**，是各民族中最接近儒家婚礼体系者。

**核心要素**：
1. **「议婚」「纳采」**——托媒议婚，男家送「纳采」（四柱单、请婚书）。
2. **「新郎婚礼」在女家举行**——新郎先至女家行婚礼（「亲迎」在此完成）。
3. **「奠雁礼」**——新郎向女家献木雁（「奠雁」），承古礼遗意。
4. **「交拜」「合卺」**——行礼交拜、合卺共饮。
5. **「币帛礼」**——新娘向公婆献礼（「币帛」），拜见长辈。
6. **「三日于归」「再行」**——婚后三日新郎先归，随后迎娶新娘归夫家（「三日于归」）。

## 二、历史源流

- **朝鲜王朝时期**：以《朱子家礼》为国家礼制典范，婚礼高度制度化，并随移民传入中国东北。
- **明清至近代**：朝鲜族迁入东北，婚礼连同家礼文本一并移植。
- **当代**：礼俗显著简化，多在礼堂或酒店举行；「币帛礼」「三日于归」等形式在传统婚礼中保留。

## 三、仪节流程

1. **议婚**：托媒议婚、合婚（看「宫合」）。
2. **纳采**：男家送请婚书与「四柱单」。
3. **亲迎（新郎婚礼）**：新郎至女家行奠雁、交拜、合卺。
4. **币帛礼**：新娘向公婆献礼。
5. **三日于归**：婚后三日新郎先归，再迎新娘归夫家。
6. **祭祀与回门**：祭告祖先，归宁省亲。

## 四、地域与支系变体

- **延边朝鲜族自治州**：民族聚居，传统礼俗保存较多。
- **黑龙江、辽宁聚居区**：与汉族杂居，仪式简化。
- **城市朝鲜族**：酒店婚礼为主，家族礼俗延续。
- **与其他民族关系**：朝鲜族与汉族同属儒家婚仪传统，但程序与用语有别，须分别记录。

## 五、器物与文书

- **器物**：木雁（奠雁）、合卺杯、彩礼、韩服婚装。
- **服饰**：新娘「绿衣红裳」、新郎礼服。
- **文书**：请婚书、四柱单、婚书、族谱。
