# 塔塔尔族婚俗

## 一、释义

塔塔尔族主要分布于新疆伊宁、乌鲁木齐、塔城、阿勒泰等地。婚俗以**伊斯兰教「尼卡」、揭盖头与「麦西热甫」**为特色。

**核心要素**：
1. **「提亲与定亲」**——男方家长携礼物至女家提亲，定亲后送彩礼。
2. **「尼卡」**——由阿訇主持念「尼卡」。
3. **「揭盖头」**——婚礼中唱歌揭去新娘盖头。
4. **「撒糖果」**——婚礼中撒糖果、食品，寓甜蜜美满。
5. **「麦西热甫」**——婚宴举行歌舞聚会。
6. **「崇尚教育」**——塔塔尔族重视教育，婚礼多尚简朴。

## 二、历史源流

- **清代**：塔塔尔族（「鞑靼」）自俄境迁入新疆，婚俗带伊斯兰与俄式影响。
- **近代**：伊宁、塔城形成聚居，婚礼沿伊斯兰教法办理。
- **当代**：城市塔塔尔族婚礼趋于简化。

## 三、仪节流程

1. 提亲、说媒。
2. 定亲、送彩礼。
3. 尼卡（阿訇主持）。
4. 迎娶、婚宴（麦西热甫）。
5. 揭盖头。
6. 回门。

## 四、地域与支系变体

- **伊宁、塔城**：塔塔尔族聚居区，婚俗保存较完整。
- **乌鲁木齐**：城市婚礼趋于简化。
- **与其他民族关系**：塔塔尔族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：手鼓、糖果、抓饭、首饰。
- **服饰**：绣花小帽、裙装、坎肩。
- **文书**：宗教婚约、礼单。
