# 黎族婚俗

## 一、释义

黎族是海南岛世居民族，分「哈」「杞」「润」「美孚」「赛」等方言支系。婚俗以**「放寮」（夜游对歌）择偶、「不落夫家」与婚宴共食**为特色。

**核心要素**：
1. **「放寮」（即「夜游」）**——青年男女夜晚对歌交友（部分支系有「寮房」社交形式）。
2. **「提亲」「订婚」**——男方托媒提亲，送聘礼（酒、猪、米、槟榔）。
3. **「不落夫家」**——婚后新妇住娘家，待生育或数年后长住夫家（部分支系）。
4. **「槟榔为礼」**——婚事中槟榔为重要礼信。
5. **「合亩制」影响**（部分黎区历史形态）——婚姻与「合亩」组织相关。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **先秦至唐宋**：黎族先民（「骆越」后裔）婚俗见于史籍与考古。
- **明清**：方志（琼州府志、各县志）「黎情」门载婚俗。
- **近代**：与汉族、苗族杂居，部分习俗汉化。
- **当代**：婚俗在黎村保存，「放寮」等进入民族志记录。

## 三、仪节流程

1. 放寮对歌交友。
2. 提亲（送槟榔、酒）。
3. 订婚：议聘礼、定婚期。
4. 迎娶：接亲、宴客、共食。
5. 不落夫家：婚后暂住娘家。
6. 长住夫家／回门。

## 四、地域与支系变体

- **五指山、琼中（杞、赛方言区）**：传统婚俗保存较多。
- **白沙、昌江（润方言区）**：习俗近汉族地区。
- **乐东、三亚（哈方言区）**：人口最多，支系内差异明显。
- **美孚方言区（东方、昌江）**：习俗另有特点。
- **与其他民族关系**：黎族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：槟榔、聘礼（酒、猪、米）、黎锦、银饰。
- **服饰**：黎族筒裙、黎锦服饰。
- **文书**：聘礼单、婚约。
