# 白族婚俗

## 一、释义

白族主要聚居于云南大理白族自治州。婚俗**受汉族礼制、佛教（阿吒力）与本土信仰多重影响**，礼数讲究。

**核心要素**：
1. **「提亲」「订婚」**——托媒提亲，送聘礼（茶、酒、布、银饰），近汉礼而自有规格。
2. **「哭嫁」**——新娘出嫁前哭嫁。
3. **「迎亲」「拜堂」**——花轿迎娶，拜天地、拜本主。
4. **「本主」祭告**——婚事中祭告村落「本主」（保护神）。
5. **「三道茶」待客**——婚宴以「一苦二甜三回味」的三道茶待客。
6. **「回门」**——三朝归宁。

## 二、历史源流

- **南诏、大理国时期**：佛教（密宗阿吒力）盛行，婚俗带宗教色彩。
- **元明清**：受汉文化与道教影响，礼制渐备；方志载婚仪与「本主」祭祀。
- **当代**：城居婚礼为主，乡村保留本主祭告与三道茶之俗。

## 三、仪节流程

1. 提亲、合婚。
2. 订婚：送聘礼、定婚期。
3. 哭嫁：婚前哭嫁。
4. 迎亲：花轿迎娶，拜堂、祭告本主。
5. 婚宴：三道茶、宴客。
6. 回门：三朝归宁。

## 四、地域与支系变体

- **大理坝区**：礼数规整，本主信仰与婚俗结合。
- **洱源、剑川**：与汉族、彝族杂居，习俗互渗。
- **怒江、保山白族（勒墨人、那马人）**：支系习俗较古朴。
- **与其他民族关系**：白族婚俗与汉族有交融，但程序与信仰基础不同，须分别记录。

## 五、器物与文书

- **器物**：花轿、聘礼（茶、酒、布）、三道茶具、本主祭品。
- **服饰**：白族服饰（「风花雪月」头饰）。
- **文书**：庚帖、聘礼单、婚约。
