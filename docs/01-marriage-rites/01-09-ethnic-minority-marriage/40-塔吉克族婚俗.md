# 塔吉克族婚俗

## 一、释义

塔吉克族主要聚居于新疆塔什库尔干塔吉克自治县，并分布于莎车、泽普、叶城等地。婚俗以**伊斯兰教「尼卡」、撒面粉祝福与鹰舞叼羊**为特色。

**核心要素**：
1. **「尼卡」**——由阿訇按伊斯兰教法主持念「尼卡」，确认婚约。
2. **「撒面粉」祝福**——婚礼中以面粉撒向新人，为古老祈福遗俗。
3. **「拜火遗存」**——新娘入夫家时绕火、跨火，留有祆教（拜火教）痕迹。
4. **「三日婚礼」**——婚礼历时三日，含「尼卡」与「揭盖头」等环节。
5. **「鹰笛与鹰舞」**——婚礼吹鹰笛、跳鹰舞，并伴「叼羊」「赛马」竞技。
6. **「库勒塔帽与盖头」**——新娘戴「库勒塔」绣帽，第三日揭盖头。

## 二、历史源流

- **唐代以来**：塔吉克族先民（「羯盘陀」等）地处丝路要冲，伊斯兰教随丝路传入。
- **明清**：色勒库尔（今塔什库尔干）地区婚俗见于《西域图志》等。
- **当代**：帕米尔高原塔吉克族传统婚礼与鹰舞在非遗保护中受到重视。

## 三、仪节流程

1. 提亲、说媒。
2. 定亲、送聘（衣料、首饰、牲畜）。
3. 尼卡（阿訇主持）。
4. 迎娶、撒面粉、绕火。
5. 婚宴、鹰舞、叼羊。
6. 第三日揭盖头、回门。

## 四、地域与支系变体

- **塔什库尔干**：塔吉克族聚居核心区，婚俗特色最鲜明。
- **莎车、泽普、叶城**：平原塔吉克，与维吾尔族往来较多。
- **与其他民族关系**：塔吉克族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：鹰笛、手鼓、面粉、首饰、马匹。
- **服饰**：「库勒塔」帽、绣花头巾、红裙。
- **文书**：宗教婚约、礼单。
