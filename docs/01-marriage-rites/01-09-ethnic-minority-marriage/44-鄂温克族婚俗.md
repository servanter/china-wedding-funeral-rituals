# 鄂温克族婚俗

## 一、释义

鄂温克族主要分布于内蒙古呼伦贝尔（鄂温克族自治旗、根河敖鲁古雅）及黑龙江讷河等地。婚俗以**族外婚、驯鹿与猎马为聘及篝火歌舞**为特色。

**核心要素**：
1. **族外婚**——同氏族不婚，由媒人牵线说合。
2. **「求婚与过彩礼」**——男方携酒、哈达求婚，聘礼视支系为驯鹿、马匹或猎获物。
3. **「使鹿支系」**——敖鲁古雅使鹿鄂温克以驯鹿为聘、驯鹿迎亲。
4. **「抢婚遗存」**——旧俗迎亲时有象征性「抢婚」。
5. **「篝火与歌舞」**——婚礼围绕篝火举行，唱歌跳舞。
6. **「萨满祈福」**——旧俗请萨满为新人祈福。

## 二、历史源流

- **清代**：鄂温克（「索伦」「通古斯」「雅库特」）婚俗见于《黑龙江外记》与方志。
- **近代**：猎区、牧区、使鹿区婚俗差异显著。
- **当代**：鄂温克族自治旗与敖鲁古雅传统婚礼在文化活动与非遗保护中呈现。

## 三、仪节流程

1. 媒人求婚。
2. 订婚、议彩礼（驯鹿或马匹）。
3. 迎亲（猎马或驯鹿）。
4. 篝火仪式、萨满祈福。
5. 婚宴歌舞。
6. 回门。

## 四、地域与支系变体

- **鄂温克族自治旗**：牧区鄂温克，聘礼以马、牛、羊为主。
- **敖鲁古雅（根河）**：使鹿鄂温克，聘礼以驯鹿为特色。
- **黑龙江讷河等地**：与达斡尔、汉族杂居，婚俗交融。
- **与其他民族关系**：鄂温克族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：驯鹿、猎马、哈达、酒浆、桦皮器。
- **服饰**：鄂温克族皮袍、驯鹿皮靴、头饰。
- **文书**：婚约、礼单（旧以口头约定为主）。
