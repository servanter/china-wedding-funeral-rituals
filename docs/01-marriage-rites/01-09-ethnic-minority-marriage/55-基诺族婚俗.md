# 基诺族婚俗

## 一、释义

基诺族主要聚居于云南西双版纳景洪基诺山（基诺乡）。婚俗以**「串姑娘」、对歌哭嫁与寨老主持**为特色。

**核心要素**：
1. **「串姑娘」**——青年男女夜聚对歌，恋爱较为自由。
2. **「成年礼」**——青年行成年礼后方可「串姑娘」交往。
3. **「说亲与定亲」**——男方父母托媒提亲，送茶、酒定亲。
4. **「哭嫁」**——新娘出嫁前唱哭嫁歌。
5. **「寨老主持」**——婚礼由「卓巴」「卓生」（寨老）主持。
6. **「大鼓与特懋克」**——「大鼓」崇拜与「特懋克」（打铁节）为关联习俗。

## 二、历史源流

- **清代**：基诺族（旧称「攸乐」）婚俗散见《普洱府志》与傣文文献。
- **近代**：「串姑娘」、寨老制婚俗见于 1950 年代民族调查资料。
- **当代**：基诺山传统婚俗与「特懋克节」列入非遗保护。

## 三、仪节流程

1. 串姑娘、对歌。
2. 提亲、送茶酒定亲。
3. 订婚、议彩礼。
4. 迎亲、哭嫁。
5. 寨老主持、宴客对歌。
6. 回门。

## 四、地域与支系变体

- **基诺山（景洪）**：基诺族聚居核心区，婚俗保存较完整。
- **西双版纳其他乡镇**：与傣、哈尼族杂居，婚俗交融。
- **与其他民族关系**：基诺族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：茶、酒、大鼓、纺织器具。
- **服饰**：基诺族条纹麻布衣、尖顶帽。
- **文书**：婚约、礼单。
