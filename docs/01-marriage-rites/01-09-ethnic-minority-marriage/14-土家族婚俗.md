# 土家族婚俗

## 一、释义

土家族主要聚居于湘西、鄂西、渝东南、黔东北。婚俗以**「哭嫁」与「陪十姊妹」**最具特色。

**核心要素**：
1. **「哭嫁」**——新娘出嫁前哭嫁歌（「哭嫁」为土家族标志性婚俗），内容为谢父母、别亲友。
2. **「陪十姊妹」「陪十兄弟」**——婚前男女分别由同伴陪伴对歌，通宵达旦。
3. **「提亲」「订婚」**——托媒提亲，送聘礼（酒、肉、布、米）。
4. **「拦门」「对歌」**——迎亲时女方设拦门之礼。
5. **「拜堂」「坐帐」**——程序齐全。
6. **「回门」**——三朝归宁。

## 二、历史源流

- **先秦**：土家族先民（巴人）尚歌舞，《楚辞》与巴楚巫风渊源相关。
- **唐宋**：巴人歌俗见于记载，「哭嫁」传统在歌俗中孕育。
- **明清**：方志（永顺府志、施南府志等）载婚仪与哭嫁之俗。
- **当代**：「哭嫁歌」「撒叶儿嗬」等进入非遗保护，传统婚俗在清江、酉水流域保存。

## 三、仪节流程

1. 提亲、合婚。
2. 订婚：送聘礼、定婚期。
3. 哭嫁、陪十姊妹（婚前）。
4. 迎亲：拦门对歌、接亲。
5. 拜堂、坐帐、宴客。
6. 回门。

## 四、地域与支系变体

- **清江流域（长阳、五峰）**：哭嫁、跳丧等民俗保存完整。
- **湘西（龙山、永顺）**：与苗族杂居，兼有苗俗。
- **渝东南（酉阳、秀山）**：近重庆，习俗与川渝相类。
- **黔东北（铜仁）**：与侗、苗族杂居，习俗互渗。
- **与其他民族关系**：土家族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、肉、布、米）、锣鼓、歌堂用品。
- **服饰**：土家族服饰（西兰卡普织锦）。
- **文书**：聘礼单、哭嫁歌抄本、婚约。
