# 傣族婚俗

## 一、释义

傣族主要分布于云南西双版纳、德宏及普洱、临沧等地，信仰**南传佛教**。婚俗以**「丢包」择偶、「从妻居」（上门）与拴线祝福**为特色。

**核心要素**：
1. **「丢包」「串寨」**——青年男女以「丢包」、对歌交友。
2. **「提亲」「订婚」**——男方托媒提亲，女方允婚后议彩礼。
3. **「从妻居」（上门）**——婚后男子先到女家居住（时间一至数年不等），再携妻回夫家或长期从妻居（西双版纳尤常见）。
4. **「拴线」祝福**——婚礼中由长者以白线拴新郎新娘手腕，诵祝词，为核心仪节。
5. **「滴水」回向**——婚事中亦有「滴水」祈福。
6. **「祭寨神」**——婚事与村寨祭祀相关。

## 二、历史源流

- **唐宋**：南传佛教经由东南亚传入，与傣族原始信仰结合。
- **元明清**：土司制度下，村社与佛寺共同参与婚事；方志载其婚俗。
- **近代**：「从妻居」「拴线」之俗延续。
- **当代**：城居婚礼简化，「拴线」与泼水节等节庆婚俗并行。

## 三、仪节流程

1. 丢包、对歌交友。
2. 提亲、订婚（议彩礼）。
3. 婚礼：拴线祝福、滴水祈福。
4. 从妻居：男子先入女家居住（视约定）。
5. 婚宴：村寨共贺。
6. 转至夫家或长期从妻居。

## 四、地域与支系变体

- **西双版纳（傣泐）**：「从妻居」与拴线之俗完整，佛教色彩浓。
- **德宏（傣那）**：与景颇、阿昌族杂居，习俗互渗。
- **普洱、临沧**：支系习俗有别。
- **与其他民族关系**：傣族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：白线（拴线用）、银饰、彩礼（布匹、酒、蜡条）、滴水器。
- **服饰**：傣族筒裙、银腰带。
- **文书**：彩礼单、婚约（结婚证）。
