# 苗族婚俗

## 一、释义

苗族分布广（贵州、云南、湖南、广西、重庆、四川等），支系众多，婚俗差异较大。共同特点是**以歌择偶、以酒待客、部分支系行「不落夫家」**。

**核心要素**：
1. **「游方」「跳花」「赶秋」**——青年男女以对歌（「游方」）择偶，为婚前的社交形式。
2. **「提亲」「订婚」**——托媒提亲，送聘礼（酒、肉、银饰、衣物）。
3. **「拦门酒」**——迎亲时女方设「拦门酒」，迎亲者须饮酒对歌方得入门。
4. **「不落夫家」**——部分支系婚后新妇仍住娘家，待生育或数年后长住夫家。
5. **「姊妹歌」「哭嫁」**——婚前女友陪唱姊妹歌、新娘哭嫁。

## 二、历史源流

- **先秦至唐宋**：苗族先民（「三苗」「南蛮」）婚俗见于史籍。
- **明清**：方志（贵州通志、湖南通志等）「苗俗」门载婚仪与「游方」之俗。
- **近代**：基督教传入部分苗区，少数家庭行教会婚礼。
- **当代**：传统婚俗在黔东南、湘西仍保存；「游方」「姊妹节」等进入非遗名录。

## 三、仪节流程

1. **游方择偶**：青年男女对歌相识、相恋。
2. **提亲**：男方托媒提亲。
3. **订婚**：议聘礼、定婚期。
4. **迎亲**：迎亲队至女家，饮「拦门酒」、对歌。
5. **婚礼**：拜见长辈，宴客（吹芦笙、唱歌）。
6. **不落夫家（部分支系）→ 长住夫家**：随生育或约定时间转入夫家生活。

## 四、地域与支系变体

- **黔东南（台江、雷山、剑河）**：「游方」「姊妹节」传统浓厚。
- **湘西（湘西州）**：与土家、汉族杂居，婚俗交融。
- **黔西北、滇东北（毕节、昭通）**：近彝族，习俗互有影响。
- **滇南、桂北**：与壮、瑶、布依族杂居。
- **与其他民族关系**：苗族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：芦笙、银饰、米酒、糯米、聘礼（酒肉、布料）。
- **服饰**：苗绣盛装、银冠银饰。
- **文书**：聘礼单、婚约（今为结婚证）。
