# 土族婚俗

## 一、释义

土族主要聚居于青海互助、民和、大通及甘肃天祝等地。婚礼以**「哭嫁」「纳什金（迎亲对歌）」与歌舞**为特色。

**核心要素**：
1. **「提亲」「订婚」**——托媒提亲，送聘礼（酒、茶、布、银饰）。
2. **「纳什金」**——迎亲者（「纳什金」）赴女家，双方对歌、泼水嬉闹，为土族婚礼核心环节。
3. **「哭嫁」**——新娘出嫁前哭嫁。
4. **「歌舞」**——婚礼中唱「道拉」（婚礼歌）、跳「安昭」舞。
5. **「拜天地与祭祖」**——行拜礼、祭告祖先（藏传佛教与民间信仰并行）。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **元明**：土族（「土人」）形成于河湟地区，藏传佛教与民间信仰并行。
- **明清**：方志（西宁府志、碾伯县志等）载其婚俗。
- **近代**：与汉、藏、回族杂居，婚俗互有影响。
- **当代**：「土族婚礼」「安昭舞」列入非遗名录。

## 三、仪节流程

1. 提亲、订婚。
2. 送聘礼、定婚期。
3. 哭嫁（婚前）。
4. 迎亲：「纳什金」对歌、泼水。
5. 婚礼：拜天地、祭祖、跳安昭舞、宴客。
6. 回门。

## 四、地域与支系变体

- **互助、民和**：婚礼歌与安昭舞最典型。
- **大通、天祝**：与藏、汉族杂居，仪式简化。
- **与其他民族关系**：土族婚俗受藏传佛教影响较深，与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、茶、布、银饰）、泼水用具、安昭舞服饰。
- **服饰**：土族服饰（七彩袖、绣花）。
- **文书**：聘礼单、婚礼歌抄本、婚约。
