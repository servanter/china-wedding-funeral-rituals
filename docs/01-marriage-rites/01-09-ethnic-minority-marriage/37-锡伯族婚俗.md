# 锡伯族婚俗

## 一、释义

锡伯族主要聚居于新疆伊犁（察布查尔锡伯自治县），并分布于辽宁、吉林、黑龙江等地。婚俗受满、汉影响较深，以**「哈拉莫昆」外婚、说亲迎亲与「装烟」礼**为特色。

**核心要素**：
1. **「哈拉莫昆」外婚**——同「哈拉」（氏族）、同「莫昆」（家族）不婚，讲究辈分与门第。
2. **「说亲」「定亲」**——托媒提亲，送酒礼定亲，纳彩礼（布匹、首饰、牲畜）。
3. **「打丁巴」**——迎亲日男方组成迎亲队赴女家，双方嬉闹、对歌助兴的仪式。
4. **「装烟」礼**——新娘入门拜天地、拜公婆，并为长辈装烟点火，以示敬奉。
5. **「贝伦舞」**——婚宴跳贝伦舞、唱满调助兴。
6. **「屯垦戍边与跨族通婚」**——新疆锡伯族屯垦戍边，与汉、哈萨克、维吾尔等族往来渐多。

## 二、历史源流

- **清代**：锡伯族编入八旗，婚俗受满族影响；乾隆年间部分西迁伊犁戍边，形成察布查尔聚居区。
- **近代**：保留满式婚礼仪节，「装烟」「打丁巴」等俗见于方志与民族志。
- **当代**：察布查尔等地传统婚礼与「贝伦舞」在文化活动与非遗保护中重现。

## 三、仪节流程

1. 说亲：媒人提亲，合婚、议亲。
2. 定亲：男家送酒礼、首饰，正式订婚。
3. 送彩礼：婚期前致送布匹、糕点等礼。
4. 迎亲：「打丁巴」，迎亲队赴女家，嬉闹对歌。
5. 拜堂、装烟：拜天地、拜公婆，新娘为长辈装烟。
6. 婚宴、回门：设宴跳贝伦舞，婚后择日归宁。

## 四、地域与支系变体

- **察布查尔（新疆伊犁）**：锡伯族聚居核心区，满式婚俗保存最著。
- **辽宁、吉林、黑龙江**：与汉、满族杂居，婚礼趋于汉满合流。
- **伊犁河谷**：戍边屯垦聚落，与哈萨克、维吾尔族往来较多。
- **与其他民族关系**：锡伯族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：酒礼、首饰、布匹、喜饼、婚宴器皿。
- **服饰**：满式旗袍、坎肩、绣花鞋（新娘）。
- **文书**：婚约、礼单（今为结婚证）。
