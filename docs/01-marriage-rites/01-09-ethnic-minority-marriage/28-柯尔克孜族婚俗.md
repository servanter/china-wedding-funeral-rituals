# 柯尔克孜族婚俗

## 一、释义

柯尔克孜族主要分布于新疆克孜勒苏柯尔克孜自治州及伊犁、阿克苏等地，信仰伊斯兰教。婚配实行**部落外婚**，婚礼依宗教规范并保留游牧特色。

**核心要素**：
1. **「提亲」「订婚」**——男方托媒提亲，送彩礼（马、羊、布匹、银饰）。
2. **「念尼卡」**——婚礼请阿訇念「尼卡」证婚。
3. **「对歌」与竞技**——婚礼中青年男女对歌，并有赛马、叼羊等活动。
4. **「揭面纱」**——新娘入夫家行揭面纱礼（与哈萨克族习俗相类）。
5. **「婚宴」**——设席待客（奶茶、手抓肉、马奶酒视教门而定）。
6. **「回门」**——婚后归宁。

## 二、历史源流

- **伊斯兰教传入后**：婚礼规范与游牧旧俗结合。
- **清代**：柯尔克孜部众分布于天山南北，婚俗与宗教信仰相应。
- **当代**：城市婚礼简化，传统竞技与对歌在牧区保留。

## 三、仪节流程

1. 提亲、订婚。
2. 送彩礼。
3. 念尼卡：阿訇证婚。
4. 揭面纱：新娘入夫家行礼。
5. 婚庆：对歌、竞技、宴客。
6. 回门。

## 四、地域与支系变体

- **克孜勒苏（阿图什、乌恰）**：聚居区，仪轨规范。
- **伊犁、阿克苏**：与维吾尔、哈萨克族习俗相邻。
- **与其他民族关系**：同遵伊斯兰婚礼诸族细节有异，与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：彩礼（马、羊、布匹）、毡房、马具、库姆孜（拨弦乐器）。
- **服饰**：柯尔克孜族服饰（银饰、白毡帽）。
- **文书**：彩礼单、婚约（结婚证）。
