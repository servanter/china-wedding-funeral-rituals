# 高山族婚俗

## 一、释义

高山族是对台湾地区南岛语系各民族的统称（包括阿美、泰雅、排湾、布农、邹、达悟等族群），大陆亦有高山族同胞。各族群婚俗差异极大。

**共同特征**：
1. **年龄组织与择偶**——青年男女通过年龄组织（如「青年会所」）社交、歌舞相识。
2. **「从妻居」或「从夫居」**——不同族群取向不同（阿美等族群行**从妻居**，男子入赘女家）。
3. **聘礼**——多以猪、酒、粟（小米）、槟榔、布匹为聘。
4. **歌舞为礼**——婚礼以集体歌舞（「丰年祭」式歌舞）为核心。
5. **祖灵与禁忌**——婚礼须祭告祖灵；丧期禁忌繁复，与婚事严格分开。
6. **族外婚**——禁止近亲婚配，规则严格。

## 二、历史源流

- **史前至明清**：台湾考古所见的聚落与墓葬材料与各族群婚俗相应；明清方志（台湾府志等）载「番俗」婚仪。
- **近代**：外来宗教（基督教）传入部分族群，婚礼形式改变。
- **当代**：各族群文化复兴使传统婚俗受到关注与部分恢复。

## 三、仪节流程

1. 歌舞社交、择偶。
2. 提亲（托族中长老或媒人）。
3. 议聘礼、定婚期（祭告祖灵）。
4. 迎娶（视族群行从妻居或从夫居）。
5. 婚礼歌舞、宴飨。
6. 婚后定居安排、祭祖。

## 四、地域与支系变体

- **阿美**：从妻居，年龄组织与歌舞突出。
- **泰雅、赛德克**：山地族群，婚配禁忌严格。
- **排湾、鲁凯**：贵族制度影响婚配（阶级内婚倾向）。
- **达悟（雅美）**：海岛族群，另有特定婚俗与禁忌。
- **与其他民族关系**：高山族各族群属南岛语族文化系统，与汉族婚俗无继受关系，须分别记录。

## 五、器物与文书

- **器物**：聘礼（猪、酒、粟、槟榔、布）、乐器（弓琴、木鼓）。
- **服饰**：族群服饰（贝珠、琉璃珠）。
- **文书**：族中议婚记录（口传）、婚约。
