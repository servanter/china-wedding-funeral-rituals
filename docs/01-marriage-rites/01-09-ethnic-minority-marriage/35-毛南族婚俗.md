# 毛南族婚俗

## 一、释义

毛南族主要聚居于广西河池（环江毛南族自治县等地）。婚俗以**「对歌」「不落夫家」与「花竹帽」**为特色。

**核心要素**：
1. **「对歌择偶」**——节日、歌场中以对歌交友。
2. **「提亲」「订婚」**——托媒提亲，聘礼为酒、肉、布、银饰。
3. **「花竹帽」**——毛南族「顶卡花」（花竹帽）为定情、婚嫁的重要信物（男方送女方）。
4. **「不落夫家」**——婚后新妇暂住娘家，待生育或约定期满后住夫家。
5. **「分龙节」与婚俗**——分龙节（祭祖节）为说亲、成婚的常见节点。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋至明清**：毛南族先民（「茅滩」「冒南」等称谓）见于史籍与方志（庆远府志等）。
- **近代**：与壮、汉族杂居，婚俗汉化程度较高。
- **当代**：传统婚俗在环江乡村保存。

## 三、仪节流程

1. 对歌交友。
2. 提亲、订婚（送花竹帽）。
3. 迎娶：对歌迎客、拜堂、宴客。
4. 不落夫家：婚后暂住娘家。
5. 长住夫家。
6. 回门。

## 四、地域与支系变体

- **环江（上南、中南、下南）**：毛南族聚居核心区，习俗保存较完整。
- **河池其他地区**：与壮、汉族杂居，习俗交融。
- **与其他民族关系**：毛南族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：花竹帽（顶卡花）、聘礼（酒、肉、布、银饰）。
- **服饰**：毛南族服饰（蓝靛染布）。
- **文书**：聘礼单、婚约。
