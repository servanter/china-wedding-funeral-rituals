# 佤族婚俗

## 一、释义

佤族主要分布于云南临沧、普洱（沧源、西盟等地）。婚俗以**「串姑娘」对歌、「抢婚」遗俗与村寨共食**为特色。

**核心要素**：
1. **「串姑娘」**——青年男女夜晚对歌交友（部分村寨有「公房」社交形式）。
2. **「提亲」「订婚」**——托媒提亲，聘礼为酒、米、鸡、牛（视家力）。
3. **「抢婚」遗俗**——部分地区婚礼有象征性「抢亲」（双方事先约定）。
4. **「魔巴占卜」**——以占卜定婚期、择吉。
5. **南传佛教影响**——部分佤族信仰南传佛教，婚礼兼有佛事。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋至明清**：佤族先民婚俗见于《蛮书》与明清方志。
- **近代**：部分地区的旧俗在 20 世纪中期废止；佛教影响加深。
- **当代**：传统婚俗在沧源、西盟等佤族聚居区保存。

## 三、仪节流程

1. 串姑娘对歌交友。
2. 提亲、占卜择吉。
3. 订婚（议聘礼）。
4. 迎亲：象征性「抢亲」、对歌、宴客。
5. 婚礼：村寨共食、歌舞。
6. 回门。

## 四、地域与支系变体

- **西盟、沧源**：佤族聚居区，传统婚俗保存较多。
- **普洱、临沧其他地区**：与傣、拉祜族杂居，受南传佛教影响。
- **与其他民族关系**：佤族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、米、鸡、牛）、木鼓（村寨祭祀重器）、祭器。
- **服饰**：佤族服饰（黑红为主的织锦）。
- **文书**：聘礼单、婚约。
