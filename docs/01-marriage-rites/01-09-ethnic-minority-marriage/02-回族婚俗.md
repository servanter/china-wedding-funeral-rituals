# 回族婚俗

## 一、释义

回族婚礼以**伊斯兰教婚姻规范**为本，核心是**阿訇证婚、双方自愿、念「尼卡哈」**。

**核心要素**：
1. **「尼卡哈」（尼卡）**——由阿訇主持的证婚仪式，念婚礼经文，询问双方是否自愿。
2. **「聘礼」（麦哈尔）**——男方须向女方交付聘礼，女方自愿收取。
3. **「送大礼」「下聘」**——婚前送聘礼（茶叶、糖、衣物、首饰）。
4. **婚宴（「乜贴」）**——设席待客，忌用酒（部分家庭严格禁酒）。
5. **禁忌**——不拜天地、不烧香拜偶像、不看风水、不择「吉日」（以方便为要）；婚礼中不用烟酒、不摆供品（视教门严格程度）。

## 二、历史源流

- **唐宋**：穆斯林（「蕃客」「回回」）入华，宗教婚礼随之传入。
- **元明**：回回民族共同体形成，清真寺与「掌教」主持婚礼；「尼卡哈」之制确立。
- **明清至民国**：回民社区自治程度高，婚礼规范由阿訇与寺坊主持。
- **当代**：宗教仪轨与婚姻登记并行；城市婚礼简化，但「念尼卡」「请阿訇」仍普遍。

## 三、仪节流程

1. **提亲**：由男方家长托媒或亲友说合。
2. **订婚（下定）**：送聘礼、订亲（多为「送大礼」）。
3. **婚礼（尼卡哈）**：请阿訇念「尼卡哈」，双方表态自愿，阿訇祝福。
4. **婚宴**：设席待客，亲友道贺。
5. **「认亲」**：新娘拜见公婆与长辈（「认大小」）。
6. **回门**：婚后择日归宁。

## 四、地域与支系变体

- **西北（宁夏、甘肃、青海、新疆）**：宗教仪轨严格，社区参与度高。
- **中原与华北**：与汉族杂居，严守宗教规范而不采汉俗。
- **东南（福建、广东、海南）**：沿海回族社区，婚礼从简。
- **与其他民族关系**：维吾尔、哈萨克、东乡、撒拉、保安、柯尔克孜、乌孜别克、塔吉克、塔塔尔等族同遵伊斯兰婚礼，细节有异，须分别记录。

## 五、器物与文书

- **器物**：聘礼（茶、糖、衣料、首饰）、喜糖、婚宴用品。
- **宗教器物**：《古兰经》、清真寺。
- **文书**：婚约（念尼卡时的记录）、结婚证、彩礼单。
