# 拉祜族婚俗

## 一、释义

拉祜族主要分布于云南普洱、临沧、西双版纳、红河等地。婚俗以**「串姑娘」对歌、「从妻居」与芦笙歌舞**为特色。

**核心要素**：
1. **「串姑娘」「对歌」**——青年男女夜晚对歌交友。
2. **「提亲」「订婚」**——托媒提亲，聘礼为酒、米、布、银饰。
3. **「从妻居」**（部分支系）——婚后男子先至女家居住数年，再携妻回夫家。
4. **「芦笙歌舞」**——婚礼以芦笙伴舞，通宵达旦。
5. **「叫魂」**——婚事中为新人「叫魂」祈福。
6. **基督教影响**——澜沧部分拉祜族信仰基督教，婚礼行教会仪式。

## 二、历史源流

- **唐宋至明清**：拉祜族先民（「倮黑」等称谓）婚俗见于史籍与方志。
- **近代**：基督教、南传佛教在不同地区传播，婚礼形态分化。
- **当代**：传统婚俗在澜沧、孟连等聚居区保存。

## 三、仪节流程

1. 串姑娘对歌交友。
2. 提亲、订婚。
3. 婚礼：芦笙歌舞、叫魂祈福。
4. 从妻居：男子先入女家居住。
5. 婚宴：村寨共贺。
6. 回夫家或长期从妻居。

## 四、地域与支系变体

- **拉祜纳（澜沧、孟连）**：与傣、佤族杂居，佛教与基督教影响并存。
- **拉祜西（澜沧、西盟）**：支系习俗较古朴。
- **苦聪人（金平、绿春等）**：原为拉祜族一支，习俗另有特点。
- **与其他民族关系**：拉祜族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（酒、米、布、银饰）、芦笙、竹编器具。
- **服饰**：拉祜族服饰（黑色为主的衣饰、银饰）。
- **文书**：聘礼单、婚约。
