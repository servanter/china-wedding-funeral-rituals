# 东乡族婚俗

## 一、释义

东乡族主要聚居于甘肃临夏（东乡族自治县等地）及新疆部分地区，信仰伊斯兰教，婚礼依**宗教规范**并含本民族特色。

**核心要素**：
1. **「提亲」「订婚（送定茶）」**——男方托媒提亲，送「定茶」（茶、糖、衣料）为定礼。
2. **「彩礼」**——议定聘礼（银钱、衣料、首饰），称「麦哈尔」。
3. **「念尼卡」**——婚礼请阿訇念「尼卡」证婚。
4. **「婚宴」**——设席待客（忌酒）。
5. **「认亲」**——新娘拜见公婆与长辈。
6. **「回门」**——婚后归宁。

## 二、历史源流

- **元明**：东乡族形成于甘肃河州地区，伊斯兰教（含门宦制度）在社区生活中居核心地位。
- **明清**：清真寺承担婚礼与婚礼文书事务。
- **当代**：仪轨沿袭，城乡均有清真寺参与婚礼。

## 三、仪节流程

1. 提亲。
2. 订婚（送定茶、议彩礼）。
3. 念尼卡：阿訇证婚。
4. 婚宴：设席待客。
5. 认亲：拜见公婆长辈。
6. 回门。

## 四、地域与支系变体

- **甘肃东乡族自治县**：集中聚居，仪轨规范。
- **临夏其他地区及兰州**：与回、保安、撒拉族杂居，习俗相类。
- **新疆东乡族**：与维吾尔、哈萨克族习俗相邻。
- **与其他民族关系**：同遵伊斯兰婚礼诸族细节有异，与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：定茶（茶、糖、衣料）、彩礼、婚宴用品。
- **宗教器物**：《古兰经》、清真寺、拱北。
- **文书**：彩礼单、婚约（结婚证）。
