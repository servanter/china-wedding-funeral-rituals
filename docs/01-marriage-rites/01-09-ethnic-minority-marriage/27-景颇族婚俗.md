# 景颇族婚俗

## 一、释义

景颇族主要聚居于云南德宏（芒市、盈江、陇川等）。婚配实行**「姑舅表婚」与族外婚**并存的原则，婚礼以**对歌、抢婚遗俗与集体歌舞**为特色。

**核心要素**：
1. **「串姑娘」对歌**——青年男女夜晚对歌交友。
2. **「提亲」「订婚」**——托媒提亲，聘礼以牛、猪、酒、布为主。
3. **「抢婚」遗俗**——部分地区婚礼有象征性「抢亲」（双方约定后举行）。
4. **「董萨占卜」**——请祭司「董萨」占卜定吉期。
5. **「目瑙」歌舞**——婚庆与「目瑙纵歌」等集体歌舞相联系。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋至明清**：景颇族先民（「寻传蛮」等）婚俗见于《蛮书》等史籍。
- **近代**：受傣族、汉族影响，婚俗有所融合；山官制度对婚事有规范作用。
- **当代**：传统婚俗在山区保存，「目瑙纵歌」列入非遗。

## 三、仪节流程

1. 串姑娘对歌交友。
2. 提亲、占卜择吉。
3. 订婚（议聘礼）。
4. 迎亲：象征性「抢亲」、对歌。
5. 婚礼：集体歌舞、宴客。
6. 回门。

## 四、地域与支系变体

- **德宏山区（陇川、盈江）**：传统婚俗保存较多。
- **坝区（芒市、瑞丽）**：与傣族杂居，习俗互渗。
- **与其他民族关系**：景颇族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（牛、猪、酒、布）、长刀、筒帕（织锦挎包）、乐器（象脚鼓、铓锣）。
- **服饰**：景颇族服饰（银泡、黑红织锦）。
- **文书**：聘礼单、婚约。
