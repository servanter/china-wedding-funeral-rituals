# 普米族婚俗

## 一、释义

普米族主要分布于云南宁蒗、兰坪、丽江、维西及四川木里、盐源等地。婚俗以**姑舅表优先婚、背新娘跨火塘与「苏里玛」酒礼**为特色。

**核心要素**：
1. **「姑舅表优先婚」**——舅家之子优先娶姑家之女，若不娶则须送「舅礼」补偿。
2. **「定亲酒礼」**——男家携酒、茶、猪膘肉至女家定亲。
3. **「背新娘」**——新娘由兄弟或舅舅背出家门上马，脚不沾地。
4. **「跨火塘、敬锅庄」**——新娘入夫家跨火塘、拜锅庄（家神），为婚礼核心。
5. **「苏里玛与猪膘肉」**——婚宴饮「苏里玛」（黄酒）、食猪膘肉。
6. **「走访婚遗存」**——宁蒗部分普米族与摩梭相邻，存走访式婚俗遗存。

## 二、历史源流

- **元明清**：普米族（「西番」「巴」）婚俗见于《元史》与滇西北地方志。
- **近代**：姑舅表婚、火塘崇拜等俗见于民族调查资料。
- **当代**：兰坪、宁蒗等地传统婚俗保存。

## 三、仪节流程

1. 说亲、合婚。
2. 定亲：送酒、茶、猪膘肉。
3. 迎亲：迎亲队赴女家对歌。
4. 背新娘上马，脚不沾地。
5. 跨火塘、拜锅庄。
6. 婚宴（苏里玛）、回门。

## 四、地域与支系变体

- **兰坪、维西**：普米族聚居区，婚俗保存较完整。
- **宁蒗（泸沽湖一带）**：与摩梭相邻，存走访婚遗存。
- **四川木里、盐源**：与藏、彝、纳西族杂居，婚俗交融。
- **与其他民族关系**：普米族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：酒礼（苏里玛）、猪膘肉、茶、马匹、火塘供器。
- **服饰**：普米族披羊皮褂、银饰、包头。
- **文书**：婚约、礼单。
