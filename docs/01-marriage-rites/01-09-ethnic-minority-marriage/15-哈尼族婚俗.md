# 哈尼族婚俗

## 一、释义

哈尼族主要分布于云南红河、普洱、玉溪、西双版纳等地。婚配沿**「寨内分宗」与族外婚**的原则，婚礼以**「抢婚」遗俗与对歌**为特色。

**核心要素**：
1. **「串姑娘」「对歌」**——青年男女以对歌交友（有的支系有「姑娘房」社交形式）。
2. **「提亲」「订婚」**——托媒提亲，送聘礼（米、酒、银饰、布）。
3. **「抢婚」遗俗**——部分支系婚礼有象征性「抢亲」（双方事先约定，以嬉闹相配合）。
4. **「祭寨门」「叫魂」**——婚事与村寨祭祀、叫魂仪式相关。
5. **「长街宴」待客**（部分支系）——村寨公共宴饮形式。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋**：哈尼族先民（「和蛮」等）婚俗见于史籍。
- **明清**：方志（临安府志等）载其婚俗；梯田稻作社会中的村寨礼俗稳定传承。
- **近代**：受傣族（南传佛教）、彝族习俗影响。
- **当代**：传统婚俗在红河、普洱乡村保存。

## 三、仪节流程

1. 对歌交友。
2. 提亲、合婚（占卜）。
3. 订婚：送聘礼、定婚期。
4. 迎亲：象征性「抢亲」、对歌、宴客。
5. 婚礼：拜见长辈、祭寨门、叫魂。
6. 回门。

## 四、地域与支系变体

- **红河（元阳、红河、绿春）**：哈尼族聚居核心区，习俗保存较完整。
- **普洱、玉溪（墨江、元江）**：与彝、傣族杂居。
- **西双版纳、澜沧**：受傣族南传佛教影响。
- **与其他民族关系**：哈尼族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：聘礼（米、酒、银饰、布）、竹编器具、梯田农具。
- **服饰**：哈尼族服饰（头饰、银饰）。
- **文书**：聘礼单、口传歌谣、婚约。
