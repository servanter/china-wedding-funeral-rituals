# 德昂族婚俗

## 一、释义

德昂族主要分布于云南德宏（芒市、瑞丽、陇川）及临沧镇康、耿马等地。婚俗以**「串姑娘」、南传佛教拴线与婚后「从妻居」**为特色。

**核心要素**：
1. **「串姑娘」**——青年男子夜至女家竹楼「串姑娘」、对歌。
2. **「以茶为礼」**——提亲、订婚送茶与烟草，「酸茶」为德昂族特色。
3. **「拴线祝福」**——受南传佛教影响，婚礼中由长者拴线祝福。
4. **「从妻居」**——婚后男方到女家居住（「上门」若干年）旧俗。
5. **「礼佛与泼水」**——婚礼前后礼佛，「泼水节」为择偶节点。
6. **「酸茶与槟榔待客」**——婚宴以酸茶、槟榔待客。

## 二、历史源流

- **明清**：德昂族（旧称「崩龙」）婚俗散见《滇略》与滇西方志。
- **近代**：「串姑娘」「从妻居」等俗见于民族调查资料。
- **当代**：芒市三台山等地传统婚俗保存。

## 三、仪节流程

1. 串姑娘、对歌。
2. 提亲、送茶订亲。
3. 订婚、议彩礼。
4. 迎亲、拴线祝福。
5. 从妻居（上门）。
6. 婚宴、礼佛。

## 四、地域与支系变体

- **芒市三台山**：德昂族聚居区，婚俗保存较完整。
- **临沧镇康、耿马**：与傣、佤族杂居，婚俗交融。
- **与其他民族关系**：德昂族婚俗与汉族「六礼」不同源，须分别记录。

## 五、器物与文书

- **器物**：酸茶、槟榔、烟草、供佛器物。
- **服饰**：德昂族筒裙、银饰、包头。
- **文书**：婚约、礼单。
