# 纳西族婚俗

## 一、释义

纳西族主要聚居于云南丽江及迪庆、四川凉山等地。婚俗兼有**东巴教（东巴主持、诵经）与汉礼（六礼遗意）**，泸沽湖地区摩梭人另有「走访制」特点。

**核心要素**：
1. **「提亲」「订婚」**——托媒提亲，送聘礼（茶、酒、米、银饰）。
2. **「东巴诵经」**——婚事中请东巴祭司诵经祈福、祭告祖先。
3. **「迎娶」「拜堂」**——花轿迎娶，拜天地、拜祖先。
4. **「祭天」相关**——纳西族「祭天」大典与婚配、祭祖观念相关。
5. **摩梭人「走访制」（阿注／阿夏）**——泸沽湖地区历史上行「男不娶、女不嫁」的走访婚形态，不属汉族婚制。
6. **「回门」**——归宁省亲。

## 二、历史源流

- **唐宋**：纳西族先民（「麽些」）见于史籍，东巴教在唐宋间形成。
- **明清**：木氏土司时期东巴文化兴盛；清代改土归流后，汉文化影响加深，婚制趋同汉礼。
- **当代**：婚俗在东巴文化保护中留存；摩梭走访制成为民族学关注对象。

## 三、仪节流程

1. 提亲、合婚。
2. 订婚：送聘礼、定婚期。
3. 东巴诵经祈福。
4. 迎娶：花轿迎娶、拜堂、宴客。
5. 祭天祭祖：告于祖先。
6. 回门。

## 四、地域与支系变体

- **丽江坝区**：汉礼因素明显，东巴仪式并行。
- **迪庆（三坝、香格里拉）**：东巴文化保存较多。
- **四川（盐源、木里）**：与彝、藏族相邻，习俗互渗。
- **泸沽湖畔摩梭人**：走访制与母系家庭背景下的婚俗形态。
- **与其他民族关系**：纳西族婚俗与汉族「六礼」有交融但基础不同，须分别记录。

## 五、器物与文书

- **宗教器物**：东巴法器、东巴经、《神路图》（丧仪用，婚仪亦有东巴祈福）。
- **器物**：聘礼（茶、酒、米、银饰）、花轿。
- **文书**：庚帖、聘礼单、婚约。
