# 嫡庶、继室与侧室称谓

## 一、释义

传统婚姻制度中的身份称谓，与**宗法继承**直接相关。

| 称谓 | 含义 |
| --- | --- |
| **正室（嫡妻、元配、发妻）** | 正式聘娶的妻子 |
| **继室（继配、填房、续弦）** | 元配亡故后再娶之妻 |
| **侧室（妾、如夫人、姨娘）** | 非正妻的配偶 |
| **平妻（兼祧婚中的双妻）** | 特定历史情形（如兼祧兼娶） |
| **嫡子** | 正妻所生之子 |
| **庶子** | 妾所生之子 |
| **嫡母／庶母（生母）** | 嫡子对正妻称嫡母，对生己之妾称庶母（「生母」） |
| **外室（外妇）** | 未入家门的非正式配偶 |

**礼制意义**：嫡庶之别直接影响**宗祧继承、服制（如「庶子为父后」之服）与家族地位**，是宗法制度的核心范畴。

## 二、历史源流

- **先秦**：宗法制度确立「嫡长继承」，嫡庶称谓在礼经与史籍中已成体系。
- **汉唐**：律令对嫡庶地位有明确规定；「兼祧」「平妻」等特殊情形见于案例。
- **明清**：律例（《大明律》《大清律例》）详定妻妾名分与嫡庶继承。
- **近代**：1931 年《民法·亲属编》确立一夫一妻制，妾制在法律上被废止。
- **当代**：法律上仅有一夫一妻，嫡庶称谓成为历史语汇（文学与族谱中可见）。

## 三、仪节流程

1. **议婚与聘娶**：正妻须行六礼；纳妾多不行六礼。
2. **婚礼行礼**：正妻行「拜堂」「合卺」；妾多仅行「拜见」之礼。
3. **见舅姑**：新妇拜见公婆，确立媳妇身份。
4. **入族谱**：正妻入谱称「娶某氏」；妾多记「侧室某氏」或不入谱。
5. **祭祀与服制**：嫡庶在服制与祭祀权上有别（如「为人后者」之服）。

## 四、地域与民族变体

- **汉族地区**：嫡庶之别在宗族社会（闽粤、徽州）最为严格。
- **少数民族**：部分民族历史上有一夫多妻或一妻多夫形态，其称谓与制度各异，不属汉族嫡庶体系，须分别记录。

## 五、器物与文书

- **文献依据**：《尔雅·释亲》《称谓录》《大明律》《大清律例》。
