# 媒人（月老、红娘、冰人）

## 一、释义

媒人的称谓极为丰富，分**雅称**与**俗称**两类，各有出处与用法。

| 称谓 | 出处／来源 | 用法 |
| --- | --- | --- |
| **媒／媒人／媒妁** | 《诗经》《周礼》「媒氏」 | 通称 |
| **月老／月下老人** | 唐·李复言《续玄怪录》「定婚店」 | 雅称，谓姻缘前定 |
| **红娘** | 元·王实甫《西厢记》 | 雅称，尤指热心撮合者 |
| **冰人** | 《晋书·索紞传》「冰上为阳，冰下为阴」 | 文言雅称 |
| **伐柯人** | 《诗经·豳风·伐柯》「伐柯如何？匪斧不克」 | 雅称 |
| **掌判** | 《周礼》「媒氏掌万民之判」 | 文言称谓 |
| **介绍人／牵线人** | 近代通称 | 俗称 |
| **媒婆／媒公** | 俗称 | 多含戏谑或贬义色彩 |
| **大妗姐** | 岭南地区 | 婚礼中随行协助的女性 |

**职能**：「通两姓之好」——说合、传庚帖、议聘礼、定婚期、随行礼。

## 二、历史源流

- **周代**：《周礼》设「媒氏」之官；《诗经》「娶妻如之何？必告父母……匪媒不得」，反映媒的必要性。
- **晋唐**：「冰人」「月老」之典出现。
- **宋元**：媒人职业化，「媒婆」之称见于话本杂剧（《西厢记》「红娘」）。
- **明清**：媒人有「官媒」「私媒」之别，方志多载「媒妁」。
- **当代**：「介绍人」「红娘」「婚介机构」并行；网络交友兴起后出现「线上媒人」。

## 三、仪节流程

1. **提亲**：媒人向双方传递议婚意愿。
2. **传庚帖**：往来传递生辰八字。
3. **议聘**：居间商议聘礼多寡。
4. **定婚期**：居中协请期。
5. **随礼**：婚礼当日居中协助，受谢媒之礼。

## 四、地域与民族变体

- **华北**：称「媒人」，谢媒以蹄髈、酒肉。
- **江南**：称「媒人」「月老」，有「媒人十八只蹄髈」之谚。
- **闽台**：「媒人婆」，婚礼中有「媒人礼」。
- **广东**：「大妗姐」为婚礼随行女性，兼具媒与礼之职。
- **少数民族**：有的民族由村寨长者、舅父充当婚介（「媒公」），称谓与职能有别，须分别记录。

## 五、器物与文书

- **文书**：庚帖、婚书（媒人署名）、礼单。
- **器物**：媒人礼（酒肉、糕饼、红包）。
- **文献依据**：《周礼·地官·媒氏》《称谓录》。
