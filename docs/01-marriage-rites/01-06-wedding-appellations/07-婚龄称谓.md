# 婚龄称谓（及笄、弱冠、待字、出阁）

## 一、释义

| 称谓 | 年龄／阶段 | 出处与含义 |
| --- | --- | --- |
| **总角／垂髫** | 幼年 | 儿童发式 |
| **豆蔻** | 十三四岁少女 | 唐·杜牧诗「豆蔻梢头二月初」 |
| **及笄** | 女子十五岁（**笄礼**） | 《礼记·内则》「十有五年而笄」，表示可嫁 |
| **待字（待字闺中）** | 已及笄而未婚 | 「字」谓许嫁 |
| **弱冠** | 男子二十岁（**冠礼**） | 《礼记·曲礼》「二十曰弱，冠」 |
| **出阁** | 女子出嫁 | 「阁」指闺阁 |
| **于归** | 女子出嫁 | 《诗经》「之子于归，宜其室家」 |
| **结发** | 初婚 | 汉魏以降，「结发为夫妻」 |
| **花甲／古稀** | 老年 | 与婚龄无关，但用于寿婚称谓（如「花甲重谐」） |

**礼制依据**：男子二十行冠礼、女子十五行笄礼，表示成人可婚。「男三十而娶，女二十而嫁」（《周礼》）为理想婚龄，实际历代婚龄偏低。

## 二、历史源流

- **先秦**：《礼记》定冠、笄之礼与婚龄观念。
- **汉唐**：早婚普遍（男子十五六、女子十三四成婚者多）。
- **宋明清**：礼法主张「及时婚嫁」，但实际婚龄因地区与阶层而异。
- **近代**：法定婚龄逐步提高；1950 年《婚姻法》规定男二十、女十八。
- **当代**：《民法典》规定男二十二、女二十；晚婚成为趋势。

## 三、仪节流程

1. **笄礼（女十五）**：束发加笄，改童装为成人装。
2. **冠礼（男二十）**：加冠命字，标志成人。
3. **议婚**：及笄、弱冠后进入议婚阶段（「待字闺中」）。
4. **许嫁**：纳征后「字」（许配）。
5. **出阁（于归）**：出嫁成礼。

## 四、地域与民族变体

- **汉族地区**：冠礼、笄礼在明清民间多已简化，仅存「上头」「梳髻」等遗俗。
- **闽台**：婚礼前有「上头」（为新人梳头）之俗，与笄礼遗意相关。
- **少数民族**：各民族成年礼（如瑶族「度戒」、苗族「成年礼」、藏族「戴头」）与婚龄观念相关，须分别记录。

## 五、器物与文书

- **器物**：笄（簪）、冠、礼服。
- **文书**：婚书（载男女年龄）、庚帖。
- **文献依据**：《礼记·内则》《礼记·曲礼》《周礼》。
