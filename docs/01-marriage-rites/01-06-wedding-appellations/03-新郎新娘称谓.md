# 新郎与新娘称谓源流

## 一、释义

| 称谓 | 时代／来源 | 说明 |
| --- | --- | --- |
| **新郎／新娘** | 唐宋以降 | 「郎」「娘」为对青年男女的美称，「新」指婚时 |
| **新人** | 唐宋 | 婚礼当日对新婚夫妇的统称 |
| **新妇** | 汉魏以降 | 初指新嫁娘，后亦用为对妻子、儿媳的称呼 |
| **官人** | 唐宋 | 妻对夫的称呼（「官人」有尊称意） |
| **娘子** | 唐宋 | 夫对妻的称呼；后泛用 |
| **良人** | 先秦 | 《诗经》「今夕何夕，见此良人」 |
| **外子／内子** | 文言 | 夫称外子，妻称内子 |
| **拙荆／贱内** | 文言谦称 | 夫对他人称己妻 |
| **夫君／相公** | 明清 | 妻对夫的称呼 |
| **阿娜／达令** | 当代 | 外来语影响下的昵称 |

**称谓的礼制含义**：「官人」「娘子」的对称，体现传统夫妻间的**尊卑与敬爱并存**；「外子／内子」则体现**内外分职**的家庭秩序。

## 二、历史源流

- **先秦**：「良人」「昏（婚）礼」之称见于《诗经》《仪礼》。
- **汉魏六朝**：「新妇」通用；「郎君」「娘」渐作称呼。
- **唐宋**：「新郎」「新娘」「官人」「娘子」定型并普及。
- **明清**：「相公」「娘子」并用；近代「先生」「太太」「爱人」出现。
- **当代**：「老公」「老婆」「先生」「太太」「爱人」「伴侣」并用。

## 三、仪节流程

1. **订婚后**：称「未婚夫」「未婚妻」。
2. **婚礼当日**：称「新郎」「新娘」「新人」。
3. **改口礼**：新人互称及对双方长辈改口。
4. **婚后**：视场合选用敬称（对外）、昵称（对内）。
5. **生育后**：多转为「孩子他爹／他妈」式称呼。

## 四、地域与民族变体

- **华北**：「当家的」「媳妇」「婆姨」（部分西北）。
- **江南**：「先生」「娘子」「屋里人」。
- **闽台**：「牵手」（夫妻互称，最具地方特色）。
- **广东**：「老公」「老婆」「太太」通用。
- **少数民族**：各族夫妻称谓各异（如「阿夏」「阿注」等），须分别记录。

## 五、器物与文书

- **文书**：婚书、喜帖中以「乾造」「坤造」称男女双方。
- **文献依据**：《尔雅·释亲》《释名》《称谓录》。
