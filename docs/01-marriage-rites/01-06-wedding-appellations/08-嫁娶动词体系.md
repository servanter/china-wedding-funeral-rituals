# 嫁娶动词体系（娶、嫁、适、归、赘）

## 一、释义

表示婚姻缔结的动词群，带有**方向、尊卑与宗法意味**。

| 动词 | 用法 | 说明 |
| --- | --- | --- |
| **娶** | 男家娶妇 | 「取」义，男家主动 |
| **嫁** | 女家嫁女 | 「往」义，女子适人 |
| **适（適）** | 女子出嫁 | 《尔雅》「女子子适人」 |
| **归（于归）** | 女子出嫁 | 《诗经》「之子于归」；「归」谓归夫家 |
| **赘（入赘）** | 男子入女家成婚 | 又称「上门」「招赘」「倒插门」 |
| **招（招婿）** | 女家招婿 | 「招赘」「招郎」 |
| **聘（聘娶）** | 以下聘礼订婚 | 「聘则为妻」 |
| **纳／纳妾** | 收纳侧室 | 「买妾」之别 |
| **字** | 女子许嫁 | 「待字闺中」 |
| **再醮／改嫁** | 寡妇再嫁（古称） | 「醮」为古代婚礼饮酒之礼 |
| **续弦／填房** | 男子再娶 | 文言俗称 |

**语义差别**：「娶」「嫁」标示**男家为主动、女家为被动**的单向婚姻形态；「赘」「招」则标示与此相反的例外形态，故在传统语境中含贬义（「赘婿」地位低）。

## 二、历史源流

- **先秦**：《尔雅·释亲》《仪礼·丧服》系统使用「适」「嫁」「归」等词。
- **汉魏**：《释名·释亲属》以音义解「嫁」，谓「女及人曰嫁」。
- **唐宋以降**：「娶」「嫁」为通称；「入赘」「招婿」之俗见于律令与方志。
- **明清**：律例对赘婿、招婿的财产继承有规定。
- **当代**：「结婚」「成家」为通称；「入赘」之说渐淡，「两家婚」「两头婚」等新形态出现。

## 三、仪节流程

1. **聘**：男家下聘订婚。
2. **字**：女家许嫁。
3. **嫁／娶**：婚礼当日女家「嫁女」、男家「娶妇」。
4. **于归**：新妇入夫家。
5. **赘／招（例外）**：男子入女家，改姓或不改姓，视约定与族规。

## 四、地域与民族变体

- **汉族地区**：「娶」「嫁」为通称；招赘在南方山区（如浙南、闽北）相对常见。
- **江南**：「入赘」称「上门女婿」，礼仪简化。
- **少数民族**：部分民族行「从妻居」（如傣族、部分彝族支系），婚姻方向与汉族相反，须分别记录。

## 五、器物与文书

- **文书**：婚书（多用「娶」「适」等词）、入赘契约（赘婚文书）。
- **文献依据**：《尔雅·释亲》《释名》《称谓录》。
