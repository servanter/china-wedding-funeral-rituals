# 妯娌、连襟、姑嫂、翁婿

## 一、释义

| 称谓 | 关系 | 说明 |
| --- | --- | --- |
| **妯娌** | 兄弟之妻之间 | 「妯」「娌」为兄弟妻的互称 |
| **连襟（连袂、襟兄弟）** | 姐妹之夫之间 | 「襟」谓衣襟相连；北方称「一担挑」「连襟」 |
| **姑嫂** | 夫之姐妹与媳妇之间 | 「姑」指夫之姊妹（「大姑子」「小姑子」） |
| **翁婿（岳婿）** | 岳父与女婿 | 「翁」指岳父 |
| **叔嫂、兄嫂** | 夫之兄弟与媳妇 | 「大伯子」「小叔子」 |
| **姗（姊夫与弟妻）** | 古称 | 现代少用 |
| **舅嫂** | 妻之兄弟之妻 | 通称「舅嫂」「大舅子」「小舅子」 |
| **姨表、姑表** | 姻亲衍生的表亲 | 「姑表亲」「姨表亲」 |

**礼制意义**：姻亲平辈称谓标示「**同辈协作**」的义务（如妯娌共理家务、连襟互帮），与宗族内部的秩序互补。

## 二、历史源流

- **先秦**：《尔雅·释亲》以「娣妇」「姒妇」称妯娌（兄妻曰姒、弟妻曰娣）。
- **汉魏**：《释名》释「娣姒」之义。
- **唐宋以降**：「妯娌」「连襟」渐成通称。
- **明清**：《称谓录》详列各地异称（如「一担挑」「连襟」）。
- **当代**：农村仍用「妯娌」「连襟」；城市多以「嫂子」「姐夫」泛称。

## 三、仪节流程

1. **婚礼当日**：新人拜见夫家、娘家的平辈姻亲，确立称谓。
2. **认亲**：逐户拜访，互赠礼物。
3. **日常往来**：妯娌共理家务，连襟协作互助。
4. **节令聚会**：逢年节共聚，称谓固定。
5. **分家后**：妯娌关系转向「各立门户」的往来。

## 四、地域与民族变体

- **华北**：连襟称「一担挑」「连襟」。
- **江南**：妯娌称「叔伯姆」「妯娌」，连襟称「连襟」。
- **闽台**：妯娌称「同姒」，连襟称「同门」。
- **广东**：连襟称「连襟」「老襟」。
- **少数民族**：姻亲平辈称谓与本族制度相应（如有的民族有「姑舅表优先婚」，称谓与婚配规则绑定），须分别记录。
