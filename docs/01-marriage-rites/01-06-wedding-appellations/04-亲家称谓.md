# 亲家、亲家公、亲家母

## 一、释义

「**亲家**」是**姻亲双方家长之间的互称**，是婚姻缔结在称谓上的直接体现。

| 称谓 | 指称 | 说明 |
| --- | --- | --- |
| **亲家／亲家公** | 对方父亲 | 互称 |
| **亲家母／亲家婆** | 对方母亲 | 互称 |
| **岳父／岳母（丈人／丈母娘）** | 妻之父母 | 女婿之称 |
| **公公／婆婆（公婆）** | 夫之父母 | 媳妇之称 |
| **舅姑** | 夫之父母（古称） | 古礼用语（「妇见舅姑」） |
| **外舅／外姑** | 妻之父母（古称） | 文言 |
| **泰山／泰水** | 岳父／岳母 | 文言雅称（「泰山」典出唐·段成式《酉阳杂俎》） |

**称谓的相对性**：同一对象因说话人身份不同而有不同称呼——**婆家看媳妇、娘家看女婿**，故称谓同时标示「立场」。

## 二、历史源流

- **先秦**：《尔雅·释亲》「妻之父为外舅，妻之母为外姑」；「舅姑」指夫之父母。
- **唐宋**：「泰山」之雅称为岳父（唐代典故）。
- **明清**：「亲家」「亲家公」「亲家母」成为通称；《称谓录》详列。
- **当代**：婚礼「改口」后，双方家长互称「亲家」，新人称对方父母为「爸、妈」。

## 三、仪节流程

1. **议婚期**：双方以「尊亲家」相称。
2. **订婚后**：正式以「亲家」相称并互致问候。
3. **婚礼当日**：新人行「改口礼」，称对方父母「爸、妈」。
4. **婚后往来**：逢节令「走亲」，称谓常在。
5. **生育后**：升格为「外公／外婆」「爷爷／奶奶」。

## 四、地域与民族变体

- **华北**：「亲家」「亲家母」，女婿称「丈人」「丈母娘」。
- **江南**：「亲家」「丈人」「岳母」并用。
- **闽台**：称「亲家」「丈人爸」「丈母娘」；媳妇称公婆「大家」「大官」。
- **广东**：「外父」「外母」（岳父母），媳妇称「家公」「家婆」。
- **少数民族**：各族姻亲长辈称谓与亲属制度相应，须分别记录。
